## 실행 증거

실행 결과와 배포 경로는 [빌드 안내](../BUILD-NOTES.md)의 차수별 기록과 `build/checks/`(`status.txt`, `unittest.log`, `gui.log`)를 기준으로 한다. `run_checks.cmd`는 실패 단계에서 중단하며, 현재 실행에서 생성되지 않은 EXE를 성공 결과로 사용하지 않는다.
