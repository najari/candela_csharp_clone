## T4 인계 범위

T3를 통과하면 Attribute 개요 → Compact View → Compare → 상태 그래프 → 번역 표 순으로 진행한다. 각 기능은 독립 완료 기준으로 기록한다.

- Attribute 개요: 객체·경로·키·타입·값 표시. 일괄 변경을 지원할 경우 읽기 전용과 공유 영향 표시, 하나의 명령으로 Undo를 보장한다.
- Compact View: 두 변형을 선택하고 원본·참조·독립 객체를 구분한다. 이름이 같다는 이유로 공유라고 판단하지 않는다.
- Compare: 먼저 같은 프로젝트의 두 변형 비교를 대상으로 범위를 명시한다. 추가·삭제·속성 차이와 참조 차이를 구분하며 비교만으로 DB를 변경하지 않는다. 다른 문서 비교는 별도 완료 항목으로 관리한다.
- 상태 그래프: 실제 그룹·상태·전이·서비스 근거로 생성한다. 실행 가능 조건과 전이를 혼동하지 않는다. 읽기 전용 시각화부터 구현한다.
- 번역 표: 객체·필드별 로캘 값을 표시한다. 실제 저장된 번역과 fallback을 구분하며 변경은 기존 명령·트랜잭션·Undo를 거친다.

작업별 모델·추론 강도는 [AGENTS.md](../AGENTS.md)에 따른다. 구현·테스트·빌드는 GPT-6 Sol / medium, 검토·난제는 GPT-6 Astra / high다.
