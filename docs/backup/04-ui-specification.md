# 화면·상호작용 명세

[목차](README.md) · [시나리오](03-user-scenarios.md)

## 공통 레이아웃

QMainWindow 중앙에 QSplitter를 사용한다. 좌측 탐색 트리, 가운데 위 QTableView 목록, 그 아래 선택 객체 창(데이터 배치·세부 표·속성 탭), 하단 검증·작업 Dock을 배치한다. 목록과 선택 객체 창은 세로 분할이다(23차, 그전에는 우측 속성 패널). MVP는 Qt Widgets를 사용하며 QML·WebView·상용 리본 라이브러리에 의존하지 않는다.

최소 작업 해상도는 1280×720을 목표로 한다. 고해상도 배율 100/150/200%에서 필드와 대화상자 버튼이 잘리지 않아야 한다. 패널 크기는 사용자 설정이며 프로젝트 파일에 넣지 않는다.

| UI-03 | ECU: 이름, qualifier, 설명, 제조사, 지원 프로파일 | ID·입력 버전·해시는 읽기 전용; 변경은 하나의 명령 |
| UI-04 | 변형: 이름, qualifier, 기본 여부, 기준 변형, 공유 객체 수, 잠금 | 기본 표시 직접 수정 금지; 생성/분리/사용처 보기; 삭제 영향 확인 |

| UI-06 | 타입: encoding, bit length, byte order, array length, conversion, factor, offset, unit | 사용처 보기와 복사; 원시/물리 미리보기; 잘못된 조합은 적용 금지 |
| UI-07 | 서비스: SID, subfunction, routine ID, 요청/응답, NRC, 상태 조건 | 프로파일 헤더는 읽기 전용; payload 순서 편집; 바이트·비트 시각화 |

| UI-10 | 검증: severity, rule, 객체 경로, 원인, 수정 안내, 차단 여부, revision | 행 선택으로 필드 이동; 오래된 결과 배지; 오류/경고 필터 |
| UI-11 | 출력: 변형, 언어, 범위, 의존 객체 수, 출력 경로, 사전 검사, 결과 | 차단 사유 해소 전 실행 금지; 완료 후 보고서 열기 |
| UI-12 | 복구: 원본 경로, 작업 시각, 저장 시각, 무결성, 원본 변경 여부 | 복구/나중에/명시 폐기; 원본 변경 시 별도 저장 기본 |

## 표와 속성 편집 계약

- 표는 QAbstractTableModel, 트리는 QAbstractItemModel을 사용한다. 셀마다 위젯을 만들지 않는다.
- 셀 편집은 Enter/포커스 이동으로 유효성을 검사하고 명령을 제출한다. Esc는 아직 제출하지 않은 편집을 취소한다.
- 복합 속성 대화상자는 적용/취소 단위를 가진다. 여러 필드가 한 명령으로 반영된다.
- 행 선택은 object ID, 열은 고정 column key로 보존한다. 필터·정렬 후 행 번호를 객체 ID처럼 사용하지 않는다.
- 숫자 열은 내부 숫자 기준 정렬하고 표시만 16진수로 할 수 있다. 텍스트 검색은 이름·qualifier의 NFC 정규화+casefold 검색 키를 사용한다.
- Ctrl+C는 보이는 선택 셀을 TSV로 복사한다. 붙여넣기는 행·열 매핑 미리보기와 동일한 사전 검사를 거친다.
- F2 편집, Ctrl+S 저장, Ctrl+Shift+S 다른 이름 저장, Ctrl+Z/Y Undo/Redo, Ctrl+F 검색, F5 검증을 제공한다.
- Delete는 즉시 행을 없애지 않고 삭제 영향 계산을 요청한다. 편집 불가능한 경우 확인창 전에 사유를 표시한다.

## 공유·미지원·오류 상태

공유 수가 2 이상이면 '공유 2개 변형' 배지를 표시한다. 수정 진입 시 '공유 객체 전체 수정'과 '현재 변형에서만 수정'을 선택한다. 초기 선택은 현재 변형만이다. 분리 복사 대상과 영향을 받는 객체 목록을 보여준다.

미지원 노드는 이름·원본 경로·이유·출력 영향을 보여주는 읽기 전용 뷰다. 원본 XML은 명시적인 상세 보기에서만 텍스트로 표시하며 스크립트나 첨부물을 실행하지 않는다.

필드 오류는 색상과 텍스트를 함께 사용한다. 저장 가능한 초안 오류와 저장 불가능한 DB 무결성 오류를 구분한다. ODX 차단 경고는 심각도가 warning이어도 '출력 차단' 배지를 표시한다.

## 진행·저장·닫기

작업 상태는 대기→실행→취소 요청→완료/취소/실패로 표시한다. 500ms 이상 작업은 진행 표시를 제공하며 취소 요청 즉시 버튼을 비활성화한다. 이미 원자적 교체 단계에 들어간 저장은 취소할 수 없음을 해당 단계에서 설명한다.

저장 중에는 읽기·탐색은 유지하고 수정 명령만 잠시 대기시킨다. 저장 실패는 원인·경로·재시도를 제공하며 창을 닫지 않는다. 닫기 선택은 저장/저장하지 않음/취소다. 읽기 전용 문서는 변경 기능을 비활성화한다.

선택한 객체가 작업 결과로 삭제되면 부모 또는 다음 객체로 이동하고 변경 이유를 표시한다. 검증 이동으로 필터를 해제했을 때는 원래 필터로 돌아가는 버튼을 제공한다.

## CANdelaStudio 13 화면 대비 보완 (22차 구현, GUI 스모크 전)

[화면 검토](ui-candela13-screen-review-2026-09-26.md)의 U2~U6을 다음처럼 구현했다. GUI 스모크를 통과하기 전이므로 인수 기준으로 쓰기 전에 [빌드 안내](../BUILD-NOTES.md) 22차의 한계를 확인한다.

- **선택 객체 창**(22차에는 목록 오른쪽, 23차부터 목록 아래): 탭 3개. `데이터 배치`는 멤버 표(바이트, 비트, 이름, 데이터 타입, 기본값, 상수, 설명)와 바이트 × Bit7..Bit0 격자이고, 전체 / 멤버 표만 / 격자만을 고른다. `세부 표`는 마스터·디테일의 디테일(상태 그룹의 상태, 변형의 식별 패턴)이다. `속성`은 기존 텍스트다. 선택한 객체에 맞는 탭이 앞에 온다.
- **페이지 머리**: 목록 위에 장 소개 문장, 클래스 설명 또는 인스턴스 요약을 보인다. 고장 메모리 인스턴스에는 `고장 메모리 레코드` 버튼(DtcStatusMask, DTC 표, 스냅샷, 확장 데이터 읽기 전용 탭)이 있다.
- **진단 인스턴스 페이지(UI-07 보완)**: 템플릿이 정한 서비스를 모두 행으로 보인다. 열은 사용, 역할, 프로토콜 서비스, 요청·긍정·부정 패턴(`2E F1 90 zz` / `6E F1 90` / `7F 2E rc`)이다. 쓰지 않는 템플릿 서비스와 보존 원문 서비스는 회색 읽기 전용 행이다. 서비스를 고르면 데이터 배치 탭에 요청·긍정 응답·`NR (rc)` 탭이 나온다.
- **트리 중간 노드**: 지원 인터페이스(통신 파라미터), 식별 특징·식별 패턴, 지원 진단 클래스, 상태 그룹·의존성·기본 상태 전이, 미지원 서비스 NRC. 보존 원문에서 온 표는 읽기 전용이다.
- **공유 객체 편집**: 여러 변형이 쓰는 DID·서비스를 편집하면 `이 변형에서 사본으로 바꾼 뒤 수정`(기본) / `참조하는 모든 변형 수정`을 고른다. 서비스는 진단 인스턴스 단위로 사본을 만든다.
- **표**: 끝에 새 항목 행을 두고, 누르면 추가 대화상자를 연다(읽기 전용 목록 제외). DTC 코드는 0x 16진(기본) 또는 SAE 문자형으로 보인다. 의존성은 서비스별(여러 행 선택 후 F2 일괄 변경) 또는 클래스별 묶음으로 보인다.
- **속성 대화상자**: 데이터 타입은 일반·변환·예외값·열거값·Packet 구조·속성 탭이다. `◀ 이전` / `다음 ▶`으로 목록의 이웃 객체로 넘어간다. 사용 중인 타입은 길이에 영향을 주는 필드를 잠그고 이유를 보인다.
- **작업 기록**: 시각·종류·내용 표, 종류(오류/경고/정보)·내용 필터. Rework 목록(완료, 내용, 연결 경로)은 프로젝트 메뉴에 있다.

## CANdelaStudio 13 도움말 대비 상호작용 (제안, 미구현)

[도움말 대비 검토](../ui-manual-review-2026-09-26.md)는 셀 편집(F2·Tab), 여러 행 입력·값 복사, 필터·찾기·출력 창 링크, 대화상자 공통 규칙 등 29개 항목(M1~M6)을 제안하고, 화면은 [목업](../ui-manual-review-2026-09-26.html)으로 보인다. 위 "표와 속성 편집 계약"의 셀 편집은 아직 구현되지 않았고(지금 F2는 편집 대화상자) M1-1·M3-3에서 맞춘다. 검토의 결정 D1~D7이 정해지면 이 명세에 반영한다.
