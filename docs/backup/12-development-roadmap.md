## 산정 기준

1인 개발·AI 지원·주당 30시간 기준의 초기 추정이다. 24주=720시간이며, 호환성 대응 여유 최대 6주=180시간을 별도로 둔다. AI 지원을 이유로 미확인 형식·표준 검증 공수를 0으로 잡지 않는다. 아래 기간은 이번 문서 작성에 실제 사용한 시간이 아니다.

현재 완료 대상은 문서 세트다. 아래 앱 구현 작업은 후속 개발 계획이며 아직 실행 결과가 없다.

## 우선순위와 일정 변경

지원할 CDD/OEM 범위가 늘면 형식별 corpus·검증·변환 공수를 추가한다. 기존 단계의 테스트를 삭제해 범위를 늘리지 않는다. 일정이 초과하면 P1/P2를 연기하고 P0의 데이터 무손실·복구·지원 범위 표시는 유지한다.

Rust는 720시간에 포함하지 않는다. 성능이 충족되면 TASK-19를 실행하지 않는다. 도입 시 빌드/배포/호출 비용까지 산정하고 Python 대조 구현을 보존한다.

## 후속 로드맵

P1 순서: 고급 데이터 구조 → Snapshot/Extended Data 및 추가 UDS → 비교와 PDX → XLSX·HTML 출력. 각 기능은 실제 입력 자료와 출력 검증 방법을 먼저 확보한다.

P2: CDD/CDDT 쓰기·템플릿 편집, AUTOSAR DEXT, 요구사항 동기화, 다국어 번역·TMX, 외부 도구 연계. 양방향 CDD는 별도 호환 프로젝트로 다루며 현재 reader의 존재만으로 쓰기 가능을 가정하지 않는다.
