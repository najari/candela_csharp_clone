이 화면의 검토 항목

M6-3데이터 타입 바꾸기

타입의 사용처 목록에서 행을 골라 다른 타입으로 한 번에 바꿉니다. 원본 보존 항목이나 비트필드를 넘는 길이처럼 바꿀 수 없는 행은 충돌 열에 이유를 보이고 고를 수 없습니다. 길이가 바뀌어 뒤 멤버 위치가 움직이는 것은 영향 열에 보입니다. 지금은 독립 복사 뒤 사용처를 하나씩 고칩니다.

근거: Replace Data Type dialog · Replace Data Type feature(D001·D002)
