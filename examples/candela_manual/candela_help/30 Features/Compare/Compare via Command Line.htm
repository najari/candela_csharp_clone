Compare via Command Line

Compare View allows to export the computed difference to a file [CMP-R131-DiffExport].

CANdelaStudio even provides this export via command line, without opening the user interface and Compare View.

Command Line Parameters

[CMP-R135-CompareCommandLine] Command line parameters as defined in chapter Command Line have a specialized meaning in the Compare Export case:

Option Meaning in Use Case 'Diff Export' Definition in chapter Command Line
/i 'Left' file for comparison. [CLI-R100-importFile]
/r 'Right' file for comparison. [CLI-R100-referenceFile]
/o Exported diffs. [CLI-R100-output]
/e Output format, e.g. "textdiff" [CLI-R100-DataExchange]
/g Optional: Log File. [CLI-R100-logfile]
/u Optional: Defines the language the documents are compared in, e.g. 'en-US' (for comparing multi-language documents).
If not specified, the first completely translated language (in both languages) is used, if these do not match, an error is thrown.
Best practise: Always set this parameter in automated diff exports (e.g. per batch file). Otherwise, adding new fully translated languages might change diff export behavior behind the scene!		 [CLI-R100-documentLanguage]
/l Optional: this parameter defines the language of the User Interface the export is started with. In the 'Diff Export' use case this controls in which language headings are exported, e.g.:

In the left panel, -l "de-DE" was used, in the right -l "en-US".		 [CLI-R100-language]
/q Optional: quiet mode. [CLI-R100-quiet]

Example

CANdelaStudio.exe -i "D:\test\source.cdd" -o "D:\test\diff_output.txt" -r "D:\test\target.cdd" -g "D:\test\out.log" -e "textdiff"
