[EDOP-R100] Creating a new Extended Data Record

  • with given Extended Data Record Number and Protocol
  • If this is the first Extended Data Record for a Protocol, CANdelaStudio creates Extended Data Data for the Protocol [SR-R200], with...
    • empty DID lists
    • no Specific Extended Data Data
  • Depends on authorization "Primary properties modifiable" [DIA-R040-Extended DataData], see also [DIOP-D010]

[EDOP-R110] Deleting one or multiple Extended Data Records:

  • If the operation deletes the last Extended Data Record for a Protocol, CANdelaStudio deletes all Extended Data Data for the Protocol [SR-R200].
  • Depends on authorization "Primary properties modifiable" [DIA-R040-Extended DataData], see also [DIOP-D010]

[EDOP-R120] Modifying Extended Data Record Name / Qualifier

  • Depends on authorization "Primary properties modifiable" [DIA-R040-Extended DataData], see also [DIOP-D010]

[EDOP-R130] Modifying further Extended Data Record Properties

  • Properties:
    • Description
    • Trigger, customTrigger
    • Updated
    • Attributes
  • Depends on authorization "Secondary properties modifiable" [DIA-R050], see also [DIOP-D010]

Extended Data Record Stored for DTC

[EDOP-R260] Check "Stored"

  • Sets "Extended Data Record Stored for DTC" [EDR-R300] to true for the given DTC and Extended Data Record
  • Depends on authorization "Primary properties modifiable" [DIA-R040-ExtendedData], see also [DIOP-D010]

[EDOP-R265] Un-check "Stored"

  • Same as previous operation, but setting to false.
