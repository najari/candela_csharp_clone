Export (PVCDI)

[EPV-R100] Export to a PVCDI file

[EPV-R110] Option: the variant or library to export.

[EPV-R120] When you export a document to PREEvision for the first time, ...

  • CANdelaStudio displays a message, that this is the first export to PREEvision,
  • and that CANdelaStudio now prepares the CDD for data exchanges with PREEvision.
  • This requires the document to be saved.
  • Then CANdelaStudio sets the document property [DOC-R420] and saves the document.
