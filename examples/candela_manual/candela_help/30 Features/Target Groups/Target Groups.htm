Target Groups (Audience) (CDS-1226)

You can describe for which target groups he considers a diagnostic instance or service to be interesting for (or being too much detailed). This set of target groups is the "audience" of the diagnostic instance or service.

Typical target groups: Supplier, Development, Manufacturing, After-sales.

For various exports, you can select the audience: which diagnostic instances and services should be put into the exported file, and which are filtered, i.e. not exported.

Administration as well as an overview of target groups are available in ribbon tab Documents.

Target groups

In the document template, a collection of target groups is predefined and not changeable in standard mode. In expert mode, it may be changed in a template and even in a document. The collection must not be empty. At most 16 target groups are supported.

Each target group consists of a name and description (multi-language).

The sequence of target Groups should be user-defined. It seems to be appropriate to sort the target Groups in a process-chronological order.

Audience for which Objects

  • Diagnostic instance (to entirely hide data objects, e. g. base configuration for any supplier), see Target Groups at a Diagnostic Instance.
  • Service (to hide the fact that data objects can be written, not only read)

If not all target groups are set on a diagnostic instance, service or job container, a special icon indicates this state in the Tree view.

Relation to "Authorization"

Definition of target groups is possible in expert mode only.

Modification of audience is controlled by authorization.

Filtering Reduces Information

Audience works as a filter and allows to exclude information from an exported document. Consequently, you can effectively "remove" information from an exported document even if you do not have authorization to erase it from the CANdela document itself.
