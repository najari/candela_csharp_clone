Compact Report (CDS-1207)

Use Case

You want a complete textual presentation of a CANdela document without redundancy between data of multiple variants.

Specification

Compact mode is not activated if you specify only one variant for export (e.g. if the document contains just the base variant). In this case, the "Compact representation" option is ignored.

The content of all variants is merged into a single “Content” chapter.

No other chapter is affected (for the handling of the variant identification and history items see below).

Each sub-chapter represents a diagnostic class or singleton diagnostic instance (as in non-compact mode). The diagnostic class sub-chapter contains diagnostic instances.

As the title of a subchapter, the report uses the common name of all diagnostic instances combined in the subchapter. If the diagnostic instance occurs in more than one variant, the title includes number of variants like „(5)”.

Diagnostic class properties that are different in different variants are exported with a hint in which variants they occur.

The diagnostic instances are merged from all variants, with a hint in which variants the diagnostic instance occurs.

Only referenced diagnostic instances (the same object!) are merged by the compact mode. Diagnostic instances that have the same name but are not the same object are exported several times, numbered like “4 of 5”.

The title page contains a hint that the document is a compact one.

Variant identifications are printed in the variants overview chapter in compact mode.

The diagnostic instances are sorted in the order they occur in the base variant. Diagnostic instances from other variants are merged in by identifier (i.e. behind the last diagnostic instance with the same identifier or before the first diagnostic instance with the next identifier), then by order of first variant in which they occur.

Job Containers are also merged.

R950.0 (DIDs, CDS-37944 8.5): report the DIDs of a variant before the diagnostic instances, like diagnostic instances (i.e. list the variants in which the DID occurs).
