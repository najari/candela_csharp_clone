Special Attributes

Purpose

The list below is a central register of attributes used by CANdelaStudio and plug-ins.

Attributes not Described here

Some attributes may be missing below:

  • customer-specific functionality
  • ODX Import - see ODXImport Options.pdf (available in the CANdelaStudio documentation folder)
  • Attributes for AUTOSAR Diagnostic Extract export

Use of this List

  • The list below enumerates key properties of all attributes.
  • If there is a feature chapter that describes a given attribute,
    • then that chapter contains full details,
    • the list below just contains a link to that chapter.
  • ... otherwise the list below contains full details.
  • Other chapters have a link to the chapter which contains the full details.
