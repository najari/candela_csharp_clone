Attribute Authorization

Attribute Category

  • Visible: specifies whether the attribute category is displayed e.g. in a drop-down list that filters attributes in a property sheet. The setting does not have an effect on the visibility attributes - these have their own authorization.

Attribute

  • [ATTRA-R010 Visible in Standard view]: specifies whether the attribute is visible in Standard View.

  • [ATTRA-R020 Properties modifiable]: specifies whether the overriding values of the attribute may be modified in the Standard View.

  • [ATTRA-R030 Export to specification] (CDS-7777 5.5):
    • specifies whether the attribute is output in the specification report in the attributes chapter. Note: output of the entire chapter is controlled by an option [OPT-R540].
    • The setting does not apply to report output in the list of objects [ATTR-R090] (e.g. in the DTC list).
    • The setting does not apply to data oriented exports (e.g. ODX export).
