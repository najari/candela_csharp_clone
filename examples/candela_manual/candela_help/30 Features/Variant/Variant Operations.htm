Variant Operations

Create

[VAR-R100 Create from Other Variant in Document] (Variant Wizard)

  • [VAR-R100-DI] Create copies of or references to diagnostic instances
    • as specified in the wizard;
    • ensure consistency conditions for new diagnostic instances [DI-R010]
  • [VAR-R100-Attributes Copy Variant Attributes] when creating the new variant, CANdelaStudio optionally copies all attributes from the other variant to the new variant.

Modify Variant Qualifier

  • [RQ-R093-SelVariantRename] reset the variant selected for requirements and diagnostic objects.

Lock Variant

  • see Lock Variant.

Unlock Variant

  • see Lock Variant.

Copy/Paste

Within a Document

[VAR-R700 CopyNPaste IntraCdd] Pasting a variant to the same document:

  • [DID-R260] take over all DIDs from the other variant as a reference
  • ensure consistency conditions for new diagnostic instances [DI-R010]

Across Documents

[VAR-R705 CopyNPaste InterCdd] Pasting a variant to a different document:

  • [DID-R262] take over all DIDs from the other variant including referenced data types.
  • ensure consistency conditions for new diagnostic instances [DI-R010]

Delete

[VAR-R750 Delete Variant] Delete a variant:

  • [DID-R265] delete all DIDs contained in the variant.
  • [RQ-R093-SelVariantDelete] reset the variant selected for requirements and diagnostic objects.
