Base Variant (Common Diagnostics)

The Base Variant or "Common diagnostics" is...

  • the single variant in a document template
  • the first variant in a CANdela document

The name of the base variant is defined in the template.

Purpose of the Base Variant

You can use the Base Variant as a...

  • minimal initial version,
  • common subset or
  • superset

... of diagnostic functionality for all variants.

CANdelaStudio leaves the policy up to the user.

Effect on other Variants

  • If you insert a diagnostic class or diagnostic instance in the base variant, CANdelaStudio prompts to automatically insert the new object into all extended variants.
  • The same applies if you delete a diagnostic class or diagnostic instance from the base variant.

Reference as Common Diagnostics

You can replace the common diagnostics at any time by an extended variant. To do this, in the context menu of the extended variant, select the command Reference as Common Diagnostics. The extended variant replaces the existing common diagnostics. The existing common diagnostics is irretrievably deleted!
