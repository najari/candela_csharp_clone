Attribute Existence

[ASR-D010] Attributes Exist :=

  • all attributes of [ASR-D001] exist...
    • at the respective object type
    • with the specified qualifier.
  • no further details (type of attribute, default, restrictions...) shall be considered.

    • attributes with that qualifier must exist (instead of attributes with qualifier "RequirementsId")

  • "DiagnosticConnectionPriority" see [ASR-D001_DiagnosticProtocolPriority] above

Attribute Details

[ASR-D030] ASR SWC ServiceDependency Ref

  • The attribute value contains an AUTOSAR instance reference to a service dependency within the SYS-EX.
  • See [ASR-D050] below for mapping an SWC with a DTC or with an Event.
  • At a data object, the attribute holds info about a Client/Server DID port (CDS-72028 v13).

The instance reference is coded using the following syntax:

Value ::=
  "RCR:"<value of ROOT-CONTEXT-REF><blank>
  [
    "CSCPR:"<value of CONTEXT-SW-COMPONENT-PROTOTYPE-REF>[,<value of CONTEXT-SW-COMPONENT-PROTOTYPE-REF>]*<blank>
  | ["CSCPR:"<value of CONTEXT-SW-COMPONENT-PROTOTYPE-REF><blank>]*
  ]
  "TSSDR:"<value of TARGET-SWC-SERVICE-DEPENDENCY-REF>

Example (single blank replaced by a line-break for readability):

RCR:/SYSTEM/Systems/RootSoftwareComposition
CSCPR:/SwComponentTypes/COP/ECU_Composition/KBiCSCPR:/SwComponentTypes/COP/KB/SWC_DIAG_A6
TSSDR:/SwComponentTypes/COP/SWC_DIAG_A6/XDIS_curfy7xyg/SD_S_DRS_RoutineName1

Note:

  • A <blank> is required before and behind the entire CSCPR: list, but not within.
  • A reference may contain alphanumeric characters, underscore '_', slash '/' and comma ',' but not ':'
  • Therefore in the example above, the substring KBiCSCPR: is not ambiguous, since the keyword CSCPR: cannot be part of the preceding reference.

ServiceDependency Ref at DTC vs. Event

[ASR-D050] Mapping an SWC with a DTC or with an Event

  • AUTOSAR maps a SWC with an Event
  • CANdelaStudio before v12 supported DTCs only
  • CANdelaStudio since v12 supports Events
  • SWC Sync [SWC-R0420]:
    • ... sets the attribute value for Routine Diagnostic Instances and DTCs
      • in the table above: [ASR-D001_ASR_SWC_DIServiceDependency_Ref] and [ASR-D001_ASR_SWC_DTCServiceDependency_Ref];
    • it does not use Events.
  • PREEvision data exchange:
    • If the CANdela document Supports Events [EV-R010],
    • PREEvision data exchange sets/reads the attribute value [ASR-D001_ASR_SWC_EvServiceDependency_Ref] at Events;
    • otherwise, it does not set/read a corresponding info at DTCs.
  • DEXT Export evaluates the attribute value [DEXT-R710]...
    • if the CANdela document Supports Events [EV-R010]:
      • at Events,
      • otherwise at DTCs.
  • [ASR-D050-Combination] Therefore, you can use Event Combination [EV-R230-Combination] with PREEvision data exchange and DEXT Export.
  • See also Events in the Vector Toolchain.

[ASR-D040] ASR SWC DataElement Ref

  • SWC Sync sets it for data objects in DIDs
    • in the table above: [ASR-D001_ASR_SWC_DODataElement_Ref]
  • The attribute value contains an AUTOSAR instance reference to a data element within the SYS-EX.
  • AUTOSAR Diagnostic Extract export evaluates it [DEXT-R710].

The instance reference is coded in the following syntax:

Value ::=
  "CRCR:"<value of CONTEXT-ROOT-COMPOSITION-REF><blank>
  ["CCR:"<value of CONTEXT-COMPONENT-REF>]*<blank>
  "CPR:"<value of CONTEXT-PORT-REF><blank>
  "TDPR:"<value of TARGET-DATA-PROTOTYPE-REF>

(note the <blank> outside the repetition)

Example (line-breaks inserted for readability):

CRCR:/SYSTEM/Systems/RootSoftwareComposition
CCR:/SwComponentTypes/COP/ECU_Composition/KBi
CCR:/SwComponentTypes/COP/KB/SWC_Diag_A6
CPR:/SwComponentTypes/COP/SWC_Diag_A6/P_DiagDisplayables
TDPR:/PortInterfaces/COP/IP_diagnostic_disps_SWC_A6/DiagDisplayable1

Obsoleted Attributes

[ASR-D090] Obsoleted attributes (former [DOCUI-D500])

Effect of Obsoleting Attributes

  • A new version of CANdelaStudio may obsolete one of the attributes described above.
  • Checking the GUI checkbox [DOCUI-R500] in the new CANdelaStudio version will no more create the attribute,
  • but older CANdelaStudio versions will show the checkbox as unchecked,
  • and will create the attribute when you check the checkbox.

List of Obsoleted Attributes

  • obsoleted in CANdelaStudio 11:
    • [ASR-D090-Max] attribute [ASR-D001_MaxAttemptsToLock] (CDS-70966).
    • also removed from the Vector UDS Template 2.4.0 [VUDS-R910-MaxAttemptsToLock]
  • obsoleted in CANdelaStudio 12:
    • [ASR-D090-Data] at Diagnostic Instance and DTC: ASR SWC DataElement Ref (ASR_SWC_DataElement_Ref)
    • SWC Sync does not fill the attribute
    • DEXT Export does not use the attribute
    • So far the checkbox [DOCUI-R500] still creates it (CDS-71413).
