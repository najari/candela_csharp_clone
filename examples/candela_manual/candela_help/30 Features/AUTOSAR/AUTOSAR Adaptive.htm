AUTOSAR Adaptive

Besides the established AUTOSAR Classic Platform, in 2016 the AUTOSAR development partnership started work on the Adaptive Platform. The first release was 17-03.

The Adaptive Platform targets at high-performance computing applications like autonomous driving. It dynamically links services and clients during runtime and provides service-oriented communication. This enables dynamic reloading of software components, the use of standard libraries – such as for image analysis–, self-learning of functions and an accelerated production cycle.

Expected use: Adaptive will be used for few specific ECUs, not the mass market.

AUTOSAR Adaptive in CANdelaStudio

[ARA-R100] CANdelaStudio 13 supports export to DEXT for AUTOSAR Adaptive (2020-02, CDS-712943).

Restrictions

The CANdelaStudio dialogs...

  • do not use specific terms from AUTOSAR Adaptive ("Software cluster"...)
  • but just continue using terms from AUTOSAR Classic ("ECU"...).
  • Adaptive supports multiple software clusters for an ECU
    • Vector daVinci does not support this (as of 2020-01).

Versioning

  • AUTOSAR Adaptive releases 2x per year
    • ... whereas AUTOSAR Classic releases 1x per year
    • One of the Adaptive releases is together with AUTOSAR Classic.
  • The version numbering is like "19-11" (year-month), for both Classic and Adaptive.
    • There is no "AUTOSAR 4.5"!
    • The internal schema version is like "v00049".

SWC Sync

  • Schedule:
    • no Adaptive SWC-Sync in v13
  • Intended use of AUTOSAR Adaptive:
    • describe AUTOSAR Adaptive in PREEvision
    • complete the diagnostics in CANdelaStudio.
