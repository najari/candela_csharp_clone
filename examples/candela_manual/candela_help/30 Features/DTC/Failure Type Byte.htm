Failure Type Byte (FTB)

ISO 15031-6 / SAE J2012 defines a list of failure type bytes. The list contains 1 byte values for typical failure situations, like

  • 8: Bus Signal / Message Failures
  • 17: circuit short to ground
  • 24: circuit current below threshold

The list helps to unify the DTC values.

FTB in CANdela

You can setup a template [DOC-R400] to take Byte 0 (LSB) of a 3 byte DTC from a list:

[DTC-R500] The FTB is taken from a text table in the data type list.

Each text table entry associates a 1 byte value with a translatable text.

Editing

This setup enables editing of DTCs [DTCUI-R030] using

  • two bytes DTC (free input)
  • error text (free input)
  • 1 byte Failure Type Byte (selecting from list)

CANdelaStudio automatically shows the text associated with the FTB as a suffix of the error text.
