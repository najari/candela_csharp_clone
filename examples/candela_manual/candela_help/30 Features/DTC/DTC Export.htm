DTC Export

CANdelaStudio provides an export of DTCs, started in the DTC lists.

Export Example with SPN FMI in Excel

Using Excel

For export of DTCs to Excel, CANdelaStudio uses an installed version of Excel.

CANdelaStudio reads the version of the installed Excel application from the following Windows registry key: HKEY_LOCAL_MACHINE\SOFTWARE\Classes\Excel.Application\CurVer.

Export of DTCs is available...

  • ... to .xls: if Excel 2000 (registry Excel.Application.10) or higher is installed
  • ... to .xlsx: if Excel 2007 (registry Excel.Application.12) or higher is installed;

"or higher" means:

  • (for CANdelaStudio up to 8.2 SP2) up to Excel 2010 (registry Excel.Application.14);
  • (for CANdelaStudio 8.2 SP3 and higher): no limit for newer Excel versions (CDS-34805).

Export Formats

  • [DTCE-R050] Regular export: includes translated names of diagnostic objects.
  • [DTCE-R060] Language independent export: specifics see below.

Exported Rows

The export includes

  • [DTCE-R100] a first row with headings (see next chapter)
  • [DTCE-R110] one row per DTC, with values (see next but one chapter).

Heading Row

[DTCE-R120] In the regular (not language-independent) export, the heading row contains...

  • [DTCE-R120-DTC] "DTC" (for the code)
  • [DTCE-R120-ErrorText] "DTCText" (for the error text)
  • [DTCE-R120-FTB] "Failure Type" and "DTCTypeText" if the document uses columns for Failure Type Byte (FTB) [DTC-R028]
  • [DTCE-R120-FMI] "SPN", "FMI" and "DTCTypeText" if the document uses columns for Failure Mode Identifier (FMI) [DTC-R028]
  • [DTCE-R120-ColumnHeading] for a DTC Column: the name
  • [DTCE-R120-AttributeHeading] for an attribute: the name
  • [DTCE-R120-VSGHeading]: the constant string "Vehicle System Groups"

Value Rows: Exported Columns

The export includes columns for...

  • [DTCE-R210] DTC Code [DTC-R025]
  • [DTCE-R220] DTC Error Text [DTC-R030]
  • [DTCE-R230] if the document uses columns for Failure Type Byte (FTB) or Failure Mode Identifier (FMI) [DTC-R028]:
    • [DTCE-R230-Byte] the separate byte value (column behind "DTC")
    • [DTCE-R230-String] its string representation (column behind "DTCText")
  • [DTCE-R240] the DTC Columns [DTC-R040]
  • [DTCE-R250] the DTC attributes [ATTR-R050-DTC]
    • [DTCE-R250-All] export includes all attributes, independent of
      • the flag “visible in separate table column” [ATTR-R090]
      • the authorization “view” [ATTR-R080 Authorization]
    • [DTCE-R250-Effective] for each attribute, export writes the "effective" value, i.e....
      • the overridden value [ATTR-R140] (if set),
      • otherwise the default value [ATTR-R040].
  • [DTCE-R260] the associated Vehicle System Groups [VSG-R100-DTC]
    • [DTCE-R260-Format] export writes all associated Vehicle System Groups in one cell, separated by ", " (comma blank).
    • [DTCE-R260-Name] for each Vehicle System Group, export writes the name (in regular export).

Language Independent Export (CDS-28395 8.0 SP2)

The language independent export helps to avoid roundtrip issues in case different users open a document in different languages [OPEN-R420].

Heading Row

The heading row for the language independent export differs from that of the regular export described above.

[DTCE-R420] The heading row contains...

  • [DTCE-R420-ColumnHeading]: the qualifier of a DTC Column
  • [DTCE-R420-AttributeHeading]: the qualifier of the attribute
  • [DTCE-R420-VSGHeading]: "Vehicle System Groups", same as [DTCE-R120-VSGHeading] above.

Value Rows: Exported Columns

Some values in the language independent export differ from those of the regular export described above.

The export includes the specific values...

  • [DTCE-R440] for a DTC Column:
    • [DTCE-R440-EnumColumnValue] for an enumeration DTC column [DTCC-R010-Enum],
      • the numeric value [DTCC-R010-Enum] for the multi-language symbol.
    • [DTCE-R440-TranslatableColumnValue] for a translatable DTC column [DTCC-R010-Translatable],
      • the TextID (if set),
      • otherwise the translatable string.
  • [DTCE-R450] for an attribute:
    • [DTCE-R450-EnumAttributeValue] for an enumeration attribute [ATTR-R020-enum],
      • the numeric value for the multi-language symbol.
  • [DTCE-R460] for Vehicle System Groups:
    • [DTCE-R640-Qual] for each Vehicle System Group, export writes the qualifier.
