Group of DTC (CDS-448)

Some services reading/clearing DTCs let you specify groups of DTCs to be used in a request, e.g. UDS 0x14 "Clear Diagnostic Information".

Optionally, the request may contain a concrete individual DTC instead of a group.

Typical groups are: powertrain, chassis, body, network communication, emission related systems.

A group is a numeric value that specifies a range of DTCs, e.g. Chassis group value 0x400000 for the range 0x400000 .. 0x7FFFFF.

Special numeric values denote e.g. "All groups" 0xFFFFFF.

See also the Group of DTC user interface.

Group of DTC in CANdela

Group of DTC Data Model

In the template, ...

  • a text table data type defines which groups are supported by the ECU.
    • The data type is shown in the data type list.
  • a Group of DTC Proxy Component references the data type
    • ... in all Protocol Service components that represent a group of DTCs.

In a diagnostic instance, Group of DTC is represented by a special data object. It...

  • is typically used...
    • in a Fault Memory diagnostic instance
    • in Control DTC Setting (UDS 0x85)
  • corresponds with the Group of DTC Proxy Component (see above)

Supported Groups

  • the Group of DTC Data Object contains a "local" text table that describes the supported groups;
    • the set of text table entries is a subset of the entries of the "master" text table referenced at the Proxy Component
    • the text table entries are copies of the master text table entries
    • each group not supported is missing in the local text table
  • For a DTC group that is declared to be supported, CANdelaStudio does not check whether the DTC list actually contains a DTC in that range.

Supports Individual DTCs

  • the Group of DTC Data Object contains a flag indicating whether it supports individual DTCs
  • the possible values of the data object on the line are...
    • the "group" text table entries
    • plus (if "supports individual DTCs" is true) all individual DTCs defined in the DTC list in the diagnostic instance.
