DTC Authorization

Authorization settings for a DTC can be specified in the DTC Pool in Expert View.

Overview

The following overview shows depending on the DTC Authorization whether a DTC...

  • may be missing ("-")
  • may exist as a copy
  • must exist as a reference ("ref")

... in the DTC list of the respective Error Code Table [ECT-R001] in Fault Memory:

Fault Memory DTC not required DTC required DTC required as reference
in Variant
- Primary / WWH-OBD - / copy / ref copy / ref ref
- except: User Defined Fault Memory only [UDFM-D105] - / copy - / copy - / copy
- OBDII - / copy / ref copy / ref ref
in Library - / copy / ref - / copy / ref - / copy / ref

Note: there is no Pool for User Defined Fault Memory [DTCP-R003].

May Be Modified

[DTC-R010] May Be Modified

  • default true

[DTC-D210-mayBeModified] The DTC "may be modified" authorization...

  • can be set in the DTC Pool and
  • applies to the “DTC instance”, i.e. to the DTC in all places where it is referenced (like for diagnostic instances).
  • As a consequence, if authorization allows deletion of a DTC, and you delete and re-create the DTC, modification is possible for the new DTC by default.

[DTCA-R030-mayBeModified]: In standard view, CANdelaStudio shall forbid modification and deletion of DTCs with “mayBeModified”=false (CDS-13824 R031).

Note: this property does not extend to snapshot or extended data, which are not considered properties of the DTC per se.

Required in all Variants

[DTC-R012 Required in all Variants]:

  • [DTC-R012-No] “no”
    • the DTC is not required,
    • the DTC can be deleted in Standard View.
  • [DTC-R012-Yes] “yes” (= “required”)
    • the DTC is required: a DTC with the given numeric code must exist in all variants (as a reference or as a copy).
    • All these DTC instances must have required="yes".
    • Use this setting to ensure the code exists, but allow modification of other DTC properties.
    • You cannot delete such a DTC in Standard View.
    • You may replace a reference by a copy, or vice versa.
    • See also the common rules above.
  • [DTC-R012-ReqAsRef] “as reference” (= “required as reference”)
    • the DTC is required: the DTC from the DTC Pool must be referenced in all variants.
    • You cannot replace the reference to such a DTC by a copy of the DTC.
    • Use this setting to ensure the DTC exists exactly with the properties defined in Expert view.
    • See also the common rules in the next chapter.
  • [DTC-R012-Default] default: “no”,
  • can be set in the DTC Pool

Note: the document level authorization [DLA-R100-PoolOnly] does not enforce “as reference” in the data model.

Common Rules

[DTCA-R020.0 Semantics]:

  • [DTCA-R020-reqDel] The Fault Memory diagnostic instance as a whole may be missing.
    • This does not violate the DTC authorization.
  • [DTCA-R020-reqCodeText] For a DTC with required “yes” or “as reference”, in Standard View, you cannot modify the DTC code and error text.

In Library

  • [DTCA-R020-reqLIB] [DTCA-R020-reqAsRefLIB] The property has no effect on the use of the DTC in a Library, i.e. a library...
    • need not contain a DTC with the given code, or
    • may contain it as a copy.
    • See also Libraries in Document Context.
  • [DTCA-R020-LIB]: a DTC...
    • in a library
    • that is not referenced from the DTC Pool
    • shall have required = "No".

In User Defined Fault Memory

  • [DTCA-R020-UDFM]: a DTC...
    • in a DTC List for User Defined Fault Memory only [UDFM-D105]
    • is not affected by the "Required" property of a DTC in DTC Pool
    • must not be referenced from the DTC Pool [DTCP-R002-UDFM],
    • shall have required = "No".

Required "Yes"

  • [DTCA-R020-req Required "Yes"]:
    • the DTC is required: a DTC with the given numeric code must exist in all variants (as a reference or as a copy).
    • All these DTC instances must have required="yes".
    • Use this setting to ensure the code exists, but allow modification of other DTC properties.
    • You cannot delete such a DTC in Standard View.
    • You may replace a reference by a copy, or vice versa.
    • See also the common rules above.

Required "as Reference"

  • [DTCA-R020-reqAsRef "Required as reference"]:
    • the DTC is required: the DTC from the DTC Pool must be referenced in all variants.
    • You cannot replace the reference to such a DTC by a copy of the DTC.
    • Use this setting to ensure the DTC exists exactly with the properties defined in Expert view.
    • See also the common rules above.
