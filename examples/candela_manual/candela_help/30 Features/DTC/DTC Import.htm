DTC Import

This chapter describes the data formats for an import of DTCs from an Excel file (.xlsx, .csv).

For a description of the import wizard, see How to Import DTCs from Excel.

Selection of Worksheet

[DTCI-R100] The import wizard lets you select one of the worksheets in the Excel file.

Table Rows

DTCs in Excel Example

[DTCI-R120] DTC Import from Excel expects the following table structure:

  • Heading:
    • The top line of the Excel table must match the column headers of the CANdela DTC table.
    • When the document contains multiple languages, it is safe to use the qualifiers of the DTC table columns.
    • CANdelaStudio displays these qualifiers when you move the mouse pointer over the column header in the DTC table.
  • (Rows):
    • the following lines of the Excel table must contain the DTCs
    • import stops after a line that does not contain a DTC.

Table Columns

  • [DTCI-R150] DTC Number:
    • the first column(s) must represent the DTC number
    • see next chapter
  • [DTCI-R160] Error Text:
    • the following column(s) must contain the error text
    • see next chapter
  • [DTCI-R170] All further columns:
    • import copies column values to the CANdela document, if ...
    • ... the Excel column header matches the CANdela column header (i.e. matches the name in the displayed language, or the qualifier),
    • ... or you have manually assigned the columns in the import dialog.
    • for DTC columns of type enumeration [DTCC-R010-Enum], there are further restrictions, see below.
    • for a mandatory column [DTCC-R060-Required], ...
      • if the column is completely missing in the import file (i.e. the header does not exist),
      • then import fills the column with the default value [DTCC-R080] from the template;
    • otherwise, if the mandatory column exists in the import file, but its cell is empty in a DTC row,
      • then import wizard shows that DTC row in red color and skips the DTC.
      • Workaround, in order to avoid that import skips these DTCs: delete the entire column in the import file (assuming there are no DTCs where the column contains meaningful values in the import file).

DTC Number and Error Text

CANdelaStudio supports multiple conventions for the display of DTCs, controlled by the Display of DTCs document setting.

DTC Export writes the corresponding format. You can use DTC Export to create an example for the DTC list that can be imported:

Display of DTCs Sample exported DTC Number
ISO 14229-1 (Hex) 0x000992
ISO 15031-6 / SAE J2012 P0009, 0x92
SAE J1939-73 (Version 4) 264448, 18

[DTCI-R200] DTC Import accepts all formats, independent of the "Display of DTCs" setting in the target document!

Example: you can import...

  • an xlsx file containing SAE J1939-73 DTCs
  • into a document with "Display of DTCs" set to ISO 14229-1 (Hex).

The following subchapters describe the different formats in detail.

The procedure How to Convert Number Formats in Excel may be useful to prepare the data in Excel.

ISO 14229-1 (Hex)

[DTCI-R210] For ISO 14229-1 (Hex), the first column contains the DTC number, the second one contains the error text:

Column #1 #2
Property DTC error text
Column name (does not matter) (does not matter)
Notation hex or SAE string
Column Name in DTC Export DTC DTCText

Table example:

DTC Error Text Set Condition
C002011 ABS Pump Motor Control - Circuit short to ground Value < 0,2V...
C002012 ABS Pump Motor Control - Cicuit short to battery Value > 5V...

ISO 15031-6 / SAE J2012

[DTCI-R220] For ISO 15031-6 / SAE J2012, the first two columns must contain the root DTC and the FTB:

Column #1 #2 #3 #4
Property DTC FTB (numeric) Error text FTB text
Column name BaseDTC FTB DTCText DTCTypeText
Column name (alternatives) DTC Failure Type DTCText DTCTypeText
Notation hex or SAE hex or SAE string string
Column Name in DTC Export DTC Failure Type DTCText DTCTypeText

Note: import ignores column DTCTypeText because the information is already contained in the referenced FMI text table.

Table example:

DTC Failure Type DTCText DTCTypeText Set Condition
C0020 0x11 ABS Pump Motor Control - Circuit short to ground Circuit Voltage Above Threshold Value < 0,2V...
C0020 0x12 ABS Pump Motor Control - Cicuit short to battery Circuit Current Below Threshold Value > 5V...

SAE J1939-73 (Version 4)

[DTCI-R230] For SAE J1939-73 (Version 4), the first two columns must contain the SPN and the FMI:

Column #1 #2 #3 #4
Property SPN (dec) FMI (dec) Error text FMI text
Column name SPN FMI DTCText DTCTypeText
Notation decimal decimal string string
Column Name in DTC Export SPN FMI DTCText DTCTypeText

Note: as of v10, the import wizard shows the SPN and FMI values in hex notation only.

Table example:

SPN FMI DTCText DTCTypeText Set Condition
8256 17 ABS Pump Motor Control - Circuit short to ground Low – least severe (1) Value < 0,2V...
8256 18 ABS Pump Motor Control - Cicuit short to battery Low – moderate severity (2) Value > 5V...

DTC Number Notation

[DTCI-R300] For ISO 14229-1 (Hex) and ISO 15031-6 / SAE J2012, the DTC number can have hex or SAE notation:

Example Format Interpretation
0x402011 prefix "0x" hexadecimal DTC number
C002011 prefix "P", "B", "C" or "U" DTC number in SAE notation

DTC Column Type Enumeration

[DTCI-R310] For enumeration [DTCC-R010-Enum], the values in the import file may contain the ID or symbol:

Example Format Interpretation
Replace ECU string match against enum symbols (in current language)
0 number match against enum ID (numeric value)

Table example:

DTC Error Text Corrective Action
C002011 ABS Pump Motor Control - Circuit short to ground Replace ECU
C002012 ABS Pump Motor Control - Cicuit short to battery 0
