Failure Mode Identifier (FMI)

SAE J1939-73 Version 4 defines a list of failure mode identifiers. The list contains 5 bit values. The values describe failure of an electronic component or suspect signals that indicate abnormal operating conditions, like

  • 0: High - most severe (3)
  • 3: Voltage Above Normal
  • 9: Abnormal Update Rate
  • 21: Data Drifted Low

A 3 byte DTC consists of

  • 19 bit DTC Suspect Parameter Number (SPN)
  • 5 bit text Failure Mode Identifier (FMI)

The conversion of 19 bit SPN + 5 bit FMI to a 24 bit DTC value is defined in SAE J1939-73 Version 4.

Conversion:

3 Byte hex DTC (Part) SPN (Part) FMI Example value
most significant byte (closer to CAN identifier) lowest significant byte 10111000
middle byte middle byte 00000100
least significant byte, 3 most sig. bits highest significant byte, 3 bits 000
least significant byte, 5 least sig. bits whole FMI 00011
Example values
Binary 10111000 00000100 000 00011 000 00000100 10111000 00011
Decimal - 1208 3
Hexadecimal 0xB80403 0x4B8 0x3

Note about sort order in CANdelaStudio:

  • since the lowest significant byte of SPN corresponds with the most significant byte of a 3 byte hex DTC,
    • a DTC with a smaller 3 byte hex value may have a bigger SPN value
  • CANdelaStudio sorts DTCs ascending by 3 byte hex value (e.g. in the view for snapshot data),
    • therefore the SPN values are typically not sorted ascending:
3 byte DTC (hex) SPN (dec) FMI (dec)
0x00F0E2 520192 2
0x01E5E2 517377 2

FMI in CANdela

You can setup a template [DOC-R400] to take bits 0..4 of a 3 byte DTC from a list:

[DTC-R510] The FMI is taken from a text table in the data type list.

Each text table entry associates a 5 bit value with a translatable text.

Editing

This setup enables editing of DTCs [DTCUI-R040] using

  • 19 bit DTC (free input, decimal format)
  • error text (free input)
  • 5 bit Failure Mode Identifier (select from list)

CANdelaStudio automatically shows the text associated with the FMI as a suffix of the error text.
