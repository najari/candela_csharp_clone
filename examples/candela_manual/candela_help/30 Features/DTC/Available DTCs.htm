Available DTCs (DTC Pool) (CDS-13824 6.5)

Use-Case

Some car manufacturers centralize DTCs: instead of adding an ad hoc code and text in the description of an ECU, they maintain a centralized list. DTCs existing in that list must be reused as far as possible.

ODX 2.2 also allows references to DTCs (see chapter 7.3.6.8 “DTC data object property” of ISO 22901-1:2008).

DTC Pool

The DTC pool provide DTCs which can be used in the CANdela document by referencing.

It also provides import and export for DTCs.

A CANdela document may contain multiple “Error Code Tables” [ECT-R001], e.g. one for 16 bit (OBDII), one for 24 bit. Each one has an according DTC Pool.

  • the semantics of the Pool is to support authoring;
  • the DTC list and its DTCs in the pool are not considered part of the ECU
  • and are not expected to be exported in data oriented exports.

Data Model

[DTCP-R001.0 DTC Pool]: For each “Error Code Table” [ECT-R001],...

  • the ECU document contains a “Pool” of DTCs stored outside all variants.
  • [DTCP-R001-unique] The list cannot contain duplicate numeric codes.
  • The pool itself does not have attributes (contained individual DTCs have).

[DTCP-R002.0 DTC Referencing]: for each DTC in the Pool, it shall be possible to reference the DTC...

  • from each DTC list in the variants or libraries
  • of the respective Error Code Table [ECT-R001]
  • [DTCP-R002-UDFM] except from a DTC List for User-Defined Fault Memory only [UDFM-D105].
  • See the diagram for the DTC Data Object [DTC-R021].
  • Note: References are only allowed into the Pool, not between DTCs in variants.

[DTCP-R003]: there is no DTC Pool for User Defined Fault Memory in CANdela.

  • Motivation: we assume there is no use-case to centralize or prescribe DTCs for the special User Defined Fault Memory.

See also DTC Authorization.

Operations

See DTC Operations.

Migration

[DTCP-R022.0 Migration 6.0 to 6.5] After loading an older document into CANdelaStudio 6.5, the DTC Pools shall be empty (CDS-13824 R022).

[DTCP-R024.0 Migration 6.5 to 6.0] When saving a document to a version oder than 6.5, CANdelaStudio shall (CDS-13824 R022)...

  • drop the Pool;
  • in the variants, save all references into the pool as copies.
