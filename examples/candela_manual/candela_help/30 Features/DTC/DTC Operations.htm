DTC Operations

This chapter describes operations for DTCs in DTC Pool and in diagnostic instances.

[DTCOP-R010 Create DTC]: creates a new DTC.

  • It shall exist in the DTC List only (not referenced in other DTC lists).
  • It shall have required="No" [DTC-R012].

Not allowed outside the DTC Pool if...

  • [DTCOP-R010-PoolOnly] document authorization "Creation of DTCs" is „in Chapter "Available DTCs" only“ [DLA-R100-PoolOnly]
  • the Conditions for Modifying Operations within a Diagnostic Instance [DIOP-D010] do not permit

[DTCOP-R012 Modify DTC Code]: modify the DTC Code of the DTC.

Not allowed in Standard View if...

  • the DTC is "Required" or "Required as Reference" [DTCA-R020-reqCodeText] (even in DTC Pool), or
  • the DTC is referenced [DTCP-R002] (even in DTC Pool), or
  • the Conditions for Modifying Operations within a Diagnostic Instance [DIOP-D010] do not permit

[DTCOP-R013 Modify Error Text]: modify the Error Text of the DTC.

  • in the DTC Pool, if the DTC is "Required", modify the Error Text at copies of the DTC in all variants;

Not allowed in Standard View if...

  • the DTC is "Required" or "Required as Reference" [DTCA-R020-reqCodeText]
  • the Conditions for Modifying Operations within a Diagnostic Instance [DIOP-D010] do not permit

[DTCOP-R014-notReq Set "Required" to "No"]: [DTC-R012]

  • also set "Required" to "No" in copies of the DTC with the same code in variants.

Not allowed...

  • outside the DTC Pool, or
  • in Standard View

[DTCOP-R014-req Set "Required" to "Yes"]: [DTC-R012]

  • in all variants, process DTC copies that have the numeric code of the DTC:
    • not in a DTC List for User-Defined Fault Memory only [UDFM-D105]
    • ensure the DTC exists [DTCA-R020-req]
    • set "Required" to "Yes"

Not allowed...

  • outside the DTC Pool, or
  • in Standard View

[DTCOP-R014-reqAsRef Set "Required" to "Required as reference"]: [DTC-R012]

  • ensure the DTC is referenced [DTCP-R002] in all variants [DTCA-R020-reqAsRef]
    • [DTCP-R002-UDFM] but not in a DTC List for User-Defined Fault Memory only [UDFM-D105]

Not allowed...

  • outside the DTC Pool, or
  • in Standard View

[DTCOP-R016 Modify other DTC Property]

Not allowed if...

  • in Standard View if "Properties Modifiable" is false [DTCA-R030-mayBeModified]
  • the Conditions for Modifying Operations within a Diagnostic Instance [DIOP-D010] do not permit

[DTCP-R018 Delete DTC in DTC Pool]

  • Delete the DTC from the DTC List.
  • For all references [DTCP-R002] to the DTC in the document,
  • if "Creation of DTCs" is allowed in chapter "Available DTCs" only [DLA-R100-PoolOnly],
  • then CANdelaStudio shall...
    • [DTCP-R018-Delete] delete them (not replace by copy)
    • [DTCP-R018-Hint] emit a hint (info level) in logging
    • [EVOP-R240] Remove the association of Events with the DTC
  • else CANdelaStudio shall (after GUI confirmation)...
    • [DTCP-R018-Copy] replace all references to the DTC by a copy.
    • [EVOP-R235] Lets Events reference the DTC copy.

Not allowed if...

  • [DTCP-R018-RO] in Standard View, DTC "Properties Modifiable" is false [DTCA-R030-mayBeModified]

[DTCOP-R018 Delete DTC Outside DTC Pool]

  • delete the DTC from the DTC List.
  • [EVOP-R240] Remove the association of Events with the DTC

Not allowed if...

  • a DTC with the same code in the DTC Pool has "Required in all Variants"="yes" or "as reference" [DTC-R012], or
  • in Standard View, "Properties Modifiable" is false [DTCA-R030-mayBeModified]
  • the Conditions for Modifying Operations within a Diagnostic Instance [DIOP-D010] do not permit

[DTCOP-R020 Copy from Available DTCs] (DTC Pool)

  • inserts DTCs as a copy of DTCs in DTC Pool

Not allowed if...

  • in DTC Pool (obvious)
  • a DTC with the same code in the DTC Pool has "Required in all Variants"="as reference" [DTC-R012].
  • the Conditions for Modifying Operations within a Diagnostic Instance [DIOP-D010] do not permit

[DTCOP-R030 Reference from Available DTCs] (DTC Pool)

  • inserts DTCs as a reference to DTCs in DTC Pool

Not allowed if...

  • in DTC Pool (obvious), or
  • in User Defined Fault Memory (obvious) [DTCA-R020-UDFM]
  • the Conditions for Modifying Operations within a Diagnostic Instance [DIOP-D010] do not permit

[DTCOP-R035 Copy Value into Selected DTCs] (CDS-6149 5.0 SP1)

Copies the value of a user defined DTC column (not e.g. code or error text) from one DTC to a list of other DTCs.

Not allowed if...

  • the DTC column does not allow duplicates [DTCC-R050], or
  • in Standard View if "Properties Modifiable" of a target DTC is false [DTCA-R030-mayBeModified]
  • the Conditions for Modifying Operations within a Diagnostic Instance [DIOP-D010] do not permit

For the user interface see [DTCUI-R035].

[DTCOP-R040] Paste

  • Pastes DTCs from the clipboard (if it contains DTCs).
  • They shall have required="No" [DTC-R012].

Not allowed if...

  • the document level authorization is „in Chapter "Available DTCs" only“ [DLA-R100-PoolOnly], or
  • outside DTC Pool, if DTCs in the DTC Pool with the same codes have "Required in all Variants"="as Reference" [DTC-R012].
  • the Conditions for Modifying Operations within a Diagnostic Instance [DIOP-D010] do not permit

Note:

  • copying a DTC does not copy its snapshot data
    • CANdela does not consider them being "part" of the DTC
  • copying a DTC does not copy Events that reference the DTC
    • ... but copying an Event may copy the reference to a DTC,
    • see the Event operation [EVOP-R060]
    • ... and Procedure How to Copy Events and DTCs.

[DTCOP-R045 Paste Contents]

  • Pastes DTCs from the clipboard (if it contains DTCs),
  • They shall have required="No" [DTC-R012].
  • assigns a new DTC code for a code to paste that already exists in the list;
    • must not use codes of DTCs in the DTC Pool that have "Required in all Variants"="as Reference" [DTC-R012]

Not allowed if

  • the document level authorization is „in Chapter "Available DTCs" only“ [DLA-R100-PoolOnly]
  • the Conditions for Modifying Operations within a Diagnostic Instance [DIOP-D010] do not permit

[DTCOP-R048 Paste as Reference]

  • Pastes DTCs from the clipboard (if it contains DTCs copied from the DTC Pool)

Not allowed if...

  • in DTC Pool (obvious), or
  • in User Defined Fault Memory [DTCA-R020-UDFM]
  • the Conditions for Modifying Operations within a Diagnostic Instance [DIOP-D010] do not permit

[DTCOP-R050 Replace Reference with Copy]

  • removes the reference into DTC Pool, replaces it by a copy with the same properties
  • [EVOP-R235] for Events that referenced the DTC referenced from the DTC Pool: associates them with the copy
  • Note: used e.g. in...
    • Lock Variant [VAR-R015-d2]

Not allowed if...

  • in DTC Pool (obvious), or
  • in User Defined Fault Memory (obvious) [DTCA-R020-UDFM]
  • for a DTC that is not a reference into DTC Pool (obvious), or
  • if the DTC referenced in the DTC Pool has required="as reference" [DTCA-R020-reqAsRef].
  • the Conditions for Modifying Operations within a Diagnostic Instance [DIOP-D010] do not permit

[DTCOP-R060 Replace Copy with Reference]

  • removes the DTC, replaces it by a DTC reference into DTC Pool to a DTC with the same code.
  • [EVOP-R235] for Events that referenced the DTC: associates them with the DTC reference into DTC Pool

Not allowed if...

  • in DTC Pool, or
  • for a DTC that already is a reference into DTC Pool (obvious), or
  • in User Defined Fault Memory [DTCA-R020-UDFM]
  • the Conditions for Modifying Operations within a Diagnostic Instance [DIOP-D010] do not permit
