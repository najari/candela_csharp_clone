MDX DTC Columns

Feature since CANdelaStudio 6.0 (CDS-12925), extended in 6.5 by CDS-14019 (see D003), available for "Diagnostics Based on" (manufacturer) Ford.

D001: let the following attribute category exist in a template:

  • Qualifier “MDX_DTCRefs”
  • Usage “system”

Attributes assigned to this category are considered to store DTC specific data needed by MDX export (started via ribbon tab Data Exchange [MENU-R160]).

D002: if two default attributes with the same name and qualifier, both referencing the attribute category of D001, exist at the DaMe objects ECU and DTC, and an overridden attribute with the same name and qualifier exists at the ECU, then these attributes constitute a so-called (Pool, Subset) = (P, S) tuple:

  1. the default attribute and overridden attribute located at the ECU specify a pool P of values,
  2. whereas the attribute located at a DTC contains a subset S of the values stored in P.

Note: A migration moves the default attribute.defaultValue (as of < 6.5 SP 1) to the overridden attribute.value (as of >= 6.5 SP 1). No back migration is done.

D003: to support MDX specific DTC table columns, the template shall contain the following (P, S) tuples (pairs of non-translatable string attributes):

  1. Name = “Control Routine”, qualifier = “MDX_DTCCR”
  2. Name = “Monitoring Cycle”, qualifier = “MDX_DTCMC”
  3. Name = “Warning Indicators”, qualifier = “MDX_DTCWI”
  4. Name = Qualifier = "MDX_DTCID" (added with CDS-14019 in 6.5)

None of the attributes must be reported to specification, and none must be visible in Standard view.

D004: the attributes specified by D003 shall contain as value of the overridden attribute a list of strings separated by new-line characters. Depending on the qualifier of the attribute, the following value types shall be stored in the strings:

  1. MDX_DTCCR: routine (qualifier)
  2. MDX_DTCMC: value (e.g. hexadecimal “0x01”)
  3. MDX_DTCWI: value
  4. MDX_DTCID: inhibiting (hexadecimal) DTC values

D005: the description (in the first up-to-date language) of the P default attribute of a (P, S) tuple shall define the maximum allowed number “n” of routines or values that may be selected in an S attribute. The format of the definition is:

maxSelect=<number>

If this definition is not recognized in the description, maxSelect is assumed to be 1.

Semantics:

Each S attribute of a (P, S) tuple defines a column in the DTC table.

The pool P defines the available values for the column.
