Import of SUB-COMPONENTs

Each SUB-COMPONENT from ODX is imported as an individual VehicleSystemGroup in CANdelaStudio.

In ODX, the SHORT-NAMEs of SUB-COMPONENTs are unique inside the BASE-/ECU-VARIANT. This differs to CANdela, where all Vehicle Systems Groups are stored in one container - hence the names/qualifiers of the according vehicle system need to be globally unique (inside the CDD) by prefixing the corresponding DIAG-LAYER SHORT-NAME.

ODX SUB-COMPONENT CANdelaStudio VehicleSystemGroup
SEMANTIC Semantic
SUB-COMPONENT-PARAM-CONNECTOR Assigned Diagnostic Instances and Job Containers
