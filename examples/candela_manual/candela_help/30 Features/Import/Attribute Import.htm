Attribute Import (CDS-8613 5.5)

[ATTI-R010] Imports attribute values from a CSV file.

Motivation

Attributes are a generic data-driven way to extend the data model implemented in CANdelaStudio.

Some describe settings for code generation, or typically represent properties specific to the process of the manufacturer.

It may be useful to transport these settings from a CANdela document to a related other one.

How to Run the Import

  • [MENU-R255] Ribbon Tab Data Exchange | Import | Attributes
  • [ATTOV-R255] Attribute Overview, button "Import"

Attribute Import Wizard

The Attribute Import Wizard [AIUI-R010] prompts for import settings, then runs the import.

Import

[ATTI-R100] Import reads attribute values from the specified CSV file:

  • [ATTI-R110] using the separator specified in the wizard [AIUI-R110],
  • [ATTI-R200] optionally restricting affected attributes by the category specified in the wizard [AIUI-R200].

[ATTI-R120] Import reports the result in the Output Window as an Info message, like

Import of attribute values finished, 6 attribute value(s) changed.

[ATTI-D100] The import...

  • does not create new attributes,
  • it just reads attribute values for attributes already defined in the CANdela document.

CSV File

Import consumes the format written by the Attribute Export, see [ATTE-R300].
