SWC Sync Data Objects

Extraction of SYS-EX Data Objects

(for Stored Data Records, Present Value Records or Control State Records)

A SYS-EX Data Object is an instance reference to a data element, with the following conditions:

  • The parent SWC type belongs to the ECU-INSTANCE.
  • The SWC type includes a SWC-SERVICE-DEPENDENCY with a ROLE-BASED-DATA-ASSIGNMENT pointing to a VARIABLE-DATA-PROTOTYPE.
  • Note: SWC Sync does not check the role name (typically “signalBasedDiagnostics”).
  • The SWC-SERVICE-DEPENDENCY contains a DIAGNOSTIC-VALUE-NEEDS.

SWC Sync interpretes the SYS-EX Data Object as follows:

  • Data Object of a Control State Record:
    • Condition: the DIAGNOSTIC-VALUE-NEEDS is referenced as CURRENT-VALUE-REF by a DIAGNOSTIC-IO-CONTROL-NEEDS.
    • The requirement SDs are at the parent SENDER-RECEIVER-INTERFACE of the VARIABLE-DATA-PROTOTYPE.
  • Data Object of a Present Value Record:
    • Condition: the parent interface of the VARIABLE-DATA-PROTOTYPE is a SENDER-RECEIVER-INTERFACE.
    • The requirement SDs are at the VARIABLE-DATA-PROTOTYPE.
  • Data Object of a Stored Data Record:
    • Condition: the parent interface of the VARIABLE-DATA-PROTOTYPE is an NV-DATA-INTERFACE.
    • The requirement SDs are at the VARIABLE-DATA-PROTOTYPE.
  • Init Values (CDS-68846 8.5 SP3 P9)
    • SWC Sync reads init values for synchronized data objects and stores them in the "Implementation Default" attribute.
    • For data objects referencing array or record data types, it separates the init values of the individual elements by a blank in the "Implementation Default" attribute.

Sync of Stored and Present Value Data Records

[SWC-R0610]: For each data object in the stored data and present value lists extracted from the SYS-EX,...

  • if there is a data object whose sync ID [RQ-R115] is equal to the requirement ID of the SYS-EX data object,
  • [SWC-R0620] SWC Sync replaces the data object by a new data object.
  • Note: the data type of the replaced data object may get deleted [SWC-R1250] afterwards.
  • [SWC-R0630]: SWC Sync takes the name of the new data object from the SYS-EX data object name (made unique if necessary).
  • [SWC-R0640]: SWC Sync takes the qualifier of the new data object from the SYS-EX data object short name (made unique if necessary).
  • [SWC-R0650]: SWC Sync sets the “ASR SWC DataElement Ref” attribute [SWC-R220] of the new data object from the instance ref of the SYS-EX data object.
  • [SWC-R0660]: The new data object references the CANdela data type created from the data type referenced by the synced data object [SWC-R1210]
  • [SWC-R0670]: SWC Sync updates data objects even if authorization does not allow the modification manually (e.g. in case of a locked variant).
  • [SWC-R0680]: SWC Sync does not modify...
    • existing data objects without sync ID [RQ-R115],
    • data objects with sync IDs for which no corresponding data object is extracted from the SYS-EX.
