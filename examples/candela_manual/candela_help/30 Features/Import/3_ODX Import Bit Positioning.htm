ODX Import - Positioning of Bit Objects (CDS-40540 8.5 SP2)

ODX import places ODX parameters that have no byte or bit position at a new byte (since 8.5 SP2):

Sometimes, the position of a parameter cannot be determined until runtime, so the BYTE- and the BIT-POSITION shall be omitted in the ODX instance. The parameter starts then at the byte edge next to the end of the last parameter.

ODX 2.2.0 spec ISO 22901-1:2008, chapter 7.3.5.4.

For details about ODX Import, see the documentation in the CANdelaStudio documentation folder.
