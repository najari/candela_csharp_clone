Import from Network Description (CDS-13054 8.0 SP2)

Import of DTCs and Data from a network description.

This import is different from SWC Sync...

  • which reads info from software components (SWCs) with ports
  • and updates diagnostic objects based on matching requirement IDs.

Use-Case

In a CANdb (.dbc), FIBEX or AUTOSAR (.arxml) file, you may have defined a network description with messages and signals.

You may want some of the signals…

  • to be accessible via a diagnostic data object by a test system,
  • and to set a diagnostic trouble code (DTC) when the signal is not available (e.g. for a communication error).

Import of DTCs and Data

[IND-R100] The import offers creation of…

  • a DTC for each signal,
  • a data object or packet data type for...
    • each signal and
    • each message.

... from AUTOSAR

The AUTOSAR .arxml file must contain a network description.

Background: an AUTOSAR .arxml file may contain different parts:

  • the description of software components (SWCs)
  • a network description
    • same structure as a FIBEX file
    • may contain multiple ECUs.

The import of DTCs and data from a network description does not consider software components in the .arxml file!
