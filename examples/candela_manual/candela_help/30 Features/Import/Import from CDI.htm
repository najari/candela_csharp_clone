Import from CDI

[CDI-R010] Import from the CANdela Data Import (CDI) format

  • CDI import is based on an XML file structure which CANdelaStudio can import.
  • For details about the format, see the description in the Documentation folder of the CANdelaStudio installation.
  • The import includes...
    • DTCs
    • data types and
    • data objects
  • The import is available...
    • in Ribbon "Data Exchange" [MENU-R220]
    • as a "File type" in the file selection dialog of DTC Import in Fault Memory.
  • It fills...
    • the DTC List and
    • the Import Pool.
