SWC Sync DTC

Extraction of SYS-EX DTCs

SWC Sync expects a SYS-EX DTC as an instance reference to a port, with the following conditions:

  • The parent SWC type belongs to the ECU-INSTANCE.
  • The SWC type includes a SWC-SERVICE-DEPENDENCY with a ROLE-BASED-PORT-ASSIGNMENT pointing to an R-PORT-PROTOTYPE.
  • Note: SWC Sync does not check the role name (typically “DiagnosticMonitor”).
  • The SWC-SERVICE-DEPENDENCY contains a DIAGNOSTIC-EVENT-NEEDS.
  • Requirement SDs are at the R-PORT-PROTOTYPE.

Sync of DTCs

[SWC-R0410]: For each DTC extracted from the SYS-EX,...

  • if there is a DTC in the CANdela document whose Sync IDs [RQ-R115] equal the requirement ID of the SYS-EX DTC, ...
  • [SWC-R0420] the SWC Sync overwrites the value of the attribute “ASR SWC ServiceDependency Ref” [SWC-R210] with the instance ref from the DTC,
  • [SWC-R0430] ... even if authorization does not allow the modification manually (e.g. in case of a locked variant).
  • [SWC-R0440]: SWC Sync does not modify...
    • existing DTCs without sync ID [RQ-R115],
    • DTCs with sync IDs for which no corresponding DTC is extracted from the SYS-EX.
  • For the mapping of SWC with DTC vs. Event, see [ASR-D050].
