SWC Sync Synchronize Element References

[SWC-R1500] The checkbox "Synchronize Element References" [SWCUI-R350] in the SWC Sync Dialog controls whether SWC Sync sets the attributes listed in [ASR-D001].

This controls whether daVinci Configurator uses Element References to automatically map the diagnostic objects to the objects in the SYS-EX, which is the default.

In exceptional cases, it makes sense to suppress the automatic mapping. Example:

  • the OEM defines elements in PREEvision as mere placeholders
  • the supplier creates detailed diagnostic objects
  • in this case, daVinci should not map the diagnostic objects to the placeholders.

Synchronize Element References off

[SWC-R1500-Off]

"Synchronize Element References..." off

  • SWC Sync does not set attribute values
  • no automatic mapping from diagnostic objects to SYS-EX objects in daVinci

Synchronize Element References on

[SWC-R1500-On]

"Synchronize Element References..." on

  • SWC Sync sets attribute values
  • ... which daVinci uses for automatic mapping from diagnostic objects to SYS-EX objects
