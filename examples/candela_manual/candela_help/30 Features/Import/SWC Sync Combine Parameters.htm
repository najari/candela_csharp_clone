SWC Sync Combine Parameters

[SWC-R1600] The checkbox "Combine Parameters of Synchronized DIDs in DEXT Export" [SWCUI-R360] in the SWC Sync Dialog...

  • controls whether SWC Sync sets the attribute ASR3LegacyCombineDID at imported DIDs
  • ... which will trigger DEXT Export of the DIDs as uint8 array, see [DEXT-R205] and [DEXT-R207].

While the default is to export DIDs as individual parameters, export of an uint8 array may be useful if...

  • the SYS-EX uses not recommended model structures which daVinci Configurator does not handle (as of 2019), or
  • a DID contains a large number of data objects which would be high effort to map interactively in daVinci Configurator.

Combine Parameters... off

[SWC-R1600-Off]

"Combine Parameters..." off

  • attribute value = 0
  • the generated callback receives a struct
  • ports for the data objects must be mapped

Combine Parameters... on

[SWC-R1600-On]

"Combine Parameters..." on

  • attribute value != 0
  • the generated callback receives an uint8 array
  • the callback must handle the placement of the individual data objects within the array

DIDs vs. Diagnostic Instances

[SWC-R1610]

  • [SWC-R1610-DID] SWC Sync sets the attribute ASR3LegacyCombineDID at DIDs.
  • [SWC-R1610-DiagInst] SWC Sync sets the attribute ASR3LegacyCombineDID at a diagnostic instance that describes a UDS DID (SWCSYNC-163 v12).

Background:

  • CANdelaStudio allows to describe DIDs (data only) in a tree node separate from the Diagnostic Classes.
  • The use of these separate DIDs can be enforced by setting [DID-R050] in the Diagnostic Class Template.
