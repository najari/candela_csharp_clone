Import from ASAP2 (CDS-3791 4.0 SP2)

Import of data types and data objects from an ASAM MCD-2MC (ASAP2, .a2L) file.

Use-Case

In a ASAP2 (.a2L) file, you have defined calibration and measurement data ("labels").

You may want some of the labels to be accessible via the diagnostic protocol to a test system (using diagnostic data objects).

Import

[IA2L-R100] ASAP2 import handles

  • data types (COMPUMETHOD)
    • coefficients form
    • formula
    • tables: number -> number, and number -> string
  • data objects
    • name
    • reference to a COMPUMETHOD
    • address (but no relation to a diagnostic service)
    • [IA2L-R100-DA] if...
      • the document has the attribute category "CANdesc",
      • and the sourceInfo is set in the ASAP2 file,
      • then import assigns the sourceInfo to the attribute with qualifier VariableForDirectAccess (CDS-4740 4.0 SP2)
