SWC Sync IO Controls

Sync of IO Controls

Note: SWC Sync supports...

  • only IO Controls with a scalar type like uint8,
  • no composite types such as records.

Update of Control State Records

[SWC-R1010]: SWC Sync...

  • for each SYS-EX IO control data object
  • whose port interface requirement ID equals the “Instance Type” attribute [SWC-R200] of (one or more) CANdela IO control diagnostic instances,
  • update the control state records of the diagnostic instances:
    • it replaces all data objects of a control state record of any IO control service subfunction
    • by a new data object corresponding to the SYS-EX IO control data object.
    • ... following the same rules as in synching stored and present value data records (see SWC Sync Data Objects)

[SWC-R1030]: If...

  • no such CANdela IO Control diagnostic instance exists,
  • or a routine record or subfunction is missing,

...SWC Sync...

  • write a warning to the log,
  • with a hint that such an IO Control diagnostic instance must be created with the appropriate “Instance Type” attribute [SWC-R200] value
  • either manually or automatically (e.g. after a re-import of updated requirements from PREEvision, DOORS…).

[SWC-R1040]: SWC Sync does not modify...

  • any IO Control diagnostic instance which does not have an “Instance Type” attribute [SWC-R200] value corresponding to a IO Control data object extracted from the processed SYS-EX (it completely ignores such IO Control diagnostic instances).

Update of SWC Service Dependency References

[SWC-R1050]: SWC Sync...

  • for each CANdela IO control instance
  • whose “Instance Type” attribute [SWC-R200] equals the port interface requirement ID of the SYS-EX IO control data object
  • update the “ASR SWC DataElement Ref” attribute [SWC-R220]
  • but only if there is no other CANdela IO Control diagnostic instance with the same “Instance Type” in any of the variants that diagnostic instance belongs to.

[SWC-R1060]: SWC Sync overwrites the “ASR SWC DataElement Ref” attribute [SWC-R210] from the instance ref of the IO control data object.
