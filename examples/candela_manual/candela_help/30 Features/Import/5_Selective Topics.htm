Deactivate all CANdela diagnostic instances and job containers

  • if the import wizard option is unchecked, import...
    • just adds data to the CANdela document, and
    • does not affect existing jobs.
  • if this option is checked, the CANdela document resulting from import to correspond with the contents of the imported ODX file.
    • To achieve this, import de-activates diagnostic instances and job containers missing in the import data (it intentionally does not provide the option to delete them).
    • see the following chapter about how to protect individual jobs from being de-activated.

Prefer Flat DIAG-SERVICE over TABLE Using DIAG-SERVICE (CDS-35161 8.1 SP2 P1)

  • In case a DID used by DIAG-SERVICEs 0x22 or 0x2E is defined twice, ...
    • one time using a TABLE
    • and the other time in a flat DIAG-SERVCE,
  • import shall provide a meaningful message and drop the TABLE DIAG-SERVICE,
  • depending on the value of an ECU string attribute having qualifier Prefer_flat_DID:
    • if the attribute does not exist, do not drop;
    • ALL: apply to all DIDs;
    • comma-separated list of DIDs (e.g. F1A1;F1A2;F1A3): apply to these DIDs only.
