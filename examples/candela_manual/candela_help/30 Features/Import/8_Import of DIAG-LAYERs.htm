Import of ODX DiagLayers with their DiagServices

In CANdelaStudio, an ODX BaseVariant with its EcuVariants can be selected as ODX ECU description. An ODX BaseVariant can be imported into a CANdelaStudio BaseVariant. All DIAG-SERVICEs which are visible in the Server-API for an ODX BASE-VARIANT (independent on which DIAG-LAYER they are defined, IMPORT-REF and DIAG-COMM-REF are provided as well) are considered to be imported. Hence, all ODX DiagServices which are executable in the ODX BaseVariant are executable in the CANdelaStudio BaseVariant as well after having done the import. The same import procedure is applied for an ODX ECU-VARIANT. Therefore, all DIAG-SERVICEs which are visible in the Server-API for an ODX ECU-VARIANT are considered to be imported.

The import of an ODX ECU-VARIANT is done automatically for all ECU-VARIANTs for a selected ODX BASE-VARIANT which shall be imported. If there is no CANdelaStudio Variant having the same qualifier as the ODX ECU-VARIANT SHORT-NAME a new CANdelaStudio Variant is created, else the data is imported into the CANdelaStudio Variant having the same qualifier as ECU-VARIANT SHORT-NAME.

Import of VARIANT-IDENTIFICATION

The VARIANT-IDENTIFICATIONs found in ODX are mapped to CANdelaStudio Identifiying Features of the base variant as well as the identifying patterns of the specific ECU variant.

Starting with CANdelaStudio release 8.0 ECU-VARIANT-PATTERNs referencing SINGLE-ECU-JOBs get also imported as an identification detail.

Import of ECU-SHARED-DATA

All data of ECU-SHARED-DATA which is visible via DIAG-SERVICEs of an imported BASE-VARIANT or ECU-VARIANT is imported. The file ECU-SHARED-DATA is imported as well.

Moreover, if the following ODX objects are defined in a ECU-SHARED-DATA and used by imported ODX DIAG-SERVICEs the odx-link references to the used objects are stored in the CDD file if the ODX mode is enabled for the CDD file:

  • DTC-DOPs
  • DOPs which correspond to a CANdelaStudio data type
  • UNITs

The ODX Export will write the ECU-SHARED-DATA and the odx-link references to the used objects.

Starting with CANdelaStudio 7.5 SP3 it is also possible to import one/more ECU-SHARED-DATAs without having a BASE-VARIANT. In this case CANdelaStudio internally creates an empty BASE-VARIANT which inherits from all provided ECU-SHARED-DATAs. (CDS-26063)

From CANdelaStudio 8.5 SP3 onwards, ECU-SHARED-DATAs will be imported into the Library Category of CANdelaStudio. For more details, see ODX Import of Libraries.

Import of COMPARAM-REFs

The given COMPARAM values for a BASE-VARIANT defined by COMPARAM-REFs or by inheritance of the default COMPARAM-SPEC values are imported as CANdelaStudio Comparams. The COMPARM-REFs must specify a PROTOCOL (via SNREF). Then the COMPARAM-REF value is imported to the CANdelaStudio ECU interface having the same qualifier as the SHORT-NAME of the referenced PROTCOL where the prefix "PR_" of the SHORT-NAME is ignored.
