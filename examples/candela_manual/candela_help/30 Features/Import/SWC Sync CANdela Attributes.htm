SWC Sync CANdela Attributes

SWC Sync identifies attributes by their qualifier without regard to the name. The following table shows recommended names (attribute names are defined in Expert View).

For details how the attributes are used, inspect the above chapters for references to the FeatureIDs like [SWC-R200].

Attribute Qualifier Description
typically: SYNCHELEMENT
or RequirementsId		 See [RQ-R115]. The attribute qualifier varies depending on the template.
Instance_Type [SWC-R200]: (string) port interface requirement ID of a SYS-EX routine or IO Control.
ASR_SWC_ServiceDependency_Ref [SWC-R210]: (string) instance ref from a DTC or routine.
ASR_SWC_DataElement_Ref [SWC-R220]: (string) at a diagnostic instance and data object, instance ref of the originating SYS-EX object.
ASR_Encoding [SWC-R230]: (string) at a data type. Valid values:

UNDEFINED
TWOCOMP
IEEE754
ISO88591
ISO88592
WIN1252
UTF8
UTF16
UCS2
NONE
BOOLEAN
