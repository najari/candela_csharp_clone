Synch attribute

On importing parts (data types, parameters, ...) from ODX into the data type list or the import pool of a CANdela document, it is possible to specify a synchronization attribute.

Details on the CANdelaStudio synchronization feature can be found in the application note "AN-IDG-1-014_How_to_synchronize_Data_Objects_via_Import_Pool" and in the reference for the Import Pool regarding the use of Processing Instructions and SDGs.
