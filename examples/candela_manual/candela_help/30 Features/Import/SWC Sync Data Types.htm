SWC Sync Data Types

Extraction of SYS-EX Data Types

A SYS-EX Data Type is a combined object of...

  • the application data type referenced by...
    • a SYS-EX Data Object (see SWC Sync Data Objects)
    • or a SYS-EX Routine argument (see SWC Sync Routines)
  • and its associated implementation data type.

Conditions:

  • SWC Sync assumes the referenced data type is an application data type
  • SWC Sync assumes that the parent SWC type providing...
    • the SYS-EX Data Object or
    • implementing the SYS-EX Routine
    has a DATA-TYPE-MAP referencing the application data type and an implementation data type.
  • SWC Sync takes the properties of the SYS-EX Data Type from...
    • the COMPU-METHOD of the application data type,
    • the DATA-CONSTRAINTS of the application data type, and
    • the base type of the implementation data type.
    Property Description
    ByteOrder ByteOrder of the base type: distinguish between big-endian (Motorola) and little-endian (Intel) byte ordering.
    Length Length of the base type in bytes.
    Encoding Encoding of the base type (signed integer, unsigned integer, float, etc.)
    MinimumValue Phys Lower limit of the DataConstr of the application data type in the physical domain
    Minimum Value Phys Interval Type Distinction between open, closed, and infinite interval
    MaximumValue Phys Upper limit of the DataConstr of the application data type in the physical domain
    Maximum Value Phys Interval Type (as for "Minimum Value Phys Interval Type")
    MinimumValue Raw Lower limit of the DataConstr of the application data type in the raw domain
    Minimum Value Raw Interval Type (as for "Minimum Value Phys Interval Type")
    MaximumValue Raw Upper limit of the DataConstr of the application data type in the raw domain
    Maximum Value Raw Interval Type (as for "Minimum Value Phys Interval Type")
    CompuMethod Computation method of the application data type. Two kinds are supported: linear and enumeration
    Unit Unit attached to the application data type

A CompuMethod of kind "linear" has the following properties:

Scale Scale factor of the CompuMethod
Offset Offset of the CompuMethod

A CompuMethod of kind "enumeration" is represented by an array. Each element exposes the following properties:

Enum Textual name of the enumeration value
Value Numerical value that corresponds to the textual name

In addition to a pure linear and a pure texttable CompuMethod, there may also be a mixture of both.

SWC Sync identifies the applicable kind of CompuMethod by the "category" attribute, which can have the following values:

  • LINEAR
  • TEXTTABLE
  • LINEAR_AND_TEXTTABLE

Sync of Data Types

Creation and Deletion of Data Types

[SWC-R1210]: SWC Sync creates a new CANdela data type...

  • from each SYS-EX data type
  • that is referenced by a SYS-EX data object
  • from which at least one new CANdela data object is created.

[SWC-R1220]: For a SYS-EX data type...

  • with computation method type LINEAR,
  • SWC Sync creates a CANdela linear data type
  • and assign the respective properties.

[SWC-R1230]: for a SYS-EX data type...

  • with computation method type TEXTTABLE,
  • SWC Sync creates a CANdela text table data type
  • and assign the respective properties.

[SWC-R1240]: for a SYS-EX data type...

  • with computation method type SCALE_LINEAR_AND_TEXTTABLE,
  • SWC Sync also creates a CANdela linear data type,
  • assign the respective properties of the SYS-EX linear part
  • and create invalid values from the SYS-EX text table part, with the "kind of invalidity" set to undefined.

[SWC-R1250]: SWC Sync deletes all CANdela data types that were referenced only by CANdela data objects replaced by the SWC.

Data Type Encoding

[SWC-R1260]: If a direct match is possible, SWC Sync sets the encoding [DTENC-R100] of the CANdela data type to the AUTOSAR encoding.

[SWC-R1270]: Otherwise (e.g. for AUTOSAR encoding BOOLEAN) SWC Sync sets the encoding...

  • to unsigned by default, and
  • to signed in case of a linear conversion whose scaling factor or offset is negative.

[SWC-R1280]: In any case, SWC Sync stores the original AUTOSAR encoding in the “AUTOSAR Encoding” attribute [SWC-R230] of the CANdela data type.
