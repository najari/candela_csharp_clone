ODX Import - Introduction

See also the ODX Import User Interface and the menu for ODX Import [MENU-R210].

Overview

ODX Import imports an ODX file into a CANdela Document.

You can create such a document by instantiating a Document Template.

A Document Template captures the diagnostic specification of an OEM. It restricts the possible structure of diagnostic services.

ODX Import respects these template restrictions, so that...

  • imported (or exported) data always fulfills the template restrictions,
  • therefore ODX data exchange with CANdelaStudio always fulfills the specification of the OEM, implemented in the template.

Import Settings

ODX Import offers different modes for different use-cases.

  • Import of a complete ECU description
  • Import of variants with service selection
  • Import of specific small parts (DOPs, DTCs, ...)
  • Import of Libraries

There are options to parameterize the Import.

[ODXI-R300] No Support for "Checkbox Feature"
