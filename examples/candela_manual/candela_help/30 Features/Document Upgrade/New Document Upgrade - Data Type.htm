New Document Upgrade - Data Type

[DOCUP-R1210] (CDC-44226 v12)

If New Document Upgrade reduces the range of identifiers in a Text Table [DCLT-R400],

  • it makes each corresponding Identifier in a Diagnostic Instance valid
  • and creates a rework list entry for it.
