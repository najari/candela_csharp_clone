New Document Upgrade - Diagnostic Instance

[DOCUP-R1110] (CDC-44069 v12) If...

  • a non-activated diagnostic instance T from the template
  • replaces an activated diagnostic instance in the document,
  • after the upgrade, T is activated.

[DOCUP-R1120] (CDC-44234 v12)

Document Upgrade handles DTCs in the global DTC Pool [DTCP-R001]:

  • where possible it establishes references
  • if not possible, it creates a copy in the diagnostic instance and mentions it in the Rework List.
