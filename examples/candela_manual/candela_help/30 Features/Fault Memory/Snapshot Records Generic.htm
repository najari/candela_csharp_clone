Snapshot Records (Generic)

CANdelaStudio provides two ways to describe the layout of Snapshot Data, see [FM-D200].

This chapter provides details about the generic, Multiplexer based Snapshot Records data structure.

It does not apply for the specialized AUTOSAR based data structure (v13).

Snapshot Record Numeration Type in Generic Fault Memory (v11 CDS-70902)

In AUTOSAR, a Fault Memory has the property DemTypeOfFreezeFrameRecordNumeration with the values Calculated and Configured, for details see [SR-D050].

[SR-R023] A CANdela template using the generic Snapshot Record data model [FM-D200-Generic] can support this distinction for each Fault Memory diagnostic instance using a special attribute.

  • Qualifier: Snapshot_Record_Numeration_Type
  • Type: Enum
  • Values:
    • [SR-R023-Calculated] 0: Calculated
    • [SR-R023-Configured] 1: Configured

The DEXT Export uses this attribute [DEXT-R340].

Note: in v13, this info can be described directly as a property of the diagnostic instance, if the template has been setup for the AUTOSAR Fault Memory.
