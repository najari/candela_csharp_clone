AUTOSAR Fault Memory Introduction (CDS-71541 v13)

Generic Fault Memory Multiplexer

Traditionally, CANdelaStudio represents the contents of the Fault Memory within a generic Request and Response communication structure.

  • e.g. for Snapshot Data specific per DTC, a Multiplexer is used.

This generic data structure is not well suited to configure the Fault Memory code generation.

CANdelaStudio 8.2 (2015) provided a specific data structure, but that data structure...

  • did not cover detailed AUTOSAR properties, and
  • allowed complex constellations not covered by AUTOSAR
    • e.g. Snapshot Data (DIDs) being different in Snapshot Records "First Occurrence" and "Most Recent Occurrence".

CANdelaStudio 13 introduces a specific data structure for Snapshot Records and Extended Data Records, conforming with the AUTOSAR Standard.

The user interface provides...

  • editing of details in a non-modal embedded property sheet to the right, with
  • mass-editing for multiple selected list elements.

Fault Memory 8.2 Constellations not Conforming with by AUTOSAR

8.2 Fault Memory in Tree

CANdelaStudio 13 no more supports the specific 8.2 Fault Memory modelling of Snapshot Records and Extended Data Records.

For 8.2 Fault Memory constellations not conforming with AUTOSAR, CANdelaStudio 13 provides an automatic migration to the generic Fault Memory (Multiplexer based).

Migration of Constellations Conforming with AUTOSAR

CANdelaStudio 13 migrates any Fault Memory constellations of Snapshot Records and Extended Data Records that conform with AUTOSAR to the new v13 modelling:

  • the generic modelling (using Multiplexer)
  • as well as the 8.2 Fault Memory

Drawbacks of v13 AUTOSAR Fault Memory

  • Snapshot Record Numbers are defined and modifiable in a Diagnostic Instance
    • You cannot fix them document-wide
    • ... which was possible by defining them in Fixed Data in the Protocol Service.
  • You cannot forbid individual Snapshot Record Numbers
    • ... which was possible by defining Invalid Values at a Text Table that described Snapshot Records.
  • For constellations not compatible with AUTOSAR, the comfortable GUI of 8.2 is no more available
