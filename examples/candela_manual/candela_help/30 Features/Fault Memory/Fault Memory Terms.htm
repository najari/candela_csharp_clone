Fault Memory Terms

[FM-D010]

  • Aging: a DTC will be automatically removed from fault memory if the monitor function was executed and no failure was detected for a configured number of Operation Cycles.
  • Combined DTC: a DTC referenced by multiple Events
  • Event Combination: having a Combined DTC
  • Event Memory, e.g. Primary memory, holds Event Memory Entries
  • Event Memory Entry: single container for one Event and its data
    • Freeze Frames (Snapshot Records)
    • Extended Data
  • Event Qualification (getting qualified):
    • when a passed or failed result is set
    • within DEM, from another BSW module or SW-C
  • Failure Counter = the "Trip Counter" of UDS
    • counts the number of Operation Cycles (driving cycles) where a malfunction occurred
    • when it reaches a treshold, the confirmed bit changes from 0 to 1
  • Fault Detection Counter (FDC): an sint8 value as used in ISO
  • Freeze Frame: a record of data (DIDs/PIDs), same as Snapshot Records
  • Healing:
    • switching off an Indicator
    • handling passed results
    • triggered by period of time / count of operation cycles
  • Monitor: routine checking proper functionality of a component, also "diagnostic function"
  • Operation Cycle:
    • base of Event Qualification and DEM scheduling
    • e.g. ignition on/off, driving cycle
  • OBD ECUs: a vehicle can have 3 types of ECUs:
    • Master ECU (1 per vehicle)
    • Primary ECU (several)
    • Secondary/Dependent ECU (several)
  • Primary ECU: in its Event memory, stores its own errors and those of related Secondary ECUs
  • UDS DTC Status Byte
    • see [FMUDS-D050].

Cf. AUTOSAR_SWS_DiagnosticEventManager ch. 2.1.
