19 06 Wizard Data Model (CDS-11966 6.5)

This chapter describes data model behind the 19 06 Wizard dialog.

It applies to Extended Data defined within the service structure in a diagnostic instance (based on a Multiplexer in the Protocol Service).

For the specific AUTOSAR data model available since CANdelaStudio 13, see the Extended Data Records (v13, AUTOSAR) page.

Definitions

D001: let the Request primitive of protocol services 0x19 0x04 and 0x19 0x06 contain

  • one Multiplexer Component at the end of the primitive.

D002: protocol service 0x19 0x04 - let the Positive Response primitive contain...

  • one End of Service Iteration Component at the end of the primitive containing at the end of the iteration...
    • one Fixed Data Component and
    • one Multiplexer Component.

D003: protocol service 0x19 0x06 - let the Positive Response primitive contain...

  • one End of Service Iteration Component at the end of the primitive containing at the end of the iteration...
    • one Fixed Data Component and
    • one Multiplexer Component.

D004: let the Fixed Data Components of D002 and D003 contain at least

  • a first data object referencing a Text table data type, respectively,
  • which defines the set of 19 06 record numbers.

Data Storage

A "Master data type" contains the list of all available record numbers.

CANdelaStudio stores the assignment of DTCs and record numbers in text table data types:

  • for each combination of record numbers,
  • it creates a new text table.

For each DTC, CANdelaStudio...

  • creates a data object in a Multiplexer case for the DTC
  • and lets the data object reference the text table with the corresponding record number combination.

CANdelaStudio generates the name of the text table...

  • using the name of the "Master data type",
  • appending the text "Group [A..Z][1..9]"
  • and the selected record numbers.
