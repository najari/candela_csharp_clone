Iteration Data Types (CDS-10215 in 6.5)

Mutual nesting of iteration datatypes is forbidden (CDS-15487, 6.5).

Creation and use of an iteration data type can be forbidden in the template, e.g. if a tool chain does not support it (see menu File | Properties | Data Type Authorization).
