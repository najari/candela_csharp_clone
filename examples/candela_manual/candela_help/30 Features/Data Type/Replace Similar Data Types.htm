Replace Similar Data Types (CDS-68992 v11)

See also the description of the "Replace Similar Data Types" Dialog.

Use-Case

  • The CANdela document contains multiple data types,
    • i.e. data types that have the same values for crucial properties (conversion, length...)
    • and differ in irrelevant properties only (blanks in the description...)
  • Such data types may result from multiple import,
    • where the first import creates a new data type (the "original"),
    • and a subsequent import maybe with a slightly modified data type creates a "duplicate".
  • Editing operations in a huge data type list may also result in unintended duplicates.

Introduction

  • The feature analyzes the entire data type list for similar data types;
  • then for each group of similar data types,
    • you choose one data type to be kept as an "original"
    • by default, CANdelaStudio deletes all other data types of the group,
    • but you can choose to keep individual ones of these, too.
    • CANdelaStudio replaces all references to deleted data types by a reference to the chosen original data type.

Conversions

[RDT-R010] The feature detects similar data types of the conversions:

  • [RDT-R010-Identity] Identity (raw values)
  • [RDT-R010-Linear] Linear Formula
  • [RDT-R010-TextTable] Text Table

Crucial Properties

[RDT-R020] For analyzing data types for similarity, you can specify whether the following properties is crucial, or shall be ignored:

  • [RDT-R020-Desc] Description
  • [RDT-R020-Enc] Encoding [DTENC-R100]
  • [RDT-R020-Attr] Attributes
  • [RDT-R020-ByteOrder] Byte Order
  • [RDT-R020-DisplayFormat] Display Format
  • [RDT-R020-TID] TextID
    • Note: the checkbox for TextID may be hidden [RDTUI-R120-TextID].
  • [RDT-R020-v11] Note: missing in v11 (CDS-71212):
    • Linear data types with different byte order are never in the same group.
    • Text tables with different encoding are never in the same group.

[RDT-R030] You can define default settings of these properties using the special INI file parameter [INI-R500-Default].

[RDT-R040] Editing of these settings can be prevented in Standard View by an INI file parameter [INI-R500-Cfg].

Authorization Ignored for Document Modifications

[RDT-R050] Caution: the feature so far does not consider authorization (CDS-70978, open):

  • data type deletion [DTAUTH-R320]
  • data type used in a locked variant or library [VAR-R010]
  • data type used in a protected diagnostic instance: secondary properties modifiable, [DIA-R050])
  • data type used in a protected DID: DID modifiable [DID-R010]

Contexts

[RDT-R060] The operation replaces data type references in the contexts:

  • Data Object,
  • Complex Data Type,
  • DID number Data Object,
  • Data Object in Fixed Data.
