Unit

[UNIT-R005] The Unit at a data type specifies the unit for physical values based on the data type, like "40 km/h".

Specification

[UNIT-R010] The unit is free text (non-translatable).

[UNIT-R020] The unit may be empty.

Predefined List

[UNIT-R030] You can predefine a list of units for selection in the data type property dialog, using the special attribute Units.

ECU-SHARED-DATA

Cf. the unit from ECU-SHARED-DATA [DTLIST-R200] shown in the data types list.
