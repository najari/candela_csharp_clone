Characteristic Curve

A Characteristic Curve converts a raw byte x using points or ranges on the x-axis in which a value y applies, i.e.

  • a set of (x, y) pairs in a Cartesian coordinate system with
    • abscissa (x axis) and
    • ordinates (y axis).

See also the dialog.

Example: Temperature

Raw Value Physical Value
0x00 0.125
0x01 (interpolated) 0.1875
0x02 0.25

Interpolation

The following describes the conversion of raw to physical values.

The same holds vice versa for the conversion of physical to raw values.

Note: in the corresponding ODX element TAB-INTP, physical values are always interpolated.

Without Interpolation

The entries of the table refer to single coded values which are mapped to a (single) physical one.

Only raw values for which an (x, y) pair exists are converted to physical values.

With Interpolation

For an x value not contained in the data type definition, ...

  • the range of adjacent x values is taken, and
    • the y value is computed (interpolated) using a linear formula...
    • from the y values of the adjacent x values.
  • This includes extrapolation below the minimum and above the maximum defined x value.
  • The interpolation causes a growth of the coded range beyond the actual table entries, as all values in between the table entries are also considered as valid values.

Note: this defines a similar mapping as a piecewise linear data type, but it uses single values as supporting points to be interpolated in between.
