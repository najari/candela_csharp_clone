Iteration Data Type Constraints

Data Objects Contained

The data object collection in an iteration data type...

  • must not remain empty;
  • when the data type is referenced from a diagnostic instance: must respect the size restrictions of the proxy component;
  • when contained in one of...
    • counter iteration
    • end-marker iteration
    • end-of-service iteration,
    must not contain (directly or indirectly) a data object that references any of these three datatypes (CDS-15487 6.5).

Referencing Data Object

A data object that references an iteration data type must...

  • must not have a default or const value
  • not be inside a bit field
    • same as for Mux CDS-10216 R006 1.)
