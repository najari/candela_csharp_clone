Counter Iteration

For an overview, see the Complex Data Types Introduction.

A counter iteration data type describes iterated transmission of data objects in a telegram until a specified number of iterations is reached.

The number of iterations is transmitted in a selector data object. The selector (or counter) data object is not part of the counter iteration data type. When you let a data object reference the Counter Iteration Data Type, you must also specify the selector data object.

  • needs selector: yes
  • the data object used as selector for the Counter Iteration...
    • must exist in the same telegram table where the Counter Iteration is used, and
    • must be located before the Counter Iteration (same as for Mux CDS-10216 R006 7)
  • must not be used at a position before the end of the PDU
  • More constraints: see Iteration Data Type Constraints.
