Replace Data Type (CDS-3177, 7.0)

D001: The following objects reference a data type which can be replaced:

  • DO (data object) ::= { data object, bit field }
  • TO (template object) ::= { variable value component, GroupOfDtc proxy component, StatusOfDtc proxy component, GroupOfDtc data object }
  • IF ::= { Identifying Feature }

D002: A data type may be replaced by another one of the same or different conversion, if the following conditions are fulfilled:

  • Authorization of the object containing the DO allows modification of the data type.
  • If replacing at a DO: the telegram table is not incremented above its maximally allowed length.
  • The DO is not used as a Mux selector.
  • None of the two data types needs a selector.
  • If replacing at a TO: the file opened is a template (cddt), and both data types have the same conversion and length.
