Bitmask

[DT-R500] A Data Type has a Bitmask.

  • [DT-R500-Size] The data type bitmask is a 4 byte unsigned integer.
  • A test system applies it to the raw value from the line, before it applies the byte order:
    • each 0 bit in the bitmask sets the respective bit of the raw value to 0.

Example:

  • 0x1234 raw value,
  • 0xFFF0 bitmask,
  • 0x1230 resulting value.

[DT-R510] The bitmask is not supported for 64 bit integers [DTENC-R200] (constraints violation, cf. CDS-26911).
