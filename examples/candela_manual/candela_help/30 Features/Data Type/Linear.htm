Linear

Linear formula optionally with a unit, and restricted by Start and/or End Range (= lower/upper limit).

Examples

Conversion Result
0x78 x revolutions 1000rpm
0x02 x throttle value angle 27,3°

See also the dialog.

Factor, Divisor, Offset

[LIN-R100] A linear data type converts a raw value using a formula of the form

phys = (factor/divisor)*raw + offset

Factor and divisor effect in a fixed quantization.

Divisor

[LIN-R110] While from the view of mathematics, the factor would suffice, the additional divisor (default: 1.0) helps to specify the resolution of the raw value.

Example:

  • data object on the line:
    • represents a current
    • in a resolution of 1/1000 V.
  • With just a factor, the linear formula would be
    • phys = 0.001*raw + 0 [V].
  • To make the resolution more obvious, you may specify
    • phys = 1/1000*raw + 0 [V].
  • Effect: raw value 1000 => physical value 1V
  • Formula:
    • factor = 1
    • divisor = 1000
    • offset = 0
    • unit = "V"

Lower and Upper Limit

[LIN-R120] Optionally, the domain of the formula can be restricted by a lower limit and an upper limit (on the raw value), see Start and/or End Range.

Inverse Value

[LIN-R1300] An inverse value can be defined if the factor is 0.

Note: as of 2016, Vector test systems (e.g. CANalyzer 9.0) support the inverse value for text tables only.

Physical Value

[LIN-R140] Often the data type also specifies a physical unit.

Values are shown in decimal or float notation, with a specified number of decimal places.
