End-Marker Iteration

For an overview, see the Complex Data Types Introduction.

An end-marker iteration data type describes iterated transmission of data objects in a telegram until a specific value, the "end marker" or "termination value", is transmitted.

  • needs selector: no
  • stores termination value as unsigned int
  • end marker position is at relative bit position 0 (as in ODX).
  • Note: the bytes which will be used to match the termination value are determined by the byte size of the first data object in the iterator’s data object collection.
  • The termination value must fit the size of the first data object in the iterator’s collection, i.e. termination value < 2^(MaxBitLen of first data object).
  • As the termination value is an unsigned value, the first data object must have a fixed size <= 8 bytes (no variable size), and must be byte sized (for bit fields at position 0, the top level data object is taken).
  • must not be used at a position before the end of the PDU.
  • More constraints: see Iteration Data Type Constraints.
