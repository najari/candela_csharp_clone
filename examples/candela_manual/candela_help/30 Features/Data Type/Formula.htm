Formula

A Formula data type uses...

  • a mathematical formula “f(x) =…” defined as a text string for converting raw to physical values, and
  • an optional other formula string for converting physical to raw values.

The formula can use a hard-coded set of supported mathematical functions (sin, asin, ... min, max, abs) and a C-like “switch”.

Example:

y = f(x) = 2*cos(x+1)
  x = 2.14159
  y = -2

See also the dialog.

Input Value

The input value is represented by the variable „x“, like in the formula 1/x.

  • for the raw to phys. conversion, x represents the raw value,
  • for the phys. to raw conversion in the "Phys->Raw" page, x represents the physical value.

No other variable names are supported.

Operators

The following operators are supported in formulas:

Operator Description Example
+ Plus 8 + 2 = 10
- Minus 8 - 2 = 6
* Multiplication 8 * 2 = 16
/ Division 8 / 2 = 4
& Binary and 8 & 2 = 0
| Binary or 8 | 2 = 10
^ Binary xor 8 ^ 2 = 10

Functions

The following functions are allowed:

Function Description Example
sin Calculate sine sin(x)
asin Calculate arcsine asin(x)
sinh Calculate hyperbolic sine sinh(x)
cos Calculate cosine cos(x)
acos Calculate arccosine acos(x)
cosh Calculate hyperbolic cosine cosh(x)
tan Calculate tangent tan(x)
atan Calculate arctangent atan(x)
tanh Calculate hyperbolic tangent tanh(x)
exp Calculate exponential function exp(x)
pow Calculate value raised to a power pow(x,3)
sqrt Find square root sqrt(x)
log Calculate natural logarithm log(x)
log10 Calculate base-10 logarithm log10(x)
max Return larger of two values max(x1,x2)
Min Return smaller of two values min(x1,x2)
Abs Find absolute value abs(x)
switch switch(selector, default value, x1, value1, x2, value2,…) switch(x,99999,1,x+2,2,x-2,3,x*2,4,x/2)

Note: for trigonometric functions, the x value is in radian (rad), e.g. cos(pi) = -1.

ODX

  • ODX does not support this kind of general formula.
  • It supports a rational function (ISO 22901-1: 7.3.6.6.3),
    • like y = 10000/x,
    • with any exponent >= 0 in the numerator and denominator, respectively.

ODX export converts a formula to an ODX COMPU-METHOD IDENTITY.

ODX import converts a rational function into a formula (which is always possible since a formula is more general).
