Data Type References

See also References (Common Properties) of CANdela objects in general.

Data types are referenced by various other objects:

Object references Data Type…
Bit field [BF-R100] Whole bitfield: Definition of length, conversion etc.
Data object [DO-R100] Definition of length, conversion etc.
DTC Status Bits [DTCSB-R050] Definition of total length of the bits.
Used Protocol Service [DCLT-R400] Text Table for range of Identifiers
Variable Value Component [PS-R450] Default Text Table for range of Identifiers
Document Option "Failure Type Byte" [DTC-R500] Text Table for 1 byte FTB
Document Option "Failure Mode Identifier" [DTC-R510] Text Table for 5 bit FMI
Document Option "Default Data Type" [RQ-R094] used to create data objects from requirements
