Fixed Count Iteration

For an overview, see the Complex Data Types Introduction.

[FCDT-R100] A fixed count iteration data type describes iterated transmission of data objects in a telegram. The number of iterations is defined as a constant in the CANdela document.

  • [FCDT-R110] needs selector: no
  • [FCDT-R120] stores number of iterated data objects > 0
  • [FCDT-R130] may be used at a position before the end of the PDU.
  • More constraints: see Iteration Data Type Constraints.
