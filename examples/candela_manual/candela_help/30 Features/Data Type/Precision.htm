Precision - Decimal Places

[DT-R600] For display format "Floating Point", the optional value "Precision" specifies the number of decimal places (digits after the decimal point) available for values.

[DT-R610] Reasonable values are...

  • [DT-R610-float] between 2 and 7 decimal places for float,
  • [DT-R610-double] between 2 and 15 decimal places for double.

The decimal places are evaluated e.g. in ...

  • the CANdelaStudio data type dialogs where values are input e.g. for linear formula limits
  • CANdelaStudio ODX import and ODX export
  • Vector tools providing diagnostic functionality, like CANoe

Limitation

The number of significant digits that can be represented in a value at all is limited by the encoding (float or double). For background, see the Wikipedia article about IEEE floating point.

Decimal Places vs. Significant Digits

[DT-D600] Before 8.5, the dialog showed the explanation "significant digits" (CDS-39461 8.5), but actually the value specified the decimal places:

  • significant digits: the number of digits before and after the decimal point
  • decimal places: the number of digits after the decimal point

Example:

  • create a linear data type with length 4 bytes, encoding "IEEE Float (single)"
  • leave factor and divisor 1, offset 0
  • enter "Lower limit (raw)" "12.3456"
  • set precision to 2
  • if precision where handled as significant digits, the "Lower limit (phys)" value would be changed to "12"
  • actually, precision is handled as decimal places, therefore the value is changed to "12.35"
