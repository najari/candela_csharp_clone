Text Table

A text table maps...

  • numeric raw values "Start", optional different "End"
  • to a an "Assigned Text"
  • and to "Additional Info".

See also the dialog.

Start and End

[TT-R100] The text table is based on numeric raw values:

  • [TT-R100-Start] Start
  • [TT-R100-End] End
  • [TT-R100-Discrete] Start = End denotes a discrete raw value
  • [TT-R100-Range] Start != End denotes a range, with both Start and End included in the range.
    • Note: the text table dialog [TTUI-R110] provides a checkbox to enforce discrete values.
  • [TT-R100-ValueType] the values given for Start and End must fit the Value Type of the text table.
    • e.g. for a data type with a field size (i.e. an array data type), Start and End values are arrays.

Assigned Text

[TT-R110] For a discrete Start value or a range (see above), the text table defines a string Assigned Text.

  • [TT-R110-ML] The Assigned Text is multi-language.

Additional Info

[TT-R120] For a discrete Start value or a range (see above), the text table defines an optional string Additional Info.

  • [TT-R120-ML] The Additional Info is multi-language.

Examples

Discrete raw values:

Value Text
0x00 gear „N“
0x01 gear “1”
... ...

... or a Boolean:

Value Text
0x00 off
0x01 on

Ranges:

Value Text
0x00..0x0F not plausible – below valid range
0x10..0xEF valid
0xF0..0xFF not plausible – above valid range

Combined discrete values and ranges of values:

Value Text
0x00 Switch “off”
0x01 - 0xFF Switch “on”
0x00 Variant “Europe”
0x01 Variant = “US”
0x02 Variant = “Japan”
0x03 Variant = “Asia”
0x04 Variant = “South America“
0x05..0x07 Variant = “invalid”

Inverse Values

If...

  • one line has a range of raw values (Start < End), or
  • multiple lines have the same assigned text T,

... then the inverse conversion from a physical value T to a raw value is ambiguous: it could use any of the involved raw values as a result.

To resolve the ambiguity, each line (assigned text) can have an inverse value (CDS-4979 6.0).

With an inverse value given, the inverse value is used to unambiguously compute a raw value for a given physical value T.

Note: the inverse value is used even if...

  • it is outside the raw value Start/End range of the line, or
  • the raw values are disjoint, i.e. the conversion is reversible.

In the user interface, inverse values must be enabled for each text table individually.
