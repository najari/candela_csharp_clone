Self-Referencing Multiplexer (CDS-37611 8.5 SP2)

A general Multiplexer data type (Mux) defines multiple telegram tables ("Mux cases"), selected at runtime by the value of a selector data object.

A "self-referencing Mux" is a Mux which refers to itself as a selector. In other words, it is a way to describe multiple interpretations of a part of the telegram.

While ODX allows to describe a self-referencing Mux, the CANdela data model does not support it directly.

Use-case

One use-case is to describe invalid values, like

  • 0x00: not installed
  • 0x01: no signal available
  • 0x02 .. 0xFE: valid values
  • 0xFF: value out of range

Alternatives

Actually, to describe such data, ...

  • ODX provides the more appropriate ODX-CONSTRAINTs
  • CANdela provides the "Invalid Values" feature at a data type.

Support in CANdelaStudio

In an ODX based process, you may want to...

  • import ODX data including a self-referencing Mux into a CANdela document and
  • export it back to ODX.

To avoid loss of information, CANdelaStudio (since 8.5 SP2) uses a workaround to store data of an ODX self-referencing Mux:

[DTMUX-R800 Self-Referencing Mux] CANdelaStudio shall represent an ODX self-referencing Mux...

  • [DTMUX-R800-Identity] using an identity data type that takes the role of the selector,
    • [DTMUX-R800-Mux] which indirectly reference a Multiplexer data type that takes the role of the Multiplexer;
    • [DTMUX-R800-Attribute] the indirect reference at the identity data type is represented by a special attribute which contains the qualifier of the Multiplexer;
    • [DTMUX-R800-AttributeDangling] if the attribute value is non-empty but does not denote a Mux qualifier, the identity data type shall not be treated as a self-referencing Mux.
    • This situation may arise e.g. when you copy the identity data type but not the Mux to another document.
  • [DTMUX-R800-Import] ODX import shall represent an ODX Mux using such a data object (CDS-39873);
  • [DTMUX-R800-Export] ODX export shall reconstruct the self-referencing Mux in ODX from the data object;
  • [DOUI-R800] the CANdelaStudio user interface shall provide special support.
