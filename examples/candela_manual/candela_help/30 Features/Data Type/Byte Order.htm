Byte Order

The byte order at a data type specifies

  • for values defined for the data type
  • e.g. at a data object
  • how the value (i.e. a bit sequence)
  • is mapped from/to a byte sequence
  • e.g. for transport on the line.

For details about this mapping, see the chapter Bit and Byte Positions.

[BO-R100] Byte order applies to...

  • integer values with size > 1 byte,
    • at data types with quantity atom.
    • If the data type has quantity field, the optional attribute "ReverseBitFieldBytes" may be used instead.
  • 2 byte (i.e. Unicode) character values,
    • i.e. to each element in a data type with quantity field.

[BO-R110] For the type of physical values, the byte order property...

  • is not relevant since it is implicitly given by the test system.
  • For identity data types, it must be identical to the byte order of the coded value type.
  • For all other data types, it may differ from that of the coded value type.
