Display Format

[DTDF-R100] The display format controls how data is presented to the user.

  • ... as opposed to the encoding [DTENC-R100]
  • which defines the convention how data is stored in memory and transported on the line.
  • See also chapter "Encoding and Display Format" [DTDEP-R120].

[DTDF-R110] Possible values:

Display Format Description Example
hex [DTDF-R110-hex] hexadecimal, base 16, digits 0..9 and A..F 0xFF
dec [DTDF-R110-dec] decimal, base 10, digits 0..9, minus -1
oct [DTDF-R110-oct] octal, base 8, digits 0..7 o377
bin [DTDF-R110-bin] binary, base 2, digits 0..1 %11111111
float [DTDF-R110-flt] floating point, digits 0..9 and decimal point 3.1415
text [DTDF-R110-txt] Ascii or Unicode character(s) "VIN"

Example 1 for Unsigned and Ascii

Bits in memory Encoding Value per display format Meaning
0010 0000 unsigned dec 32 integer decimal 32
" " hex 0x20 dito
" ascii text " " " " (space character)

Example 2 for Unsigned and Ascii

Bits in memory Encoding Value per display format Meaning
1001 0000 unsigned dec 144 integer decimal 144
" " hex 0x90 dito
" signed dec -112 integer decimal -112
" " hex 0x901 dito
" BCD dec 902 integer decimal 90
(internally saved as 0x90 = dec 144)
  • for a one byte value, -112 becomes 0x90;
  • for a two byte value, -112 becomes 0xFF90 (cf. CDS-38828).
