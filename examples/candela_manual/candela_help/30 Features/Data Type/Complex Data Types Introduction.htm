Complex Data Types Introduction

[CDT-R100] A complex datatype contains data objects (each of which references either a simple or even a complex datatype):

In a document, the use of these complex data types can be restricted by Data Type Authorization.

Complex Data Type Variations

Nesting

A nested complex datatype contains a data object which references another complex datatype.

In a document, the nesting of complex data types can be restricted by Data Type Authorization.
