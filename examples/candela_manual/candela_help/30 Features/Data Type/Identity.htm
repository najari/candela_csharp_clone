Identity

An identity data type (also called “raw values” or “hex dump”) does not actually convert a value from the ECU. The value is just...

  • interpreted using a given encoding (unsigned, signed, bcd, …) and
  • shown using a given display format (dec, hex, bin, oct…).

The coded value type is the same as the physical value type.

See also the dialog.

Examples

Data Type Raw Value Physical Value
High-resolution counter (see below) 0xFFF 4095
Input value of I/O Control 0x3FF 0x3FF
Hash value 0xffeeddcc FF EE DD CC
Decimal hash value 0xffeeddcc 255 238 221 204
Info string 0x415D425E „AaBb“

E.g. high-resolution counter:

  • Encoding: Unsigned
  • Length: 2 bytes
  • Display format: decimal
  • Raw value: 0xFFF
  • Physical value: 4095
