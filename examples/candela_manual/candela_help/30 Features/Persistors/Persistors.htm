Persistors Add-on

Motivation

Due to customer-driven extensions of the CANdela data model, each new release of CANdelaStudio (7.5, 7.0, 5.5…) implements a modified CDD file format, which older CANdelaStudio versions cannot read per se.

Up to CANdelaStudio 3.0, the load/save component delivered with CANdelaStudio and other Vector tools was able to read and write all older file formats (read: down to v1.1, save: 2.0). A tool based on the CANdelaStudio 2.0 format could not read v3.0 CDD files.

Use-cases

  • Migrate data from an older to a current file format when loading file in CANdelaStudio

  • Allow loading newer a file format in other Vector tools (e.g. CANoe; note that in CANoe COM environment no user interaction is possible)

  • Allow loading a newer file format in an older CANdelaStudio (e.g. in case OEM and supplier exchange CDD files, and one of the process partners has not yet updated to the newer CANdelaStudio)

Compatibility

The document migration tries to preserve the structure of the communication (services, data objects).

It cannot in general preserve all additional authoring features. Features which are supported only in a newer version may be dropped or replaced by data structures available in the older versions, so that the net communication is the same.

See the hints about Version Compatibility.
