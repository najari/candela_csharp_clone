Dictionary (CDS-547)

Some manufacturers want to use terms from a central "dictionary" for the diagnostic objects described in a CANdela file.

CANdelaStudio can use such a dictionary in the form of a TMX file, and offer the terms from the dictionary when you edit a name.

See the procedure How to Use a Dictionary.

Dictionary Setup

R001.0 (Frontend): in Ribbon Tab File | Options | Edit

a) provide setting “Path to dictionary file (.tmx)”. Remember the setting in INI file / registry. Default: empty.

b) provide “Reload” button to force reloading of the TMX file, specified in the edit box

c) The user cannot leave dialog when TMX file path is non empty and D002 not fulfilled

Definition D001: two language codes match, if

a) they either match exactly (e.g. “en-US” with “en-US”), or

b) they match based on the language part only (e.g. “en-GB” with “en” or with “en-US”) NOT in 6.5 SP1

Definition D002: the dictionary is available for a document if

a) it is non-empty (= at least one entry from TMX file of R001 has been read), and

b) at least one document language matches (see D001) with at least one language in the TMX file.

D003: attribute “AcceptOnlyTextIDFromDictionary”: see Special Attributes.

R010.0 (Frontend): provide a dialog similar to “Edit translation memory”:

a) title “Select term from dictionary”

b) on top of the list: edit control to filter the list, with button to clear the control. If user enters the filter value, after some time delay (tip: 0.7 sec), apply the filter to the contents of all columns shown in the list (with case-sensitivity according with CDS-15525).

c) On entry of the dialog, set the focus into the filter edit control of b).

d) If the text from the calling edit control matches at least one term (row of the list), then

d1) enter this text in the filter control,

d2) apply the filter (show only matching rows),

d3) select the row that matches all up-to-date translation items from the calling edit control (see R020).

e) If the text from the calling edit control does not match any term, then leave the filter empty.

f) in the list, show all terms / filtered terms from the TMX file specified in R001. Do not allow editing in the list. Allow selection of a single list row.

g) Show the current GUI language in first column. After installation, sort the list by first column and use reasonable column widths. Then remember the sort criteria and the column widths.

h) iff. document supports TextIDs, and TextID mode is “Edit” (not “CompletionOnly”), show a second column “TextID” filled from the TMX file (cells may be empty!).

i) provide buttons “Apply” and “Close” (do not show the other buttons “Add TMX…” etc. shown at the bottom of the “Edit translation memory” dialog).

Dictionary Use

R020.1 (Frontend):

Iff. a dictionary according to D002 is available:

a) add a button “…” (Use icon e.g. dictionary that opens the dialog of R010)

[DICT-R020-a1] in each object property dialog, to the right of the “Name” edit control,

[DICT-R020-a2] in the DTC property dialog for the “Error text”

[DICT-R020-a3] In the TextTable property dialog (e.g. at the right). Enable button when a text table entry is selected and open the dialog for the respective entry when the button is clicked

[DICT-R020-a4] In service property page for shortcut name as in the object property dialog (a1) dialog

c) if user leaves the dialog of R010 with “Apply”, and “AcceptOnlyTextIDFromDictionary” (see D003) exists and is non-zero, CANdelaStudio puts the TextID from the selected TMX entry into the calling dialog, it shall not modify any other property of the translatable object.

d) if user leaves the dialog of R010 with “Apply”, and “AcceptOnlyTextIDFromDictionary” (see D003) does not exist or is zero, CANdelaStudio puts the terms (including TextID) from the selected TMX entry into the calling dialog:

d1. it shall insert any non-empty term (i.e. in different languages) from the TMX entry into the dialog, with uptodate=true, for each TMX TUV element with a language code matching (see D001) the language code in the document.

d2. it shall keep any term that is missing or empty in the TMX entry unchanged in the dialog (even if it is the term for the GUI language), it shall not modify the uptodate flag for this term during “Apply”. If the user modifies the term in the edit control later on, it shall set uptodate=false for all other languages, as usual).

Iff. a dictionary according to D002 is NOT available:

CANdelaStudio shall show a message and shall not open the TMX dialog.

Action Variable

R050.1: “DictionaryPath” variable:

a) CANdelaStudio shall provide a new action variable “DictionaryPath”;

b) when used in a action, CANdelaStudio shall replace the variable by the path described in R001.

c) after an action was executed that used this variable, CANdelaStudio shall reload the TMX file and write an error message if the TMX file does not conform to D002.
