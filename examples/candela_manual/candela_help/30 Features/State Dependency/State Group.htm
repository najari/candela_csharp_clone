State Group

State Groups and States

A State Group is the key element of the State Dependency feature in CANdela. It generalizes the concrete diagnostic uses-cases like "Session" and "Security" and can have any free-text name and qualifier.

State Group Properties

A State Group contains...

  • [STG-R010] the common properties Name, Qualifier and Description
  • attributes [ATTR-R050] since 6.0 (CDS-12713)
  • semantics (see below)
  • an associated Negative Response Code [NRC-R050]
    • shown at the service with a special icon
  • States

Semantics

[STG-R050] a State Group has a predefined semantics for the most frequent use-cases of the state dependency feature:

  • [STG-R050-none]
  • [STG-R050-Session]
  • [STG-R050-Security]
  • [STG-R050-Authorization] (see below)

The predefined semantics allows to clearly detect the concrete diagnostic use-case in any tool that consumes the CANdela data, no matter how you call the State Group.

It is up to you to specify the state transitions consistently, e.g. for semantics "Session", the UDS service 0x10 should change the session state.

Semantics "Authorization" (CDC-43749 9.1)

[STG-R200] when saving a newer file to 9.0 or older, CANdelaStudio stores semantics “Authorization” as semantics “none”.

[STG-R210] when loading a 9.0 or older file...

  • for a state group with qualifier or name “Authorization”
  • for manufacturer != Daimler,
    • CANdelaStudio sets the semantics of a State Group to “Authorization";
  • [STG-R210-D] for manufacturer = Daimler,
    • CANdelaStudio deletes the state group...
    • with a hint to run the plug-in "Update State Group Authorization".
