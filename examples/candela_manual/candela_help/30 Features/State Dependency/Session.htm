Session

Some extended services may only be executed in a certain diagnostic session. CANdelaStudio handles this in a generalized way, using the State Dependency Feature.

Before sending the extended service, a test system needs to establish the required session:

Example: Use of Session in CANoe

  1. Session control: Extended Diagnostic Session
  2. Tester Present
  3. IO Control for ID 0xFD74

Sessions in CANdela

In CANdela documents based on the KWP or UDS protocol, a session has two aspects:

  1. Communication:
    • a diagnostic instance in diagnostic class "Session"
    • KWP: 0x10 - StartDiagnosticSession;
    • UDS: 0x10 - DiagnosticSessionControl;
  2. Service Blocking / State Transition:
    • a state in state group "Session"

You can create the diagnostic instance and the state comfortably by using the Session wizard.
