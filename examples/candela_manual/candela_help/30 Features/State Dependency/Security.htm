Security Level in CANdela

In CANdela documents based on the KWP or UDS protocol, a security level has two aspects:

  1. Communication:
    • two diagnostic instances in diagnostic class "Security Access"
    • The first of the two diagnostic instances requests a random seed value for creating a key ("Request Seed"),
    • whereas the second diagnostic instance transmits the created key back to the ECU ("Send Key"), to unlock it.
    • Both diagnostic instances use the same UDS protocol service (0x27 - SecurityAccess),
    • ... but have different identifiers (Access types).
  2. Service Blocking / State Transition:
    • a state in state group "Security Access"

You can create the diagnostic instances and the state comfortably by using the Security level wizard.

Security Access Data Record

According to UDS, you can optionally send data ("Security Access Data Record") in the "Request Seed" to the ECU. Whether this is supported is specified in the template in the protocol service.

AUTOSAR

See the restriction [STTR-R028] for a service having a transition in state "Locked" of state group "Security Access".
