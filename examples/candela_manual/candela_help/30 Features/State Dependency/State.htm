State

For an introduction, see the State Dependency feature in CANdela.

A State is part of a State Group.

It helps to describe whether execution of a service is blocked or not.

State Properties

A State contains...

  • [ST-R010] the common properties Name, Qualifier and Description
  • attributes [ATTR-R050] since 6.0 (CDS-12713)
  • status authorization (see below)

A State has a relationship with a service, the State Transitions.

State Authorization

A state has the following authorization properties to control editing:

  • [ST-R050 Modifiable] if unset, ...
    • you cannot modify properties of the state in Standard View;
    • you cannot modify some state transitions, see [STTR-R030].
  • [ST-R060 Deletable] if unset, ...
    • you cannot delete the state in Standard View.
