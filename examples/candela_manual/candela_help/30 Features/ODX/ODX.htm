Introduction to ODX

The Open Diagnostic eXchange format (ODX) is an XML-based ISO standard (ISO 22901-1:2008) for describing ECU data relevant for diagnostics.

Vehicle, ECU and tester manufacturers can use the ODX format to describe and exchange diagnostic data. ODX was designed as an open format for data exchange. It is a good choice for joint projects between automotive OEMs.

Vector ODX Mission Statement

Vector supports ODX in all diagnostic-related products, providing a simple and effective way to handle ODX diagnostic data.

Since 2001, Vector is contributing to define the ODX standard in ASAM and ISO working committees. ODX is now released officially as ISO 22901-1:2008. Some automotive OEMs and suppliers are already integrating ODX into their development processes. It is now apparent that in practice the flexibility of the ODX standard leads to different ODX dialects. Vector strives to meet the challenge of supporting these ODX dialects in all phases of the diagnostic process.

ODX Support by CANdelaStudio

CANdelaStudio supports ODX in the form of special consistency checks, import and export functions, and by creating shortcut names and qualifiers.

The CANdelaStudio delivery additionally includes ODXStudio View to display ODX files before import or after export.

ODX and Authoring Guidelines

The ODX specification is flexible, therefore typically an OEM develops an own Authoring Guideline (AGL) and uses it for creating an OEM specific "flavor" of ODX. The OEM specific AGL reduces the flexibility of the pure ODX standard to the set of features required for the OEM specific process.

In CANdelaStudio, the template represents part of the information covered by an AGL. Therefore in order to support a specific AGL in CANdelaStudio ODX import and export, you need...

  • an appropriate CANdela template,
  • a customized ODX Import and
  • a correspondingly customized ODX Export.

To this purpose, Vector provides a customization project.

CANdela Template and ODX RS

ODX Recommended Style (ODX RS) is an authoring guideline that reduces the flexibility of the pure ODX standard to a set of features agreed by multiple OEMs (members of the ASAM - Association for Standardization of Automation and Measuring Systems).

Basically CANdelaStudio is able to import ODX RS data if

  • the structure of the ODX data
  • is compliant with the structure of the template.

So provided there is a template compliant with the ODX RS structure, it is possible to import ODX RS data.

So far, Vector does not provide a template with specific ODX RS settings.
