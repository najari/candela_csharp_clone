Diagnostic Instance

Authorization:

[DIOP-D010] All the following operations are subject to basic restrictions for editing in a diagnostic instance.

[DIOP-R310] Modify Snapshot Numeration Type from Configured to Calculated

  • see data model [DI-R310-Calculated]
  • if UDS Snapshot Records [SR-D130-UDS] exist
    • the operation is not allowed.
  • Depends on authorization "Primary properties modifiable" [DIA-R040-NumerationType], see also [DIOP-D010]

[DIOP-R350] Modify Snapshot Numeration Type from Calculated to Configured

  • see data model [DI-R310-Configured]
  • no further action
  • as a result,
    • no configured UDS Snapshot Records will exist (as before)
    • the number of Snapshot Records to Store per DTC [DTC-R310] is lost.
  • Depends on authorization "Primary properties modifiable" [DIA-R040-NumerationType], see also [DIOP-D010]

Compare View: Transfer of Complete Diagnostic Instance

When you check the entire diagnostic instance, Compare View...

  • transfers the different type and
  • transfers all dependent information (Snapshot Records list, "to Store" information).

When you un-check any of the properties in the diagnostic instance subtree, Compare View...

  • shows the type difference
  • shows the difference in Snapshot Records list contents
  • shows the "to Store" information as separate subtrees (checkboxes vs. numbers)
  • transfers the actually checked data only
  • allows transfer of the type difference
    • adds/deletes Snapshot Records
    • resets the "to Store" information to default (all checked / default for the number)
    • does not try to derive detail info, e.g. does not compute the "Calculated" number from the maximum checked Snapshot Record Number (wait for customer input)
  • does not allow individual transfer of the dependent information (Snapshot Records list, "to Store" information).
    • Only after the type difference has been transferred, you can individually transfer the dependent information.

Snapshot Record

[SROP-R100] Creating a new Snapshot Record

  • with given Snapshot Record Number and Protocol
  • If this is the first Snapshot Record for OBD on UDS, CANdelaStudio creates the OBD on UDS Snapshot Data [SR-R200-OBDonUDS], with...
    • empty DID lists
    • no Specific Snapshot Data
    • for all DTCs, Snapshot Record to Store due to [SR-R300-Default]
  • Depends on authorization "Primary properties modifiable" [DIA-R040-SnapshotRecord], see also [DIOP-D010]
  • Creating an UDS Snapshot Record [SR-D130-UDS] is not allowed for Snapshot Numeration Type "Calculated" [DI-R310-Calculated].

[SROP-R110] Deleting one or multiple Snapshot Records:

  • If the operation deletes the last Snapshot Record for a Protocol, CANdelaStudio deletes all Snapshot Data for the Protocol [SR-R200].
  • Depends on authorization "Primary properties modifiable" [DIA-R040-SnapshotData], see also [DIOP-D010]

[SROP-R120] Modifying Snapshot Record Name / Qualifier

  • Depends on authorization "Primary properties modifiable" [DIA-R040-SnapshotRecord], see also [DIOP-D010]

[SROP-R130] Modifying further Snapshot Record Properties

  • Properties:
    • Description
    • Trigger, customTrigger
    • Updated
    • Attributes
  • Depends on authorization "Secondary properties modifiable" [DIA-R050-SnapshotRecord], see also [DIOP-D010]

Snapshot Data

[SROP-R200] Move DIDs up

  • moves a continuous sequence of DIDs up (to the front) one position in a Snapshot Data Case [SR-R240].
  • not possible if...
    • the selection contains the first DID
    • the selection is not continuous (i.e. has not selected DIDs in between)
  • Depends on authorization "Primary properties modifiable" [DIA-R040-SnapshotData], see also [DIOP-D010]

[SROP-R210] Move DIDs down

  • moves a continuous sequence of DIDs down (to the back) one position in a Snapshot Data Case [SR-R240].
  • not possible if...
    • the selection contains the last DID
    • the selection is not continuous (i.e. has not selected DIDs in between)
  • Depends on authorization "Primary properties modifiable" [DIA-R040-SnapshotData], see also [DIOP-D010]

[SROP-R220] Add DIDs to Common Snapshot Data

  • Adds DIDs to...
    • Common Snapshot Data [SR-R230-Common],
    • keeping them unique [SR-R240-Unique].
  • [SROP-R220-OnlyCommon] If any of the added DIDs was used in Default Snapshot Data or Overridden Snapshot Data of the Protocol,
    • then the operation removes it there.
    • Motivation: preserve condition [SR-R230-OnlyCommon].
  • Depends on authorization "Primary properties modifiable" [DIA-R040-SnapshotData], see also [DIOP-D010]

[SROP-R230] Remove DIDs from Common Snapshot Data

  • Removes DIDs from Common Snapshot Data [SR-R230-Common].
  • Depends on authorization "Primary properties modifiable" [DIA-R040-SnapshotData], see also [DIOP-D010]

[SROP-R225] Add DIDs to DTC Specific Snapshot Data

  • Adds DIDs to...
    • Default Snapshot Data [SR-R230-Default] or
    • Overridden Snapshot Data [SR-R230-Overridden],
    • keeping them unique [SR-R240-Unique].
  • [SROP-R225-OnlyCommon] If any of the DIDs is used in Common Snapshot Data of the Protocol,
    • then the operation skips it.
    • Motivation: preserve condition [SR-R230-OnlyCommon].
    • Note: the user interface should avoid this.
  • Depends on authorization "Primary properties modifiable" [DIA-R040-SnapshotData], see also [DIOP-D010]

[SROP-R235] Remove DIDs from DTC Specific Snapshot Data

  • Removes DIDs from
    • Default Snapshot Data [SR-R230-Default] or
    • Overridden Snapshot Data [SR-R230-Overridden]
  • Depends on authorization "Primary properties modifiable" [DIA-R040-SnapshotData], see also [DIOP-D010]

[SROP-R250] Reset Overridden Snapshot Data to Default

  • Removes the Overridden Snapshot Data [SR-R230-Overridden] Case
  • Depends on authorization "Primary properties modifiable" [DIA-R040-SnapshotData], see also [DIOP-D010]

Snapshot Record to Store for DTC

[SROP-R260] Check "to Store"

  • Sets "Snapshot Record to Store for DTC" [SR-R300] to true for the given DTC and Snapshot Record
  • Depends on authorization "Primary properties modifiable" [DIA-R040-SnapshotData], see also [DIOP-D010]

[SROP-R265] Un-check "to Store"

  • Same as previous operation, but setting to false.

[SROP-R270] Set the MaxSsrNum

  • Sets the MaxSsrNum [DTC-R310] for the given DTC
  • Depends on authorization "Primary properties modifiable" [DIA-R040-SnapshotData], see also [DIOP-D010]
