Enable ODX Mode (CDS-5907 5.0)

Use-Case

Prepare a template or document for use with ODX.

Solution Overview

The plug-in creates attributes needed for describing specific ODX-related properties.

Specification

[PEnODX-R001.0]: the plug-in creates attributes required for ODX mode...

  • for any manufacturer
  • plug-in file name: "Enable ODX mode"

[PEnODX-R004.0]: Plug-in name: "Enable ODX Mode"

[PEnODX-R002.0]: the plug-in creates attributes with category "ODX".

[PEnODX-R002-a0] For each of the attributes described below: if the attribute already exists, the plug-in leaves it unchanged.

[PEnODX-D001 ODX Link] Definition "ODX Link" := 3 attributes

  • [PEnODX-D001-DOCTYPE]
    • Enum attribute
    • qualifier ends with "DOCTYPE"
    • name ends with "DOCTYPE"
    • enumeration: 0 = CONTAINER, 1 = LAYER
    • default of enumeration: 0 = CONTAINER
  • [PEnODX-D001-DOCREF]
    • non-translatable string attribute:
    • qualifier ends with "DOCREF"
    • name ends with "DOCREF"
  • [PEnODX-D001-ID_REF]
    • non-translatable string attribute:
    • qualifier ends with "ID_REF"
    • name ends with "ID-REF"

[PEnODX-R002-a DIAG-LAYER]

  • Service Enum attribute
  • is visible
  • not modifiable in standard mode
  • qualifier = "DIAG_LAYER"
  • name = "DIAG-LAYER"
  • enumeration of:
    • 0 = not specified (default value)
    • 1 = PROTOCOL
    • 2 = FUNCTIONAL-GROUP

[PEnODX-R002-b]

  • ECU non-translatable String attribute
  • is visible and modifiable in standard mode
  • qualifier = "FUNCTIONAL_GROUP_SHORT_NAME"
  • name = "FUNCTIONAL-GROUP.SHORT-NAME"

[PEnODX-R002-c] ECU non-translatable String attribute

  • is visible and modifiable in standard mode
  • qualifier = "PROTOCOL_SHORT_NAME"
  • name = "PROTOCOL.SHORT-NAME"

[PEnODX-R002-d1] ECU "ODX Link" [PEnODX-D001] attributes for Base Variant:

  • is visible and modifiable in standard mode
  • DOCTYPE:
    • qualifier "BASE_VARIANT_PARENT_REF_DOCTYPE"
    • name "BASE-VARIANT.PARENT-REF.DOCTYPE"
  • DOCREF:
    • qualifier "BASE_VARIANT_PARENT_REF_DOCREF"
    • name "BASE-VARIANT.PARENT-REF.DOCREF"
  • ID-REF:
    • qualifier "BASE_VARIANT_PARENT_REF_ID_REF"
    • name "BASE-VARIANT.PARENT-REF.ID-REF"

[PEnODX-R002-d2] ECU "ODX Link" [PEnODX-D001] attributes for Functional Group:

  • is visible and modifiable in standard mode
  • DOCTYPE:
    • qualifier "FUNCTIONAL_GROUP_PARENT_REF_DOCTYPE"
    • name "FUNCTIONAL-GROUP.PARENT-REF.DOCTYPE"
  • DOCREF:
    • qualifier "FUNCTIONAL_GROUP_PARENT_REF_DOCREF"
    • name "FUNCTIONAL-GROUP.PARENT-REF.DOCREF"
  • ID-REF:
    • qualifier "FUNCTIONAL_GROUP_PARENT_REF_ID_REF"
    • name "FUNCTIONAL-GROUP.PARENT-REF.ID-REF"

[PEnODX-R002-e] Diagnostic Class Enum attribute

  • is visible and modifiable in standard mode
  • qualfier "Export_as_TABLE"
  • name "Export as TABLE"
  • enumeration: 0 = no, 1 = yes
  • default of enumeration is: 0 = no

[PEnODX-R002-f] Data Type "ODX Link" attributes

  • DOCTYPE, DOCREF, ID-REF see [PEnODX-D001] above
  • is visible
  • not modifiable in standard mode

[PEnODX-R002-i] DTC "ODX Link" attributes

  • DOCTYPE, DOCREF, ID-REF see [PEnODX-D001] above
  • is visible but not modifiable in standard mode

[PEnODX-R002-k1] DTC integer attribute for error code

  • not visible in standard mode
  • qualifier "Source_Error_Code"
  • name "Source Error Code"

[PEnODX-R002-k2] DTC non-translatable string attribute for error text

  • not visible in standard mode
  • qualifier "Source_Error_Text"
  • name "Source Error Text"

[PEnODX-R002-L] ECU Enum attribute "ODX Mode" (CDS-5625 5.0)

  • is visible in standard mode and modifiable
  • qualifier "ODX_Mode_Enabled"
  • name "ODX Mode Enabled"

[PEnODX-R002-m] Service non-translatable attribute for ODX SHORT-NAME

  • is visible in standard mode and modifiable
  • qualifier "DIAG_SERVICE_SHORT_NAME"
  • name "DIAG-SERVICE.SHORT-NAME"

[PEnODX-R002-n] DataType Enum attribute for STATIC-FIELD

  • not visible in standard mode
  • qualfier "Is_STATIC_FIELD"
  • name "Is STATIC-FIELD"
  • enumeration: 0 = no, 1 = yes
  • default of enumeration is: 0 = no

[PEnODX-R005.0 Units] The plug-in...

  • creates the Units attribute
  • ... and adds the following SI units to the attribute:
    • m (=0)
    • kg (=1)
    • s
    • A
    • K
    • mol
    • cd (=6)

[PEnODX-R003.0]: after creating the attributes, the plug-in enables "ODX mode" by setting the ECU Enum attribute [PEnODX-R002-L] (above).
