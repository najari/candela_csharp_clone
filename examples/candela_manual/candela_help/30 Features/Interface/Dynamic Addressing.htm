Dynamic Addressing

Use Case

Support for UDS on ECUs that use Dynamic Addressing is a requirement for...

  • ECUs on an ISO 11783 (ISOBUS) and
  • optional for ECUs on a J1939 bus.

With dynamic addressing, ECUs do not have a statically defined address. Each ECU goes through an “Address Claiming” process upon start up. The address claimed is valid for that ignition cycle only.
