Services Supported for Interfaces (CDS-22520 7.5)

See also the user interface.

Services Supported for Interfaces

Use-Cases

  • describe OBD and Enhanced diagnostic services in one document, restricting OBD services to the OBD interface
  • describe K-Line services (Start/Stop) not available for a CAN interface
  • distinguish LIN services
  • describe services available in a flash bootloader via a specific interface
  • evaluate the restriction in CANoe.DiVa

Data Model

[SSI-R100] The feature specifies whether...

  • a Used Protocol Service
  • is supported by a given Interface or not.

[SSI-R110] The default is "yes".

Consistency Condition

[LCP-R200] If a “Used Protocol Service” is not supported for an Interface, you cannot specify communication parameters of the Interface locally at a Service based on the “Used Protocol Service”.

Migration

See down migration [MIG75-R200] and up migration [MIG75-R210].

Uses of the Information

The information is listed in the report [RP-R175].
