CAN FD

Introduction

CAN FD (CAN with flexible data rate) has been standardized in ISO 11898-1:2015. It allows...

  • longer data (up to 64 bytes)
  • optionally switching to a faster bit rate for the data phase

Support in Vector tools

  • CANdelaStudio: CAN FD support is a matter of having...
    • the required communication parameters,
    • maybe in a separate interface.
    • Both can be created in the Expert View by the template expert.
  • The Vector UDS Template contains CAN FD interfaces (CDS-41638 9.0)
  • CANdelaStudio ODX Export supports export of the required communication parameters to ODX since 2017-01 (CDS-41701 8.2 SP2)
  • Vector diagnostic test systems support CAN FD
    • vFlash: 2.6 / 3.0 for ISO CAN FD
    • Indigo: 4.5
    • D-PDU API: 1.0 SP3.
  • Newer Vector Informatik network interfaces support CAN FD.

Communication Parameters

Parameter Comment
CP_CANFDBaudrate TP layer
CP_CANFDBitSamplePoint TP layer
CP_CANFDSyncJumpWidth TP layer
CP_CANFDTxMaxDataLength Physical layer. Value != 0 enables CAN FD.
CanFdDataBaudrate ODX Export 8.2 SP3 (CDS-41701): CAN FD is present if the interface contains this parameter.
CanFdBrsHandling (Vector toolchain) deprecated, bit rate will be switched directly in CAPL for individual PDUs without having a ComParam.
CanFdHandling (Vector toolchain) deprecated, was used by older Vector tools to enable CAN FD, before the officical PDU API qualifiers had been defined.
