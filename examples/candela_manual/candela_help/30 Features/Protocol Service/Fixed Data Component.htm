Fixed Data Component

Fixed Data is the position where data objects fixed in the template (= fix in all diagnostic instances) can be placed.

Fixed data may occur at any position after the protocol service signature with the following exception:

[FD-R200] If the component contains a data object with variable length, no further components may follow (cf. CDS-4167).

[FD-R210] In a fixed data component, ...

  • if enabled by Authorization setting [DLA-R060],
  • then CANdelaStudio allows variable length data objects of deterministic length [DTL-D120] at all places (CDS-70854 v13).
