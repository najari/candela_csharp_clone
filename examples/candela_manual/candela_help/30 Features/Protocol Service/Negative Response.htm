Negative Response (Primitive in Protocol Service)

Constraints

  • Only the negative response primitive can contain a proxy component with destiny resCode.
  • It must have exactly one such proxy component.
  • It must not contain proxy components of any other destiny.
  • The proxy component must
    • be mandatory,
    • have a minimum and a maximum bit length
    • both lengths must be equal.
