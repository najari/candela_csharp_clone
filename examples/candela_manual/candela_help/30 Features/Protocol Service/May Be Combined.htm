May Be Combined (of Protocol Service)

Use-case

The test system wants to combine multiple data services (0x22) into one:

  • The test system enumerates identifiers from multiple service Requests in a combined Request.
  • The ECU responds with an combination of the according positive responses.

Example

Request: 
  0x22 0x40 0x01  0x40 0x02  0x40 0x03

Positive Response: 
  0x62 0x40 0x01 (2 bytes data objects1...)
       0x40 0x02 (4 bytes data objects2...) 
       0x40 0x03 (1 byte data objects3...)

"May be Combined" in CANdela

[PS-R610] A Protocol Service has a flag "may be combined".

  • CANdelaStudio shows the flag in the "Extended" page of the Protocol Service property dialog.
  • For code generation, you may specify the maximum number of identifiers, see Multiple Identifier Request.

Effect

  • If "may be combined" is true,
  • then in all Diagnostic Instances...
  • within a Diagnostic Class that uses [DCLT-R305] this Protocol Service,
  • a tester...
    • allows to combine multiple Requests
    • and accepts multiple combined Responses.

Definition of the Combined Request

The combined Request consists of:

  • If the Request in the Protocol Service starts with one or multiple Constant Components [PS-R300] (typically the ServiceID 0x22):
    • the entire Request of the first Service,
    • followed by the other Services, with only the Components following the initial Constant Components
      • (typically the Variable Value [PS-R400] for the Identifier [DID-R025]).
    • E.g. 0x22 0x40 0x01 - 0x40 0x02 - 0x40 0x03.
  • If the Request does not contain an initial Constant Component:
    • all entire Requests combined.
  • The Requests are considered in the order of the Diagnostic Instances in the document.

Denied Services

For a combined...

  • physical Request:
    • if at least one of the identifiers fails,
    • the entire Request gets a negative response;
  • functional Request:
    • if one of the identifiers fails,
    • the negative response for the identifier is simply suppressed.

Availability in Vector tools

  • in CANape since 17.0 SP3.

"May be Combined" in ODX

  • ODX has no corresponding flag.
  • You may express the combination by iteration.

No Relation with "hasMultipleResponses"

"May be combined" is not related with "hasMultipleResponses" [PS-R720].
