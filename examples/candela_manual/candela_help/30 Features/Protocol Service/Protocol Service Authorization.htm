Protocol Service Authorization

Introduction

A Protocol Service...

  • has authorization properties only for Services based on the Protocol Service:
    • for the addressing properties;
  • has no authorization properties for editing itself:
    • it is part of the template,
    • so you cannot modify it in Standard view, anyway.

Addressing Authorization

The following Protocol Service properties define the modifiability of the addressing properties at services based on the Protocol Service:

Authorization Property Description
Physical request
"Test system sends physical request" modifiable
 [PS-R840] if true,
and a positive response primitive exists:
the user may modify "Test system sends physical request" [PS-R740]
and "The test system shall set the SPRMIB..." [PS-R750].
"ECU sends a response" modifiable
 [PS-R850] if true,
and a positive response primitive exists,
and "Test system sends physical request" is true:
the user may modify "ECU sends a response" [PS-R760].
Functional request
"Test system sends functional request" modifiable
 [PS-R845] (dito for a functional request)
"ECU sends a response" modifiable
 [PS-R855] (dito for a functional request)

Default values for the authorization properties are true.
