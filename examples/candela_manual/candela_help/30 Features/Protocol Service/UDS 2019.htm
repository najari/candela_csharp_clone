UDS 2019

As of 2019-09, CAN UDS 2019 (ISO 14229-1 2019(E)) is in state FDIS, not yet released as an ISO Standard.

The Vector UDS Template contains...

  • data types and DIDs for new data identifiers, see e.g.
    • UDS Version [VUDS-R350]
    • CAN Protocols Supported [VUDS-R360]
  • the 0x29 Authentication Protocol Service [VUDS-R8290]

Major Changes

  • New Diagnostic Service "0x29 Authentication"
    • Authentication with PKI Certificate Exchange (APCE)
    • Authentication with Challenge Response (ACR)
    • Transmit Certificate
  • Reworked Response On Event
    • New subfunctions
    • Clarified behavior
