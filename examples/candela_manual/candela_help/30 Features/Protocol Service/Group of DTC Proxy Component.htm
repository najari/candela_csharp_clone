Group of DTC Proxy Component

In a ProtocolService, a Group of DTC Proxy Component represents a place where a group of DTCs is specified, typically DTC values with some bits set zero, like 0x400000, 0x800000.

  • the Proxy Component references a "master" text table
    • The length of the proxy is taken from the datatype.
  • the text table defines the set of groups
  • CANdelaStudio supports at most 16 groups
  • in a diagnostic instance, a Group of DTC Data Object corresponds with the Proxy Component.

See the overview diagram in the Group of DTC Data Object chapter.
