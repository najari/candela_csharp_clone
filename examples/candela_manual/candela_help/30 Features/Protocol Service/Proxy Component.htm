Proxy Component

Overview

A Proxy Component represents a set of data objects. Typically, the diagnostic specification (like UDS) uses lists of data elements for the transmission of the actual data content. Proxy Component indicates the position in the Primitive (request, ...) where data objects may be placed in a diagnostic instance (telegram table).

Combined Proxy Component

Several Proxy Components may be combined (shared) in a Diagnostic Class Template, e.g.

  • a Proxy Component from the positive response of "reading" Protocol Service may be shared with
  • a Proxy Component from the "writing" Protocol Service Request.

The sharing is expressed by using one Combined Proxy Component in the Diagnostic Class Template associated with the respective Proxy Components in the Protocol Services.

Semantics Property

[PC-R100 Proxy Semantics] The Semantics property controls the kind of user interface for the data objects.

Semantics Description
any Represents a kind of "variable" telegram part where the value can neither be given as a constant during data entry in CANdelaStudio, nor can be described by a data object.
Note: after a Proxy Component with semantics any and variable bit length, no further Components may be present!
data Represents telegram table with data objects in the diagnostic instances
dtc
obdDtc		 [PC-R050-dtc] Represents Diagnostic trouble codes (DTCs), 3 bytes length.
[PC-R050-obddtc] Represents OBDII Diagnostic trouble codes (DTCs), 2 bytes length.
[PC-R050-dtcErrorCodeTable] Both Require an Error Code Table of the same byte size as the proxy component.
envData Represents a telegram table with environment data (Snapshot Data) in the diagnostic instances (the "generic way" with Multiplexer).
sr [PC-R050-sr] Represents a Snapshot Record Number (1 byte) (v13 AUTOSAR Fault Memory, CDS-71541);
in a diagnostic instance complemented by a list of Snapshot Records [SR-R030], a text table like data structure.
[PC-R050-srUse] If a Primitive contains an sr proxy component, it may not contain an sd component.
[PC-R050-srUnique] A Primitive may contain at most one sr proxy component.
sd [PC-R050-sd] Represents Snapshot Data (v13 AUTOSAR Fault Memory, CDS-71541);
in a diagnostic instance complemented by Snapshot Record Data [SR-R200], a Multiplexer like data structure (with DTC as selector, additionally distinguishes UDS / WWH-OBD etc.).
[PC-D050-sdsrUse] If a Primitive contains an sd proxy component, it must also contain an sr proxy component.
[PC-D050-sdUse] If a Primitive contains an sd proxy component, it should also contain a dtc or obdDtc component.
The dtc/obdDtc component provides the Selector for the Cases in the Snapshot Data [SR-R200].
[PC-R050-sdNoDtc] ... but the Primitive may not contain a dtc/obdDtc component, see [SR-D240-RuntimeNoDTC].
[PC-R050-sdUnique] A Primitive may contain at most one sd proxy component.
[PC-R050-sdMux] A Primitive must not contain both an sd proxy component and a Multiplexer component.
edr [PC-R050-edr] Represents Extended Data Records (v13 AUTOSAR Fault Memory, CDS-71541)
[PC-R050-edrUnique] A Primitive may contain at most one edr proxy component.
ed [PC-R050-ed] Represents Extended Data (v13 AUTOSAR Fault Memory, CDS-71541)
[PC-D050-ededrUse] If a Primitive contains an ed proxy component, it must also contain an edr proxy component.
[PC-R050-edUnique] A Primitive may contain at most one ed proxy component.
resCode Represents negative response codes (NRCs)
groupOfDtc Represents Group of DTC information, see the Group of DTC Proxy Component
dtcStatus Represents the DTC Status, see the DTC Status Proxy Component

Within one Primitive, some values of Semantics may occur at most once (it is not possible to have e.g. two Proxy Component with Semantics "dtc" within one request).

Semantics "Any"

A Proxy Component with Semantics "any" does not have a Combined Proxy Component, i.e. it has no representation in the Diagnostic Class Template and Diagnostic Instances.

Proxy Components with semantics "any" that have variable length are only allowed as last Component in top-level of any Primitive (request,...). If this conditions fails, this is a non-fatal error.

Simple Proxy Component

A Simple Proxy Component is the position where a Combined Proxy Component is to be attached in a Diagnostic Class Template, which allows placing a possibly shared telegram table (a list of data objects, which describes values dynamically appearing in a test system) within a diagnostic instance.
