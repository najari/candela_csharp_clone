UDS 2013

UDS 2013 (ISO 14229-1 2013(E)) has few differences in ProtocolServices compared with UDS 2005 (ISO 14229-1 2005(E)):

  • service 0x10: P2 timing record mandatory and only as a P2 record allowed (bus system independent);
  • service 0x19: subfunctions 0x16..0x19 and 0x42 added;
  • service 0x22 and 0x2A: NRC 0x31 only sent when none of the requested DIDs is supported in the active session, not when a single DID is not supported (which is simply skipped);
  • service 0x23 and 0x3D: NRC 0x31 on zero "BlockSize" parameter length;
  • service 0x28: subfunctions 0x04 and 0x05 are valid;
  • service 0x2A was also allowed as USDT (single frame only) in UDS 2005, now it is allowed on UUDT only. This may require an additional communication parameter for UUDT in the template;
  • service 0x31: NRC flow chart detailed;
  • new service 0x38 Request File Transfer;
  • addressing method functional/physical: a server shall execute any supported diagnostic service independently on the request addressing type;
  • on functional request, besides NRCs 0x11, 0x12, 0x31, also NRC 0x7E and 0x7F not suppressed;
  • concurrent client request handling defined.
