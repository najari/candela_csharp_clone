Constant Component

[PS-R300] A Constant Component represents...

  • a constant value
  • predefined in the template (it is not changeable in the document)
  • the constant value has a symbolic name
  • used e.g. for ServiceID

“Specification” Property

[PS-R300-Specification Constant Component "Specification"] The following values are available for the "Specification" property:

  • Service ID
  • Subfunction
  • Status
  • Identifier
  • None (CDS-27480 8.0)
