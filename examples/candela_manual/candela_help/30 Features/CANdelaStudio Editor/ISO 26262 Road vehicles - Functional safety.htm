ISO 26262 Road vehicles – Functional safety

For CANdelaStudio and ODXStudio a tool confidence level TCL1 can be determined, therefore no tool qualification according to ISO 26262 is necessary. Rationale:

  1. The diagnostic protocol does not implement safety-related functionality. It can only parameterize such functionality. The application of the ECU determines to what extent these parameters influence the behavior of the ECU. The application of the ECU is responsible for ensuring that any faults that could jeopardize functional safety are properly handled. An authoring tool such as CANdelaStudio or ODXStudio takes no responsibility for this (Tool Impact TI1).

  2. The probability of detecting a diagnostic error by a simple test is very high (Tool Error Detection TD1).

German version:

Für CANdelaStudio und ODXStudio kann ein Tool Confidence Level TCL1 ermittelt werden, daher ist keine Toolqualifizierung gemäß ISO 26262 notwendig. Begründung:

  1. Das Diagnoseprotokoll implementiert keine sicherheitsrelevante Funktionalität. Es kann lediglich solche Funktionalität parametrisieren. Die Applikaton der ECU bestimmt, inwieweit diese Parameter das Verhalten der ECU beeinflussen. Die Applikation der ECU ist verantwortlich dafür, dass alle Fehler, die die funktionale Sicherheit gefährden könnten, ordnungsgemäß behandelt werden. Ein Authoring Tool wie CANdelaStudio oder ODXStudio übernimmt hierfür keine Verantwortung (Tool Impact TI1).

  2. Die Wahrscheinlichkeit, einen Diagnosefehler durch einen einfachen Test zu erkennen, ist sehr hoch (Tool Error Detection TD1).
