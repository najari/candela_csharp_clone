Logging

During execution, CANdelaStudio logs messages...

  • that can be written to a text file ("logfile"), and
  • that can be shown in the Output Window.

like...

Info 12:36:14.84 CANdelaStudio Executing command 'notepad.exe CANdelaStudio.log'.

Typical messages are...

  • error messages and warnings e.g. from the consistency check
  • info about long-running operations
  • the result of a search with "Find All" [SRCH-R200]
  • detailed internal status info.

To configure this feature, use the property page Logfile and the Output Window toolbar [OW-R500].

Message Type

[LOG-R100] Each logging message has a type (or "level", "severity"):

Message Type Example
Error Data constellation that prevents from exporting
Warning Invalid data constellation that should be repaired.
Info The name of the variant currently processed in an export.
Status Internal state information helpful for debugging.

Timestamp

[LOG-R110] Time when the message was created (hour, minute, second, millisecond), like 12:36:14.842.

CANdelaStudio records this property independent of option [OPT-R640].

Origin

[LOG-R120] Origin - a functional part of CANdelaStudio:

Origin Description
CANdelaStudio Functionality in general, user interface
ImExport Import, export, plug-ins
Search Search result (from the Find dialog [SRCH-R200])

Link

[LOG-R130] A message optionally references an object in a CANdela document.

  • [LOG-R130-Remove] When you close a document, CANdelaStudio removes all links into this document from the messages.

Logfile

CANdelaStudio optionally clears the logfile at start-up, see option [OPT-R630].

The logfile includes the time stamps [LOG-R110] only if enabled by option [OPT-R640].

Path

[LOG-R200] The path of the logfile is...

  • defined in the options dialog [OPT-R620];
  • by default (e.g. for 8.5) C:\Users\USERNAME\AppData\Local\Vector\CANdelaStudio\8.5\CANdelaStudio.log
  • stored in CANdelaStudio.ini

Example Contents

----------------------------------------------------------------
Start of logging 2016-04-18 11:41:31 encoding='utf-8'
----------------------------------------------------------------
[11:41:31.496] D: Start of logging:
[11:41:31.496] I: Running C:\Program Files (x86)\Vector CANdelaStudio 8.2\Bin\CANdelaStudio.exe v8.2.3100.0

Level Indication

CANdelaStudio writes the message type [LOG-R100] abbreviated to one character:

Message Type Abbreviation
Error E
Warning W
Info I
Status D
