Expert View

Introduction

CANdelaStudio provides multiple Views which are enabled depending on the CANdelaStudio Edition you are using.

The Expert View is available in the Admin edition only, specified in the Open Page [OPEN-R010].

It is used to edit a CANdela Document Template.

A running CANdelaStudio application shows its edition in menu Help|About [MENU-R1270].

For a document opened in Expert View, the title line of CANdelaStudio shows the suffix -- Expert View --.

Specific Operations

Expert View (as opposed to Standard View) allows...

  • to modify template data, see the Document Template chapter.
  • to delete individual revision entries [REVUI-R200-Delete]
