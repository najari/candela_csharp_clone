Keyboard Shortcuts

See also the Ribbon Key Tips.

Shortcut Functional description
Alt Displays the ribbon key tips
F1 Opens the online help.
Ctrl+F1 Minimizes/expands the ribbon
F2 Starts edit mode for the selected cell of a table. Some tables support this even for multiple rows.
F6 Switches back and forth between Tree view and the entry mask and sets the insertion pointer on the current section or input box.
Shift+F6 Behaves just like F6.
Ctrl+F6 Switches to the next open document window.
F9 Checks the consistency of the currently opened document.
Ctrl+C Copies an element or portion of text to the clipboard.
Ctrl+D Moves selected elements down in a list, like [MENU-R485].
Ctrl+N Generates a new document based on the previously used template.
Ctrl+O Brings up the file dialog for opening a document.
Ctrl+R Inserts an element from the clipboard into the document as a reference.
Ctrl+S Saves the current document.
Ctrl+U Moves selected elements up in a list, like [MENU-R480].
Ctrl+V Inserts an element or portion of text from the clipboard into the document.
Ctrl+X Cuts an element or portion of text.
TAB In a dialog: navigates to the next cell to the right/bottom.
If you have reached the last cell in the last row of a list: creates a new element.
Shift+TAB In a dialog: navigates to the previous cell to the left/top.
Ctrl+TAB In a dialog: navigates to the next property page.
In a text field: inserts a TAB character.
Del Deletes an element or marked portion of text without placing the element or portion of text in the clipboard.
Shift+Insert Inserts a copied portion of text.
Up arrow Navigates one row up in the table.
Down arrow Navigates one row down in the table.
Left arrow Navigates one cell left in the table.
Right arrow Navigates one cell right in the table.
Page up Navigates one screen page up in the table.
Page down Navigates one screen page down in the table.
ENTER In a dialog: exits the dialog and accepts the modifications.
In cell edit mode: ends edit mode and accepts the modifications.
ESC In a dialog: exits the dialog and discards modifications.
In cell edit mode: ends edit mode and discards the modifications.
In the navigation tree: restores an object that has been cut.
In Full Screen mode e.g. in a DTC list: leave Full Screen mode.
Shift+Arrow Marks multiple contiguous rows of a table.
Ctrl+Arrow Marks multiple non-contiguous rows of a table.
