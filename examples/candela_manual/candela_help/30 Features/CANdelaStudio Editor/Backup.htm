Backup (CDS-1380, 1.3)

When a CANdela file is saved, a backup file is generated in the same directory as the original file. If the backup file cannot be written (e.g. directory or file is write protected), the file is not generated (with a warning in logging).

File name prefix: „Backup Copy of“ (German: „Sicherungskopie von“).

File name extension: *.cbk.

To restore a backup copy to a usable CANdela document, open Windows Explorer and change the file name extension of the backup copy from cbk to cdd.

Note: there is also a backup of the logfile (8.0 SP2, CDS-3749; not described here).

You can disable creation of a backup copy in menu Tools|Options.

See also Auto Save.
