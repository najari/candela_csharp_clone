License Types

CANdelaStudio supports several license types, due to historical reasons.

The Vector License available since CANdelaStudio 9.1 is the current mechanism.

FlexNet License

(also called "Legacy License")

Software Based License

A Legacy License uses the older licensing mechanism:

  • "Legacy" = not the current Vector License which was added with CANdelaStudio 9.1
  • "Local" = the license check accesses only the local trusted storage of FlexNet

There are three possible ways to get such a local license:

  • License Server: License obtained from the Vector license server or a locally installed license server with the Vector License Manager [IBP-R020] (the default mechanism)
  • ASR File: License injected by using the LicenseInjector.exe and an adequate ASR file. This way is still used by some customers and for the preparation of training computers.
  • Pool License: If a "standard" pool license is checked out for three months, this license also resides in the local trusted storage.

Hardware Based License

CANdelaStudio supports license check-out from an installed Vector network iterface (e.g. CANcase) since version 8.0 SP2, for interfaces that support more than 128 license bits:

  • Supported (CDS-30409 8.0 SP2):

    • CANboardXL
    • CANcardXL
    • CANcaseXL
    • Keyman Dongle (CDS-16481, since 7.5). Usage of this dongle requires the installation of the Keyman dongle drivers from the Vector Hardware Driver CD.
    • VN16xx (CDS-32115 8.0 SP3)
    • VN5610
    • VN7570
    • VN7600
    • VN891x

  • Not supported:

    • old blue USB-Dongle
    • CANcardX
    • VN2610
    • DEXT Export since R21 does not accept a hardware license, see [DEXT-R030-HardwarePool].

Pool License (CDS-25243 8.0 SP2)

  • Pool licensing must be activated by a CANdelaStudio.ini parameter ("LicenseType" in section "General").

  • In this case, a second parameter "PoolLicenseEdition" chooses a concrete edition to start.

    Parameter Name Valid Values Description
    LicenseType Per Seat Local licenses shall be used (USB, HW, local Flexnet). Default value.
    Pool Pool licenses shall be used.
    The customer has to run a local license server.
    The parameter "PoolLicenseEdition" chooses a concrete edition to start.
    Education License
    Student License
    Education Campus License
    For LicenseType "Pool":
    PoolLicenseEdition CANdelaStudio Admin Edition to be used (no default value)
    CANdelaStudio Pro
    CANdelaStudio Standard
    CANdelaStudio ViewX
    CANdelaStudio View

In practice IT department of the customer switches all users to pool licensing and enforces the usage of a concrete edition by setting these parameters (e.g. during rollout).

CANdelaStudio Pool License Activation Dialog

If pool licensing is switched on, the user has to checkout his pool license the first time he starts CANdelaStudio. Using the Activation Dialog shown at start-up, the user can check out a "standard" license (and he will keep this license for 3 month) or a "sporadic" license that is only claimed during the time of usage.

Note: DDM since R21 does not accept a FlexNET Pool license, see [DEXT-R030-HardwarePool].

Up to 8.2: Hardware Based License for View Edition

In version 8.0, 8.1 and 8.2, CANdelaStudio checked for Vector Hardware licenses of main versions of the following products (CDS-25244 8.0, CDS-40007 8.5):

  • CANoe
  • CANape
  • CANdito
  • Indigo
  • vTESTstudio (CDS-31362 8.0 SP2, also checks FlexNET license)

It also checked for "old" Vector USB dongle licenses for an installed CANoe, CANape or CANdito (CDS-30942, 8.0 SP2).

It checked for Keyman dongle license of

  • ODXStudio (CDS-29179, 8.0)
  • Indigo, CANoe, CANape (CDS-30309, 8.0 SP1)

If one of these products was licensed via hardware, CANdelaStudio ran as a View Edition ("Bundle View").

Note: CANdelaStudio shows the edition info in Ribbon Tab File | Product Information, section "About", see [MENU-R1270].

Vector License (CDS-40816, 9.1)

In 2017, Vector reworked the licensing terms and conditions and the licensing types:

  • License program:
    • ELA (Enterprise License Agreement)
    • EULA (End User License Agreement)
  • License models:
    • Perpetual
    • Subscription License
  • License types :
    • Device License (can be activated on a PC, a Vector network interface or a dongle),
    • Named User License (can be activated on a PC, a Vector network interface or a dongle. Requires an assignment of the named user prior to activation. Enterprise only. See also Remote Desktop below).

The Vector Licensing Portal helps to...

  • manage licenses and
  • activate software.

On the local computer, the Vector License Client [IBP-R040] manages the licenses.

For details, please contact the Vector Sales team.

[LIC-R600] CANdelaStudio always checks Vector Licenses in addition to Software/Hardware Based Licenses (there is no configuration switch).

For a list of hardware supported for Vector Licenses, see the article Hardware Compatibility With New Vector License Model in the Vector Knowledge Base (link as of 2018-11).

Licensing and Old Versions

Use-case:

  • the manufacturer does not yet use the newest version of CANdelaStudio
  • and wants suppliers to use the same version;
  • but the supplier receives the newest version from Vector.

Solution:

  • A CANdelaStudio license includes the use of older versions.
  • Up to version 8.1, the service packs available on the Vector download center were full versions, usable with the newer license;
    • the supplier could just download and install the service pack.
  • Starting with version 8.2, the service packs availabale on the Vector download center are differential versions, they assume a full version has been installed already;
    • the supplier can get a full version from Vector support.

Licensing Command Line Switches

Edition Selection switch /m

Starts CANdelaStudio in a "lower" edition than the currently licensed one, see [CLI-R100-edition].

Note: The comand line switches /ignoreDongle and /ignoreFlexNet are no longer available (CDS-32094, 8.5). They have been replaced by CANdelaStudio.ini parameters:

Licensing INI File Parameters

R115.0: INI file switches to disable a specific license type

In the CANdelaStudio.ini file in Section "General", parameters allow disabling the check of a specific license type.

Grace Period

From 6.0 SP1 up to before 8.2, CANdelaStudio worked for 2 days without product activation, beginning at first CANdelaStudio start. This was called the "grace period". It allowed instant use of CANdelaStudio after installation. It had no impact on server license versions. (CDS-11342, CDS-29069)

License and Bundling

The CANdelaStudio delivery contains ODXStudio as bundled product, and vice versa. The bundled product runs as a View edition (but you can license it separately for a higher edition).

See also Installation Blocking [CDSMSI-R001].

Start without License

When run without a license, CANdelaStudio starts as View edition (CDS-40007 8.5). This holds independent of...

  • running the CANdelaStudio user interface or in batch mode via Command Line;
  • command line parameters for licensing;
  • INI parameters to disable a specific license type;
  • whether using Pool licensing or not.

Use via Remote Desktop

For a Vector License:

  • Device License:
    • The Terms and Conditions do not permit to use the Product that is licensed with a Device License by remote connection or automated use. This means among others, that the licensed Product never may be operated on a compile server, build server or similar server types.
  • Named User License:
    • The Terms and Conditions permit to use the licensed Product by remote connection or automated use if it is used for the Named User´s own purposes.
    • In case of use by remote connection, this means concretely that such use is only allowed if the Named User operates the Product himself via the remote connection.

Other license types do not permit use via remote desktop.

  • This includes the use on an automation server for „Continuous integration“ e.g. controlled by Jenkins (https://jenkins.io).

Use in a Virtual Machine

For a Vector License:

  • Device License:
    • The Terms and Conditions do not permit to virtualize the Device, to which the Product is assigned.
  • Named User License:
    • The Terms and Conditions do not explicitly mention Virtualization. It is ok for Vector to virtualize a Named User License for the Named User’s own purposes.
