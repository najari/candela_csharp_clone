Introduction

CANdelaStudio Launcher

You can use the CANdelaStudio Launcher to...

  • open a document or template,
    • with selecting the CANdelaStudio version, document language and View,
  • create a document from a template,
  • or just start a specific version of CANdelaStudio without a document or template.

Start

[CDSL-R080]

  • [CDSL-R080-Start] You can start the CANdelaStudio Launcher via the Windows start menu [ISTM-R050].
    • In this case, no file is selected in the Filename control [CDSL-R400].
    • The latest CANdelaStudio is selected in the Version control [CDSL-R100].
  • [CDSL-R080-File] You can start the CANdelaStudio Launcher in Windows Explorer via the context menu of a CANdela file.
    • In this case, the CANdela file is selected in the Filename control [CDSL-R400].
    • The CANdelaStudio version with which the file was saved is selected in the Version control [CDSL-R100].
    • To provide the Launcher in the context menu, start it once with Admin privileges.

Version

[CDSL-R100] The version list shows all installed versions of CANdelaStudio.

  • Default value: see Launcher Start [CDSL-R080].
  • When you specify a file in the Filename control [CDSL-R400],
    • the dialog selects the version with which the file was saved (it that version is installed on the system).
  • [CDSL-R120] You may select any of the installed CANdelaStudio versions.
    • On "New Document" or "Open" [CDSL-R500], the dialog will start the selected CANdelaStudio version.

Document Language

[CDSL-R200] When you selected a document, ...

  • the list shows the languages contained in the document
  • as in File | Open [OPEN-R420]
  • [CDSL-R210] You may select any of the completely translated languages.
    • On "New Document" or "Open" [CDSL-R500], the dialog will open the file in the selected language.

Open in

[CDSL-R300] The list shows all CANdelaStudio Views.

  • [CDSL-R310] You may select a View.
    • On "New Document" or "Open" [CDSL-R500], the dialog will open the file in the selected View.
  • Some Views may be not available for selection, depending on...
    • the Edition of CANdelaStudio
      • (which you may restrict by the "Set license" list [CDSL-R810])
    • and whether you selected a document or template.
  • If a View is not available, the Launcher...
    • either disables the View,
    • or shows a hint on Open.
  • The same choice of Views is provided in File | Open [OPEN-R410].

Filename

[CDSL-R400] Lets you select the document or template to open.

  • [CDSL-R410] The edit control accepts only file name extensions supported by CANdelaStudio.
  • [CDSL-R420] You can specify a file by drag and drop onto the button "...".
  • Initial value: see Launcher Start [CDSL-R080].
  • Filename as in File | Open [OPEN-R130]

New Document / Open

[CDSL-R500] The standard button shown at bottom left depends on your selection. If...

  • "Standard View" is selected in "Open in" [CDSL-R300], and
  • a template is shown in the Filename control [CDSL-R400],
  • then the standard button is "New Document",
  • otherwise it is "Open".

Button "Open"

[CDSL-R510] Opens the document or template, see operation [DOC-R610];

  • uses the settings specified in the controls above,
  • and closes the Launcher.

Button "New Document"

[CDSL-R520] Creates a document from the template you selected, see operation [DOC-R600];

  • uses the settings specified in the controls above,
  • and closes the Launcher.

Buttons > and <

[CDSL-R600] Buttons > and < at top right expand or collapse the Details View to the right.

Details View

TAB Document Info

[CDSL-R700] This TAB page shows information about the document selected in the Filename control [CDSL-R400] (if any).

  • [CDSL-R710] Type: .cdd for a document, .cddt for a template.
  • [CDSL-R720] Version: the format of the file,
  • [CDSL-R730] Diagnostics based on: shows the document information "Diagnostics Based on", see [DOC-R110].
  • [CDSL-R740] Document Languages: the document information shown in the list [CDSL-R200], in the raw form from the CANdela file.
  • [CDSL-R750] Up-to-date Languages: dito.

TAB Settings

[CDSL-R800] This TAB page controls how to start CANdelaStudio:

  • [CDSL-R810] Set license:
    • allows to select an Edition more restricted than the one installed.
    • You can select the CANdelaStudio version to run in the list [CDSL-R100],
      • the available license may vary between these versions.
    • The "Set license" list does not reflect the selected CANdelaStudio version,
      • it leaves the check to the CANdelaStudio version you start.
    • The same choice is provided on the command line [CLI-R100-edition].
  • [CDSL-R820] Program Language: selects the language of the CANdelaStudio user interface.
    • This has the same effect as selecting the appropriate entry in the Windows Start Menu, see [ISTM-R010].
