candelastudio: URI Scheme (CDS-11284 6.0)

Opening a CANdela Document via Software

[URI-R010] Any application may open a CANdela document using the candelastudio: URI scheme.

[URI-R020] CANdelaStudio opens the CANdela document passed in the URI path.

[URI-R030] CANdelaStudio navigates to the object passed in the URI fragment as an object path.

Example

For the following simple HTML code in an HTML file:

<html>
<body>
    <a href="candelastudio://C:\Users\Public\Documents\Vector\CANdelaStudio\9.0\Examples\ABS_ESP-Example.cdd#qpath:/BaseVariant/Sessions/DefaultSession/Data">Open ABS_ESP-Example.cdd</a>
  </body>
</html>
  • if you open the HTML file in a web browser...
  • and click the hyperlink (which must contain the path to a CANdela document on your computer),
  • the web browser will start CANdelaStudio
  • which will open the CANdela document...
  • and navigate to the default session.

Background

Uniform Resource Identifier (URI)

A Uniform Resource Identifier (URI) is a concept from the world wide web to identify a resource.

In general, it consists of the following parts:

 scheme:[//[user[:password]@]host[:port]][/path][?query][#fragment]

URI in Windows

The Windows operating system can automatically open an application associated with a given file...

  • based on the file type, e.g. .cdd
  • or using an URI scheme, e.g. candelastudio.

URI for CANdelaStudio

For a CANdela document in the local file system, the relevant URI parts are:

 scheme:///path[#fragment]

where ...

  • scheme is "candelastudio"
  • /path is the path in the local file system, e.g. C:\Users\Public\Documents\Vector\CANdelaStudio\9.0\Examples\ABS_ESP-Example.cdd
  • #fragment (optional) is an object path, e.g. qpath:/BaseVariant/Sessions/DefaultSession/Data

Complete Example:

candelastudio://C:\Users\Public\Documents\Vector\CANdelaStudio\9.0\Examples\ABS_ESP-Example.cdd#qpath:/BaseVariant/Sessions/DefaultSession/Data

If you enter this string with an existing file path in HTML code (see above) or into the address entry field of the Windows Explorer, it will...

  • start CANdelaStudio or bring it to front,
  • open the CANdela document and
  • navigate to the given object path.

The mechanism uses...

  • a running instance of CANdelaStudio,
  • otherwise the most recently installed CANdelaStudio version.

Setup

[URI-R040] The CANdelaStudio installer associates

  • the candelastudio: URI scheme
  • with the CANdelaStudio application.

Therefore the CANdelaStudio version most recently installed "wins".
