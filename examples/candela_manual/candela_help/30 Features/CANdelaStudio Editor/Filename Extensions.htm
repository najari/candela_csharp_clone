File Name Extensions

Each file has a file name. Typically the file name has an extension: the last part after a dot, like cdd in the file name Sample.cdd. The extension indicates the purpose or internal format of the file.

Windows typically hides file name extensions e.g. in Windows Explorer or on the desktop.

CANdelaStudio uses the following file name extensions:

Extension Purpose, Format
.cbk Backup copy of a CANdela document
.cdd CANdela document
.cddt CANdela template file
.chm Help file
.csv Comma separated values (used for data exchange, open e.g. in Excel)
.dll Dynamic libraries required by CANdelaStudio
.ini Settings
.log Logfile written automatically by CANdelaStudio
.odx Open Diagnostic Data Exchange (XML-based)
.rtf Rich Text Format (created by specification report
.tmx Translation Memory Exchange (used in translation memory).
.txt Plain text
.vck Variant Coding Keys (format defined by CANdelaStudio)
