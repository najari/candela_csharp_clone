Use of Excel

CANdelaStudio uses an installed version of Excel to import and export DTCs.

CANdelaStudio reads the version of the installed Excel application from the following Windows registry key: SOFTWARE\Classes\Excel.Application\CurVer.

Import/Export of DTCs is available...

  • ... via .xls: if Excel 2000 (registry Excel.Application.10) or higher is installed
  • ... via .xlsx: if Excel 2007 (registry Excel.Application.12) or higher is installed;

"or higher" means:

  • (for CANdelaStudio up to 8.2 SP2) up to Excel 2010 (registry Excel.Application.14);
  • (for CANdelaStudio 8.2 SP3 and higher): no limit for newer Excel versions (CDS-34805).
