Saving a Document or Template

PREEvision UUID Repair

[SV-R110] When saving a CANdela file (CDDT/CDD), ...

  • if the property "Supports PVCDI" document property [DOC-R500] is set,
  • no matter in which context a CDD is saved (user interface, command line...),
  • CANdelaStudio runs a repair mechanism for UUIDs [PUID-R010].
