Auto Save (CDS-274, 7.0)

CANdelaStudio enables automatically saving the currently active modified document at the next opportunity, based on a user-defined time interval.

It does not matter at which point in time the document has been first or last modified.

Requirements

R001.1 (Frontend): in Ribbon Tab File | Options | General, provide checkbox “Auto-save” (“Automatisches Speichern”), with spin-button (like for maximum path length, sensitive if checkbox is on) for 1..60 minutes. Add explanation like “Saves the current document to a temporary file with extension (not e.g. during editing in a modal dialog”)

CANdelaStudio shall not trigger the action “Save current version done”.

CANdelaStudio shall not show the prompt for revision history.

R030.2 (Frontend): on opening a document via File menu or drag’n drop (not e.g. when opening a file for a batch plug-in), if there is an “Auto-Save” file that is newer than the document to open, CANdelaStudio shall prompt the user whether the auto-save file should be used.

If yes, move it onto the document (e.g. delete document, rename auto-save file to document) and open the resulting document. If the auto-save file cannot be opened (e.g. corrupt file), show a message and fall back to open the document.

If no, drop the auto-save file and open the original document.
