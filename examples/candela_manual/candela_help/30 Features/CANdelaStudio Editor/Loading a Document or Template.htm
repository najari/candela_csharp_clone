Loading a Document or Template

Automatic Migrations

For modified or new features, CANdelaStudio may need to migrate data during loading a file in a new version. For details, see the Migrations chapter.

Error Messages for a Corrupted File

A CANdela file may be corrupted e.g. during email transmission. In support cases, we saw files just truncated in the middle, and files with non-CANdela data inserted.

On loading a file, CANdelaStudio detects the corruption and writes a message like

... the file has been corrupted! If it was a data transfer (via email, download from manufacturer portal ...) that corrupted the file, it may help to transfer the original CANdela file again in a zip file.

Please follow the advice given in this message!

[LOAD-R100] Error situations detected:

  • invalid token (CDC-41950 9.0)
  • no elements (CDC-43784 9.1)
  • unclosed token (CDC-43784 9.1)

Other Error Messages

  • [LOAD-R210] For a document containing a DID both in the Common Snapshot Data and in DTC specific snapshot data, CANdelaStudio shall write an error on loading, but not reject loading (CDS-69048 9.1; cf. CDC-43727).

Automatic Corrections

  • [LOAD-R200] If a Diagnostic Instance of a type [DCLT-R200] other than "Fault Memory"...
    • [LOAD-R200-Events] contains Events (i.e. [EV-R020-Type] violated),
    • [LOAD-R200-SR] or contains AUTOSAR Snapshot Records [SR-R030] (i.e. [SR-R030-Type] violated),
    • [LOAD-R200-SD] or contains AUTOSAR Snapshot Data [SR-R200] (i.e. [SR-R200-Type] violated),
    • [LOAD-R200-EDR] or contains AUTOSAR Extended Data Records [EDR-R030] (i.e. [EDR-R030-Type] violated),
    • CANdelaStudio deletes them with a status message.
    • Cf. modification of the class type [DCLTOP-R200].
