32 or 64 Bit

[APP-R100] CANdelaStudio is available as 64-bit application only (CDS-70702 v13).

History

  • v13 (2020-02) 64-bit only
  • v12 (2019-07) showed a hint that v13 would be available as 64-bit application only (CDS-71412 v12), former [STRT-R032].
  • v10 (2018-07):
    • The DVD-ROM contained only the 64-bit application (CDS-70019 v10).
    • For a 32-bit Windows system, the 32-bit application was availabe from Vector support.
  • Since 9.1 (2018-01), CANdelaStudio was available as 32-bit or 64-bit application (CDS-41013 9.1)
  • Before, CANdelaStudio was available as 32-bit application only.
  • The 32 bit application showed "32 bit"...
    • in the splash screen [STRT-R020] shown at start-up, and
    • in ribbon Tab File, in Recent [MENU-R340] and Product Information [MENU-R930].
    • The 64 bit application showed no additional info.
