Actions.ini

Stores data for actions (not described here).

Path to INI Files

CANdelaStudio writes the INI file to the first writable of the following folders (in this order, examples for CANdelaStudio 8.5):

  1. Path optionally given on the command line [CLI-R100-ini]
  2. Global Location
    • = the default
    • e.g. C:\ProgramData\Vector\CANdelaStudio\8.5\CANdelaStudio.ini.
  3. Bin Folder
    • = Installation folder of CANdelaStudio.exe
    • e.g. C:\Program Files (x86)\Vector CANdelaStudio 8.5\Bin\CANdelaStudio.exe
    • retrieved from registry entry e.g. HKEY_LOCAL_MACHINE\SOFTWARE\VECTOR\CANdelaStudio\8.5\Path
    • INI files are saved in the bin folder if the global location is write-protected
    • Note: the Windows Program Files... folder is write-protected, but you may have installed CANdelaStudio into a different folder.
  4. Temp Folder
    • = folder specified in %TEMP% Windows environment variable
    • e.g. C:\Temp
    • INI files are saved in the temp folder if the global location and the bin folder are write-protected

Registry Key for INI Path

CANdelaStudio stores the used INI folder path in the registry key

HKEY\_LOCAL\_MACHINE\SOFTWARE\Vector\CANdelaStudio\<version>\IniPath

On Installing

The CANdelaStudio installation...

  • creates the folder (see above)
  • creates the registry key (see above)
  • does not install any INI file (initially, CANdelaStudio uses hard-coded defaults) (since 4.0 SP2, CDS-4710)
  • takes over INI files from a previous version (7.5 SP3, CDS-14171):
    • during the first installation of a main release
    • not for an SP installed onto the same main release
    • if CANdelaStudio.ini and Action.ini of an older or the current CANdelaStudio version exist, CANdelaStudio copies the files to a location which is read by the current version.
  • if CANdelaStudio.ini file [Output]FileName
    • specifies a logfile path containing the version number of an older CANdelaStudio version,
    • then CANdelaStudio modifies it to a path with the current version (CDS-41281 9.0)

    • Example:

        [Output]
  FileName=C:\Users\USERNAME\AppData\Local\Vector\CANdelaStudio\8.1\CANdelaStudio.log

      becomes

        [Output]
  FileName=C:\Users\USERNAME\AppData\Local\Vector\CANdelaStudio\8.5\CANdelaStudio.log

On Uninstalling

If CANdelaStudio gets deinstalled, the INI files remain.

Use in CANdelaStudio

During execution, CANdelaStudio reads/writes the INI files.

The point of time for writing is not determined – in case of a crash, modified settings may have been already written or not.

Issue in 8.2 SP3 and 8.5: CANdelaStudio.ini not Saved (CDS-40497)

  • Issue: CANdelaStudio did not create a CANdelaStudio.ini after the first installation
    • i.e. if the file did not exist during start of CANdelaStudio
  • Workaround: manually create an empty INI file
    • e.g. for 8.2 SP3: C:\ProgramData\Vector\CANdelaStudio\8.2\CANdelaStudio.ini
    • likewise for 8.5
  • Versions affected: 8.2 SP3 and 8.5 (before SP2)

ReplaceSimilarDataTypes

[INI-R500] The "Replace Similar Data Types" feature is controlled by the following options.

[INI-R500-Conversions] Options for each conversion supported [RDT-R010]:

Feature ID Option Description
[INI-R500-Cfg] MergeDataTypesAllowConfigurationInStandardView 1 = allow to configure crucial properties [RDT-R020] in Standard View (the default)
0 = prevent from changing the default setting of crucial properties
[INI-R500-Default] IdentityFilterOptions
LinearCompFilterOptions
TextTableFilterOptions
 Default for: which of the properties of similar data types shall be ignored for group computation.

Example:
[ReplaceSimilarDataTypes]
IdentityFilterOptions=0,1;1,1;2,1;3,1;4,1;5,1;6,0;

Format:
5 or 6 pairs of numbers, for the properties in the order shown in the dialog:
- Description
- Encoding
- Attributes
- Byte Order
- Display Format
- (optional) TextID
Note: the pair for the TextID property is optional, depending on the document setting [DOCUI-R320].

Each pair consists of:
- first number: property index, 0-based;
- second number: whether the property shall be ignored,
 0 = the property is crucial, differences prevent from putting data types into a group,
 1 = ignore the property, differences do not matter.
CANdelaStudio logs a warning if it does not detect the format.

If MergeDataTypesAllowConfigurationInStandardView=0, these values define the fixed setting.

Registry

The following options are defined in the Windows registry, from which CANdelaStudio reads them.

Tip: before you set a registry key, close CANdelaStudio.

CANdelaStudio

Path in registry:

  • HKEY_CURRENT_USER/Software/Vector/CANdelaStudio
  • <version> is the CANdelaStudio version
    • it has a trailing ".0" even for version 10 and later.
  • Example in v10 for key xx:
    • HKEY_CURRENT_USER/Software/Vector/CANdelaStudio/xx

Keys:

Feature ID Key Description
[INI-R400] PersistorIdMethod 0 = using memory addresses (fast), 1 = using counter

Studio

Path in registry:

  • HKEY_CURRENT_USER/Software/Vector/CANdelaStudio/<version>/<language>/Studio
  • <language> is one of "en-US", "de-DE", "ja"
  • <version> is the CANdelaStudio version
    • it has a trailing ".0" even for version 10 and later.
  • Example in the English v10 for key OpenCDDTInExpertMode:
    • HKEY_CURRENT_USER/Software/Vector/CANdelaStudio/10.0/en-US/Studio/OpenCDDTInExpertMode

Keys:

Feature ID Key Description
[INI-R300] OpenCDDTInExpertMode Drag and Drop behaviour for templates, see [DDF-R110]. Default value: 0 (CDS-4695 5.0)
[INI-R310] WriteMigratorLogFile 0: no migration files like Load_migration_5.0.140_to_6.0.120_Neues Steuergerät 1.50.log will be written (CDS-12769 6.5)
