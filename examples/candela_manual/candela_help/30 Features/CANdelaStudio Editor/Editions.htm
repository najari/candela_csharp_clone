Editions

CANdelaStudio is available in different editions.

A running CANdelaStudio application shows its edition in Ribbon Tab File | Product Information | About [MENU-R1270].

For an Overview of Editions, Views and Editing, see the Views chapter.

Edition Description
View

not sold separately, but shipped with other Vector tools that support diagnostics (e.g. CANoe, CANalyzer Exp/Pro).

Standard edition without saving (read-only), with exports RTF, CSV but no data oriented exports, no import, no compare, no plugins. All languages. No ODX Viewer from within CANdelaStudio, but shipped separately by bundling products like CANoe.

Shows hint at start-up. No restriction for manufacturer specific files, no time restriction.

Standard View (read-only)
ViewX

Standard edition without saving, with compare and exports. All languages. Includes ODX Viewer.

Edition to be sold standalone.

Standard View (read-only)
Standard

Comfortable editing of ECU document data.

All languages. Includes ODX Viewer.

Standard View
Pro Standard edition plus Translation View
Admin Pro edition plus Expert View

Note the spelling: "CANdelaStudio View" (blank separated, “View”, not “Viewer”; “Pro”, not “Professional”).

Demo Version

There is no demo version (since 8.2; CDS-32042); a test installation is available.
