Commands Menus - Rules For Ribbon / Menu Items

If A Command Is Not Available… Then Ribbon/Menu Item…
categorically [CM-R100] Hide (in ribbon: Show insensitive)
obviously (single selection)
 [CM-R110-Show] Show insensitive (in context menu also for a set of related commands like Back/Forth, Cut/Copy/Paste)
[CM-R110-Hide] Hide (in context menu, otherwise)
not obviously (single selection) [CM-R120] Show sensitive, show info why command is not available
for parts of multi-selection [CM-R130] Show sensitive, apply as far as possible, then show info

Why Command Is Not Available

If it depends on… … a command is not available… Example
Data not possible in CANdela categorically „New bitfield“ within bitfield.
Document loaded categorically „Save“ when no document loaded
Document or template categorically „New Variant“ when template loaded.
CANdelaStudio edition categorically „Store document as template.“
Document opened in which view categorically „New Default Attribute“ in Standard View.
„Translation Memory“ in Standard View.
„Save“/exports in View Edition
Document manufacturer obviously Diogenes export.
Diogenes qualifier overview.
Template data properties obviously Attribute does not exist in a diagnostic class
not obviously Iteration Data Type forbidden.
Maximum telegram length.
Current pane/dialog obviously „New Variant“ in telegram table
Clipboard state obviously „Paste“ when clipboard empty.
„Paste“ in data types, clipboard contains data object.
Properties of selected object(s) obviously „Go To DID“ on data object;
„New Variant“ in telegram table
not obviously Delete multiple data objects, result violates minimum telegram length

Note: One command can have different values of „not available“ for different values of „depends on“. E.g. „New bitfield“ is categorically not available within another bitfield, but could be „not obviously“ not available if the template would forbid adding bitfields.
