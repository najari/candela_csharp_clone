Views

Introduction

CANdelaStudio supports multiple „views“ on files:

  • Standard View for editing CANdela documents
  • Translation View for translation of multi-language templates or documents
  • Expert View for editing template aspects of templates or documents

Overview of Editions, Views and Editing

Overview of Editions, Views and Editing

  • You initially specify the view when opening [OPEN-R410] the file.
  • You can re-open a CANdela document in a different view using ribbon tab Document - Switch View [MENU-R772].
  • CANdelaStudio Admin Edition supports all views
  • CANdelaStudio Standard Edition supports only Standard View
  • Standard View edits only Document Data (describing a concrete ECU) in a CANdela document, no template.

For details about Editions, see the Editions chapter.

Standard View

[VIEW-R100]

  • Creating and editing CANdela documents using CANdela templates
  • Compare View for comparing two CANdela documents, or parts of CANdela documents
  • Exporting the CANdela document to various data formats, see Ribbon Tab Data Exchange
  • Importing data from various data formats, see Ribbon Tab Data Exchange
  • Inspecting and Editing one up-to-date language at a time, determined when opening the file [OPEN-R010]
  • Support for eastern European and Asian languages, e.g. by generating qualifiers from Japanese syllables ("Romanization")

Translation View

[VIEW-R200]

(only in Pro and Admin edition)

  • translating and editing terms in any of the document languages
  • see Translation View

Expert View

[VIEW-R300]

(only in Admin edition)

  • creating and editing the template parts of a CANdela document or template file
  • specifying authorization settings on objects
  • modifying objects without restriction by authorization settings
  • see Expert View
