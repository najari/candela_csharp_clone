DTC Columns

DTC Columns

[DTCC-R001] Each CANdela Error Code Table [ECT-R001] (DTC Table) has a list of DTC Columns.

  • The "columns" in the DTC Table are defined in Expert View in the CANdela template (described here);
  • The values for a DTC column at an individual DTC are shown and edited in the DTC list in Fault Memory.

DTC Columns vs. Attributes

Besides these core properties, a DTC can have attributes, also defined in Expert view in the CANdela template. A DTC attribute can be configured to be shown in the DTC list, too.

Recommendation: use...

  • a DTC column to describe a diagnostic aspect of a DTC, like the "set condition"
  • a DTC attribute to describe an authoring aspect of a DTC, like its "maturity".

In practice, it may be difficult to distinguish the aspects. The following hints may help:

  • tools in the Vector toolchain (e.g. CANoe.DiVa) consume DTC columns, not DTC attributes
  • the DTC list shows DTC columns before the DTC attributes
  • attributes support more types [ATTR-R020] than DTC Columns (see below)

List of DTC Columns

The order of columns is respected for display, but not significant otherwise.

Types of DTC Columns

[DTCC-R010 Types] CANdelaStudio supports three different column types in the DTC table:

  • [DTCC-R010-Enum] Enumeration (CDS-3912 4.0)
    • Columns of this type make it possible to select a value from a fixed set of "symbols".
    • The set of Symbols is specified in the template and cannot be changed in documents.
    • [DTCC-R010-ID] is a unique numeric value for the symbol
    • [DTCC-R010-Symbol] is a multi-language string for the symbol
    • See [DTCC-R090] below.
    • Note: for type Translatable, there is a similar feature: selection list [DTCC-R095]
  • [DTCC-R010-Unsigned] Unsigned.
    • Columns of this type allow entry of an unsigned integer value.
  • [DTCC-R010-Translatable] Translatable.
    • Columns of this type allow entry of a text that can be translated in the translation view.
    • Additionally, the template can contain an optional selection list [DTCC-R095].
    • See [DTCUI-R095] how to leave the value empty when the Column is optional [DTCC-R060-Optional] and has a selection list.

Properties of a DTC Column

General

[DTCC-R020] A DTC Column has

  • [DTCC-R020-Name] Name, multi-language
  • [DTCC-R020-Qualifier] Qualifier
    • identifies the DTC column, e.g. "SetCondition".
    • before 3.0, this was described using a hard-coded enumeration.
  • [DTCC-R020-Description] Description, multi-language

Value May Be Duplicate

[DTCC-R050 MayBeDuplicate]

  • If true, a value may occur at multiple DTCs in the DTC list.
  • If false, values must be unique in the DTC list.
  • This applies even to empty translatable columns (i.e. at most one may be empty).
Column Type May Be Duplicate
Enumeration (always true)
Unsigned defined in template
Translatable defined in template

Convention

[DTCC-R060 Convention] defines a restriction for values of the column at a DTC:

  • [DTCC-R060-Required]
  • [DTCC-R060-Optional]

The property makes sense for Column Type "Translatable" only:

Translatable Convention Semantics
Required String value must not be empty
Optional String value may be empty

See [DTCUI-R095] how to leave the value empty when the Column has a Translatable list.

Default Value

[DTCC-R080 Default Value] (CDS-4271 4.0)

  • [DTCC-R080-Required] a DTC Column has the required property "default value".
  • [DTCC-R080-New] CANdelaStudio assigns the default value to new DTCs, for required and for optional DTC columns ([DTCC-R060], exception see below).
  • [DTCC-R080-Translatable] For a translatable DTC column, the default value may be an empty string.

Exceptions for a translatable DTC column with empty default value:

  • for convention "required" [DTCC-R060-Required], CANdelaStudio...
    • [DTCC-R080-TrRqGeneral] in general sets the column value to "_", ...
    • [DTCC-R080-TrRqDai] for Daimler documents sets the column value to "tbd"...
    • in interactive DTC creation (CDS-3581 3.0)
    • in DTC update from requirements (CDC-43842 9.1; before 9.1: "t.b.d." CDC-34442 8.2).
  • for convention "optional" [DTCC-R060-Optional], CANdelaStudio...
    • [DTCC-R080-TrOptDai] for Daimler documents leaves the column value empty in interactive DTC creation.

Enumeration Symbols

[DTCC-R090 Symbols] (for Column Type enum only)

  • define the set of available values in the DTC column

Selection List for Translatable

[DTCC-R095 Selection List] (for Column Type translatable only) (CDS-4502 5.0)

  • the list defines predefined, suggested values for the DTC property
  • a user may select one of the values, or enter a different free text for the DTC property
  • in order to specify a value not contained in the selection list, see [DTCUI-R090].
