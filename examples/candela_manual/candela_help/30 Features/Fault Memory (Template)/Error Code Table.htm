Error Code Table

See also the Error Code Table User Interface and the introduction to Fault Memory.

An Error Code Table is defined in a CANdela template. It describes the structure of DTCs.

Data Model

[ECT-R001] A CANdela template can contain up to 2 Error Code Tables:

  • [ECT-R001-3] Primary/User-Defined/WWH-OBD (3 byte) (CDS-42498 U035 9.0)
  • [ECT-R001-2] OBD-II (2 byte)

[ECT-R010 DTC Columns] Each Error Code Table contains its own DTC Columns which define the set of properties available for a DTC in a CANdela document.

Note: having an Error Code Table of the according byte size is required for defining a Proxy Component with semantics "dtc" [PC-R050-dtcErrorCodeTable] in a Protocol Service.

Specific DTC Columns

  • [ECT-R510] Qualifier DTC_OCCURRENCE_FLAG
    • see DEXT Export [DEXT-R360]
  • [ECT-R520] Qualifier UDS_DTC_Reference
    • evaluated by Vector DEM at an OBD-II DTC
      • CANdesc has no support for OBD-II
    • Defines the UDS DTCs which shall be linked with the OBD-II DTC.
    • Format:
      • 3 byte hexadecimal DTC numbers
      • with optional "0x" prefix
      • separated by comma
    • Example: 0x402025,403113
    • See [VUDS-R480] for use in the Vector UDS Template.
