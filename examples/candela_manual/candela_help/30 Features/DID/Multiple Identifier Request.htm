Multiple Identifier Request

Use Case

UDS allows that multiple identifiers may be combined in one request: specify the maximum number of identifiers which can be sent within one request.

Editing

The following properties are shown and edited in the ECU Property Page "Maximum Number of Identifiers".

Maximum Number of Identifiers

A CANdela ECU has a property Maximum Number of Identifiers, ...

  • used by a code generator for the number of identifiers in a request message for UDS service 0x22 and 0x2A.
  • applies only to ProtocolServices that have mayBeCombined set to true
  • default: 5

Maximum Number of Identifiers in ECU Scheduler

A CANdela ECU has a property Maximum Number of Identifiers in ECU Scheduler, ...

  • used by code generator for periodic data reading scheduler size (e.g. UDS service 0x2A)
  • relevant for a tester and code generation
  • need not be specified

Note: for UDS service 0x2C, CANoe.DiVa employs a 7 byte boundary.

Note: as of 2015, CANoe.DiVa uses the minimum value of the two options “Maximum number of Identifiers” and "Maximum number of Identifiers in ECU Scheduler” (cf. DIVA-28661). This makes a difference to code generation in case “Maximum number of Identifiers in ECU Scheduler” > “Maximum number of Identifiers”.
