Convert to Template

[DOC-R700 Convert to Template] Operation to convert a document to a document template.

Use-Case

In order to add new protocol services, diagnostic class templates or attributes to a document:

  1. convert the document to a template,
  2. modify the template as desired,
  3. then via ribbon tab Document | Template | Document Upgrade [MENU-R560], perform a Document Upgrade.

Basic Operation

  • Menu Tools | Convert Document to Template shows the Windows file dialog.
  • Select the document you wish to convert to a template.
  • The Save as file dialog appears. Enter the file name of the new template.
  • CANdelaStudio creates a template from the document and saves it.

Convert to Template and File|New

Specification

[DOC-R710] On "Convert document to template", CANdelaStudio...

  • [DOC-R710-Name] ... puts the template name + qualifier into ECU name+qualifier (CDS-14160 7.0 SP1, see Details below)
  • [DOC-R710-SaveNumber] ... puts template save number [DOC-R100-SaveNumber] into ECU save number [DOC-R200], incremented by 1. (CDS-14160 7.0 SP1)
  • [DOC-R710-ComParam] ... drops overriding communication parameter values [CP-R050-OverridingValue] (CDS-38382 8.2 SP3)
