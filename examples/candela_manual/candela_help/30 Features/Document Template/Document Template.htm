Document Template

Introduction

A document template...

  • has the .cddt file name extension
  • is the basis for a CANdela document (.cdd)
    • like a Word template (.dotx) is the basis for a Word document (.docx)
  • has a different data structure than a CANdela document
    • you cannot just rename a *.cdd to *.cddt, CANdelaStudio rejects such a file on loading (CDS-4286 4.0)
  • itself has no further template
    • a document template is the starting point
  • describes specifics of the diagnostics for a vehicle manufacturer or even a certain model range.

See CANdela Views for an overview of File Types, Types of Data and Languages.

Service Structure

A template captures the diagnostic specification of an OEM:

  • it defines the set of diagnostic Services and their structure.
  • in detail, the "structure" is described using CANdela ProtocolServices
    • these contain different types of variables, called proxy components
    • like Const Value, Variable Value, telegram table of data objects, DTC table, Iterators, Multiplexer, etc.).
  • Each service in a CANdela document is based on a ProtocolService:
    • it always fullfills the given structure of its ProtocolService,
    • e.g. if the ProtocolService says that there is a constant value at byte position zero, the Service has this constant value at this byte position.
    • e.g. if the ProtocolService has a telegram table of data objects beginning from byte position four in the Service, data objects can be specified beginning at byte position four.
  • Hence, the structure of ProtocolServices defines the restrictions to services.
