CDI Export

CDI Introduction

  • CDI = "CANdela Data Import"
  • The main purpose of the format is to provide a simple XML format for import of...
    • DTCs
    • data types and
    • data objects.
    • See Import from CDI.
  • For details about the format, see the description in the Documentation folder of the CANdelaStudio installation.

Export Overview

[CDI-R200] Export to the CANdela Data Import (CDI) format...

  • is available for DTCs only.
    • The original use-case was to configure the FRFM CANdesc code generation module
  • It is available as a "File type" in the "Save As" of DTC Export in Fault Memory
  • ... in two variations:
    • "CDI":
      • uses the newer XML format 1.5.0
      • which distinguishes DTC Attributes by an XML attribute type="A"
    • "CDI for FRFM":
      • uses the XML format 1.4.1
      • for compatibility with the CANdesc code generator for the FRFM module
  • It can be filtered by Vehicle System Groups, using button "More filters..." in the "Save As" dialog.
  • Export includes
    • DTC Columns [DTC-R040] and
    • Attributes [ATTR-R050-DTC] (CDS-6817 5.0).
  • In case a DTC column and an Attribute have the same qualifier, export...
    • includes the DTC Column,
    • skips the Attribute with a warning.

CDI for FRFM

The FRFM CANdesc code generation module needs the CDI XML format version 1.4.1, activated by the file type entry "CDI for FRFM" in the DTC "Save As" dialog.
