VEHICLE-INFO-SPEC

[ODXE-R1130]

A 3D system requires a minimum set of ODX-components. These components are a BASE-VARIANT, a COMPARAM-SPEC and a VEHICLE-INFO-SPEC. The later one is available since CANdela Studio 5.0 SP 1. Here a default VEHICLE-INFO-SPEC is generated, that can be used under the following preconditions:

  • The tester is directly connected to the ECU (not via a Gateway)

  • A CANCab Opto is used to connect to the CAN-Network (in case another Interface is used, the Vehicle-Connector-Pins have to be updated)
