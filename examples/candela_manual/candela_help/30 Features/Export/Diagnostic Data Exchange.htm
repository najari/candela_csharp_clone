Diagnostic Data Exchange (DDx) (CDS-35886 8.2)

Introduction

The DDx export is manufacturer specific (Chrysler, FIAT; see "Diagnostics based on").

The export’s central functionality is to generate DDx from the given diagnostic instance and data types in a CANdela file.

The export is available in ribbon tab Data Exchange | Export | Manufacturer Specific [MENU-R140].

SaveAs Dialog

[DDX-R050] The SaveAs dialog...

  • [DDX-R050-ChangeName] allows to change the default name (CDS-69602 9.1);
  • [DDX-R050-DefaultName] the default name has the file name extension .ddx (CDS-69602 9.1).

Skipped Elements

[DDX-R200] During check and export, diagnostic instances, data types and data objects may be encountered that are not described in the DDx Mapping Specification. These elements shall be recorded as skipped elements.

From a current state of the specification, specific data types, and services not covered by the mapping specification (e.g. DIAnalyzer Services, OBD services) will appear in this list.

[DDX-R005] Upon finishing the import, the list of skipped elements shall be serialized into a text file for user review. The file listing skipped elements shall be located next to the exported DDx file, having the same name but a different file name extension.

Checker

[DDX-R010] The export and the checker shall run side-by-side to check the exported document on-the-fly.

[DDX-R010-Start] An export of DDx from CANdelaStudio can be started without checking the CANdelaStudio document first. Thus the checker and the export shall run side-by-side in order to detect possible issues during export.

[DDX-R011] Run

  • The checker shall always run to completion.
    • present all errors and warnings a document contains
  • The export shall abort at any error encountered
    • exporting a large CANdelaStudio document may be expensive and would waste time.
