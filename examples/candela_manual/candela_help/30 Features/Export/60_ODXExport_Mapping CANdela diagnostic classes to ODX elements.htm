Mapping CANdela diagnostic classes to ODX elements

Mapping to FUNCT-CLASSs

Usually Qualifier, name and description of a CANdela diagnostic class are exported as SHORT-NAME, LONG-NAME and DESCRIPTION of a FUNCT-CLASS in ODX. A DIAG-SERVICE corresponds to a CANdela Service within a DiagInstance and belongs therefore to a diagnostic class and accordingly to a FUNCT-CLASS. Hence, the export writes a reference from a DIAG-SERVICE to its FUNCT-CLASS.
