Document Revisions Export (CDS-5050 5.0)

Exports all revisions to an XML file.

Motivation

Some commands need to process the revision history of a CANdela document.

Solution

Note: CANdelaStudio...

  • does not provide a menu item to run this export directly,
  • instead it provides the export in the context of actions
  • so that you can automatically process the exported file in an application of your choice.

[DRE-R100] When an action [ACT-R100] uses the variable "DocRevisionsTmpPath", CANdelaStudio writes the revision history to an XML file.

In detail: if the variable is used in a command line, on action execution, CANdelaStudio...

  1. computes a temporary path T
  2. in the action command line, replaces the variable by T
  3. writes properties of the latest history item into file T
  4. runs the command line
  5. deletes the file T

This means the application run via the command line gets the temporary path as a parameter and can process the XML file.

[DRE-R110] The temporary file contains the revision history in XML format, in encoding UTF-8.

  • The format of the XML file is described in DocRevisions.dtd in the CANdelaStudio documentation folder.
  • An application that reads this format should tolerate attributes and elements that it does not know – in order to ease compatibility with potential future extensions of the format.

[DRE-R120] If there is no history item defined,

  • if the action variable is optional:
    • CANdelaStudio substitutes an empty string;
  • otherwise
    • CANdelaStudio rejects the action.
