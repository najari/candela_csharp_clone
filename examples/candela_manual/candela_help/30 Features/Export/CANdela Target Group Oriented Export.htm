Export CANdela (Target Group Oriented) (CDS-1233 1.4)

Use-case: a supplier defines special services that shall not be visible to the manufacturer.

Solution: CANdelaStudio provides an export to the CANdela (CDD) format, filtered by variants and target groups.

The export is available in ribbon tab Data Exchange | Export [MENU-R170].

Read-Only

The exported file is set read-only to indicate that the reduced document should not be changed (CDS-6406).

Version

The export can create a file in the current or a different CANdela format.

Variants

The export can include all variants or a subset of variants (CDS-2197 3.0). The base variant is mandatory (CDS-3510).

Target Groups

A diagnostic instance or job container is included in the exported document if...

  • its set of target groups
  • intersects with the set of target groups specified for the export

... in other words, if...

  • at least one of the target groups checked in the diagnostic instance property page for target groups
  • is also checked in the export dialog.
