Service Overview Export

Use-Case

UC001.0: roughly compare the services in different ECU documents.

UC010.0: create checklists for services (e.g. which services are already tested/implemented)

UC020.0: use the service information in a documentation process.

User Requirements

U010.0: CANdelaStudio shall provide an export of services.

U020.0: it shall be possible to print the exported data on paper

U030.0: it shall be possible to modify the exported data on screen.

Requirements

The export is saved in a CSV (comma separated values) file, UTF-8 encoded.

The CSV file has the following format:

<File Name>
<Date>
<Variant>|<DiagClass>|<DiagInstance>|<Service>|<ServiceAbstract|<Path>|<ProtocolService>

The header contains the file name and the creation date of the service list. The body lists all services of an ECU document, including the paths leading to the service (for a diagnostic instance referenced in multiple variants, there are multiple paths).
