ECU-SHARED-DATA

[ODXE-R1120]

Since version 5.0 SP 1 CANdelaStudio supports the usage of ODX-ECU-SHARED-DATA. Within CANdelaStudio, UNITs, DTCs and DOPs can be referenced. These items are imported by the regular OdxImport-mechanism. For the imported items, the ODXLINK-Triple (ID-REF, DOCREF and DOCTYPE) is stored within attributes. When exporting a cdd that references items from an ECU-SHARED-DATA these items are not exported anymore, but appropriate ODXLINKs to the elements within the ECU-SHARED-DATA are generated in case the references are still valid. When DTCs are imported from an ECU-SHARED-DATA and e.g. the error-code or the error text is modified, the DTC has to be exported. It cannot be referenced from the ECU-SHARED-DATA anymore.

TABLE-ROWs from ECU-SHARED-DATA

With CANdela 7.5 CANdelaStudio supports also references to TABLE-ROWs in ECU-SHARED-DATAs. Diagnostic Instances created from TABLE-ROWs in ECU-SHARED-DATAs during OdxImport will not be exported as TABLE-ROWs in the BASE-VARIANT/ECU-VARIANT but referenced from the contained ECU-SHARED-DATA.

Support for different versions

With CANdela 8.0 it is possible to specify the ODX-Version for an ECU-SHARED-DATA. Thereby it is possible to integrate the same ECU-SHARED-DATA in different ODX-versions. This is required e.g. in case the cdd shall be exported to different ODX-versions. The ODX-Export will then use only the ECU-SHARED-DATA which has the same version as the ODX version selected for export.
