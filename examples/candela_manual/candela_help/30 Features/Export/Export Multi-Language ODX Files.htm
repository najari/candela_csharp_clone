Export Multi-Language ODX Files (CDS-8019 6.0)

[ODXE-R1160] ODX Export optionally creates a TMX file. In conjunction with the exported ODX file, you can use the exported TMX file to translate the ODX file into other languages (multi-language ODX).

Prerequisites in the Document

  • multiple languages
  • TextIDs
    • to identify a multi-language text in an ID based system e.g. a database.

Result of an Export

  • the ODX file with TextIDs set from the CANdela objects
  • an additional TMX file containing translations from multi-language texts of the CANdela document
    • mapped to the ODX file via the TextIDs.
    • You can create the translations in Translation View.

Usage in Tester

A Tester typically processes the information as follows:

  • if the ODX text has a TextID specified,
  • search for a translation in the TMX file with the same TextID.
  • If found, display the Translation for the language selected in the Tester.

TMX

TMX is a data file format for exchanging translations of texts from one language into otherlanguages (“Translation Memory Exchange”).

Example TMX fragment:

<tu tuid='1'>
<prop type='x-CANdela-text-id'>New_ECU_1_12</prop>
<tuv xml:lang='de-DE'><seg>Länge</seg></tuv>
<tuv xml:lang='en-US'><seg>Length</seg></tuv>
</tu>.
