Requirements Export to .csv

[RQ-R700]: writes the entire data to a .csv file

  • file format as described in the CANdelaStudio CSV Requirements Exchange Format.

[RQ-R705]: writes the following properties of the CANdela document as meta properties (see R645):

  • Save number,
  • version string of the last revision (if any),
  • data of the last revision (if any),
  • version of CANdelaStudio,
  • version of .csv export component,
  • date of export.

Note: more maybe added in the future.

[RQ-R710] (cf. [RQ-R680]) the VehicleSystemGroups are exported as VSG names.

[RQ-R780] For a property that does not exist at the requirement, i.e. ...

  • either a Specific Property [RQ-R030],
  • or a User-Defined Property restricted to exist at DTC Requirements [RQ-R040-ForType],

export leaves the value empty.

Action Variable RqCSVExportTmpPath (CDS-24780 7.5 SP2).

[RQ-R795] The Action variable RqCSVExportTmpPath automates postprocessing of exported requirements by an external command.

In detail: if an action contains the variable in a command line, on action execution, CANdelaStudio...

  1. computes a temporary file path T
  2. exports requirements in .csv format to T (same contents as after interactive export from requirements view, described above)
  3. in the action command line, replaces the action variable by T
  4. executes the command line (runs your external command)
  5. deletes the file T
