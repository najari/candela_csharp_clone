Attribute Export (CDS-8613 5.5)

[ATTE-R010] Exports attribute values to a CSV file.

Motivation

Attributes are a generic data-driven way to extend the data model implemented in CANdelaStudio.

Some describe settings for code generation, or typically represent properties specific to the process of the manufacturer.

It may be useful to transport these settings from a CANdela document to a related other one.

How to Run the Export

  • [MENU-R185] Ribbon Tab Data Exchange | Export | Attributes
  • [ATTOV-R185] Attribute Overview, button "Export"

Attribute Export Wizard

The Attribute Export Wizard [AEUI-R010] prompts for export settings, then writes the attribute values to a CSV file.

Export

[ATTE-R100] Export writes attribute values to the specified CSV file:

  • [ATTE-R110] Default Attributes (the attribute definition)
    • This includes the definitions of Communication Parameters [ATTR-D010].
  • [ATTE-R120] Overridden Attributes at CANdela objects.
    • If an attribute is not overridden at a CANdela object, it is not included in the export.
    • [ATTE-R120-Same] Attribute Export exports Overridden Attributes even if the value is the same as the default value (CDS-32336 v13).

[ATTE-R200] Template Data

  • If you check the option to "include attributes from template data" [AEUI-R210] in the wizard,
  • then Attribute Export also exports attributes of Template Data [ATTR-R050-Template] (CDS-32336 v13).

[ATTE-R210] Referenced Diagnostic Instances

  • If a Diagnostic Instance is referenced in multiple variants [DI-D010],
  • export writes it in each variant.
  • Cf. Attribute Overview [ATTOV-R210].

[ATTE-D220] Note for data types:

  • as of v12, export does not include the path of data types;
  • therefore the values of data type attributes values are lost on import (CDS-71866).

[ATTE-R130] Export reports a summary in the Output Window as an Info message, like

Export of attribute values finished. 364 Attributes exported.

CSV File

[ATTE-R300] CSV file format exported:

  • [ATTE-R310] Lexical Syntax:
    • Lines are separated by a line-break.
    • Cell values are separated by the separator specified in the Wizard [AEUI-R110].
    • Cell values are enclosed in double-quotes ".
      • A double-quote within the cell contents (attribute value) is written as two double-quotes.
      • Since an enclosing double-quote is followed by a separator line-break, it is well-defined that the first double-quote does not end the cell value.
    • [ATTE-R310-Multi] Multi-line column values produce multiple lines in the CSV file.
      • Since each cell value is enclosed in double-quotes, it is well-defined that the line-break does not start a new attribute.
  • [ATTE-R330] Lines:
    • there is no header line
    • each attribute value is in one line on its own,
      • or even multiple lines for a multi-line column value [ATTE-R310-Multi].
  • [ATTE-R340] Columns:
    • [ATTE-R340-Qual] Attribute qualifier [ATTR-R010-Qual]
    • [ATTE-R340-Category] Category [ATTR-R100]
    • [ATTE-R340-Default] Default value [ATTR-R040]
    • [ATTE-R340-Effective] Effective value [ATTR-D140]
      • in lines for Default Attributes, this repeats the Default value.
    • [ATTE-R340-Path] Path to the Default Attribute / CANdela object [OBJP-R200]
      • Note: path to ECU, State Group, State and Date Type since v13 (CDS-71866)

Example

"Maturity";"Editor";"in progress";"in progress";"qpath://[ECUDEFATTR]Maturity"
"MaxNumberOfDynDefinedDidReferences";"UDS";"5";"5";"qpath://[ECUDEFATTR]MaxNumberOfDynDefinedDidReferences"
"CAN";"COM.INTERFACES";"supported";"supported";"qpath://[ECUDEFATTR]CAN"
"IoSignalDescriptor";"CANdesc";"Line1
Line2";"";"qpath:/DID_0x0200_ID/[OVRATTR]IoSignalDescriptor"

Note the two lines for attribute IoSignalDescriptor, due to the multi-line string value.
