Authorization

(see State Dependency/Authorization for the runtime security topic)

Authorization for an object controls...

  • editing: e.g. whether you can view, modify or delete the object in Standard View;
  • allowed data constellations, e.g. that an object is "required as a reference" in all variants.

CANdelaStudio supports different authorization properties for different object types (see the links below).

You can modify the authorization settings in Expert View only.

Authorization restrictions for...

  • editing: apply in Standard View only - editing is not restricted in Expert View.

  • allowed data constellations: apply in Standard and Expert View:

    • if a data type is referenced by a data object, you cannot delete the data type in Expert View;
    • if a diagnostic instance is "required as reference" in all variants, you cannot replace it by a copy in Expert View (but you can modify the "required as reference" authorization and then create the copy).

The authorization settings of an object are shown in the page "Authorization" in the Properties dialog.

Translatable strings (name, description...) may be translated even if the modify flag is set to "modify not allowed".
