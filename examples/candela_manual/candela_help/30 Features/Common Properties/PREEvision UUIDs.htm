PREEvision UUIDs (CDC-44285 v13)

Starting with version 13, CANdelaStudio supports detailed roundtrip data exchange of diagnostic data with PREEvision.

Cf. the

  • AUTOSAR Diagnostic Workflow and the
  • PREEvision CANdela Data Interchange - Introduction.

UUIDs

[PUID-R010] Some CANdela objects support...

  • [PUID-R010-CDS] a CANdela UUID for PREEvision (string)
  • [PUID-R010-PV] several PREEvision UUIDs (string vector).
  • [PUID-R010-Number] The number of UUIDs depends on the object type (see below).
  • [PUID-R010-Empty] The UUID strings always exist, but may be empty.
  • [PUID-R010-Hidden] CANdelaStudio does not normally show these UUIDs, they are used for roundtrip internally.

Occurrence

[PUID-R050] The following CANdela object types support the UUIDs of [PUID-R010]:

Document level:

  • Variant [VAR-R001] and Library [LIB-R010] ("Diag Layer")
  • Vehicle System Group [VSG-R010]
  • Data Type [DT-R100]
  • Error Code Table [ECT-R001]
  • DTC Column [DTCC-R001]

Within Variant or Library:

  • DID [DID-R001]
  • Diagnostic Instance [DI-D100]
  • Data Object [DO-R010]
  • DTC [DTC-R001]
  • Event [EV-R020]
  • Indicator Connection [EV-R300]
  • Operation Cycle [EV-R500]
  • Indicator [EV-R600]
  • Condition [EV-R700]
  • Condition Group [EV-R800]

Usage

  • [PUID-R110] For a new object, the UUIDs are empty.
  • [PUID-R120] CANdelaStudio does not modify UUIDs during editing operations.
  • [PUID-R130] CANdelaStudio fills UUIDs (CDS-71795) and ensures uniqueness [PUID-R140]
    • [PUID-R130-Export] before export to PREEvision,
    • [PUID-R130-Import] after import from PREEvision,
    • [PUID-R130-Save] before saving a template or document, iff. it has been exported to or imported from PREEvision before.
    • Note: this is an optimization - only documents used for data exchange with PREEvision have UUIDs filled in.
  • [PUID-R140] CANdelaStudio ensures that non-empty UUIDs are unique within a Variant/Library.
    • Note: CANdelaStudio creates new UUIDs as unique within any CANdela document created by any instance of CANdelaStudio on any machine.
