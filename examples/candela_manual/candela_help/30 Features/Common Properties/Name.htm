Name

Most diagnostic objects in CANdela have a name, a qualifier and a description.

Note: this is different from the shortcut name of a service.

[NAME-R010] Names are multi-language.

Use of the Name

The name is typically used to to display an object in the user interface or in a report.

CANdelaStudio uses the name to generate the qualifier.

Name Restrictions

Character set

[NAME-R020] A name may contain any characters of the Unicode character set.

[NAME-R030] A name must not consist of blanks only.

[NAME-R040] A name may contain leading and trailings blanks.

  • CANdelaStudio does not forbid them (unfortunately; from the beginning).

Length

[NAME-R100] A name must not be empty.

[NAME-R110] The length of a name is limited to 255 characters (CDS-21028 7.1).

  • It was limited to 128 characters before 7.1.
