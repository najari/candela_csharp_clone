References

Use-Case

In the CANdela data model, a data object references a data type. Other types of objects have similar references.

U001.0: the user wants to see which objects reference a given referenced object, and to navigate to the referencing object.

Referencing (Use)

Some objects have references to other elements:

Object references…
Combined Proxy Component Proxy Component in the ProtocolService
Combined Variable Component Variable Value Component in the ProtocolService
DID Data Reference [DID-R160] DID
DID Reference [DID-R180] DID
DTC Column Definition of DTC Column in Error Code Table
Data object Data Type. See also further Data Type References
Group of DTC Data Object (implicitly) if "supports individual DTCs" is set: the DTC list
Group of DTC Proxy Component the "master" text table
Identifier (in diag. instance) Combined Variable Component in the Diagnostic Class Template
Function Job File
Overwritten Attribute Default Attribute
Service Used ProtocolService in Diagnostic Class Template
Telegram Table Combined Proxy Component in the Diagnostic Class Template
Translatable (implicitly)

Referencing (Sharing)

Some objects are reusable, that means they are defined in a separate pool and they are only referenced in the parent element.

Object is in… reuse in…
Variant ECU (no)
Diagnostic instance Variant Variants (1x per variant)
Service Diagnostic instance (no)
Data object Diagnostic instance or ProtocolService or complex datatype (no)
DTC DTC Pool Fault memory in variants.
DTCs can be defined locally.
NRC NRC Pool Negative response in variants.
NRCs cannot be defined locally (description can be overwritten)

A variant as a whole cannot be reused, because a CANdela file only contains one ECU (and CANdelaStudio avoids references across files).
