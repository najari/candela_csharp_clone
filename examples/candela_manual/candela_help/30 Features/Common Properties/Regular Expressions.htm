Regular Expressions

Regular expressions specify restrictions for strings (in CANdela: string attributes or version numbers in revisions).

A regular expression consists of

  • regular characters to be found in a string,
  • meta characters that have special meaning.

Regular Characters

These represent the character itself. You can use the meta character \ to cancel the meta property of a character and use it as a regular character.

Parentheses

The two meta characters ( and ) delimit a part of the regular expression from the rest of the expression. An expression delimited in this way is evaluated separately.

Dot

A dot indicates that any character, without restriction, may occur in the string.

Set of Characters

You can use the two meta characters [ and ']' to list a set of allowed characters. The []expression represents one character from this set. You can use the - (hyphen) meta character to specify a range of characters, e.g. [a-z] denotes one low-case alphabet character.

The meta character ^ at the beginning of the selection inverts the meaning, e.g. [^a-z] denotes any character except the low-case alphabet characters.

Repetition

You can use repetigion meta characters to indicate how often the characters in the preceding expression should be repeated:

Character Description
? The preceding expression may occur once or not at all.
+ The preceding expression must occur once, but may also occur more times.
* The preceding expression may occur as often as desired (including not at all) .
{n} The preceding expression must occur exactly n-times.
{min,} The preceding expression must occur at least min-times.
{0,max} The preceding expression may occur a maximum of max-times.
{min,max} The preceding expression must occur at least min-times and may occur at most max-times.

Alternatives

You can use the meta character | to specify two expressions as alternatives.

Examples

  • Version number consisting of main version and an optional version (single digit): [0-9](\.[0-9])?
  • A qualifier of the programming language "C": [A-Za-z_][A-Za-z0-9_]+
  • A decimal number: [0-9]+
  • A hexadecimal number with prefix "0x": 0x[0-9A-Fa-F]+
  • A text with all characters except special characters: [^!"&\?\(\)\.,;:]*
