Maturity (CDS-4014 4.0 SP2)

Use-case

For objects in the CANdela document, assign...

  • a working progress or
  • quality management maturity.

Solution

[MAT-D100]

  • CANdelaStudio does not support object maturity as a built-in feature.
  • But you can define a special attribute called "Maturity" at the object types desired.
    • This needs Expert view.
  • You can edit the maturity value in the Attributes Property Page of an object.
  • If enabled in Ribbon Tab File | Options | Display, CANdelaStudio displays the Maturity of diagnostic instances and job containers in the tree [TREE-R200].
