TextIDs (TIs)

While a CANdela document may contain multiple languages in itself, TextIDs are an alternative way to support multiple languages:

  • each translatable property (e.g. a name, or a description)
  • at a CANdela object (e.g. a data object)
  • may be assigned a TextID (an arbitrary string)
  • which will be associated with translations outside to the CANdela document, e.g. in a translation tool.

Enable

Support for TextIDs must be enabled in File | Properties, page "Document Info" [DOCUI-R320].

Modes

If TextIDs have been enabled in a document, there are two modes for using them:

  • Edit
  • Completion only

The concrete mode is specified in the dialog File | Properties, page "Authorization".

Operations

Reference Identical Diagnostic Instances and Job Containers

For TextID handling in the operation "Reference Identical Diagnostic Instances and Job Containers", see at the Diagnostic Instance Operations.

Replace Similar Data Types

If enabled in the document, TextIDs can be used as a criterion [RDT-R020-TID] in the "Replace Similar Data Types" operation.
