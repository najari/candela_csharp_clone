Document Operations

The following describes operations on the CANdela document level.

New

[DOC-R600 New] Lets you select a document template.

Creates a CANdela document based on the template.

  • clears the revision history of the template
  • moves some key properties of the template into the "Template Info" at the document.

Triggered by...

  • ribbon tab File | New [MENU-R010]
  • CANdelaStudio Launcher [CDSL-R520]

Open

[DOC-R610 Open] Opens the CANdela file (document or template) in the specified View.

Triggered by...

  • ribbon tab File | Open [MENU-R020]
  • drag and drop onto CANdelaStudio
  • ribbon tab File | Recent [MENU-R340]
  • CANdelaStudio Launcher [CDSL-R520]

Language Handling

[DOC-R615]

  • CANdelaStudio does not support switching to another language after the file has been opened.
  • In Standard or Expert View, you cannot open the file in a language with "translation incomplete".
  • The default for the document language is the user interface language of CANdelaStudio. If a document does not support this language, the "default language" of the document (the first language which is up-to-date) is used.
  • The default automatically applies if you open a template/document without further interactions (double-click, last opened data in the menu data, button “New”...).
  • In Translation View, you can open any file. CANdelaStudio uses the language selected in the "Languages" list as the "reference (source) language" for translation. You can still switch the target language (to be translated to) in the Translation View.

Open a renamed Template

[DOC-R630] If you open a CANdela template .cddt renamed to .cdd, CANdelaStudio shows a hint and refuses opening (CDS-70935 v11).

Use the operation "Convert Document to Template" [DOC-R700] in Ribbon Tab "Tools" instead.

Open a non-CANdela File

If you erroneously open a non-CANdela file,

  • CANdelaStudio shows a message box indicating that the file has an invalid format;

  • the output window shows

      'DOCTYPE CANDELA' not found in file ...
    • To detect a non-CANdela file, CANdelaStudio checks the DOCTYPE information in the CANdela XML file.

Open a Corrupted File

Sometimes CANdela files get corrupted during transport via email or download from a portal. If you open such a CANdela file,

  • the output window shows details about the corruption, like

      Error 4 from xml parser: not well-formed

  • if a data transfer just randomly inserted strings into the file (unfortunately, this happened), the output window shows details like

      E: Error 4 from xml parser: not well-formed (invalid token):
  E: Line 11597, Columns 0..110
  E:   valid token: <QUALGENOPTIONS case='ignore' minLen='1' maxLen='128'
  E: Line 11597,  Column: 111
  E:   invalid token: /NewProxyWeb/app/web10-extern/>
  E: Fatal error: the file has been corrupted! If it was a data transfer (via email, download from manufacturer portal ...) that corrupted the file, it may help to transfer the original CANdela file again in a zip file.

    (CDC-41950 8.5 SP3)

Save

[DOC-R620 Save] Saves the document to the path used in Open or SaveAs.

  • [DOC-R620-SaveNumber] Increments the Save number [DOC-R200] of the document.

Triggered by ribbon tab File | Save [MENU-R040].
