Document-Level Authorization

Creation of DTCs (CDS-16999 7.0)

[DLA-R100] A document shall have a property "Creation of DTCs" with values...

  • [DLA-R100-PoolOnly] „in Chapter "Available DTCs" only“, effect:
    • [DLA-R100-Creation] creation of a DTC in a fault memory diagnostic instance in a variant is not allowed, see [DTCOP-R010];
    • For a DTC in DTC Pool, CANdelaStudio does not enforce the authorization setting "as reference" [DTC-R012-ReqAsRef], but the operations in the diagnostic instances allow only references to the DTC pool.
    • any DTC in a fault memory diagnostic instance must be a reference
    • [DLA-R100-Deletion] on deletion of a DTC in chapter "Available DTCs", a referencing DTC in a fault memory diagnostic instance must be deleted, too; see [DTCP-R018].
  • [DLA-R100-DiagInst] "in Chapter "Available DTCs" and in Fault Memory instances"

Note:

  • this flag says:
    • a given DTC code may be missing in some variants;
    • but if a DTC with the code exists in a variant, it must be a reference;
  • "required as reference" [DTC-R012] at a DTC in Pool says:
    • a DTC with this code must exist at each variant,
    • and it must be a reference.

Variable length of data objects at all places in a telegram

[DLA-R060] A data object with variable, but deterministic length [DTL-D120]...

  • can in principle be used safely at all places in a telegram,
    • because the positions of objects can be computed at runtime;
  • ... but some test systems may not support the variable length.
  • The authorization property Variable length of data objects... controls the creation / use of such deterministic length data objects.
  • See also
    • the dialog [DOCUI-R440]
    • Fixed Data Component [FD-R210]

Possible Values:

Value Description
"No" never create deterministic length data objects
"Yes, but not in individually restricted combined components" create and use deterministic length data objects, except if forbidden at the individual Combined Component [CPC-R060], see dialog [CPCUI-R060].
"Yes, in all combined compontents" create and use deterministic length data objects without restriction
