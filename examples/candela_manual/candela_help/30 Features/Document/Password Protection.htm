Password Protection (CDS-17054 7.0)

Use-Case

  • An OEM protects a CANdela template from unauthorized changes by suppliers that use an Admin edition of CANdelaStudio.
  • A document author using the Admin edition protects a CANdela document from unauthorized editing, so that only users who know a password can open the document for editing with CANdelaStudio.
  • A document author using the Admin edition protects a CANdela document from unauthorized viewing, so that only users who know a password can open the document for viewing with CANdelaStudio.

Properties

[PW-R001.0 Password Protection Properties]:

  • [PW-R001-password]: a document has a string property “passwordForEdit” (may be empty).

  • [PW-R001-protectedView]: a document has an enumeration property “protectedView” with the values
    • [PW-R001-none] none
    • [PW-R001-standard] standard
    • [PW-R001-translation] translation
    • [PW-R001-expert] expert

  • [PW-R001-consistency]: Consistency condition: “passwordForEdit” is empty iff. “protectedView” is none.

[PW-D001] “protection is set” =

  • “passwordForEdit” is non-empty, and
  • “protectedView” is not “none”.

[PW-R020]: CANdelaStudio shall store the password in a hashed form.

[PW-R030]: the tool-chain, especially tools based on older CDD versions, must open the file without restriction.

Semantics:

  • If protection is not set: the document can be opened without password (standard behavior)

  • If protection is set,...
    • ... to open the document in a view >= protectedView in CANdelaStudio >= 7.0, the user must enter the password.
    • ... if protectedView is "standard", CANdelaStudio opens the document read-only if the password is not given.

Example: with protectedView = translation, the user can open the document in standard view without password, but needs a password for translation and expert view.
