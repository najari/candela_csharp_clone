CANdela File Format

Question

I was wondering if you have a document that explains an explanation of the CANdelaStudio .CDD file. We are trying to create a tool that parses a .cdd file and use the information for automatic generation of diagnostics test cases.

Answer

​The CANdela CDD file format is an open XML format, but we do not recommend to read the CDD files directly, and therefore we do not publish the XML schema. To support new features, we regularly extend the format.

The recommended approach is to use one of the export formats, like the standardized ASAM ODX 2.0.1 / ISO ODX 2.2.0, or the services or data overview CSV exports.

You select these formats in menu File | Export.

For "Open Diagnostic Data Exchange (ODX)", you select the version in the "File Types" combo-box.
