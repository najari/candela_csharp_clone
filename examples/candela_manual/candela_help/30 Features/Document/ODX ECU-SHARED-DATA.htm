ODX ECU-SHARED-DATA

A CANdela document can hold ODX ECU-SHARED-DATA files. These are...

  • embedded like attachments and images at the document level,
  • shown in a dialog via ribbon tab Data Exchange | ODX Process [MENU-R150] and
  • used in export to ODX.

Since 8.0, an integrated ECU-SHARED-DATA file can have an ODX version from which it originates (CDS-27179).

A diagnostic instance or service that originates from ODX ECU-SHARED-DATA has special attributes set, see diagnostic instance.

[TID-R050] Editing of TextIDs is restricted at objects from ECU-SHARED-Data.

[DTLIST-R200] The data types list visualized units originating from ECU-SHARED-DATA.
