Diagnostic Instance Authorization (CDS-248, 1.3)

Some diagnostic instances and services predefined in the base variant may be protected so that they cannot be changed or deleted by the standard edition user. The author of the document template predefines these access rights (they are not modifiable in Standard View).

The following applies to diagnostic instances as well as to job containers (summarized as "containers").

[DIA-R020.0 Property „required“] with the following possible values:

  • [DIA-R020-notReq]: "No",
    • the diagnostic instance is not required,
    • it can be deleted in Standard View.
  • [DIA-R020-req]: "Yes",
    • the diagnostic instance in diagnostic class C is required: a diagnostic instance with the given qualifier must exist in all variants in the diagnostic class C
    • you cannot delete the diagnostic instance;
    • you cannot delete its diagnostic class C;
    • you cannot de-select it in variant wizard.
    • [DIA-R020-reqLIB] This does not apply in Libraries: a library need not contain a diagnostic instance with the given qualifier (but it may contain it as a copy or reference). See also Libraries in Document Context.
  • [DIA-R020-reqAsRef]: "Required as reference" (CDS-10209 6.0),
    • the diagnostic instance is required: like "Yes", but the diagnostic instance from the base variant must be referenced in all variants.
    • this corresponds with the ODX property “IS-FINAL”
    • [DIA-R020-reqAsRefLIB] same as [DIA-R020-reqLIB].
  • [DIA-R020-LIB]: a diagnostic instance in a library that is not referenced in the base variant shall not have required = "Yes" or "required as reference".
