Segment Number

[SEGNUM-R100] CANdelaStudio has special support for a "segment number" used in the specific Daimler variant coding process.

This chapter describes the feature in CANdelaStudio. For information about the process, please contact Daimler.

Segment Number

In CANdelaStudio, the segment number is an optional property of a diagnostic instance.

  • Before v10, there were at most 99 segments.
  • Starting with v10, the maximum number can be defined in the CANdela template, in the range 100 - 65535.

Display

CANdelaStudio shows the segment number...

  • in the tree, see [TREE-R210];
  • in the diagnostic instance property dialog, see next chapter.

Editing

You can modify the segment number in the Attributes Property Page of the diagnostic instance.

CANdelaStudio allows to edit the segment number even if Variant Coding Keys mode is "none" (CDS-19410 7.0 SP1).

Data Storage

CANdelaStudio stores the Segment Number in a Special Attribute "Segment_Number".

Maximum 99 Segments (Old Mechanism)

  • This is the only constellation supported in CANdelaStudio before v10.
  • [SEGNUM-D010 Old SegNum Mechanism] It still works in newer versions, ...
    • either with an attribute configured as follows,
    • or with an attribute MaxAmountSegmentNumber (see next chapter) set to value 99.

Attribute type:

  • enum
  • string (since 6.5 SP2, CDS-20790)
  • Initially, it was of type unsigned (cf. CDS-7363).

Attribute values for 99 segments:

  • enum tag id=0, string = "none" (default),
  • tag id=1, string = "01", up to...
  • tag id=99, string = "99".

Attribute creation:

  • see plugin "DCSAddDiogenesAttribute" (CDS-6803 5.0 SP1).

Setting a value:

  • You can manually set the value 0.
    • This value may occur any times within a variant.
  • You can manually set a segment number in the range 1..99.
    • Each value may occur only once within a variant [SEGNUM-R330].
  • CANdelaStudio automatically sets the segment number to 0, if...
    • you create a new diagnostic instance in the diagnostic class Variant Coding;
    • the maximum number of 99 segments already exist;
    • you paste the diagnostic instance from another variant or document.
  • In all these cases, CANdelaStudio writes a warning to the Output Window.

SegNum > 99 (CDS-68973 v10)

  • This constellation is supported in CANdelaStudio v10 and newer only.
  • If the value of the new attribute MaxAmountSegmentNumber is 99, the old mechanism applies, as described in the see previous chapter.
  • When you create a diagnostic instance, a default applies [DI-R010-SegNum].

[SEGNUM-R410 MaxAmountSegmentNumber]

Attribute MaxAmountSegmentNumber - the Identifier must be set to the desired amount

  • Attribute qualifier: MaxAmountSegmentNumber
  • at a variant
  • Attribute type: enum
    • Motivation: with an integer attribute, the user in a document would be free to set any integer value. With an enum attribute, the use can only select between values specified by the template author.
  • Attribute category: "SDG"
  • Default value (id): 99
  • The template editor may add/remove enum symbols
    • The symbols list defines the choices from which a user who is editing a document may select. In the document, the user cannot define another amount besides the predefined symbols.
    • id value range: 99..65535;
    • The enum symbols (strings) have no restriction, CANdelaStudio just displays them;
    • CANdelaStudio does not check the value range!
  • Semantics:
    • The value 99 selects the old mechanism with maximum 99 Segment Numbers (see previous chapter)! Otherwise...:
    • [SEGNUM-R410-Amount] the attribute value specifies how many segment numbers you may assign at most within a variant.
    • Note: the attribute value does not restrict the segment number values, only how many of them there may be.

[SEGNUM-R420 Segment_Number]

  • Attribute qualifier: Segment_Number
  • at a diagnostic instance
  • Attribute type: signed
    • Motivation: represent special value -1 (see below).
  • Attribute category: "ODX-Daimler"
  • Default value: 0
  • Semantics of the segment number values:
    • [SEGNUM-R420-Auto] -1: special value - the effective segment number shall be taken automatically from the identifier of the diagnostic instance.
    • In this case, a direct or indirect change of the identifier of an instance has no impact on the value of the segment number attribute, but may be detected by the consistency check if the effective segment number is no more unique.
    • [SEGNUM-R420-None] 0: the diagnostic instance has no segment number assigned;
    • [SEGNUM-R420-Manual] 1..65535: a segment number manually assigned by the user.

Setting a value:

  • You can manually set the value -1.
    • This value may occur any times within a variant.
  • You can manually set the value 0.
    • This value may occur any times within a variant.
  • You can manually set a segment number in the range 1..65535.
    • Each value may occur only once within a variant [SEGNUM-R330].
  • CANdelaStudio automatically sets the segment number to 0, if...
    • you create a new diagnostic instance in the diagnostic class Variant Coding;
    • the maximum number of segments specified by the attribute MaxAmountSegmentNumber already exist (value -1 or > 0);
    • you paste the diagnostic instance from another variant or document.
  • In all these cases, CANdelaStudio writes a warning to the Output Window.

Consistency Check (CDC-44004 v10)

  • [SEGNUM-R300] If the "Old Mechanism" [SEGNUM-D010] is activated, CANdelaStudio does not check the following conditions.
  • [SEGNUM-R310] The id values of the MaxAmountSegmentNumber enum symbols are not checked.
  • [SEGNUM-R320] The segment number must be in the range -1..65535.
  • [SEGNUM-R330] A segment number value > 0 must be unique in the variant (CDS-22114 7.1 SP2).
  • [SEGNUM-R340] At most MaxAmountSegmentNumber segment numbers may have a value -1 or > 0.
