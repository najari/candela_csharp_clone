Bundled Products

The CANdelaStudio installation contains the following bundled products:

ID Bundled Product Version See also
[IBP-R010] Vector ODXStudio 7 Vector Diagnostic Toolchain
[IBP-R020] Vector License Manager 1.4 SP1 Licensing for Software Based Licenses
[IBP-R030] Vector CANdelaPersistors 12 Persistors Add-on
[IBP-R040] Vector License Client 4.4.0 Licensing for Vector Licenses (new in 2018)
[IBP-R050] Diagnostic Data Modifier 17.02.00 AUTOSAR Diagnostic Extract
[IBP-R060] Vector Support Assistant 3.3 Vector Support Assistant

See also the Installation Folder chapter.

GraphViz (not included)

[IBP-D090] CANdelaStudio does not ship the GraphViz package with its installer (for licensing reasons).

  • If GraphViz has been installed, CANdelaStudio uses it to visualize the state dependency of service execution [STUI-R180].

Vector License Service (before v10)

[IBP-R042.0] Before v10, the Vector License Service was included.
