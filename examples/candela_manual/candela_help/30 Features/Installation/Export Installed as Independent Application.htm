Export Installed as Independent Application (CDS-71297 v12)

CANdelaStudio ships with built-in export components.

On a service project basis, Vector may optionally provide an export component as an independent application.

  • The application is installed into a global folder.
  • Multiple CANdelaStudio versions (starting with v12) may use the same installed export application.
  • As a default, CANdelaStudio uses the independent application if it is newer than the built-in export, see [DXEXE-R110] below.
  • The export application shall be used by CANdelaStudio only, not standalone, so it has a license protection.

Scope

As of CANdelaStudio 12, this feature is optionally available for ODX Export only.

Built-in Component vs. Independent Application

[DXEXE-R100]

Built-in Component Independent Application
File Type DLL EXE
File Name ODXExportXXX.dll ODXExport.exe
Location CANdelaStudio bin directory Program Files\Common Files\Vector ODX Export
Start internal DLL function call via command line in a separate process
Parameters function parameters command line parameters (internal)
Shipping with CANdelaStudio as patch installer

Component Selection

[DXEXE-R110] When an export is available as independent application, CANdelaStudio determines the component to run as follows:

FeatureID Example Application Version is... Component Started
[DXEXE-R110-EXE] Built-in v13, Application v14 newer Application
[DXEXE-R110-INI] Built-in v13, Application v14 newer, Option [OPT-R245] set Built-in
[DXEXE-R110-DLL] Application v12, built-in v13 older Built-in

Sequence of Operation

[DXEXE-D120] When you execute an export with the global installation, CANdelaStudio...

  • stores the document to be exported as a copy in the Temp directory
  • stores the INI file to ensure that the ODXExport.exe has access to your recent configuration changes
  • determines the necessary command line parameters
  • runs the export via command line in a separate process
  • waits for finalization of the export process. This is required because of:
    • Feature “Show ODX Data after export” (checkbox in the dialog of [MENU-R120])
    • Action: “ODX 2.0 export done” [ACT-R200]
  • informs in the Output window about the success, the expected result and logfile
  • finally deletes the document in the Temp directory.

Logfile

[DXEXE-R130] The application writes a logfile.

  • [DXEXE-R130-Dir] Location: in the directory of the export output files.
  • [DXEXE-R130-Name] Name:
    • the name of the file given with command line parameter /o
    • with the file ending .log.
  • [DXEXE-R130-Copy] After the application terminates, CANdelaStudio copies the logfile contents to the CANdelaStudio logfile.
