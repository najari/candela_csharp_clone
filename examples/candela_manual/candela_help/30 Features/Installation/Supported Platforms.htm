CANdelaStudio Font

[ISUP-R200] CANdelaStudio since 9.1 uses the standard font Microsoft Sans Serif available on any Windows system (CDS-68599 9.1). No special font setup should be required on your installation.

Note: before 9.1, CANdelaStudio as a default used "Arial Unicode MS". This font is no more available with Office 2016.

Note: this information is also in the Readme [ISTM-R030-Readme] available in Windows start menu.
