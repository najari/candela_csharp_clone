Documentation

After installation of CANdelaStudio, you will find a folder with detailed documents in the Windows start menu under

CANdelaStudio - Help - Documentation

In the file system, it is typically located in

C:\Program Files\Vector CANdelaStudio <VERSION>\Docs

List of Files

The Documentation folder contains the following information:

File Contents
ASAM-ODX-Export-ErrorCodes.htm
ASAM-ODX-Export-WarningCodes.htm		 Docs for ODX Export
in addition to the info here in the online help.
ODXImport Options.pdf Docs for ASAM ODX Import,
in addition to the info here in the online help.
CANdelaDiff-DTD.htm
CANdelaDiff.dtd		 Docs for the export of Compare View
Cdi.dtd
cdi-dtd-1.5.2.htm
Cdi.xsd		 Docs for the "CANdela Data Import” (CDI) Format [CDI-R010]
Diogenes-Export-ErrorCodes.html Docs for Diogenes export (Daimler specific)
DocRevisions.dtd
DocRevisions.htm		 Docs for the export of revision history
DocVersion.dtd
DocVersion.htm
DocVersion.xml		 Docs for the export of versions
Readme.htm [ISTM-R030-Readme]
ReleaseNotes.htm		 Information about the current CANdelaStudio release.
The Release Notes are also here in the online help
History.htm Information about previous CANdelaStudio releases
ThirdPartySoftware (subfolder) Docs for third party software used by the CANdelaStudio implementation.
VCK-DTD-1.0.0.htm
Vck.dtd		 Docs for the Variant Coding Keys Export.
VSG-DTD-1.0.0.htm
vsg.dtd		 Docs for the Vehicle System Groups Export.
