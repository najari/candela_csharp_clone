CANdelaStudio MSI

The CANdelaStudio installation comes with

  • the CANdelaStudio.msi containing the functionality of the CANdelaStudio application,
  • bundled products and
  • prerequisites.

The CANdelaStudio installer will install these parts automatically.

The following information will be helpful if you want to take detailed control over the installation, typically for in-house installers.

Interactive Use

Only install CANdelaStudio.msi with the /quiet setting.

Interactive use may show dialogs not supported by Vector.

Installation Blocking (CDS-69584 9.1)

Use-case

  • on a computer where CANdelaStudio has been (or will be) installed as main product, typically using an in-house installer,
  • the off-the-shelf installation of another Vector diagnostic tool (CANoe, CANape...) shall not install its bundled CANdelaStudio.

Definitions

[CDSMSI-D010]: registry keys to block bundled installation:

  • [CDSMSI-D010-native] HKEY_LOCAL_MACHINE\SOFTWARE\Vector\CANdelaStudio\DoNotInstallAsBundledProduct
    • string

[CDSMSI-D020]: MSI parameter to indicate installation as bundled product:

  • INSTALLASBUNDLEDPRODUCT
  • Note: MSI forces parameter names to be upper case.

Solution

Installation Blocking Overview

[CDSMSI-R001]: when the CANdelaStudio MSI gets installed,...

  • if it has been started with parameter [CDSMSI-D020] != 0,
  • and the registry key of [CDSMSI-D010-native] exists, is not empty and not the string 0,
  • then the MSI writes an info to the logfile and skips installation, indicating success.
  • The info looks like: Skipping CANdelaStudio installation as bundled product due to registry key <path>.

Implementation

  • In the MSI, checking the registry key of [CDSMSI-D010-native] is enough, since this is how the MSI sees the key (even as 32 bit MSI on a 64 bit system).
  • All Vector tools that bundle CANdelaStudio must set the parameter [CDSMSI-D020].
    • CANape: implemented in 15.0 SP4 (CANAPE-136841) and 16.0 SP2 (CANAPE-136842).
    • CANoe/CANalyzer: implemented in 10 SP6 and 11.0.
  • In-house installers at customers must ...
    • set the registry keys [CDSMSI-D010], and
    • not set the parameter [CDSMSI-D020].

MSI Warnings

[CDSMSI-R050] CANdelaStudio.msi no more installs desktop icons (CDS-28140 8.0) in order to avoid warning ICE69.

CANdelaStudio in Windows Explorer

[CDSMSI-R060] The CANdelaStudio.msi puts the CANdelaStudio version installed (starting with 7.0) as a menu item in the Windows Explorer context menu for CDD/CDDT files (CDS-13020 7.0).
