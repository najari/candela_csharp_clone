Windows Start Menu

After installation, the windows start menu contains

  • [ISTM-R010] entries to start CANdelaStudio (one entry for each user interface language),
    • for details, see the next chapter.
    • Cf. the related choice [CDSL-R820] in the CANdelaStudio Launcher.
  • [ISTM-R050] an entry to start the CANdelaStudio Launcher
  • [ISTM-R020] a sub-folder for the example documents
  • [ISTM-R030] a sub-folder for help files:
    • [ISTM-R030-Help] online help
    • [ISTM-R030-Docs] the documentation folder
    • [ISTM-R030-Readme] the readme file
  • [ISTM-R040] a sub-folder for the productive templates

[ISTM-R100] In the Windows start menu, CANdelaStudio shows the version number at the application icons (like for the start menu folder) (CDS-38387, 8.5)

Command Files to Start CANdelaStudio (CDS-70522 v10)

  • Before v10, the installer created links to the CANdelaStudio application, using different language parameters [CLI-R100-language].
  • Under some circumstances, the Windows 10 start menu shows only one of them.
  • [ISTM-R010-Command] Therefore, since v10 the installer creates command files that start the German and Japanese language version.
