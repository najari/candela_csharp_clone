Setup (Installation)

Starting Setup

  • If you install CANdelaStudio from a DVD, typically the setup dialog starts automatically when you insert the DVD.
  • You can start the setup dialog manually by double-clicking the file autostart.exe on the DVD.

CANdelaStudio Setup

  • "Install CANdelaStudio" runs setup.exe.
  • "View Readme" opens the Readme file [ISTM-R030-Readme] in the browser.
  • "View Release Notes" opens the Release Notes in the browser.
    • You can also view these Release Notes here in the online help, where they contain hyperlinks to features.
  • "Vector Website" takes you to https://vector.com in the browser.

Setup.exe

When you...

  • click "Install CANdelaStudio" on the DVD, or
  • run a single-file installer,

the file setup.exe runs.

It ensures that fundamental prerequisites for the installation process are available:

  • [ISETUP-R100] installs Windows Installer >= 3.1,
    • checks the msi.dll exists, and the version of this dll >= 3.1
  • [ISETUP-R110] installs the .NET 4.x prerequisite,
    • checks the registry key HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full, value name "Install", value "1"

... [ISETUP-R120] then runs the installation wizard (file MSIChainer.exe).

[ISETUP-R130] Setup.exe Logfile:

  • Setup.exe writes a logfile to %TEMP%\MSIChainerSetup.log,
  • e.g. D:\Temp\MSIChainerSetup.log

Installation Wizard

Installation Wizard

The installation wizard provides the following steps (pages):

  • [ISETUP-R300] Welcome
    • (shown above) -[ISETUP-R310] Choose Destination Folder
    • The page lets you select the “root path” under which the main product and the bundled products will be installed
      • The target folder of prerequisites is usually predefined and not affected by your selection.
    • The default for the root path is the Windows program files folder
    • A static text shows the installation path of the main product,
    • ... the default is <Program files folder>\Vector CANdelaStudio <Version>
    • If you specify a different root path, the wizard updates the installation path of the main product.
  • [ISETUP-R320] Installation Settings Summary
    • displays the main product and all selected bundled products with their installation path.
    • Button "Install" actually starts installation of the files on your computer.
  • [ISETUP-R330] Installation Progress
    • [ISETUP-R330-Prog] The page shows the progress of the current product/prerequisite installation and the total progress of the installation.
    • [ISETUP-R330-Cancel] The screen allows to cancel the installation.
    • If you cancel the installation, the wizard...
      • rolls back the installation of the product / prerequisite currently being processed,
      • but keeps all products / prerequisites installed before the current one.
  • [ISETUP-R340] Installation Complete Screen
    • [ISETUP-R340-Start] The page allows to start the main product
    • [ISETUP-R340-RN] ... and to display the Release Notes (like the setup dialog above).
    • [ISETUP-R340-Link] If an error occurs during the installation, the page displays a link to the logfiles folder. Clicking the link opens the log file folder in Windows Explorer.
    • [ISETUP-R340-OKLink] The logfiles are available even if no error occurred.

[ISETUP-R350] Installation Wizard Logfile:

  • the installation wizard writes a logfile to %TEMP%\CANdelaStudio\Install\MSIChainer.log,
  • e.g. D:\Temp\CANdelaStudio\Install\MSIChainer.log
