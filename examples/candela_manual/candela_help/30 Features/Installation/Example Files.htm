Example Files

CANdelaStudio ships with the following files (links to details in chapters below):

  • CANdela templates available for productive use
  • Example CANdela documents
  • Example import files
  • Repository examples files for the Repository Integration.

Some files are directly available via...

  • the Windows start menu under Examples
    • templates, documents, import samples;
  • the File|Open page
    • templates, documents.

Installation Folder

All files are installed to a folder specific for the CANdelaStudio version, e.g.

C:\Users\Public\Documents\Vector\CANdelaStudio\10.0\Examples

CANdela Templates for Productive Use (CDS-39645 8.5)

  • Vector UDS
  • Vector KWP on CAN
  • Vector UDS on LIN

Tailored CANdela Templates

If you need a tailored template, Vector may assist you with

  • training for the Admin View
  • creation of ODX Authoring Guidelines
  • creation of a tailored template
  • verification of your template against the Vector diagnostic tool chain

Vector does not assume any liability or offer any guarantee for tailored templates that have not been verified by Vector!

Example CANdela Documents

  • ABS/ESP shows CANdelaStudio features using realistic data for an ABS/ESP system.
  • Multilingual contains four languages (German, English, French, Japanese) and demonstrates the multilingual capabilities of CANdelaStudio. The amount of diagnostic data is reduced.
