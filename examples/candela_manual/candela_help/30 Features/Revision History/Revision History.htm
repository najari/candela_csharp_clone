Revision History

Each CANdela document contains a list of revisions as well as a list of authors.

Revisions are sometimes also called "revision items".

For the User Interface, see the Revision History dialog.

Revisions

As a default, a CANdela document contains revisions that apply to all variants.

[REV-R010] A revision entry has...

  • [REV-R010-Version] Version (must optionally conform with a given version format, see below)
  • [REV-R010-Date] Date (in ISO format)
  • [REV-R010-Tool] Tool (free text)
    • [REV-R010-ToolLang] The Tool text is not multi-language.
  • [REV-R010-Status] Status (see Status chapter below)
  • [REV-R010-Author] Author (see Authors chapter below)
  • [REV-R010-Mod] Modification (free text)
    • [REV-R010-ModLang] The Modification text is not multi-language.
  • [REV-R010-Reason] Reason (free text, optional)
    • [REV-R010-ReasonLang] The Reason text is not multi-language.

Note: the texts are intentionally not multi-language.

  • They are concerned with authoring and not interesting for the user of a test system.
  • Therefore it would be unnecessary effort to synchronize them in multiple languages.

Status

For a revision entry, CANdelaStudio supports a numeric status.

The revision history dialog maps the numeric status values to hard-coded strings.

Per Variant and Library

Starting with version 7.0 (CDS-16560), the template has a boolean flag to force each variant in the CANdela document to have its own revision history (cf. the dialog).

[REV-R050-LIB] Starting with 8.5 SP2, this applies to libraries, too.

Authors

Each revision history entry references an author.

An author has

  • first name
  • last name
  • short cut (must be unique; see below)
  • company
  • department (optional)
  • email (optional)
  • phone (optional)
  • fax (optional)
  • info (optional)
  • outdated (see below)
  • responsible for this ECU (see visualization in dialog). Multiple authors can have this property.

Shortcut

The author shortcut is a unique, identifying property.

Such a shortcut seems well established in companies. Even if the shortcut may be not unique in the company, it makes sense to demand uniqueness within one CANdela document.

Outdated

If you modify author properties (e.g. change of department or even company), the modification may be inappropriate for existing revision history items that reference this author ("do not manipulate history").

If you want to precise about the relationship of the author and the revision items, you may

  • mark the existing author as "outdated"
  • create a new author with the modified properties and refer to this one in future revision entries

Revision History from Import

Import automatically adds ODX variant information to revision history (8.2 SP3, CDS-38709).

Version Format (CDS-1454 5.0)

In the template, you can define an optional format for the version string of a revision item.

  • the format is defined as a regular expression;
  • any length allowed (even 0). Empty property means no restrictions;
  • the character set is unrestricted;
  • additionally, there is a human readable description of the version format (not translatable)

Document upgrade warns if a revision version does not match Version format of the target template.

Consistency check compares the revision version against the version format from the template. It treats mismatch as a non-fatal error (= allows loading the file in CANdelaStudio, but disallows exports). It reports the mismatch as a warning, like

Revision version '4.0.a' does not match pattern '\d+\.\d+\.\d+'

When loading files with version < 5.0 (forward migration), the property is empty (no modification of existing revision versions).

When saving to files with version < 5.0 (backward migration), the property gets dropped.

Deleting Revisions

[REV-R200-DeleteAll] In Standard View, only all revision entries can be deleted together.

  • therefore, multi-selection and the DEL key are not available in Standard View (CDS-70302 v10).

[REV-R200-Delete] In Expert View, any individual revision entry can be deleted.
