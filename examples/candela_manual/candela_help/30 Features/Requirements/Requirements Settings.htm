Requirements Settings (Document Level)

These settings are shown and edited in the Property Page "Settings".

ID Prefix

[RQ-R092.0 ID Prefix]: the CANdela document shall have a string property used as prefix for the ID of new requirements [RQ-R090] (above).

Example: prefix _ID gives requirements ID _ID4711.

See the user interface [RQUI-R100-IDPrefix].

Default Data Type

[RQ-R094.0 Default Data Type]: the CANdela document shall have a default data type used to create data objects from requirements [RQ-R544-DataType].

Initially, the data type may be missing, but it must be specified before creating data objects.

See the user interface [RQUI-R100-DataType].

Library / Variant (CDS-40445 8.5 SP2)

[RQ-R093 Requirements - Selected Library or Variant]: the CANdela document defines one library or variant as the base for operations on requirements:

  • equality
  • update diagnostic objects
  • update requirements

See the user interface [RQUI-R100-Variant].

CANdelaStudio supports libraries for requirements since v11 (CDS-70801).

  • [RQ-R093-SelVariantPersistent] the library or variant setting is persistent (stored in the CDD and available after loading the document again).
  • [RQ-R093-SelVariantDefault] Default is the base variant.
  • [RQ-R093-SelVariantInitially] The default applies if you have not yet selected any library or variant.
  • [RQ-R093-SelVariantDelete] The default applies after the selected library or variant has been deleted from the document.
  • [RQ-R093-SelVariantRename] The default applies after the qualifier of the selected library or variant has been changed.
  • See also the user interface [RQUI-R100-Variant].

Update of Diagnostic Objects (CDS-41683 v11)

[RQ-R096] The setting "Update of Diagnostic Objects" has two values:

  • [RQ-R096-Copy] "Replace References with Copy" (new in v11)
  • [RQ-R096-UpdateRefs] "Update References" (the behavior before v11)

See the user interface [RQUI-R100-Update] and the effect in the operation "Update Diagnostic Objects" [RQ-R520].

  • [RQ-R096-Default] At the first run of CANdelaStudio 11, the setting is:
    • if the selected variant/library [RQ-R093] is a variant: "Replace References with Copy"
    • otherwise: "Update References"
  • [RQ-R096-Save] The setting gets lost if you save the document with a CANdelaStudio version before 11.

Note: the setting is independent from the tool wide option "Modify Referenced Diagnostic Instance" in Ribbon File|Options, page Confirmations.
