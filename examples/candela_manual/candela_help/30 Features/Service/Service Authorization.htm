Service Authorization

  • Required: if set, you cannot delete the service. Applies only for "optionalYes" or "optionalNo" services in "required" diagnostic instances in the base variant.

  • Directly executable in the test system: specifies whether the service can be executed by a user of test system directly. Corresponds with the ODX property "IS-EXECUTABLE" at DIAG-COMM (DIAG-SERVICE).
