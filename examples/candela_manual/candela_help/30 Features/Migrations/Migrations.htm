Migrations

Introduction

Due to customer-driven extensions of the CANdela data model, each new release of CANdelaStudio...

  • implements a modified CDD file format and
  • provides migration from and to older file formats.

For migration from and to newer file formats, CANdelaStudio uses the separate Persistors add-on. Vector provides updated add-on versions that support newer CANdela file formats on the Vector homepage.

The migrations implemented in the CANdelaStudio versions are described in the respective feature chapters. The following lists provide an overview and hyperlinks into the feature chapters (mainly since CANdelaStudio 8.5).
