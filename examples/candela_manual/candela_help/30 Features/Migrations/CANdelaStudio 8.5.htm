Attribute Category "UDS"

[MIG85-R001] (CDC-41386 8.5 SP2):

  • in migration from >= 8.5 SP to < 8.5 (built-in down migration),
  • if the document has the attribute category "CANdesc",
  • then at each ECU attribute that has one of the qualifiers below,
    • if the attribute has category "UDS",
    • then modify the category value at the attribute to refer to the "CANdesc" category.

Qualifiers:

  • MaxNumberOfDynDefinedDidReferences
  • Periodic_Rate_Slow_in_ms
  • Periodic_Rate_Medium_in_ms
  • Periodic_Rate_Fast_in_ms
  • DDDID_check_per_source_ID
  • DDDID_configuration_storage

[MIG85-R001-v12] Additional migrations added at the time of CANdelaStudio 12 (CDC-44051):

  • MaxAttemptsToDelay
  • MaxAttemptsToLock
  • DelayTimeMs
  • DelayTimeOnPowerOnMs

Motivation:

  • the attributes are also needed for the AUTOSAR Export,
  • actually these are UDS attributes,
  • therefore the Vector UDS Template now has category "UDS" for them,
  • but the documents must still work with CANdesc based on the 6.5 file format.
