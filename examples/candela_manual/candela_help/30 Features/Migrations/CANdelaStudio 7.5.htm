Migrations CANdelaStudio 7.5

Ford Communication Parameter (CDS-26020)

Ford CAN_Identifier Migrations

Up Migration

  • For a template/document with manufacturer Ford,
  • version < 7.5 SP2,
  • interface qualifier HS_CAN or MS_CAN
  • ComParam with qualifier CAN_Identifier
  • [MIG75-R010] CANdelaStudio since 7.5 SP2 (CDS-26020) migrates to...
    • qualifier CanIdType
    • name CAN-ID Type
    • If a ComParam with qualifier CanIdType already exists, 7.5 SP2 creates a duplicate (=> fails to load).
  • [MIG75-R020] CANdelaStudio since 7.5 SP3 P2 and 8.0 SP1:
    • If a ComParam with qualifier CanIdType already exists, does not create a duplicate.

The migration writes the following debug output:

D: Migration 7.5.2100: renamed communication parameter 'CAN_Identifier' of interface 'HS_CAN' to 'CanIdType'.
D: Migration 7.5.2100: renamed communication parameter 'CAN_Identifier' of interface 'MS_CAN' to 'CanIdType'.

Down Migration

  • [MIG75-R110] CANdelaStudio since 7.5 SP2 (CDS-26020)
    • saves the CanIdType ComParam unchanged (no clone)
  • [MIG75-R120] CANdelaStudio since 7.5 SP3 P2 (CDS-30383) and 8.0 SP1 (CDS-29690)
    • clones the CanIdType ComParam to a CAN_Identifier ComParam (if the latter does not exist)

Services Supported for Interfaces

[MIG75-R200 Down Migration] If you save a 7.5 or newer document to a document format before 7.5, and...

  • any Used Protocol Service
  • is not supported at some interface [SSI-R100],
  • the migration creates the special attribute InterfaceExcludedForService
    • authorization: visible=false, modifiable=false, export to specification=false
    • usage=system (= not visible even in Expert View)
  • and stores the information in it.

[MIG75-R210 Up Migration] If you load from a document format before 7.5, ...

  • if the special attribute InterfaceExcludedForService exists,
  • migration reads "Services Supported for Interfaces" information [SSI-R100] from the attribute
  • and deletes the attribute.
