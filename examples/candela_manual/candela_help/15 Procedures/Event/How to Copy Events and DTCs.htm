How to Copy Events and DTCs

Procedure

  1. in the source DTC list, copy the DTCs
  2. in the target DTC list, paste the DTCs
  3. do the same for the Events

Background

  • DTCs and Events are distinct objects in the CANdela data model (CDS-42224 v12)
  • In general, in a copy/paste operation it is not clear whether the operation should include the respective other object or not.
  • Therefore CANdelaStudio...
    • copies only DTCs, no referencing Events;
    • with the Event copies the reference to a DTC,
      • if the DTC already exists,
      • based on the numeric code.
    • For details, see the Event operation [EVOP-R060].
