How to Specify Event Qualifiers before v12

Introduction

  • Since CANdelaStudio 12,
    • you can describe Events directy in a CANdela document.
    • The feature is optional and must be enabled [EV-R010].
    • The following does not apply to such documents.
  • If...
    • the Events feature is not enabled in the document, or
    • in a document created before CANdelaStudio 12,
    • the export to the AUTOSAR Diagnostic Extract format derives event information from DTCs.
    • In such documents, in Expert View, you can add a DTC column that holds the Event qualifier for DEXT export.

The following describes the procedure to

  • add a DTC column for documents without Events support,
  • and make DEXT export use this information.

Create DTC Column

  • Open a CANdela template
    • The following steps are not supported in a CANdela document.
  • Navigate to the Error Code Table.
  • Create a DTC Column of type Translatable [DTCC-R010-Translatable].
    • Call it Event_Name.

Patch File to Configure DEXT Export to use the DTC Column

  • Create a "Patch file" (simple text file) with the contents:
Protocol "UDS"
Manufacturer "GENERIC"


for event [any]
use shaper "FaultMemory2" :
EXTRACT_EVENT_QUAL: call ExtractEventProp("Qualifier", "DTC", "Event_Name")
end shaper
  • Close CANdelaStudio
  • In the CANdelaStudio INI file, specify the path to the "patch file", see [INI-R352].
  • Specify Event qualifiers in the DTC column "Event_Name".

Note: this example...

  • applies to the GENERIC manufacturer handling in DEXT export only,
  • not to customer specific adaptations.
