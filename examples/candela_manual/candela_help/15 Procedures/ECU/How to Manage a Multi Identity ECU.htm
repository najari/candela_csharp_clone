How to Manage a Multi Identity ECU

  1. Open the "master" ECU document that represents one "identity" (variation) of the ECU.
    • Example: "Door Front Left"
  2. Select ribbon tab Tools | Plug-Ins (Current Document) | Manage MultiIdentityECU
    • CANdelaStudio opens a dialog with an edit control
  3. Press button "Insert alternative ECU"
    • CANdelaStudio fills the edit control with details about an alternative ECU taken from the communication parameters of the ECU document
  4. In the first line with square parentheses, insert the qualifier of the alternative ECU
    • Example: [DoorFrontRight]
    • blanks or special characters are not allowed, see Qualifier.
  5. In the line starting with "Name=", append the name of the alternative ECU
    • Example: Name=Door Front Right
  6. In the line starting with "Path=", append the name of an existing folder into which CANdelaStudio shall output the document for the alternative ECU.
    • Example: Path=d:\temp
  7. In the lines below, enter values for those communication parameters that shall be different from the master document.
    • Example: Diagnostic_CAN.ReqCanId=0xA2
    • Note: you may leave all other lines, or delete them to increase readability.

    Dialog "Manage Multi Identity ECU"

  8. Press button "Check"
    • the line on top should read "Data ok"
    • otherwise correct the erroneous lines in the edit control, and press "Check" again.
  9. Press button "Generate documents".
    • CANdelaStudio creates a document based on your input.

  10. You may inspect the output folder using Windows explorer, e.g.

    Folder with Alternative ECU

  11. In the dialog, press OK
  12. Save the master document.
  13. To decribe further alternative ECUs, open the dialog again, and press button "Insert alternative ECU" again.
    • Each time you press the button, CANdelaStudio appends settings for a further ECU in the edit control.
    • Proceed as for the first alternative ECU.
