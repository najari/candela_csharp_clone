How to Handle Issues with a Second Monitor (CDS-68957)

Context

  • When you have been using CANdelaStudio on a second monitor (e.g. notebook at the desk)
  • and later restart it with a single monitor only (e.g. notebook undocked),
  • then CANdelaStudio should be shown on the single monitor.

If this does not work as expected, the following workarounds may help.

Workaround Using Windows Key

  1. Select CANdelaStudio in the Windows Task bar
  2. Hold the Windows key
  3. Press the arrow left key
  4. Press the arrow right key

This typically brings CANdelaStudio back to the main screen.

Workaround Using INI File

  1. Close CANdelaStudio
  2. Open CANdelaStudio.ini
  3. Delete the Parameter FnMainFormPos
  4. Restart CANdelaStudio

Workaround Using Taskbar Context Menu

  1. Start CANdelaStudio twice
  2. In the Windows taskbar, in the context menu (right mouse) of the second CANdelaStudio instance, select option "Move to monitor 1" (or just "Move").
