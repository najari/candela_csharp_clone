How to Open a Template in Expert View from Windows Explorer

If you have CANdelaStudio Admin edition installed and want to open CANdela templates (.cddt files) directly from the context menu in Windows Explorer, do the following:

Windows Registry Editor Showing the Key to Create

  • open the Windows registry editor (e.g. open the Windows start menu, type "regedit", ENTER)
  • confirm the prompt to let the application perform changes
  • in the tree, navigate to HKEY_CLASSES_ROOT/CANdelaDiagnosticTemplate/shell
  • press right mouse on "shell", select "New" - "Key", enter e.g. "CANdelaStudio 8.2 (Expert View)" (corresponding with your version of CANdelaStudio)
  • press right mouse on the new entry, select "New" - "Key", enter "command"
  • in the right side, double click on "(Standard)", a dialog appears
  • enter the following command line: "C:\Program Files (x86)\Vector CANdelaStudio 8.2\Bin\CANdelaStudio.exe" /expert 1 "%1"
  • close the registry editor
  • after a Windows restart, the context menu item is shown in Windows explorer on .cddt files
