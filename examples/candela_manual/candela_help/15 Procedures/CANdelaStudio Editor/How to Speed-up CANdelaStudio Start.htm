How to Speed-up CANdelaStudio Start

If starting CANdelaStudio takes several minutes, the local storage of the FlexNET licensing mechanism may need a cleanup.

Starting with CANdelaStudio 8.5, you can use the 'LicIgnoreFlexNet' INI file parameter Licensing INI file parameters to check whether the delay is actually due to the licensing mechanism.

If this is the case, you may contact Vector Support for help with cleanup of the FlexNet local storage.
