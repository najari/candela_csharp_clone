How to Use CANdelaStudio with High DPI Scaling

Some dialogs may look strange on Windows 10...

  • with modified scaling (e.g. 150%)
  • typically on high-DPI screens (4K)

The following worked on some systems:

  • In Windows Explorer,
  • on CANdelaStudio.exe,
    • in a standard installation: C:\Program Files\Vector CANdelaStudio 11\Bin\CANdelaStudio.exe
  • open the property dialog
  • go page „Compatibility“
  • select „Change high DPI settings“
  • set to „System (Enhanced)“

More improvements are planned for v12 (2019-07).
