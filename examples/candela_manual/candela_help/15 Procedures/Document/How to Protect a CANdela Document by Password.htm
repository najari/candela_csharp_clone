How to Protect a CANdela Document by Password

From Version 7.0, CANdelaStudio offers password protection for CANdela documents or templates.

How to Assign a Password to a CANdela Template or Document

  1. Open [MENU-R020] the CANdela template or document in the Expert view.
  2. Choose ribbon tab File | Properties....
  3. Click the Password page
  4. Check the checkbox "Password protection"
  5. Enter a password under New password and Confirm new password.
  6. Select the view in which the document should be protected.
  7. Click button [OK].
  8. Save the document.

How to Remove Password Protection From a CANdela Document

  1. Follow the steps 1-3 above to open the Password page.
  2. Enter the password of the CANdela document under Current password. Leave "New password" and "Confirm new password" empty!
  3. Click button [OK].
  4. Save the document.
