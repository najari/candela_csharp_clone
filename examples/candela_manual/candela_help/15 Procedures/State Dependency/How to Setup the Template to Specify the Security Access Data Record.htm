How to Setup the Template to Specify the Security Access Data Record

In the protocol service for "Request Seed":

  • The request of the protocol service must contain a proxy component with qualifier "securityAccessDataRecord".

To specify the additional properties of the security access record for code generation, the following attributes must exist on diagnostic instance level with attribute category "CANdesc":

  • “Failure delay time” (qualifier “FailureDelayTime”, default value: 10 [sec], type: Unsigned)
  • “Failures to delay” (qualifier “FailuresToDelay”, default value: 3, type: Unsigned)
  • “Delays to lock” (qualifier “DelaysToLock”, default value: 6, type: Unsigned)

Tip: restrict the attributes to exist at diagnostic class "Security Access" only (do this in the "Restrictions" page of the attribute property dialog).
