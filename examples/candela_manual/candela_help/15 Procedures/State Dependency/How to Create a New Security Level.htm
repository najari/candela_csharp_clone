How to Create a New Security Level

  • select the variant in which the new security level should be inserted.
  • navigate to "Supported Diagnostic Classes" - "Security Access"
  • click the button "New Level..." (at the bottom), or use the context menu item "New Security Level...".
  • follow the instructions of the wizard

Note: in the diagnostic class "Security Access", you can open the wizard by clicking the button "New Level" at the bottom of the right side (note: the diagnostic class name "Security Access" is configured in the template).

The wizard creates...

  • two diagnostic instances,
  • a new state in state group "Session" and
  • best-practice state transitions for services

Note: "New diagnostic instance" in the context menu creates only one, not two diagnostic instances, no state and no specific state transitions. This is not recommended.

Specify the Security Access Data Record

If supported in the template, you can specify the data in the third wizard page:

  • a data type for the security access data record
  • its additional properties "Failure delay time", "Failures to delay" and "Delays to lock"

If the template has not been setup accordingly, then the corresponding selection list and entry fields are locked in the wizard.
