How to Prepare a Document for FTB and FMI

  • Open the document in the Expert view.
  • Switch to the "Data Types" chapter.
  • Create a data type with "Text table" conversion and a length of 8 bits for FTB, or 5 bits for FMI. Enter the error type texts for each FTB or FMI in the table.
  • Click ribbon tab File | Properties....
  • Go to page Display of DTCs
  • For FTB:
    • select "ISO 15031-6 / SAE J2012"
    • in the Failure Type Byte combobox, select the data type created above
  • For FMI:
    • select "SAE J1939-73 (Version 4)"
    • in the Failure Mode Identifier combobox, select the data type created above
  • Click OK
  • Save the document.
