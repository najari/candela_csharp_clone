How to Describe DTC Specific Snapshot Data

There are two ways, depending on the template on which your document is based.

  1. using a Multiplexer within the service structure (see below);
  2. since CANdelaStudio 13 using a special data structure for Snapshot Records (see below).

Consider doing "Replace Reference with Copy" first (see next chapter):

  • in case the Fault Memory diagnostic instance is referenced in multiple variants,
  • but you want the changes to apply only to one variant.

"Replace Reference with Copy" for Diagnostic Instance in Multiple Variants

  • Snapshot Data is defined in a diagnostic instance
  • A diagnostic instance may be referenced in multiple variants
    • see the description of tree Icons
  • if you want to apply the changes to one variant only:
    • first execute the menu item "Replace Reference with Copy" [MENU-R440] on the diagnostic instance in the tree (in ribbon tab "Home", under "Replace"; also in context menu)

Fault Memory within Service (Using Multiplexer)

  • in the CANdelaStudio tree in the respective variant, select the node "Fault Memory" or "DTCs" (the name is defined in the template)

    Fault Memory Diagnostic Instance

  • consider to "Replace Reference with Copy" first, see above.
  • Under "Service:", in the line "Read - snapshot record", click the "rr" behind "59 04"
  • at the bottom, the area for editing snapshot records is shown (Multiplexer based)
  • select a DTC in the list to the left

  • describe the snapshot data in the list to the right

See the description of the dialog.

AUTOSAR Fault Memory (v13)

Preconditions

The following is based on the simplified description of Snapshot Records since CANdelaStudio 13, which must be enabled by specific Protocol Service components in the template, see the Introduction.

Steps

DTC Specific Snapshot Data

  • in the CANdelaStudio tree in the respective variant, select the node "Fault Memory" or "DTCs" (the name is defined in the template)
  • consider to "Replace Reference with Copy" first, see above.
  • At the bottom of the dialog, click the button for snapshot records .
  • select TAB "UDS Snapshot Data per DTC"
  • select a DTC in the list to the left
  • describe the snapshot data in the list to the bottom right: click the line "Add DIDs..." and select DIDs.

DID Groups

You may want to assign the same set of DIDs to multiple DTCs.

This is sometimes called "DID Groups".

The CANdela data model does not support a "DID Group". Instead, you can select multiple DTCs in the list and assign DIDs to all of them.
