How to Transport a CANoe Automation Sequence Macro as a CANdela Job

CANoe 10 supports Automation Sequence Macros to record the byte sequence of UDS requests.

CANdelaStudio supports embedding "job files" in a CANdela document.

The following describes how to manually...

  1. store a CANoe Automation Sequence Macro in a CANdela document
  2. and later (maybe on a different computer) use the macro from the CANdela document again in CANoe.

Note: in a future version, CANoe may offer comfort for step 2 - automatically provide the Automation Sequence Macros from a CANdela document for selection in a list.

Record an Automation Sequence Macro in CANoe

  1. In ribbon "Simulation", press button "Automation"
  2. In the dialog "Automation Sequence", page "Macro", create a new macro
  3. specify a file name for the automation sequence macro

Embed the Automation Sequence Macro in a CANdela document

  1. In CANdelaStudio, open ribbon tab Document | Job File Manager.
  2. Press button "New"
  3. In the file dialog, select the file created in CANoe, close with OK.
  4. In the Job File Manager dialog, specify the runtime system "AutomationSequenceMacro"
    • in case your CANdelaStudio version does not provide this as a selection in the combo-box, you can just enter the string as free text.
  5. Press "Close" to leave the dialog. CANdelaStudio embeds the specified file in the CANdela document.

Use the Automation Sequence Macro from the CANdela document in CANoe

  1. In CANoe, open CANdelaStudio (ribbon page "Diagnostics")
  2. In CANdelaStudio, use File|Open to open the CANdela document
  3. Open ribbon tab Document | Job File Manager
  4. Select the respective file stored from the Automation Sequence Macro
  5. Press button "Save As"
  6. In the file dialog, specify a folder and file name of your choice, press OK.
  7. Close the Job File Manager dialog.
  8. Close CANdelaStudio.
  9. In CANoe, in the dialog "Automation Sequences", page "Macros", select "Add Macro File"; as a file, select the file saved from the CANdelaStudio Job File Manager dialog.

Now you can use the Automation Sequence Macro in CANoe.
