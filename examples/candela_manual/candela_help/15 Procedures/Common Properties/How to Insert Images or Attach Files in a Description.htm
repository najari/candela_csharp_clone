How to Insert Images or Attach Files in a Description

  1. Click [File manager] above the description field. The File manager dialog appears

  2. Click [Insert file…] or click the magic line of the table if you would like to insert a file or an image into the document. The file dialog appears.

  3. Highlight the file on the file list or enter the name of the file under File name.

  4. Click [Open]. The file is inserted in the current language into the table and high-lighted automatically with a colored bar.

  5. Click [Insert as picture] if you would like to insert the file as an image. Click [Insert as attachment] if you would like to insert the file as an attachment. The file manager closes, and the file has been inserted into the description field.
