How to Prepare a CANdela Document for TextIDs

  • Open the CANdela document in Expert view.
  • In ribbon File, select Properties.
  • Navigate to “Document Info”.
  • Choose option “Document supports TextIDs”.
  • Click on [OK].
  • Select ribbon tab Document | TextIDs.
    • The Edit TextIDs dialog appears.
  • Update all TextIDs if necessary.
  • Save the document
