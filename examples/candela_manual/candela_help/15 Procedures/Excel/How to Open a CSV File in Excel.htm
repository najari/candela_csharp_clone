How to Open a CSV File in Excel

The usual way: menu File | Open, or drag'n drop onto an Excel window.

If Excel does not show the contents of the .CSV file correctly separated in rows and columns, it may have used the wrong column separator character. The behaviour depends on the Windows language settings.

The alternative way: in Excel 2010, run menu Data | From Text and select the .CSV file. Now Excel shows a text conversion wizard in which you select:

  • file type: with separator (not: fixed width)
  • separator: semicolon (not: tab character, comma, blank)

With these settings, the wizard should show a preview with the .CSV file contents correctly separated in rows and columns. Just finish the wizard.
