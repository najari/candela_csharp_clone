How to Specify Communication Parameters at Services and Jobs

Enabling Communication Parameters at Services and Jobs

This can be done in Expert View only.

In the communication parameter list of an interface,

  • open the property dialog for a communication parameter, and
  • enable the checkboxes „Can be overwritten at Services“ or „Can be overwritten at Jobs“.

The example shows communication parameter „RC21CompletionTimeout“ in the interface „CANOE DoIP“:

Checkboxes for Overwriting Communication Parameters

  • In the tree node "Services Supported for Interfaces", ensure the services are supported for the interfaces.

For example, in the screenshot below, for the Used Protocol Service „Session/Start“ of Protocol Service "($10) DiagnosticSessionControl", communication parameter „RC21CompletionTimeout“ is supported for interface „CANOE DoIP“:

Services Supported for Interfaces

Overriding a Communication Parameter at a Service or Job

The property page for local communication parameter values is hidden by default (to avoid clutter of the user interface), it must be enabled in the "General" page first.

To have a local communication parameter for a service in a diagnostic instance,...

  • open the Service property dialog in the diagnostic instance, and
  • check "Edit communication parameter" in the "General" page:

Enabling Communication Parameter for Service in the Diagnostic Instance

  • With this checkbox checked, an additional page "Communication Parameter" is shown. The page shows the local communication parameters for each interface.
  • Select the desired interface in the combobox on top,
  • check a communication parameter from the list of communication parameters that are enabled for local overwriting:

Dialog to Add a Local Communication Parameter at a Service

  • press "OK"
  • the communication parameter is available in the list in page "Communication Parameter"
  • CANdelaStudio automatically inserts the value from the document-wide interfaces list (e.g. "1300").

Edit Local Communication Parameter in Service Property Dialog

  • adapt the value as desired
  • press "OK" to leave the dialog.
