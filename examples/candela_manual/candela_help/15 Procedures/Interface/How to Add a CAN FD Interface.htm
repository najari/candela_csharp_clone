How to Add a CAN FD Interface

Note: this function is available in the Admin edition only. To create new interfaces in a CANdela template or document, you have to open it in Expert View.

In the "Supported interfaces" subchapter of the chapter "ECU" in the template or document, you can create and edit the interfaces that the ECU supports.

Open the Files

  • open the document or template in Expert View
  • open the ABS/ESP Example in Expert View
    • typically located in C:\Users\Public\Documents\Vector\CANdelaStudio
    • see Example Files

Copy the Interface

  • in the ABS/ESP Example, click on "Supported interfaces" in the tree
  • in the right side, in the list entry "CAN FD", click on "not supported", switch to "supported"
  • on the list entry "CAN FD", press right mouse, select "Copy"
  • switch to your document or template
  • click on "Supported interfaces" in the tree
  • in the right side, in the list, press right mouse, select "Paste"
    • Note: unfortunately, this copies the interface only (CDS-69111).

Copy the Communication Parameters

  • switch back to the ABS/ESP Example
  • in the tree under "Supported interfaces", click "CAN FD"
  • click into the list in the right side
  • press Ctrl-A
    • CANdelaStudio selects all entries.
  • press right mouse, select "Copy"
  • switch to your document or template
  • in the tree under "Supported interfaces", click "CAN FD"
  • click into the list in the right side
  • press Ctrl-V
    • CANdelaStudio inserts all CAN FD communication parameters.
