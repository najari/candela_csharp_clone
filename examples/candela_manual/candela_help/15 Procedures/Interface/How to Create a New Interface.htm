How to Create a New Interface

Note: this function is available in the Admin edition only. To create new interfaces in a CANdela template or document, you have to open it in Expert View.

In the "Supported interfaces" subchapter of the chapter "ECU" in the template or document, you can create and edit the interfaces that the ECU supports.

  • open the document or template in Expert View
  • click on "Supported interfaces" in the tree
  • click the button "New Interface..." (at the bottom), or click on the line "Please click here..."
    • The "New Interface" dialog appears
  • select one of the options offered
  • click "OK"
    • "Properties of Interface" dialog appears
  • specify name and qualifier of the interface
  • click on the "Enum" tab
  • under "Value", specify whether the interface is supported by default or not (in a new document created based on the template)
  • click OK
