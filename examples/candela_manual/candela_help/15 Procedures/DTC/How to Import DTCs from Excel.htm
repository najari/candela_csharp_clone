How to Import DTCs from Excel

Note:

  • This feature needs Microsoft Excel installed on your computer.
  • For details on the Excel/CSV format, see DTC Import (Feature).

Available DTCs

  • navigate to the DTC list into which you want to import DTCs
    • e.g. in tree: "Fault Memory" - "Diagnostic Trouble Codes" - "Available DTCs Fault Memory (24 Bit)"
  • at bottom right, press button "DTC Import..."

File Selection

  • press "..." right to the edit field "Import DTCs from file..."
  • select the file to import DTCs from
    • see DTC Import for a description of the expected table structure
  • in the combobox "Worksheet in Excel file", select the worksheet
  • press button "Next"

Import Target

  • in the "Import Target" dialog,
    • you can assign multiple DTC lists as target of the import.
    • For assigned DTC lists, the import source (e.g. "DTC table") is shown in brackets like "Normal [DTC table]".
    • since you opened the dialog in the "Available DTCs" list, the dialog already assigned it by default
  • press button "Next"

Linking of Columns

  • in the "Linking of Columns" dialog,
    • CANdelaStudio shows the DTC property columns from the import file vs. the target CANdela document.
    • To change the default settings, click a cell in the second column "In import target (qualifier)", then click again, or press F2.
    • You can assign a CANdela DTC property not yet assigned so far, or decide to Ignore that import column.
  • optionally, button "Preview..." shows the result in the CANdela document.
  • press button "Next"

DTC Filter

  • in the "DTC filter" dialog, ...
    • the dialog shows which DTCs can be imported without conflict or missing data.
    • You can check/uncheck individual DTCs.
    • The dialog shows DTCs that cannot be imported in red color, with an explanation available in the tooltip (hover the mouse over the table row of the DTC).
  • press button "Next".
    • If you specified multiple import targets in the "Import Target" dialog above, the "Linking of Columns" and "DTC filter" will be shown again for these targets.

Summary

  • Finally, CANdelaStudio shows a summary of data to be imported.
  • press button "Finish"
