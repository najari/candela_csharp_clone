How to Edit DTCs Efficiently

Context

You edit DTCs either...

  • in the "DTC Pool" in the top-level tree node Fault Memory/Diagnostic Trouble Codes
  • or in a variant in the diagnostic instance typically named "Fault Memory" (the name is defined in the manufacturer specific template, names also seen are "DTCs" or "Events").

Features

DTC List

The following features help for efficient editing in the DTC list.

See also the description of Basic User Interface Rules in general, e.g. for sorting, navigating and editing of multiple values at once.

  • filter the DTC list:

    • enter a filter term in the edit control at top right of the list

  • [PRDTC-R035] copy a cell value to multiple other DTCs at once [DTCOP-R035]:

    • left click one of the target DTC rows,
    • in order to copy to a range of DTCs: hold the Shift key and left click the last DTC row
    • in order to copy to individual other DTCs: hold the Ctrl key and left click each desired DTC row
    • finally hold the Ctrl key and left click the source DTC in the column you want to copy from
    • press right mouse, select context menu item "Copy Value into Selected DTCs"
    • CANdelaStudio copies the value in the source DTC column to the same column of the other selected DTCs.

  • inspect the qualifier of the DTC column:

    • hold the mouse over the table header to show the tooltip

  • inspect the description of the DTC column:

    • press the button [Show Column Info] on top of the list.

  • conveniently edit multi-line properties:

    • open the DTC Property Page,
    • in the "General" page, select the property
    • and ensure "Show details" at the bottom is checked.

DTC Property Page

The DTC Property Page provides convenient access to...

  • the DTC column properties,
  • Vehicle System Groups,
  • attributes (note that attributes are shown in the DTC list only if this has been specified in the template [ATTR-R090], but all attributes are shown in the dialog).
