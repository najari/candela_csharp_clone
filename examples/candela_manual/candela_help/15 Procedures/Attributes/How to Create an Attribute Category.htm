How to Create an Attribute Category

This function is only available in the Admin Edition.

Every default attribute must be assigned to an attribute category. If a CANdela template does not yet contain an attribute category, you cannot create a default attribute.

You create and edit attribute categories in the dialog Edit categories:

  • In the tree chapter "Default attributes", select one of the tree nodes, e.g. "ECU"
  • In the right side, click button "Edit" right to the "Categories" combobox
  • CANdelaStudio shows the dialog "Edit categories"
  • click button "New" (or click the line "Please click here...")
  • CANdelaStudio inserts a new line, which represents a new attribute category
  • select into the cell of the first column, press F2 or click again once
  • in the edit control, specify the name of the attribute category
  • press ENTER to accept the name
  • optionally select other cells to specify further details
  • press OK
