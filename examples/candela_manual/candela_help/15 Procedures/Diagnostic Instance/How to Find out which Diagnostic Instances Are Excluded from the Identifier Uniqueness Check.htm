How to Find out which Diagnostic Instances Are Excluded from the Identifier Uniqueness Check

  • in the CANdelaStudio tree on the ECU or on a variant node, select context menu item "Attribute Overview"
  • click on the header of the first column "Attribute" to sort the attributes by name
  • navigate to the attribute "Diagnostic instance - Check Identifier for Uniqueness"
  • if no such attribute exists,
    • Result: no diagnostic instance is excluded from the check
  • otherwise,
    • click button "Only selected"
    • check "Show overridden attributes only" (at the bottom of the dialog)
    • Result: all overridden attributes that have value "no" are excluded from the check.
