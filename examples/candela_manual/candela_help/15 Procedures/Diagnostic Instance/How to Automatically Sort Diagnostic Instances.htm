How to Automatically Sort Diagnostic Instances (CDS-71276 v13)

Background

A Diagnostic Class contains Diagnostic Instances.

You can freely arrange the Diagnostic Instances, independent of their Identifier.

You may want to keep the Diagnostic Instances sorted by Identifier.

CANdelaStudio...

  • does not enforce this sort order
  • but it helps by inserting new Diagnostic Instances sorted.

Solution

  1. In the top tree node "ECU Information", select context menu "Sort by Identifier".
  2. When you create a new Diagnostic Instance [DIUI-R100] in the Diagnostic Class, CANdelaStudio automatically inserts it sorted by Identifier (CDS-71276 v13).
    • Note: you still can change the order of the Diagnostic Instances (this is still a feature).
  3. In case you lost the desired sorting at any time, repeat step 1 once.
