How to Optimize Diagnostic Instance Copies Between Variants

Within a CANdela document, a diagnostic instance can...

  • either be referenced between two or more variants (modifications apply to all respective variants),
  • or it can be a "copy" (= non-referenced; modifications apply only to the variant that contain it).

Diagnostic instances can exist as independent "copies" even if their content is equal. Such unnecessary copies...

  • waste space in a document
  • and hide the intention that the contents shall be identical.

To re-establish a diagnostic instance to be referenced between variants, you can do the following:

Document-Wide

  • run ribbon tab Home | Replace | "Reference Identical Diagnostic Instances and Job Container"
  • this compares the object properties and replaces copies by references where possible

For an Individual Diagnostic Instance

If one of the variants is the base variant ("Common Diagnostics"):

  • run ribbon tab Home | Replace | "Replace Copy with Reference in Base Variant"

Or in any case:

  • in one variant, delete the non-referenced diagnostic instance;
  • in the other variant, copy the diagnostic instance;
  • in the one variant, paste the diagnostic instance as a reference
    • ribbon tab Home | "Paste as Reference"
