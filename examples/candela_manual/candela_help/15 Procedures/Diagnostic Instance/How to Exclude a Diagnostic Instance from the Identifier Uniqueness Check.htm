How to Exclude a Diagnostic Instance from the Identifier Uniqueness Check

  • in the CANdelaStudio tree, on the diagnostic instance, open the context menu (right mouse)
  • un-check the menu item "Check Identifier for Uniqueness"

Note: this modifies the value of a CANdela attribute. You can also modify this value...

  • in the diagnostic instance property dialog, page "Attributes"
  • in the attribute overview.
