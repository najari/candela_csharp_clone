How to Compare Objects

  1. Open the involved document(s).
  2. Select the first object you want to compare.
  3. Select ribbon tab Home | "Select as Left Side for Compare".
  4. Select the second object (in the same or another document).
  5. Select ribbon tab Home | "Compare to".

The Compare View opens.

Note:

  • Objects of different type cannot be compared
  • For example, a Library cannot be compared to a Variant
  • Exception:
    • Different Data Types can be compared
    • For example, a Linear conversion can be compared to a Text Table
    • This will only compare properties common to both data types, for example Encodings or Byte Orders
