How to Compare Documents from Command Line

Two CANdela documents can be compared using CANdelaStudo in command line mode.

You can export the compare result in the same formats as if coming from Compare View, cf. [CMP-R131-DiffExport].

Command Line Example

To compute the differences between two documents and export them from a Console, use e.g.

CANdelaStudio.exe -i "D:\test\source.cdd" -o "D:\test\diff_output.txt" -r "D:\test\target.cdd" -g "D:\test\out.log" -e "textdiff"

See the command line parameters relevant for export of the compare result [CMP-R135-CompareCommandLine].
