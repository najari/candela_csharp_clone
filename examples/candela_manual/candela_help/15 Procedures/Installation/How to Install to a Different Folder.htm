How to Install to a Different Folder

Typically you should install CANdelaStudio using its installer, the file CANdelaStudio<version>.exe.

The installer puts CANdelaStudio into a default location. It lets you select a different installation directory for CANdelaStudio, but not for the bundled products (as of 8.5).

Likewise, if you install e.g. Vector CANoe, the installer puts CANdelaStudio into the default location.

In order to install CANdelaStudio to a different folder in exceptional cases:

  • extract the CANdelaStudio .msi file from the .exe installer (using an unzip application)
  • open a command prompt, e.g. by typing cmd in the Windows start menu
  • type the command: msiexec /i CANdelaStudio<version>.msi INSTALLDIR="<your target path>"
  • example: msiexec /i CANdelaStudio8.5.msi INSTALLDIR="D:\Temp"
  • click through the wizard

Note: this does not install prerequisites and Vector products bundled with CANdelaStudio!
