How to Copy and Paste a Variant

  • In the tree view, click on the variant you would like to copy
  • in ribbon tab Home, click "Copy", or press Ctrl-C
  • specify the place at which the variant should be inserted: click...
    • on the "Variants" subsection if you would like to paste the variant at the very beginning
    • on a variant in the list, in order to paste the variant after it.
  • in ribbon tab Home, click "Paste", or press Ctrl-V

Note on possible Conflicts when Pasting to different Documents:

  • On pasting a variant to a different document, there may occur subtle conflicts when the target already contains referenced objects that must be pasted.
  • As an example, a data type used in a source variant is transferred implicitly, but a data type with the same qualifier may already exist with different properties in the target document.
  • CANdelaStudio resolves such kinds of conflicts using heuristics.
  • Possible clash constellations and resolution principles are described in detail in Pasting Variants
