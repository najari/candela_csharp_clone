How to Edit a Variant

You can edit variants just like any other CANdela object:

  • copy and insert,
  • delete
  • edit properties

You cannot...

  • cut a variant
  • insert a variant as reference (only the DIDs, diagnostic instances and job containers within a variant can be inserted as a reference)
