How to Manage Variants MID and HIGH in one Document

Note: as of version 8.5, CANdelaStudio supports only variants that have the same CAN ID.

Setup Variants

Variants List

  • create a variant “MID”
  • create a variant “HIGH”, based on “MID” (in the “Variant Wizard”, select “Create on basis of…”) In the default setting, then, all data is shared between MID and HIGH.

Creating Variant HIGH in the Variant Wizard

  • to describe the differences between both of them, locate the diagnostic instance e.g. in HIGH, and execute “Replace Reference with Copy” in the context menu in the tree.

Diagnostic Instance "Fault Memory" after "Replace Reference with Copy"

  • as a result, the icon of the diagnostic instance indicates that it is a copy in variant "HIGH", no more referenced with variant "MID".
  • now proceed to describe the differing data in Fault Memory of variant "HIGH"

Variant Identification

If the test system involved supports automatic detection of the variant at runtime, describe the input data for this detection:

Identifying Features

  • in variant "Common Diagnostics" under "Identifying Features", specify one or more data objects that the tester may request from the ECU in order to detect the respective variant ("Software Version" in the example)
  • in variant "MID" under "Identifying Patterns", specify the value the ECU returns for the data object in that variant.
  • do the same for variant "HIGH".
