How to Add a Language to a CANdela File

To translate an existing document into a further language, you need to add the language to the document:

  • Ribbon tab File - Properties
  • Tab “Document info”
  • Button “Add”
  • select one of the available languages.

This language will be added to the document, and you can start translating.
