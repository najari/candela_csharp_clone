How to Use a Dictionary

See the dictionary feature.

  • The dictionary must be available in the form of a TMX file
  • the following describes how you can take the name of a CANdela object (e.g. a diagnostic instance) or the text in a "Text table" data type from a TMX dictionary
  • in order to also assign a TextID from the dictionary, both the document and the dictionary must support TextIDs.

How to Setup a Dictionary (TMX file)

  1. Click ribbon tab File | Options.
  2. Click the Edit page.
  3. Under Path to dictionary enter a path to a TMX file, or click [...] to open the file dialog.
  4. Click [OK].

Click the arrow button if you only wish to reload the TMX file (e.g. after a change to the file).

The dictionary can now be accessed by its name in the properties dialogs of all CANdela objects, as well as on the Text table page of the data type of the same name.

How to Select a Term from the Dictionary

  1. Open the Properties dialog of the CANdela object.
  2. Select the General page to choose the name
  3. Click the globe symbol. The Select a term from the dictionary dialog appears.
  4. Select the desired term from the table and click [Assign].
