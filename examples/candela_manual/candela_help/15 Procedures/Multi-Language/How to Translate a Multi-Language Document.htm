How to Translate a Multi-Language Document

The translation view (available in CANdelaStudio Pro and Admin) enables you to translate multi-language items in a document:

  • Start CANdelaStudio
  • choose ribbon File | Open [MENU-R020].
  • select the “translation view” option
  • choose the reference (source) language. The document must be up-to-date for the reference language.
  • When the translation view comes up, select the target language you want to update.
