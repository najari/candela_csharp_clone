How to create a New UDS Protocol Service

This function is only available in the Admin edition.

To add new UDS protocol service to your template, please follow these steps:

  • Open the Vector UDS template in Expert View
    • See the example files shipped with CANdelaStudio.
  • Navigate to the document tree node "Protocol Services"
  • Select the UDS protocol service you want to add to your template
  • Select "Copy" from the context menu
  • Switch document context to your CANdelaStudio template
  • In the "Protocol Service" list of your template, select "Paste" from the context menu.

Note:

  • versions before CANdelaStudio 11 had a "UDS Wizard" to add UDS compliant protocol services to the template (CDS-37023 8.5).
  • But CANdelaStudio supports copy/paste from the included UDS template, so this Wizard is no longer required (CDS-69965 11).
