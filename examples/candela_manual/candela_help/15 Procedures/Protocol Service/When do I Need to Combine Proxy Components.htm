When do I Need to Combine Proxy Components?

This function is only available in the Admin edition.

You connect proxies whenever they must transmit shared data. Connected proxies are represented by a single telegram table in the entry masks for diagnostic instances.

Example

You have two "Used Protocol Services" in a diagnostic class template:

  • to read (ISO 14229: 0x22 - "ReadDataByIdentifier"), and
  • to write (ISO 14229: 0x2E - "WriteDataByIdentifier")

You now want the same data objects to be included in both services.

Both protocol services have their own proxy named "Data", the reading one in the Positive Response, the writing one in the Request.

Here's how you combine the two proxies:

  • Mark both proxies in the "Combined Components" table (for example "zz" and "yy").
  • Click the button "Combine".
  • CANdelaStudio combines the two components as one with the abbreviation "zz".
