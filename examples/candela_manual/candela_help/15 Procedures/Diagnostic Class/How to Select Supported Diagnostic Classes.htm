How to Select Supported Diagnostic Classes

CANdelaStudio divides diagnostic services into diagnostic classes. It shows them under a variant in the tree node "Supported diagnostic classes", together with singleton diagnostic instances.

  • In the CANdelaStudio tree, click on the node "Supported diagnostic classes" under a variant.
  • The tree node contains the diagnostic classes and singleton diagnostic instances existing in this variant.
  • In the right side, CANdelaStudio shows all diagnostic class templates and singleton diagnostic instances predefined in the template.
  • A checkbox to the left of an object shows whether it actually exists in this variant;
  • check it to create the object in the variant;
  • un-check it to delete the object from the variant (including all contained services and data). CANdelaStudio does not allow this for diagnostic instances that have been set "required" in the template.
  • In a new, empty diagnostic class, click the button "New Instance" (in the right side, or in the context menu) to create a diagnostic instance.
