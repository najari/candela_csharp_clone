How to Configure the Diagnostic Basic Software of an AUTOSAR 4 ECU

The following decribes the configuration of an AUTOSAR 4 ECU in CANdelaStudio.

For the complete AUTOSAR workflow with PREEvision and MICROSAR4, see the Vector Application Note "How to Configure the Diagnostic BSW of an AUTOSAR 4 ECU" (see Related Topics below).

An item like [RQ-R093] refers to a FeatureID of CANdelaStudio (in this documentation; you may search for it).

Contents:

  • SYS-EX Synchronization (SWC Sync)
  • Configuration of UDS Services

Requirements Import

A CANdela document may contain textual Requirements for an ECU.

CANdelaStudio shows these requirements in the tree node "Requirements" at the bottom of the navigation tree:

Requirements in CANdelaStudio

Import

To import requirements into the CANdela document, ...

  • navigate to the "Requirements" tree node
  • delete all existing requirements:
    • click into the Requirements area
    • press Ctrl-A to select all requirements
    • press DEL to delete them.
  • press the "Import" button in the Requirements toolbar
  • in the File dialog, select the .CSV file exported from PREEvision
    • the .CSV file must follow the format conventions defined by CANdelaStudio
  • open the file.

CANdelaStudio shows the imported requirements in the Requirements area.

Setup Requirements Synchronization

In the Requirements area, property page "Settings", ...

  • select the variant or library [RQ-R093] with which you want to relate and synchronize the requirements,
  • select the data type [RQ-R094] to be used for data objects created during synchronization.
    • Tipp: in the data types list, create a special data type e.g. "Undefined" and select it here. Later, this will help you to review the data objects that need assignment of a more specific data type.

Compare Requirements with Existing Diagnostic Objects

CANdelaStudio shows each requirement with a special symbol [RQUI-R080] left to the requirement icon, indicating the synchronization state of the requirement - whether a diagnostic object exists and is up-to-date:

Requirements Synchronization State

To inspect the synchronization state in detail, ...

  • press the Show Differences toolbar button and...
    • move the mouse over a requirement.
    • CANdelaStudio shows a tooltip with details, like the name and value of differing properties.
  • ensure the "Diagnostic Objects" list is shown (use the toolbar toggles [RQUI-R012]) and...
    • inspect linked diagnostic objects;
  • filter the requirements by their synchronization state:

Requirements Synchronization State Filter

Synchronize Diagnostic Objects from Requirements

  • press the Update Diagnostic Objects toolbar button
  • inspect the eventually modified synchronization state, as described in the previous chapter
  • inspect the column "ToDo" which marks new data objects, these will typically need assignment of a specific data type (as described in chapter "Configuration of UDS Services" below).

Special Procedure for Requirements Import from Daimler DOORS

  • navigate to the "Requirements" tree node in CANdelaStudio
  • delete all existing requirements:
    • click into the Requirements area
    • press Ctrl-A to select all requirements
    • press DEL to delete them.
  • select menu Tools | Doors Requirement Import
  • select the two .CSV files exported from DOORS (for data “DIP…” and DTCs)

This special procedure...

  • is necessary to convert the specific .CSV format exported from the Daimler DOORS customization to the .CSV format accepted by CANdelaStudio.
    • You cannot import the DOORS .CSV files directly into CANdelaStudio!
  • uses an action which runs the converter.

SYS-EX Synchronization (SWC Sync)

For AUTOSAR software generation, the diagnostic objects in the CANdela document need links to the corresponding objects in the SYS-EX (System Extract of System Description).

To this purpose, CANdelaStudio provides the SWC Sync Import.

Setup

The CANdela document must contain attributes to store the links to the SYS-EX objects:

  • open ribbon tab File|Properties
  • select the "Document Info" page
  • ensure the checkbox "Attributes for AUTOSAR Diagnostic Extract export" [DOCUI-R500] is checked.

Ribbon tab File | Properties, page "Document Info"

Synchronization

  • in ribbon tab "Data Exchange", press the "SWC Sync" Button [MENU-R280]
  • select the SYS-EX .arxml file
  • open the file.

SWC Sync Dialog

  • in the "Target" column, note the objects with value "Import Pool only".
    • The requirements ID of these objects is not yet contained in the CANdela document.
    • SWC Sync will put them into the import pool.
    • After synchronization, you may move them manualy into the desired variant(s).
  • in the SWC Sync Dialog shown, optionally exclude objects being still under development from synchronization
  • start the synchronization with "OK"

Inspect

Now you may inspect import details:

  • move objects from the import pool into the desired variant;
  • if the Output Window is not shown (typically at the bottom of the CANdelaStudio window), ...
    • in the ribbon tab Window, press the button Output Window [MENU-R610] to enable the output window
  • inspect the import details shown in the window.

To inspect the imported diagnostic objects, ...

  • either inspect them in the "Diagnostic Objects" list in the Requirements area, which shows...
    • only diagnostic objects of diagnostic classes relevant for requirements [DCLT-R300]
    • the synchronization state;
  • ... or inspect them in the context of the variant in the CANdelaStudio tree.
    • CANdelaStudio shows the references for a data object in the property page "Attributes", or in the Attributes Overview.

Configuration of UDS Services

So far you have...

  • imported requirements,
  • generated or updated diagnostic objects from the requirements, and
  • added references to SYS-EX objects in the diagnostic objects.

Complete the Diagnostic Objects for Code Generation

  • navigate to the variant in the CANdelaStudio tree;
  • in the "Supported Diagnostic Classes" section, inspect the diagnostic instances;
  • create or delete additional services as needed:
    • info about services [RQ-R030-Services] is optional in Requirements,
    • it is synchronized [RQ-R560-Services] only if the service names or qualifiers match.
    • The service names in the CANdela document depend on the CANdela template used.
  • specify session and security, i.e. the state dependency
  • if the diagnostic instance contains multiple telegram tables, ensure the new data objects [RQ-R544-ServicesAtData] are in the correct one.
  • assign specific data types.

Complete the Diagnostic Objects for Use in a Tester

Additionaly you may want to...

  • set service properties, like physical vs. functional addressing
  • specify negative response codes
  • specify Variant Identification
  • ... and more details.

Diagnostic ECU Extract (DEXT) Export

Setup

See [DEXT-R050] for...

  • the AUTOSAR version(s) supported by your version of CANdelaStudio, and
  • selecting the exported AUTOSAR version via an entry in CANdelaStudio.ini.

Export

  • use ribbon tab Data Exchange|DEXT Export [MENU-R130]
  • in the File dialog, select the desired variant, confirm with "Save"
