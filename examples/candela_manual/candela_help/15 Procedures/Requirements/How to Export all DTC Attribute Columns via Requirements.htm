How to Export DTC Attribute Columns via Requirements

CANdelaStudio Requirements Pool

Generate Requirements from Diagnostic Objects

  • in the CANdelaStudio tree, navigate to "Requirements"
  • in the property page "Settings", select the variant to export from
  • in the property page "Linking with Diagnostic Objects", in the right side, select "Fault Memory"
    • Note: the name may vary, it is defined in the CANdela template on which the document is based on.
  • in the context menu (right mouse), select "Update Requirements"

CANdelaStudio fills the requirements list.

If some DTC columns are missing, you have to setup the requirements properties first (see chapter below).

Export Requirements

  • in the toolbar of the requirements list, click button "Export Requirements"
  • specify a file name
  • press Open

Setup Requirements Properties

Some of the DTC columns may be missing in the requirements list after the step "Update Requirements" above.

Reason: for DTC properties defined as generic attributes, maybe with the flag “visible in separate table column” [ATTR-R090] set, CANdelaStudio as a default does not generate requirements.

The same holds for generic attributes defined for other diagnostic objects.

Solution: for each attribute you want to represent in the requirements, define a requirements property with the name of the attribute.

  • navigate to the DTC list in a variant
  • in the DTC table, inspect the properties dialog of a DTC
  • in property page "Attributes", remember the name of the desired attribute
  • navigate to the "Requirements" tree node
  • in the right side, navigate to the "Columns" property page
  • click the line "Please click here..."
  • in the first column "Name", enter the name of the existing attribute
  • if the attribute represents a number, change the type in the second column to "Number"

Now CANdelaStudio is prepared to fill the requirements property from an attribute of the same name.

Note for multi-language documents:

  • the attribute name may vary from one language to the other
  • in this case, better use the qualifier of the attribute
  • the qualifier of an attribute is shown in expert view in the attribute property dialog.

Background

CANdelaStudio fills requirements from attributes since 8.5 SP2 (CDC-36449), see [RQ-R100-Prop].
