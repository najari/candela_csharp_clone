How to Import Identifiers via Requirements

Use-Case

Transport DIDs including their identifier from an Excel table into a CANdela document, using the import of requirements [MENU-R270] from .csv.

By default, requirements in CANdelaStudio do not support the identifier.

Solution

In the Requirements settings, define a specific column "Identifier" [RQ-R030-Identifier].

Now the update of diagnostic objects operation [RQ-R550] uses the new requirements property "Identifier" to update the identifier of DIDs.

For the number format, see [RQ-R550-Format].

Note: when CANdelaStudio updates requirements from diagnostic objects, it generates the identifier as decimal string.
