How to Export Multi-Language ODX Files

Configure ODX Export to export TMX Files:

  • Click ribbon tab File | Options
  • Navigate to “ODX Export”
  • Select “Create TMX file (multi-language ODX)”.

From now on, if you export the document to ODX, CANdelaStudio generates a TMX file along with the exported ODX file.
