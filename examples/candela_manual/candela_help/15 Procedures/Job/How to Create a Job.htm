How to Create a Job

Import the Job File

You can also perform these steps later in the "Create a Job" chapter below.

  • Ribbon tab Document | "Job File Manager" opens a dialog for job files
  • Button "New" lets you import a job file (select a file that can be executed by the test system, e.g. a JAR or CAPL file)
  • ensure input control "Runtime system" has the desired value
  • ensure input control "Version" has the desired value
  • optionally specify an encoding (if the file is encrypted)
  • optionally specify additional files (e.g. source files from compilation)
  • press the "Close" button

Create a Job

  • in the CANdelaStudio tree, navigate to the job container
  • in the list "Jobs for the Test System", click on "Please click here...".
  • the property dialog for a new job opens
  • in the "General" page, set the name and qualifier
  • navigate to the "Function" page
  • press button "Job Files"
  • the "Job File Manager" dialog opens
  • if not yet done already, import a job (see chapter above)
  • in the list on top, select the desired job file (e.g. the one imported in the previous chapter)
  • press button "Assign" at the bottom
  • the "Function" page is shown again
  • optionally specify the "Version" of the job file
  • optionally specify an "Entry Point" for the function, e.g. a function name like "main()"; this applies to job files with runtime system "fm"
  • press "OK"
  • the job is shown in the jobs list

By default, the function supports one runtime system (e.g. Java interpreter) only. If it must support more than one runtime system with different job files for each runtime system, check the option "Supports several runtime systems" in the "Function" page, and assign additional job files.

If you have specified a default file for jobs, CANdelaStudio automatically assigns that file to each new job.
