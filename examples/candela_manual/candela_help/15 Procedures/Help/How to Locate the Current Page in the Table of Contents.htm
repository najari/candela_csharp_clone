How to Locate the Current Page in the Table of Contents

Problem: you have navigated to a help page e.g. using the index, and want to see its position in the table of contents.

Solution: in the help viewer toolbar, press button "Search" (German "Suchen"):

Help Viewer Search Button (second from left)

Help viewer navigates to the page in the table of contents (German "Inhalt"):
