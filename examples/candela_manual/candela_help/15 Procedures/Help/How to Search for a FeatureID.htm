How to Search for a FeatureID

Problem: search for a FeatureID like [DTENC-R058].

Solution: in the help viewer, enter the search term as "DTENC-R058" (including double-quotes):

Help Viewer Search

  • omit the square brackets,
  • enclose the string in double quotes (otherwise the help viewer searches for the individual hyphen-separated fragments).
  • press ENTER
    • help viewer lists the matching chapters

To highlight the search term in the chapter text:

  • click into the right side of the help window (the help chapter)
  • press Ctrl-F
    • help viewer shows the "Find" ("Suchen") dialog
  • enter the term, like DTENC-R058
    • help viewer highlights all matches at once
  • press ENTER to navigate to the next match.
