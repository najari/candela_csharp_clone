How to Quickly Navigate to a Page often Used - Favorites

Problem: you find yourself to frequently navigate to or search for the same help page.

Solution: define a favorite:

Help Viewer Favorites Page

  • navigate to the page
  • in the "Favorites" tab of help viewer,
  • press button "Add" (German "Hinzufügen") at the bottom
  • help viewer adds the current page to the list of favorites (German "Themen")

In order to navigate to the page again later:

  • double-click on the page in the list of favorites.
