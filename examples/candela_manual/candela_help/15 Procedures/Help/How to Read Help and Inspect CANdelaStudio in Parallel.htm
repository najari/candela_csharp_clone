How to Read Help and Inspect CANdelaStudio in Parallel

Problem: when you open online help from CANdelaStudio and would like to inspect objects in CANdelaStudio while reading online help, access to the CANdelaStudio is blocked by the help window.

Solution: open online help in parallel to CANdelaStudio:

  1. In Windows Start, navigate to Programs - Vector CANdelaStudio... - Help
  2. Open CANdelaStudio Help
  3. In Windows Start, navigate to Programs - Vector CANdelaStudio...
  4. Open CANdelaStudio
