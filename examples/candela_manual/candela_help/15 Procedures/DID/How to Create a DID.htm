How to Create a DID

Note: hyperlinks in the description navigate to details about the respective topic.

Create a DID

  • in the CANdelaStudio tree, navigate to the variant in which you want to create a DID.

  • Navigate to the "DIDs" tree node:

    DIDs Tree Node

  • in the list in the right side, press button "New DID".
    • CANdelaStudio creates a new list entry.

  • in the new list entry, specify the DID Identifier [DID-R025] and the name of the DID ("0x0110" and "Oil Temperature" in the example):

    New DID in DID List

  • in the list at the bottom, specify one or multiple data objects for the DID:

    Data Object

Now you created the DID with its data.

In order to specify services for the DID (how the DID can be read or written), continue in the next chapter.

Specify Services for the DID

  • in the DID list at the top of the right side, select the column "Diagnostic Class".
    • Note: you can also do this already during creation of the new DID, before you create the data objects.

    DID and new Diagnostic Instance in the Tree

  • click again to open a combobox of diagnostic classes relevant for DIDs

  • select the diagnostic class "Dynamic Data".
    • CANdelaStudio creates a diagnostic instance in that diagnostic class,
    • based on the DID [DI-R020],
    • and shows it in the tree to the left, under "Dynamic Data".

  • In the tree, click on the new diagnostic instance to inspect it:

    New Diagnostic Instance

    • the identifier has been taken from the DID you created
    • the identifier is write-protected in the diagnostic instance window. You can modify it in the DID list only.
    • the telegram table of the diagnostic instance contains just a DID Data Reference [DID-R160] to the DID, visualized by the word "DID" with an arrow.

Now you can modify service details for the diagnostic instance e.g. in the service property dialog.

In order to modify the data objects of the diagnostic instances, navigate back to the "DIDs" list and modify the data in the list at the bottom.

Background

DIDs (data identifiers) associate...

  • diagnostic data
  • with a number (identifier),
  • for use in various diagnostic services

For an overview, see the DID Feature.
