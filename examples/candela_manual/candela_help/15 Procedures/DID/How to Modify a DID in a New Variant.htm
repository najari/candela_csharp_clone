How to Modify a DID in a New Variant

Context

  • a variant contains a diagnostic instance that describes a DID:

    Diagnostic Instance 0x110 "Oil Temperature"

  • Its data is described in the DID list, using a 1 byte data type:

    DID "Oil Temperature" in the base variant

Task: in a new variant, let the DID use a 2 byte data type.

Create a New Variant

  • in the CANdelaStudio tree, click the "Variants" tree node
  • in the right side, click the button "Variant Wizard" at the bottom of the list
  • enter a name e.g. "New variant"
  • right to "Create on basis of", select the newest variant e.g. "C Sample"
  • press "OK"

CANdelaStudio shows the new variant in the tree:

New Variant in the tree

Note:

  • all diagnostic instances and DIDs in the new variant are shared (referenced) with the variant selected as basis.
  • Therefore all modifications would affect both variants!
  • In order to modify the new variant only, you must first perform "Replace Reference with Copy".

DID: Replace Reference with Copy

  • in the new variant, navigate to the DID "Oil Temperature", select it in the list:

    DID "Oil Temperature" in the new variant

  • click ribbon tab Home | Replace | "Replace Reference with Copy" [DID-R230], confirm.
    • also available via right mouse in the context menu
  • The DID is now local to the new variant.
  • Also the diagnostic instance that uses [DID-D001] the DID is now local to the new variant:
    • see the meaning of the tree icons
    • Note: before 8.5 SP3 (CDS-40001), you had to "Replace Reference with Copy" for the Diagnostic Instance in a first separate step.

Modify the DID

  • navigate to the list "Data of Oil Temperature"
    • either below or to the right of the DID list, as configured in the DID toolbar: .
  • modify the data as desired

Background

The above description includes copying the diagnostic instance as well as the DID.

CANdelaStudio does not allow to copy the DID only while keeping the diagnostic instance referenced.

Reason: Consistency Rule for References [DID-D020].
