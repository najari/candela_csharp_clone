How to Move Data from a Diagnostic Instance to a DID

Context

In the CANdela data model, DIDs are defined within a variant:

  • DID Data (without services): in the DID list (since version 8.2)
  • DID Services: in a diagnostic instance

See the overview in the DID Introduction.

The following procedure applies to...

  • a diagnostic instance that does not reference a DID:

  • not to a diagnostic instance that references a DID:

Objective

  • Move the data objects from the diagnostic instance into a DID in the DID list.

Move Data of Multiple Diagnostic Instances to New DIDs

  • in the CANdelaStudio tree, navigate to the variant in which you want to create a DID
  • navigate to the diagnostic class in the tree
  • in the list of diagnostic instances in the right side, open the context menu (right mouse)
    • Note: the menu item is also available in the navigation tree on individual diagnostic instances.

  • select "Move Data to New DID"

    Context Menu of Diagnostic Instances

  • CANdelaStudio...
    • creates DIDs in the DID list, which contain the data objects from the selected diagnostic instances;
    • and replaces the data objects by a DID Data Reference to the each new DID

Now you may select one of the diagnostic instances in the tree and inspect its telegram table:

  • it contains a DID Data Reference [DID-R160] to the new DID:

    DID Data Reference to the new DID

Move Individual Data Objects to a New DID

  • navigate to the telegram table in the diagnostic instance that contains the data objects
  • select the data objects you want to move
  • open the context menu (right mouse)

  • select "Copy to New DID"

    Telegram Table: Context Menu "Copy to New DID"

  • depending on the data context, CANdelaStudio will ask for confirmation about diagnostic instances referencing, or about a conflict with an existing DID
  • then CANdelaStudio...
    • creates a DID in the DID list, the DID contains the selected data objects;
    • replaces the selected data objects by a DID Data Reference to the new DID

    DID Data Reference to the new DID
