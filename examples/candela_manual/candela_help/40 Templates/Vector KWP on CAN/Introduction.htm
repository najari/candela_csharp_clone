Vector KWP on CAN Template - Introduction

This CANdela document template example demonstrates support for KWP in CANdelaStudio.

The template is based on the standards:

  • Keyword Protocol 2000 (ISO 14230-3)
  • Diagnostics on CAN (ISO 15765-3)

You can conveniently access the template via the CANdelaStudio Open Page.

The template ships with CANdelaStudio since CANdelaStudio version 8.5.
