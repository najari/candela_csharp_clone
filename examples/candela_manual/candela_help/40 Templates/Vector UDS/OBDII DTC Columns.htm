Vector UDS Template - OBDII DTC Columns

UDS DTC Reference

[VUDS-R480]

  • References one or multiple UDS DTCs which the OBD DTC represents
  • Format:
    • 3 Byte hexadecimal DTC number with optional 0x prefix
    • e.g. 0x123456 or 123456
    • Multiple DTC numbers separated by comma ",", e.g. 0x123456,0x654321
  • see Specific DTC Columns [ECT-R520]
