Vector UDS Template - DTC Columns

See also Vector UDS Template - OBDII DTC Columns.

Note: CANoe.DiVa parses all columns for signal names.

Errortext shortname

[VUDS-R400-Errortext]

  • type Translatable [DTCC-R010-Translatable]
  • optional
  • used for DEM
  • Specifies DemDTCClass.ShortName and DemEventClass.ShortName for MICROSAR ECU-C.
  • Blanks will be replaced by underscore.

Set Condition

[VUDS-R400-SetCondition]

  • type Translatable [DTCC-R010-Translatable]
  • optional
  • used as info for implementation
  • How to implement the monitor (pre-failed / failed condition).
  • Info for After Sales tester which cause might have set the DTC.

Reset Condition & Self Healing

[VUDS-R400-ResetCondition]

  • type Translatable [DTCC-R010-Translatable]
  • optional
  • used as info for implementation
  • How to implement the monitor (pre-passed / passed condition).
  • Info for After Sales tester which cause might have reset the DTC.

DTC Priority

[VUDS-R410-Priority]

  • Unsigned Decimal
  • mandatory
  • Default: 0
  • Specifies DemEventClass.DemEventPriority (Dem104)
  • Used in DEM - the value influences the event displacement in case the respective memory is completely filled at the time of event confirmation:
    • A lower number represents higher priority.
    • So when the Fault Memory is full, the data for DTCs with a higher numeric priority value will be removed first.

Aging supported (CDS-69938 v10)

[VUDS-R420-AgingSupported]

  • type Enum [DTCC-R010-Enum]
  • optional (CDS-71479 v12)
  • For "Aging", see [FM-D010].
  • Name before v10: "Self Healing (Aging)".
  • Used in DEM - if this parameter says "supported", the aging mechanism is enabled for this DTC:
    • Aging means that the DTC will be automatically removed from fault memory if the monitor function was executed and no failure was detected for a configurable number of operation cycles.
  • The default aging behaviour is MICROSAR value DEM_AGING_TYPE_1.

Aging Cycle (CDS-69938 v10)

[VUDS-R420-AgingCycle]

  • specifies the Operation Cycle used as a base for Aging
  • type Translatable [DTCC-R010-Translatable]
  • optional (CDS-71479 v12)
    • see [DTCUI-R095] how to leave it empty.
  • For "Aging", see [FM-D010].
  • Name before v10: "Healing Cycle".
  • Used in DEM - the operation cycle name that triggers the aging of this DTC.

Aging Cycle Counter Threshold (CDS-69938 v10)

[VUDS-R420-AgingCycleCounterThreshold]

  • For "Aging", see [FM-D010].
  • Name before v10: "Healing Cycles".
  • Used in DEM - the number of aging cycles needed to unlearn/delete this DTC.
    • "aging cycles" = the number of cycles for the Operation Cycle configured in DTC Column "Aging Cycle"
    • This parameter does only take effect if “Aging supported“ is set to “supported”.

DTC Severity

[VUDS-R410-Severity]

  • Unsigned Decimal
  • type Enum
  • Default: no Severity
  • Defines the recommended action to take when the DTC gets detected
  • Reports the recommended action to be taken by the system (e.g. vehicle) operator.
  • This parameter is reported by UDS service $19 09 and can serve as a filter for UDS service $19 08.
  • A missing configuration value (or parameter) is interpreted as noSeverity.
  • Specifies DemDTCClass.DemDTCSeverity; no further influence on the function of the DEM.

Monitor Initialization Function

[VUDS-R420-MonitorInitFn]

  • type Translatable [DTCC-R010-Translatable] with selection "required" / "not required"
  • optional (CDS-71479 v12)
    • see [DTCUI-R095] how to leave it empty.
  • Used in DEM - describes whether a monitor initialization function is required for events of the DTC.
  • For value “required”, an initialization function InitMonitorForEvent is created (DemEventParameter/DemCallbackInitMForE).
  • The DEM will call this function each time the event is cleared, or the operation (monitoring) cycle restarts.

Functional Unit

[VUDS-R430]

  • type Unsigned [DTCC-R010-Unsigned]
  • required
  • default value 0x00, as in MICROSAR (CDS-72009 v13)
    • Please use 0x33 for WWH-OBD.
  • For use with UDS 19 08 and 19 09 only:
    • This parameter is necessary for reporting severity information.
    • It will be returned in the UDS services 19 08 and 19 09.
    • If these services are not used, this parameter serves no use at all.
  • Used in DEM and potentially in tester.
  • Identifies the corresponding basic vehicle / system function which monitors this DTC.
  • Specifies DemDTCClass.DemDTCFunctionalUnit; no further influence on the function of the DEM.

Repair Instruction

[VUDS-R440]

  • type Translatable [DTCC-R010-Translatable]
  • optional
  • To be displayed in tester, free text repair instructions.

Hint: Omitting AUTOSAR DTC Columns

[VUDS-D400] If some ECU project requires to skip the AUTOSAR properties (CDS-71479 v12), you can...

  • leave them empty, for translatable Columns, see [DTCUI-R095], or
  • leave the default, for other Columns.
  • Relevant Columns in the current template:
    • Aging Supported
    • Aging Cycle
    • Monitor Initialization Function
    • DTC Severity
  • Relevant Columns in previous template versions:
    • Count-In step size
    • Count-out step size
    • Use Jump-Up (Prefailed)
    • Use Jump-Down (Prepassed)
