Vector UDS Template - Diagnostic Instance

Attribute "ASR3 Legacy Combine DID" (CDS-71773 v12)

[VUDS-R611] the template contains a diagnostic instance attribute ASR3_Legacy_Combine_DID to control DEXT Export of DIDs described directly in the diagnostic instance [DEXT-R205]:

  • category „DEXT“
  • name „ASR3 Legacy Combine DID“
  • qualifier ASR3_ Legacy_Combine_DID
  • type Unsigned

Note: this complements the attribute for DIDs [VUDS-R610].
