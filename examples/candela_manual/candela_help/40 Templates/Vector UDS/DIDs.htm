Vector UDS Template - DIDs

Attribute "ASR3 Legacy Combine DID" (CDS-69896 9.1 SP1)

[VUDS-R610] the template contains a DID attribute ASR3_Legacy_Combine_DID to control DEXT Export of DIDs [DEXT-R205]:

  • category „DEXT“
  • name „ASR3 Legacy Combine DID“
  • qualifier ASR3_ Legacy_Combine_DID
  • type Unsigned

DID "UDS Version" (CDS-71406 v12)

[VUDS-R620] uses the data type "UDS Version (4 Byte)" [VUDS-R350] for the DID (new in UDS 2019).

DID "CAN Protocol" (CDS-71406 v12)

[VUDS-R630] uses the data type "CAN Protocols Supported (1 Byte)" [VUDS-R360] for the DID (new in UDS 2019).
