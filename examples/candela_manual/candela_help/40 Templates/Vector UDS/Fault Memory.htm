Vector UDS Template - Fault Memory

DTC Status Bits

[VUDS-R730] The template supports all DTC Status Bits (CDS-72058 v13), in...

  • DTC Status Mask
  • DTC Status Availability Mask
  • DTC Status

... since the AUTOSAR Diagnostic Event Manager supports all DTC Status Bits.

Snapshot Records

Snapshot Record Numbers (v11 CDS-70902)

[VUDS-R710] The first existing Snapshot Record has the number 0x01.

  • ... so it can be used for "Snapshot Record Numeration Type" [SR-R023] Calculated as well as for Configured.

User Defined Fault Memory

[VUDS-R740] The template contains one diagnostic instance of User Defined Fault Memory (CDS-71889 13.0).

  • Motivation: Vector DEM supports only one.
  • Note: the template supports creating additional ones, controlled by the User Defined Fault Memories Text Table.
