Vector UDS Template - Introduction

"Road vehicles - Unified diagnostic services (UDS)" was released in a second edition 2013-05-15 as ISO 14229-1 2013(E).

Use this CANdela template to describe an UDS based ECU.

You can conveniently access the template via the CANdelaStudio File|Open Page.

The template ships with CANdelaStudio since CANdelaStudio version 8.5.

Some older version of the template is also shipped in a CANdesc package.

Version Numbering

With CANdelaStudio 13, the template version advanced from 2.5.0 to 13.0 (CDS-72043 v13).

For background info, see [VER-R300].

Use for CANdesc Code Generation

For CANdesc code generation, ...

  • use the CANdela template shipped with your CANdesc package, or
  • use Vector_UDS_1.5.cddt (contact Vector), or
  • use the current Vector template, then configure some values in GENy, independent from the values in the CANdela document.

Background

[VUDS-R050] Starting with Vector UDS template version 2.0 (8.5 SP2), some code generation attributes have been moved from the attribute category CANdesc to the attribute categories Autosar and UDS:

MaxAttemptsToDelay, MaxAttemptsToLock (but see [VUDS-R910-MaxAttemptsToLock]), DelayTimeMs, DelayTimeOnPowerOnMs, Faultmemory Relevance (data type), IoHwAbManaged, NvmBlockDescriptor... (see the list Attributes for AUTOSAR Diagnostic Extract export).

Motivation: clarify which properties are actually defined by UDS, and which are specific to AUTOSAR.

Effect: the CANdesc (not AUTOSAR) code generator GENy has not been adapted, it still looks for the CANdesc attribute category. The migration from 8.5 to 8.2 (CDC-41386 8.5 [MIG85-R001] for ECU level; CDC-44051 planned for diagnostic instance level) changes the attribute category back from "UDS" to "CANdesc".
