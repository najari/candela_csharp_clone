Vector UDS Template - Data Types

This chapter describes special data types defined in the Vector UDS Template.

Data Types for AUTOSAR DEM Objects

[VUDS-R310] Data Types and the "Faultmemory Relevance" Attribute [SATTR-R210]

The AUTOSAR DEM (Diagnostic Event Manager)...

  • collects some statistic information about each DTC internally
  • and provides it to a client via UDS Service 19 06.

In CANdelaStudio, ...

  • when you describe a data object for UDS Service 19 06,
  • for code generation, you should specify which statistic information it represents,
    • by selecting one of the predefined data types listed below.

How this works:

  • Each of the following data types has the attribute "Faultmemory Relevance" [SATTR-R210] set to the respective predefined enumeration value.
  • By this value, the code generator detects that the data object represents information available within the DEM.

Background: why is this semantic information predefined at data types?

  • Alternative: using data object semantics [DO-R150]
    • ... whose list of values is fixed in the implementation
  • Advantages of a data type: it...
    • also predefines the desired size and encoding of the data object
    • can be referenced from multiple data objects, which is convenient and avoids redundant information
    • can be extended in the template without adapting CANdelaStudio.

User Defined Fault Memories (CDS-42499 9.0)

The data type contains a sample list of user-defined fault memories.

It is used in the respective Diagnostic Class Template to restrict the set of possible diagnostic instances for user defined fault memory.

Data Types "SnapshotRecords" and "SnapshotRecordsPlusFF" (CDS-71915 Template 2.6.0)

[VUDS-R320] The data types have entries for the Snapshot Records 0x01 and 0x02.

  • used for Service 0x19 0x18
  • The Numeration Type is "calculated", which does not allow 0x10 and 0x20.
    • See Snapshot Record Numeration Type as an attribute [SR-R023].
    • Cf. in v13 AUTOSAR Fault Memory: described by a separate property [DI-R310-Calculated].

VIN (17 Byte) (CDS-70432 v10)

[VUDS-R330] Properties of the VIN data type:

  • field fix 17 bytes
  • encoding ASCII
    • since v10
    • before, it had encoding unsigned
  • string type: no size info.

UDS Version (4 Byte) (CDS-71406 v12)

[VUDS-R350] The data type encodes the UDS Version as a 4 byte value Major (MSB), Minor, Revision, 0 (LSB); 0 to 255 each (new in UDS 2019):

4 byte value UDS Version
0x01000000 2005
0x02000000 2013
0x03000000 2019

CAN Protocols Supported (1 Byte) (CDS-71406 v12)

[VUDS-R360] The data type provides info about the CAN support of the diagnostic link connector (new in UDS 2019):

1 byte value CAN Protocols Supported
0x00 CAN Classical only
0x01 CAN FD only
0x02 CAN Classical and CAN FD

The range 0x03 - 0xFF is ISO reserved.

Former Data Types now Removed (CDS-71763 v12)

[VUDS-D370] The following former Data Types have been removed with v12 since they where unused (most of them had been used by the pre 8.2 Snapshot Data modelling):

  • DID 0xF410
  • DID 0xF411
  • DID 0xF412
  • DID 0xF413
  • DID 0xF414
  • DTC AllSupportedSnapshotRecordNumbers with FF
  • DTC SnapshotRecordNumbers only FF
  • ExtendedDataRecordNumber Group A
  • ExtendedDataRecordNumber with FF
  • SnapshotRecord DTC P000002
  • SnapshotRecord DTC P000003
  • SnapshotRecordNumber 00 and 10
  • SnapshotRecordNumber 10 and 20
