Vector UDS Template - Functional Addressing

Functional Addressing (CDS-71903, CDS-72051 v13)

[VUDS-R8010] The following Protocol Services have Functional Addressing enabled:

  • OBD-II 0x01..0x0A
  • 0x10 Diagnostic Session Control
  • 0x11 EcuReset
  • 0x14 ClearDiagnosticInformation
  • 0x19 0x02 Report DTC by status mask
  • 0x19 0x42 Report WWH-OBD DTC by mask record
  • 0x19 0x55 Report WWH-OBD DTC with permanent status
  • 0x22 0xF4 ReadDataByIdentifier (PIDs, SupportedPIDs)
  • 0x22 0xF6 ReadDataByIdentifier (OBDMIDs, SupportedOBDMIDs)
  • 0x22 0xF8 ReadDataByIdentifier (Infotype, SupportedInfotype)
  • 0x28 CommunicationControl
  • 0x3E TesterPresent
  • 0x85 ControlDTCSetting (on)
  • 0x85 ControlDTCSetting (off)
