Ribbon Tab "Tools"

Ribbon Tab Tools

Logfile

Open Logfile

[MENU-R920] Opens the log file in the editor registered with Windows.

Open Logfile Backup

[MENU-R930] Opens the last but one version of the log file.

This is useful if you want to inspect the log file after a re-start CANdelaStudio but have activated the option "Clear on CANdelaStudio start".

Template

Convert Document to Template

[MENU-R960] Runs Convert to Template.

Plugins

Plugins (Document)

[MENU-R940] Lets you run a plug-in on the current document.

  • [MENU-R940-Mod] If you have modified but not yet saved the document, CANdelaStudio shows a hint that the document must be saved first.
  • [MENU-R940-TrView] In Translation View, CANdelaStudio does not provide Ribbon Tools | Plugin (Document) (CDS-71373 v10 P4, v11 P1, v12).

Plugins (Batch)

[MENU-R945] Lets you run a plug-in on a CANdela file you select in the file dialog.

Custom Actions

Edit Actions

[MENU-R970] Opens the Edit Actions dialog.

List of Actions

[MENU-R975] In the "Custom Actions" group, CANdelaStudio shows the user-defined actions.
