File | Options | General

Ribbon Tab File | Options, Page "General"

List of Recently Used Files

The number of files to be shown in the ribbon tab File [MENU-R340].

  • minimum: 0
  • default: 4 files
  • maximum: 16 files

Maximum Path Length

The maximum permitted length for the file paths in the list of most recently opened files.

  • minimum length: 16 characters
  • maximum length: 260 characters (i.e. file paths are not truncated)
  • default value: 260 characters

Create Backup Copy

If you select this option, CANdelaStudio automatically creates a backup copy of a file with each save, see Backup.

Automatically Save Document...

Choose this option if you wish to have CANdelaStudio automatically save opened documents.

In the input box, indicate the time interval within which automatic saving should occur.

See also Auto Save.

Insert Version Number in the Name

If you select this option, CANdelaStudio includes the version number in the file name every time a document is saved in the format of a previous version.

Base Directory

If you check this option, CANdelaStudio allows to edit the "Path" entry field below the option.

[OPT-R150] The "Path" entry field specifies the base directory:

  • CANdelaStudio saves all CANdela documents, specifications, ODX files, etc. in the following folder structure:
    • the base directory
    • a subfolder, name taken from the ECU Qualifier (which CANdelaStudio shows in the property dialog of tree node "ECU Information")
  • The Open Page shows the base directory in the Quick Access Area [OPEN-R310-BaseDir].

Example:

Base Directory D:\Project
ECU qualifier ABS_ESP
Resulting folder for saving D:\Project\ABS_ESP\

Save Each Document Version in Separate Subdirectory

The dialog enables this additional option if you have checked the "Base Directory" option.

[OPT-R155] With "Save Each Document Version in Separate Subdirectory" checked,

  • CANdelaStudio saves as described in [OPT-R150] above, but with the following deeper folder structure:
    • the base directory
    • a subfolder, name taken from the ECU Qualifier (which CANdelaStudio shows in the property dialog of tree node "ECU Information")
    • a further subfolder, name taken from the document version [DOC-R130] (if it exists)

Example:

Base Directory D:\Project
ECU qualifier ABS_ESP
Version 17.04
Resulting folder for saving D:\Project\ABS_ESP\17.04\

Grid Lines

If you check this option, CANdelaStudio shows data tables with line separators:

Grid Lines On

Otherwise, CANdelaStudio does not show line separators:

Grid Lines Off

Colored Rows

If you select this option, CANdelaStudio shows table rows in alternating background colors.

Click the buttons below the checkbox to define the background colors:

  • the first button defines the color for the first and odd-numbered rows;
  • the second button defines the color for the second and even-numbered rows.
