Start-Up

Disclaimer

[STRT-R010] On start-up, CANdelaStudio shows a disclaimer dialog

"Warning! The application of this product can be dangerous. Please use it with care."

You must either accept or cancel start-up of CANdelaStudio.

Splash Screen

Splash Screen

[STRT-R020] After the disclaimer dialog, CANdelaStudio shows the splash screen with the same information as the "About" [MENU-R1270] section shown in Ribbon Tab File - Product Information [MENU-R360].

This includes information about 32 or 64 bit.

[STRT-R060] The dialog shows info about patch installers [ABOUT-R060], but somewhat restricted:

  • For the first found Patch Installer file, CANdelaStudio shows the text from the file in the first line.
  • For further Patch Installer files, CANdelaStudio replaces all blanks in the text from the file by '_' and shows them after the first line.
    • This is technically necessary to get a well formatted output in the About Dialog.

Drag'n drop of CANdela documents onto the CANdelaStudio window is disabled until the splash screen disappears (CDS-39210 8.5).

User Feedback

[STRT-R070] On start-up, ...

  • after the 15th start-up after installation of a main version (12, 13,...) (CDS-70910 v12)
  • CANdelaStudio shows the User Feedback dialog.
  • The dialog is also available in Ribbon Tab File [MENU-R1250].

Running CANdelaStudio with Admin Privileges

[STRT-R030] You may run CANdelaStudio with Windows admin privileges (not recommended!).

  • [STRT-R030-Install] This situation arises if you start CANdelaStudio directly from within the installation [ISETUP-R340-Start].

The following restrictions apply:

  • [MENU-R340-Admin] The recent file list does not show files on network shares.
  • [OPEN-R120-Admin] The File|Open page does not show network shares.
  • Reason: by default, Windows network shares are user-specific, therefore regular network shares are not available.
