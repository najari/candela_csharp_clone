Ribbon Navigation Area top right in the CANdelaStudio Window

Path Entry

[TB-R310]

Edit field to input an object path.

Press ENTER or the "Go To" button to the right to navigate to the CANdela object specified by the path.

Press the down arraw at the right end of the edit field in order to select from a list of previously entered paths (CDS-41363, 8.5 SP2). The list contains paths entered in any document of the current CANdelaStudio session.
