DIAG-SERVICE and Negative Responses

  • with Strict, CANdelaStudio imports an ODX DIAG-SERVICE only if its negative response exists both in the import file and in the CANdela document

  • Also import NRCs which do not exist in CANdela document

  • with Prefer CANdela data, CANdelaStudio imports an ODX DIAG-SERVICE in any case; but prefers the negative response from the CANdela document if it exists

Data Type

  • with option Create new you can prevent ODX import from modifying an existing data type, but the resulting document may contain an unnecessarily huge number of data types.

  • With Use existing you minimize the number of data types, but ODX import possibly modifies even write-protected data types - you should use this option value only after confirmation with the person responsible with the ECU.

  • To be defensive, use option Use existing if modifiable - this prevents ODX import from modifying write-protected data types.
