Ribbon Tab Data Exchange

ODX Process

ODX Import

[MENU-R210] Imports from ODX.

Shows the ODX import wizard to configure the import.

For command line, see [CLI-R100-import].

See the sample import file [EX-R300-PDX].

ODX Export

[MENU-R120] Exports to ODX, with selection of the...

  • version: 2.0.1, 2.1.0, 2.2.0
  • format: ODX (XML files), PDX (XML files in a zip container)
  • variants
  • audience (target groups)

[MENU-R120-Document] only allowed in a document, not in a template (CDS-69685 9.1).

For command line, see [CLI-R100-odx].

Note: [MENU-R120-ASAMBasic] CANdelaStudio since 9.0 (CDS-42708, CDS-42709) no longer supports the export to ASAM MCD-2D Basic = ODX 1.1.4 or 1.1.5.

ECU Shared Data

[MENU-R150.1 ODX ECU Shared Data]

  • [MENU-R150-Sens] always sensitive (CDS-40769 8.5 SP2)
  • [MENU-R150-Template] shown in template, too (CDS-17167 7.0 SP1)

It opens a dialog showing all ODX ECU-SHARED-DATA imported into the document as an embedded file.

Recompute OIDs

[MENU-R580] Recomputes the OIDs (object IDs) in the document.

Check Consistency

Note: [MENU-R955] CANdelaStudio since v11 (CDS-70853) no longer provides separate ODX consistency checks. Just run the ODX Export to get up-to-date checker results.

[MENU-R1010] Imports a PVCDI file into a CANdela Document [IPV-R100].

[MENU-R1020] Exports a CANdela Document into a PVCDI file [EPV-R100].

See also:

  • Introduction [PVCDI-D010]
  • Command line operation [CLI-R100-pvcdiExport]

Requirements Import

Manufacturer Specific

[MENU-R125] The ribbon contains a button for manufacturer specific exports and checks.

[MENU-R125-None]

  • If no manufacturer specific export or check is available for the current document,
  • the button reads "Manufacturer specific"
  • and is insensitive.

[MENU-R125-First]

  • If a manufacturer specific export is available for the current document,
  • the button shows the name of the first available item in the submenu (e.g. "Diogenes")
  • and is sensitive.

Diagnostic Data Exchange (DDx)

[MENU-R140] Manufacturer specific export (Chrysler, FIAT, FCA).

[MENU-R140-Default] For documents of manufacturer [DOC-R110] "Chrysler", "FIAT" or "Standard (FCA)" the menu item "DDx Export" is the default for the ribbon button "Manufacturer specific" (CDS-70324 v10).

The menu item is only active if a working DDx export module is present.

It opens the SaveAs Dialog [DDX-R050].

See the Diagnostic Data Exchange export.

ODX-E (MB Car)

Multiplex Diagnostic Exchange (MDX)

[MENU-R160] Manufacturer specific export (Ford) to MDX 4.0 (CDS-27180 7.5 SP3).

[MENU-R160-Default] For documents of manufacturer "Ford", the menu item "Multiplex Diagnostic Exchange" is the default for the ribbon button "Manufacturer specific".

  • Export to MDX 2.0 was available up to CANdelaStudio 8.2 (CDS-37887 8.5).
  • Export to MDX 3.0 was available up to CANdelaStudio 9.1 (CDS-69347 v10).

For MDX export via command line, see [CLI-R100-mdx].

For MDX specific DTC Columns, see MDX DTC Columns.

MDX Export does not support Events.

The MDX XML Schema has been developed by Ford - please contact Ford for further information.
