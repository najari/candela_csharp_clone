Ribbon Tab "File"

The ribbon tab "File" is also called "Backstage".

It closes automatically when you select a menu item (except for the items opening a sub-menu).

Ribbon Tab "File"

New

[MENU-R010] Lets you select a template (.cddt) and a language to create a document (.cdd) based on the template [DOC-R600], using the New Dialog.

Note: "Reopen in Standard View" [MENU-R780-Template] implicitly performs the same operation.

Recent

[MENU-R340] Lists files recently opened.

  • [MENU-R340-Number] The number of menu entries is specified in the Options Property Page "General".
  • [MENU-R340-RemoveFile] You can remove an individual entry via context menu "Remove file from list".
  • [MENU-R340-Remove] Rou can remove the entire list by editing the INI file [INI-R340].
  • [MENU-R340-Template] If you click a template (CDDT) in the Admin Edition, CANdelaStudio opens it in Expert View (CDS-4695 R001, 5.0).
    • cf. drag'n drop [DDF-R110].
    • This does not work in v10 (CDS-70830).
  • [MENU-R340-Admin] When you started CANdelaStudio with Windows admin privileges [STRT-R030], the file list does not contain files from network drives (CDS-71041 v11).

Open

[MENU-R020] Lets you open a CANdela document (.cdd) or template (.cddt) [DOC-R610], using the Open Page [OPEN-R010].

Properties

[MENU-R330] Opens the Property Dialog for the document.

The menu item is shown only if a document is loaded.

Save

[MENU-R040] Saves the current document or template [DOC-R620].

The menu item is shown only if a document is loaded.

Save As

[MENU-R043] Saves the current document in a different version, using the Save As Dialog.

Not available for templates.

The menu item is shown only if a document is loaded.

Save All

[MENU-R045] Saves all documents.

The menu item is shown only if a document is loaded.

RTF Report (Specification)

[MENU-R110] Creates a Specification Report in RTF format.

See the Options Property Pages Specification: General and Chapters.

The menu item is shown only if a document is loaded.

HTML Report (Specification)

[MENU-R115] Creates a Specification Report in HTML format.

See the previous chapter for details.

Close

[MENU-R030] Closes the current document or template.

Asks for confirmation if there are unsaved modifications.

The menu item is shown only if a document is loaded.

Close All

[MENU-R050] Closes all documents.

Asks for confirmation if there are unsaved modifications.

The menu item is shown only if a document is loaded (CDS-70300 v10).

Select as Left Side

[MENU-R300] Selects the current document as left side for the "Compare" operation, to be completed by "Compare File to Left Side" (see next chapter).

The menu item is shown only if a document is loaded.

Compare File to Left Side

[MENU-R310] Compares the current document to the document specified via "Select as Left Side" (see previous chapter).

See Compare View.

The menu item is shown only if a document is loaded.

Options

[MENU-R910] Opens the Options Dialog.

Vector Support Assistant

[MENU-R1256] Opens the Vector Support Assistant.

Product Information

[MENU-R360] Opens the Product Information page

Help

[MENU-R1210] Opens online help.

See also About this documentation.

Exit

[RB-R1900] Closes CANdelaStudio.

Asks for confirmation if there are unsaved modifications.
