File | Options | Logging - Logfile

Ribbon Tab File | Options, Page "Logfile"

This dialog configures the Logging feature of CANdelaStudio.

Filter

[OPT-R610] The "Filter" radio buttons set the type [LOG-R100] of messages to be written to the logfile.

Selecting a lower button includes writing messages of the upper buttons.

Path

[OPT-R620] Enter the path of the logfile...

  • in the edit box
    • the path must denote an existing text file
    • otherwise CANdelaStudio will not write the logfile
  • or click [...] to use the File selection dialog.
    • the dialog allows selection of existing files only
    • in order to use a new file, create it in the dialog first (right mouse, "New | Text file...")

Clear on CANdelaStudio start

[OPT-R630] With this option checked, CANdelaStudio clears and re-writes the logfile every time it starts. Note: you can still inspect the logfile from the previous run using Open Log File (backup version) from the Tools menu.

With the option un-checked, CANdelaStudio continually appends at the end of the existing logfile. Caution: the logfile may grow large over time!

Time Stamp in messages

[OPT-R640] With this option checked, CANdelaStudio adds the exact time of writing to each message written in the logfile.

Note: Output Window shows the time stamp anyway [OW-R110].
