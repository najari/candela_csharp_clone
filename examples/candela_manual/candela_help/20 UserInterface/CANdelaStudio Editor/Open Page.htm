Open Page

[OPEN-R010] In Ribbon Tab File, the menu item "Open" [MENU-R020] shows the Open Page in the backstage (the right side).

CANdelaStudio File|Open Page

The page lets you open...

  • a CANdela document (.cdd) in Standard View, Translation View or Expert View
  • a CANdela template (.cddt) in Translation View or Expert View

See also the document operation Open [DOC-R610] and the CANdelaStudio Views.

Starting with v11 (CDS-69946),

  • File|Open has been integrated in the backstage.
  • You can still access the conventional Windows file dialog via the button "..." at the bottom.

See also the notes for running CANdelaStudio with Windows admin privileges [STRT-R030].

Navigation

Open Page - Navigation

[OPEN-R210] The left arrow button navigates back through folders visited in the page.

[OPEN-R220] Similarly, the right arrow button navigates forth through the folders previously navigated back.

[OPEN-R230] The down arrow button opens a list to directly navigate to a folder previously visited in the page.

[OPEN-R240] The up arrow button navigates up to the parent folder of the currently visited folder. It stops at the root folder of the drive.

[OPEN-R250] The edit control shows the currently visited folder.

  • [OPEN-R250-Segments] It shows each folder name and a right arrow as a selectable segment .
  • [OPEN-R250-Click] When you click onto a segment, you navigate to that folder.
  • [OPEN-R250-Arrow] When you click the arrow to the right of the text, a list opens with folders under the folder shown in the segment.
    • E.g. being on drive D:, you want to navigate to drive E:.
    • Press the arrow of the Computer segment left to D:; in the list shown, select E:.
  • [OPEN-R250-Editing] When you click into the empty background of the edit control, ...
    • the control switches to edit mode where you can directly type or paste text.
    • Pressing ENTER or the arrow button at the right end accepts input and navigates to that folder, if it exists.
    • [OPEN-R250-EditingFolder] When you enter (edit or paste) a folder path, CANdelaStudio opens that folder.
    • [OPEN-R250-EditingFile] When you enter a file path, CANdelaStudio opens the folder of the file and selects the file in the Files and Folders List (described below, [OPEN-R120]).
    • [OPEN-R250-Missing] When you enter a path not existing, CANdelaStudio shows an error message and remains in the current folder.

Special Folders

Open Page - Special Folders

[OPEN-R300] The folders area to the left...

  • contains the lists "Quick Access" and "Recent Folders"
  • can be resized using the dotted gripper to the right.

Quick Access

[OPEN-R310] The Quick Access area lists important folders:

  • [OPEN-R310-Desktop] the Windows desktop folder
  • [OPEN-R310-MyDocuments] your personal Documents folder
  • [OPEN-R310-BaseDir] your personal Base Directory (if configured in Ribbon Tab File|Options [OPT-R150])
  • [OPEN-R310-VectorExamples] the CANdelaStudio examples folder.

Recent Folders

[Open-R340] Recent Folders contains the folders of the files listed in File|Recent [MENU-R340].

  • [Open-R340-Remove] If needed, you can cleanup the folder list by cleaning up the recent files list [MENU-R340-Remove].

Filter

Open Page - Filter

[OPEN-R110] Provides filtering using wildcard patterns for the file name:

  • CANdela Data: .cdd (documents)
  • CANdela Templates: .cddt
  • All CANdela Files: .cdd and .cddt
  • All Files: no filter, shows all files in the folder

Files and Folders

Open Page - Files and Folders

[OPEN-R120] The list shows files and folders in the currently selected folder.

  • The filters described above [OPEN-R110] optionally hide some files.
  • [OPEN-R120-Char] When you type some character(s), the dialog navigates to the first name in the list that starts with these characters ("incremental search").
    • The list must have focus.
  • [OPEN-R120-Backspace] When you type Backspace, the dialog navigates to the parent folder.
  • [OPEN-R120-Sort] You may sort the list by clicking onto the list header.
    • Sorting combines files and folders in one list.
  • [OPEN-R120-FolderDoubleClick] Double-click on a folder navigates into the folder.
  • To navigate to the parent folder, you may...
    • click the second last segment in the edit control on top [OPEN-R250-Segments], or
    • click the Up arrow button [OPEN-R240] left to that edit control.
  • [OPEN-R120-FileDoubleClick] Double-click on a file opens it with the settings specified for View Type and Language (see the next chapters).
  • [OPEN-R120-Admin] When you started CANdelaStudio with Windows admin privileges [STRT-R030], network drives are not available (this is a Windows feature).

View Type

Open Page - View Type

[OPEN-R410] Specifies the View for opening the file.

  • [OPEN-R410-StandardEdition] View, ViewX and Standard edition do not show this pane at all, since they automatically open files in Standard View only.
  • [OPEN-R410-StandardView] Standard View
    • Lets you open the file in Standard View.
    • [OPEN-R410-StandardInsens] For CANdela templates, the button is shown insensitive (Standard View is not available for templates).
    • [OPEN-R410-Keep] When you select a template, the Expert View button gets selected.
      When you then select a document, the Standard View button gets selected (CDS-71272 v12).
  • [OPEN-R410-ExpertView] Expert View
    • Lets you open the file in Expert View.
    • [OPEN-R410-ExpertViewProEdition] In Pro Edition, the button is shown insensitive (Expert View is not available in Pro Edition).
  • [OPEN-R410-TranslationView] Translation View
    • Lets you open the file in Translation View.
  • [OPEN-R410-Default] On entry, the dialog selects Standard View (CDS-71272 v12).

[OPEN-R410-DoubleClick] A double-click on a button opens the file currently specified in the edit control [OPEN-R130], using the view defined by the button.

Dependency on CANdelaStudio Edition:

  • [OPEN-R420-Standard] In CANdelaStudio View, ViewX and Standard Edition,
    • the "View Type" area is not shown at all.
  • [OPEN-R420-Pro] In CANdelaStudio Pro Edition,
    • the "Expert View" button is shown insensitive.

Languages

Open Page - Languages

[OPEN-R420]

  • shows the list of languages in the CANdela file
  • your selection determines the language of diagnostic objects to be shown in CANdelaStudio.
  • for details, see the Language Handling [DOC-R620] at the Open operation.

See also the Multi-Language Feature.

File Name

Open Page - File Name

[OPEN-R130] The edit control specifies the file name that will be used by the Open button. It can contain...

  • [OPEN-R130-Filename] a file name, like Example.cdd
  • [OPEN-R130-Absolute] an absolute path, like D:\Example.cdd
  • [OPEN-R130-Relative] a relative path, like ..\2019\Example.cdd
    • A relative path is evaluated relative to the current folder.
  • [OPEN-R130-Edit] You can edit the contents by typing and by using copy/paste.

[OPEN-R130-Explorer] The "..." button to the right end of the control opens the Windows file dialog on the current folder, which...

  • provides operations directly on the files, using the context menu.
  • provides access to further special Windows folders (Favorites, Libraries)
  • provides access to a list of previously opened CANdela templates or documents (managed by Windows) - press the Down button in the edit control at the bottom of the Windows file dialog.

[OPEN-R150-Open] The "Open" button opens...

  • the file specified in the edit control,
  • with the settings specified for View Type and Language (see above chapters).
  • As an alternative, you can open a file by ...
    • a double-click in the list [OPEN-R120-FileDoubleClick],
    • a double-click on a "View Type" button [OPEN-R410-DoubleClick].
  • [OPEN-R150-OpenCddt] When you are not using the Admin Edition:
    • if you select a CDDT file,
    • the "Open" button is insensitive,
    • since you can open a template in Expert View only.

Passwort Protection

[OPEN-R140] If the document or template is password protected, CANdelaStudio prompts for the password.
