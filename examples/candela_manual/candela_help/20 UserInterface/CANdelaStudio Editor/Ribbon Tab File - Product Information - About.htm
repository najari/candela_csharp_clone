Ribbon Tab File - Product Information - About

[MENU-R1270] In Ribbon Tab File - Product Information, CANdelaStudio shows info about the application:

CANdelaStudio About Dialog

Version

Shows the main version (e.g. 8.1) and the Service Pack / Patch / Beta.

Edition

Shows the CANdelaStudio edition you are running.

When starting CANdelaStudio, you can pass a command line option to run in a lower edition.

Before CANdelaStudio 8.2, the "View" edition was shown as "No Edition" (CDS-36418).

All manufacturers

Your CANdelaStudio instance supports CANdela documents of all manufacturers (see the document property "Diagnostics Based on").

Serial Number 1111111111

[ABOUT-R050 Serial Number]

  • [ABOUT-R050-PerSeat] For a per-seat license, the serial number is unique to your instance of CANdelaStudio (assigned in the Vector sales system). If you got CANdelaStudio on a CD, you find the serial number also on the CD.
  • [ABOUT-R050-Dongle] For a license taken from a dongle, the serial number is not shown.
  • [ABOUT-R050-Pool] For a pool license, the serial number can be identical for multiple licenses.

Patch Installer (CDS-69388 9.1)

[ABOUT-D060] Patch Installer Identification File ::=

  • text file in the CANdelaStudio bin folder
  • file name PatchInstaller_<OEM>.txt, OEM = Daimler, Porsche, ...

[ABOUT-D062] Patch Installer Identification ::=

  • the first line of a file from [ABOUT-D060] (above) contains a string that identifies the Patch Installer version
  • Syntax: <CANdelaStudio main version> PatchInstaller <patch version> (<OEM>) <date>
  • e.g. 9.0 SP1 PatchInstaller 11 (Daimler) 2017-11-10

[ABOUT-R060 Patch Installer] in the dialog of menu Help|About,

  • CANdelaStudio shows all Patch Installer Identifications (as of [ABOUT-D062]),
  • line by line,
  • below the "... Edition" line.

Note: the info is also shown in the Splash Screen [STRT-R060].
