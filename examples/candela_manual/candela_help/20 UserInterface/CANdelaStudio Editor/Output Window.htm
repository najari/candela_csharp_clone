Output Window

Output Window with Details Area

During execution, CANdelaStudio logs messages (see the Logging Feature) and shows them in the Output Window.

You can copy the contents of the Output Window and insert it in another application (a spreadsheet or text editor) using its toolbar or the context menu.

The Output Window has been modernized in CANdelaStudio 9.1 (CDS-68999).

Position and Opening

[OW-R010] The Output Window is located below the work area.

  • [OW-R010-Default] It is closed as a default.

[OW-R020] To open the Output Window, use...

  • Ribbon tab "View" [MENU-R610],
  • click "Output" at the bottom of the CANdelaStudio window:

Closed Output Window at the Window Bottom

[OW-R030] The Output Window automatically closes after some time.

[OW-R035] The pin at top-right...

  • [OW-R035-KeepOpen] if ticked, keeps the Output Window open;
  • [OW-R035-Close] if un-ticked, closes the Output Window. You can also use ribbon tab "View" [MENU-R610] to close the Output Window.

Pin at Top Right of Output Window

[OW-R040] CANdelaStudio switches to the Output Window if...

  • the Output Window is not shown,
  • but Revision view is shown, and
  • CANdelaStudio writes a new message to the Output Window.

Columns

Type

[OW-R100] Shows the type [LOG-R100] of the message.

Timestamp

[OW-R110] shows the time stamp [LOG-R110], with two digits for milliseconds.

Cf. the option [OPT-R640] for the logfile.

Origin

[OW-R120] shows the origin [LOG-R120] of the message.

Link

[OW-R130] If the message references an object [LOG-R130], the table cell shows a symbol to click.

  • [OW-R130-Click] When clicked, CANdelaStudio navigates to the object [OW-R240].

Message

[OW-R140] The text of the message.

  • [OW-R140-Truncate] Texts longer than the visible area are shown with "..." at the end (CDS-70752 v11).

Message Details (CDS-70752 v11)

[OW-R050] For better handling of long messages, CANdelaStudio optionally shows a details area at the right edge of the output window, controlled by a toolbar button [OW-R430].

  • [OW-R050-Splitter] You can move the border between the message list and the details area.
  • [OW-R050-ReadOnly] The details area is read-only.
  • [OW-R050-Copy] You can copy text from the details area to the clipboard, using the keyboard shortcuts or the context menu items for the clipboard.
  • [OW-R050-Selection] If you click a line in the list, CANdelaStudio shows the following properties in the details window:
    • Type
    • Time Stamp
    • Origin
    • Message
  • [OW-R050-Multiselection] If you select multiple lines in the message list, the contents of the details area does not change (just select a single line).

Operations

Show Logfile

[OW-R200] opens the currently written logfile in the application registered in Windows.

The path is defined in the dialog of Ribbon Tab File | Options | Logfile.

Show Logfile (Backup Version)

[OW-R210] opens the logfile written in the previous run of CANdelaStudio in the application registered in Windows.

Select All

[OW-R220] Selects all visible messages (not the message suppressed by filters).

Copy

[OW-R225] Copies the selected messages to the clipboard.

Clear

[OW-R230] Deletes all Output Window messages, independent from the filter settings.

Navigate to Object

[OW-R240] CANdelaStudio switches the active document to the document the link refers, and navigates to the object referenced in the message.

Filters

[OW-R300] The Output Window always collects all messages, independent from filters. The filters control the display only.

[OW-R310] The filters work together with an "AND" relationship.

Type Filter

[OW-R320] The "Type" filter suppresses messages depending on their type, which is shown in the first column [OW-R100].

[OW-R335] The filter for type "Status" is disabled by default.

Origin Filter

[OW-R340] The "Origin" filter suppresses messages issued by a specific functional part of CANdelaStudio [OW-R120].

Text Filter

[OW-R350] The "Text" filter suppresses messages that do not contain some text fragment. It applies to all displayed message properties, as shown in the list.

Reset Filters

[OW-R360] Resets all filters (Type, Origin and Text), so that all messages are displayed.

Show/Hide Toolbar

[OW-R400] Shows or hides the toolbar.

Note: if the toolbar is hidden, you can show it again via the context menu [OW-R600].

Show/Hide Column Headers

[OW-R410] Shows or hides the line with the column headers ("Type", "Time Stamp" etc.).

Auto-Scroll

[OW-R420] Controls whether the list automatically scrolls to new messages. Default: on.

If you inspect some existing messages, turning off auto-scroll prevents the list from automatically scrolling to new messages which CANdelaStudio may show while you navigate in the CANdela document.

Show/Hide Details

[OW-R430] Controls whether the message details area [OW-R050] to the right is shown. Default: off.

Toolbar

[OW-R500] The toolbar provides the following operations:

  • [OW-R200] Show Logfile
  • [OW-R210] Show Logfile (backup version)
  • [OW-R225] Copy (enabled if rows are selected)
  • [OW-R230] Clear
  • [OW-R320] Type filter
  • [OW-R340] Origin filter
  • [OW-R350] Text filter
  • [OW-R360] Reset filters
  • [OW-R400] Show/Hide Toolbar
  • [OW-R410] Show/Hide Column Headers
  • [OW-R420] Auto-Scroll
  • [OW-R430] Show/Hide Details

Context Menu

[OW-R600] The context menu in the list provides the following operations:

  • [OW-R220] Select All Rows
  • [OW-R225] Copy (enabled if rows are selected)
  • [OW-R200] Show Logfile
  • [OW-R210] Show Logfile (backup version)
  • [OW-R400] Show Toolbar (disabled if the toolbar is already shown)

Persistent Properties

[OW-R700] The Output Window remembers the following properties across CANdelaStudio sessions:

  • State of filter buttons
  • State of other check-buttons
  • Grid column visibility, sort, position.
