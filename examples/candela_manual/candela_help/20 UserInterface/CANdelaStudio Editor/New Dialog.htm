CANdelaStudio New Dialog

The dialog lets you select a template (.cddt) to create a document (.cdd) based on the template.

See the document operation New [DOC-R600].

File Name

Specifies the file name, optionally with a folder path, of the template to open.

Click the down button to the right end of the control to select from a list of previously opened CANdela templates.

File Type

Provides a list of wildcard patterns:

  • CANdela Templates (*.cddt)
  • All Files (*.*)

Languages

Shows the list of languages in the CANdela file, like in the Open Page.

Passwort Protection

If the template is password protected, CANdelaStudio prompts for the password.
