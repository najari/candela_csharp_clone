Switch View

[MENU-R772] Ribbon group "Switch View" provides operations to switch the view of the current document or template.

For all of the following buttons/operations:

  • [MENU-R775] the button for the current view is invisible (CDS-69961 v10);
  • [MENU-R778] the document must be saved before switching the view (CDS-70284 v10). If the document has unsaved modifications, CANdelaStudio prompts to save, then either...
    • saves the document and switches view, or
    • cancels the operation (does neither save nor switch view).

Reopen in Standard View

[MENU-R780] Reopens the document in Standard View [VIEW-R100].

  • [MENU-R780-Template] For a template, creates a new document, like File|New [MENU-R010].

The common notes above [MENU-R772] for all switch view operations apply.

Reopen in Expert View

[MENU-R785] Reopens the document in Expert View [VIEW-R200].

Reopen in Translation View

[MENU-R790] Reopens the document in Translation View [VIEW-R300].

Document Upgrade

[MENU-R560] Transfers the document data to another template. Takes even the contents of the base variant from the template.

[MENU-R565] Transfers the document data to another template. Preserves the base variant of the document, ignores that of the template.

Company Specific Info (CDS-70603 v11)

Use-case:

  • as an administrator setting up CANdelaStudio in a company, you may want to provide access to company specific info regarding CANdelaStudio, e.g. for...

  • specific CANdela templates,
  • instructions for your process
  • frequently asked questions

  • contact addresses for in-house support.

Solution:

[MENU-R390] For Ribbon Tab Document, configure a button that opens e.g. ...

  • an intranet portal page or
  • a manual specific to your process on a network drive

See the section in the INI file [INI-R580].
