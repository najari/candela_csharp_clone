CANdelaStudio Search Dialog

The Search dialog supports two ways of search:

  • list all hits in the output window.
  • navigate to the next hit.

Find what

Enter the search term.

To select from a list of recently used search terms, press the down arrow at the right end of the edit control.

Limit search to...

Limits the search to

  • Names
  • Qualifier
  • Name, Qualifier, Description, Identifier, DTC, Service shortcut, Response code
  • Service Request

Match upper/lower case

If checked, search distinguishes upper/lower case.

Example: Searching for "Year" finds objects named "Year" or "Yearly", but not objects named "yearEnd".

Match whole word only

If checked, search compares the search term against fragments of the name, qualifier etc. at the start or end or surrounded by blanks.

Example: Searching for "Key" finds objects with this name, but not with the name "Keyword".

Compare whole text

If checked, search compares the search term against the entire name, qualifier etc.

Example: Searching for "Switch on" finds objects with that name, but not objects named "Switch on and off".

Find

Starts searching at the beginning of the document, selects the object found.

Find Next

[SRCH-R150] Continues search behind the last hit, selects the object found.

  • [SRCH-R150-F3] Pressing key F3 has the same effect.
  • [SRCH-R150-Closed] Pressing key F3...
    • works also after you closed the dialog,
    • if the focus is in the navigation tree (CDS-71142 v12).

Find All

[SRCH-R200] Writes the hits as links into the output window [OW-R130].

Cancel

Leaves the dialog.

Leaves the selection at the object selected by the last "Find" operation.

After closing the dialog, key F3 performs "Find Next".

Result List (Output window)

The list shows the qpath to the object as a hyperlink, as it can be entered in the path control in the ribbon navigation area.

A click on the hyperlink navigates to the object directly, or to the closest object that can be shown without opening a modal dialog.
