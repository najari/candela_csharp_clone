User Feedback

The User Feedback dialog shows an information dialog with a link to the CANdelaStudio online feedback form (survey) (CDS-3003 3.0, CDS-9307 5.5). You can open the dialog via ribbon tab File | Help [MENU-R1250].

User Feedback Dialog

Target

The dialog provides a link to...

  • default: www.candelastudio.com (CDS-42140 8.5 SP3)
  • in German GUI: www.candelastudio.de

Checkbox "Do not remind me anymore!"

CANdelaStudio shows a checkbox that allows turning off display of the dialog.

Conditions

CANdelaStudio shows the dialog at each start, except...

  • command line switch /q [CLI-R100-quiet] has been set (CDS-16754 6.5 SP2),
  • you checked "Do not remind me anymore!",
  • in View or ViewX edition,
  • in a beta version.
