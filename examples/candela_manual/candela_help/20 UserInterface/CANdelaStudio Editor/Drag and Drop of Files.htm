Drag and Drop of Files (CDS-4695 R002 5.0)

Template (CDDT, in Admin Edition only)

[DDF-R110] If you drop a CANdela template (CDDT file) onto CANdelaStudio, ...

  • if this is the Admin Edition,
  • and the registry key [INI-R300] is != 0, CANdelaStudio opens the template in Expert View,
  • otherwise, it opens the template in Standard View.
