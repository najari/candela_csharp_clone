File | Options | Translation

Ribbon Tab File | Options, Page "Translation"

These options apply to the Translation View.

General - Ignore template data...

Select this option if the translation table shall hide names and descriptions of template objects if they are completely translated.

Automatic Translation of Matching Terms

This option controls the way the automatic translation function is to behave after you have translated a term. If you have switched on the automatic translation function by selecting one of the two bottom options, CANdelaStudio assigns the text you last entered also to other occurrences of the term.

Apply even to occurrences already translated

As a default, automatic translation only applies to terms not yet translated.
