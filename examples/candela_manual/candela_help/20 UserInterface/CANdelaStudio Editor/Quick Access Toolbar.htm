Quick Access Toolbar

Quick Access Toolbar top left in the CANdelaStudio Window

Note: the system menu is provided by the operating system, it is not part of the Quick Access Toolbar.

Predefined Quick Access Toolbar Entries

[RB-R100] As a default at the first start, the Quick Access Toolbar contains the following buttons (as shown in the screenshot above) (CDS-69946 v11):

  • New [MENU-R010]
  • Properties of the active document [MENU-R330]
  • Save [MENU-R040]
  • Save As [MENU-R043]
  • Open [MENU-R020]

You may configure the toolbar, see the next chapters.

Note: some buttons are shown only if a file has been opened.

Configuring

Buttons from Ribbon Tab "File"

[RB-R110] Using the down arrow at the right end of the Quick Access Toolbar, you can add / remove buttons.

  • The set of available entries is from the ribbon tab File.

These buttons are shown most left in the Quick Access Toolbar.

Buttons from other Ribbon Tabs

[RB-R120] On any button in the ribbon tabs besides File, ...

  • right click on the button and
  • select menu item "Add to Quick Access Toolbar"
  • ... to additionally show the button in the Quick Access Toolbar.

To remove it again, ...

  • un-check it in the menu at the right end of the Quick Access Toolbar
    • you can conveniently check it again later;
  • or click on the button in the Quick Access Toolbar or in the ribbon tab,
    • and select menu item "Remove from Quick Access Toolbar".

These buttons are shown in the order added to the toolbar.

Buttons from a Ribbon Group

[RB-R130] You can add an entire ribbon group [RB-R020] to the Quick Access Toolbar. This is useful to keep the ribbon minimized [RB-R050] but access important actions, anyway.

On the group name below a ribbon group (like "Edit"), ...

Ribbon Group Edit

  • right click on the group name and
  • select menu item "Add to Quick Access Toolbar"
  • ... to additionally show a button for the group in the Quick Access Toolbar.

When you click the group button in the Quick Access Toolbar, a sub-menu opens containing all buttons of the ribbon group.

To remove it again, the procedure is the same for buttons from other ribbon tabs (see previous chapter).

The buttons are shown in the order added to the toolbar.

Toolbar Position

[RB-R210] You can configure to "Show the Quick Access Toolbar Below the Ribbon", and back.

Quick Access Toolbar Shown Below the Ribbon

This menu item is available...

  • in the context menu of any ribbon button, and
  • in the menu available from the down arrow at the right end of the Quick Access Toolbar.
