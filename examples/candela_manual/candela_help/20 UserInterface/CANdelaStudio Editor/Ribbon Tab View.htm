Ribbon Tab "View"

Ribbon Tab "View"

Display

Output Window

[MENU-R610] Shows or hides the Output window.

See [MENU-R1135] to reset the position.

Rework List

[MENU-R625] Shows or hides the New Document Upgrade Rework List.

See [MENU-R1135] to reset the position.

Latest Revision

[MENU-R620] Shows or hides the Latest Revision window.

See [MENU-R1135] to reset the position.

Status Bar

[MENU-R640] Shows or hides the status bar at the bottom of the CANdelaStudio main window.

Windows

Tabbed

[MENU-R1115] Shows document windows with tabs.

Tile Horizontally

[MENU-R1120] Shows document windows one upon the other, in the order of the document pages (tabs) shown at the top of the CANdelaStudio window (CDS-69534 9.1).

Tile Vertically

[MENU-R1130] Shows document windows side by side, in the order of the document pages (tabs) shown at the top of the CANdelaStudio window (CDS-69534 9.1).

Cascade

[MENU-R1110] Shows document windows cascading (partially overlapping).

Reset View

[MENU-R1135] After confirmation, resets the view to the default settings:

  • Display:
    • shows the Output Window [MENU-R610], brings it to front
    • shows the Rework List [MENU-R625] and the Latest Revision Window [MENU-R620]
    • restores the order [DW-R130] of the docking windows (Output Window etc.) to the default
  • Windows:
    • sets to Tabbed [MENU-R1115]
  • Quick Access Toolbar:
    • deletes user-defined entries, resets to default [RB-R100]

No effect to the ribbon minimize/expand state [RB-R050].
