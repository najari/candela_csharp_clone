File | Options | Display

Ribbon Tab File | Options, Page "Display"

General - Fill hexadecimal values with leading zeroes

Select this option if you would like CANdelaStudio to edit hexadecimal values filled up with leading zeroes, up to the maximum size of the value.

Example: the hexadecimal value "0xA1" with 2 Byte length will be edited as "0x00A1."

When CANdelaStudio displays hexadecimal values, it fills byte-wise, up to the size of the actual value.

Example: the hexadecimal value "0xA1" with 2 Byte length will be displayed as "0xA1."

Diagnostic instance names

Identifier

Check this option to show Identifier, Local IDs, Addresses, Subfunctions etc. beside the diagnostic instance name in the navigation tree.

Target groups

Check this option to show the target groups to which a diagnostic instance or job container is assigned in the name of the object in the navigation tree.

Service addressing

Check this option to show the service addressing (functional and/or physical) in the navigation tree.

Maturity

Check this option to show the maturity of a diagnostic instance or a job container in the navigation tree.

State Diagrams - Font

Select the font that CANdelaStudio shall use for the state transition diagrams in the chapter "States/Dependencies" of a CANdela document (in the user interface and in a report).

GraphViz (dot.exe) - Path

[OPT-R250] optionally specify the folder of dot.exe to be used by CANdelaStudio.

  • CANdelaStudio uses the tool "GraphViz" to visualize the state dependency of service execution [STUI-R180].
  • The CANdelaStudio installation does not include GraphViz [IBP-D090]
  • If GraphViz has been installed on your system, but CANdelaStudio does not show the diagram, the reason may be an incorrect path in the Windows PATH environment variable. In this case, you may either...
    • correct the Windows PATH environment variable [IWS-D200] directly, or
    • use the option here to specify the path to the folder of dot.exe, like C:\Program Files (x86)\Graphviz2.38\bin.

Format of Error Codes

[OPT-R260] This option is only applied if File | Properties | "Display of DTCs" is "ISO-14229/Hex".

  • Hexadecimal: The error codes (DTCs) in the error memory are displayed in hexadecimal notation.
  • SAE format: The error codes are displayed in SAE notation, like "P0001".
Prefix Hex Prefix Starting at
P 0x0
C 0x4
B 0x8
U 0xC

Note for Daimler documents: there is an additional convention for the export of DTCs.

The option has impact on ODX Export.

Object Path

  • Name: All paths of CANdela objects are displayed as name paths. Exception: The paths of identifying features are always displayed as qualifier paths.
  • Qualifier: All paths are displayed as qualifier paths.

See Object Paths.
