Docking Windows

Some Docking Windows with Output Window active

Overview

CANdelaStudio provides special "docking windows" that you can move freely:

  • Output Window
  • Rework List
  • Latest Revision

Position

[DW-R100] A docking window can have...

  • a separate position (side by side / one upon the other), or
  • a position combined with other docking windows, in a tabbed interface (like in the screenshot above).

[DW-R110] The position can be at the top, right, bottom or left of the CANdelaStudio document windows.

Docking Window Moving

[DW-R120] You can move an individual docking window to any of these positions.

  • drag and drop the tab header onto desired position.

[DW-R130] You can combine a docking window with other ones into a tabbed interface

  • drag and drop the tab header onto the header of the other window(s).

[DW-R140] In the combined position, ...

  • you can adjust the order of the docking windows,
    • drag and drop the tab header to the desired position;
    • e.g. put the Output Window most left or most right.
  • Reset View [MENU-R1135] resets the order of the docking windows to the default.
