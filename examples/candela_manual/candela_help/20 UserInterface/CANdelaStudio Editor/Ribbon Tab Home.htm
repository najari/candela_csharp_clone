Ribbon Tab "Home"

Ribbon Tab "Home"

Navigation

The ribbon group "Navigation" provides access to previously visited objects.

See also the Ribbon Navigation Area top-right in the CANdelaStudio window for navigation using object paths.

Back

[MENU-R696] Navigates back in the history of visited objects (like in a web browser).

Forward

[MENU-R698] Navigates forward in the history of visited objects (like in a web browser).

Edit

Cut

[MENU-R410] Cuts the selected objects to the CANdelaStudio clipboard.

Copy

[MENU-R413] Copies the selected objects to the CANdelaStudio internal clipboard.

Paste

[MENU-R415] Pastes the previously cut or copied objects from the CANdelaStudio internal clipboard,

  • preserves the key properties
  • not available in case key properties would not be unique
    • as opposed to "Paste Content"

Paste Content

[MENU-R417] Pastes the previously cut or copied objects from the CANdelaStudio clipboard, adapting key properties to be unique if necessary.

Paste as Reference

[MENU-R425] Paste as Reference | Copies object(s) from the CANdelaStudio internal clipboard as a reference, see diagnostic instance operation [DIOP-R030].

  • [MENU-R425-Insens] The button is insensitive e.g. after deleting a previously copied element (CDS-70068 v10).

Delete

[MENU-R420] Deletes the selected objects.

Element

Properties

[MENU-R590] Opens the property dialog of the selected object.

For most objects, the dialog has at least the page General.

References

[MENU-R710] Opens the "References" dialog for the selected object:

  • References dialog in variants
  • Used by dialog for other objects

Document

Replace Reference with Copy

[MENU-R440] Runs the diagnostic instance operation [DIOP-R040] and the DID operation [DID-R230].

Replace Copy with Reference in Base Variant

[MENU-R450] Runs the diagnostic instance operation [DIOP-R050].

Replace Identical Diagnostic Instances and Job Container

[MENU-R460] Runs the diagnostic instance operation [DIOP-R060].

  • [MENU-R460-No] If there are no sharable Diagnostic Instances or Job Containers, CANdelaStudio shows a hint in a message box.

Replace Data Type

[MENU-R475] Opens the "Replace Data Type" Dialog.

Replace Similar Data Types (CDS-68992 v11)

[MENU-R500] Opens the "Replace Similar Data Types" Dialog.

Check Document Consistency

[MENU-R950] Runs the Consistency Check.

Move

Up

[MENU-R480] Moves the selected object up in the document (if allowed in the specific tree or list).

Down

[MENU-R485] Moves the selected object down in the document (if allowed in the specific tree or list).

Compare Element

Select as Left Side

[MENU-R490] Selects the selected object as left side for the "Compare" operation, to be completed by "Compare to Left Side" (next chapter).

Compare to Left Side

[MENU-R495] Compares the selected object to the object specified via "Select as Left Side" (see previous chapter).

See Compare View.

Find

Find

[MENU-R470] Opens the Search Dialog.

Next

[MENU-R472] Repeats the last search (also available via key F3).
