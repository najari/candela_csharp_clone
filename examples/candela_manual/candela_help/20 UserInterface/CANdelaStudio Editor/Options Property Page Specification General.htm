File | Options | Specification | General

Ribbon Tab File | Options, Page "Specification" - "General"

For the font used in state diagrams, report uses the font specified in the Page "General".

Insert page break at heading level

Enter the heading level after which page breaks shall be inserted in the specification. The default is 1, i.e. each top-level heading will start on a new page.

Manufacturer specific export

Select this option if you would like to use manufacturer specific specification features.

A manufacturer specific export is available for FIAT.

Automatically update fields in RTF Document

[OPT-R410] If you check this option, CANdelaStudio automatically runs Microsoft Word after the export, see [RP-R410] for limitations and workaround.

Write audiences

[OPT-R420] Check this option if you would like to output the audience (target groups) to which a diagnostic instance or job container belongs, in the chapter of the diagnostic instance or job container.

Write images in binary format

[OPT-R430] If you check this option, report exports images directly into the RTF file.

Otherwise, report creates a subdirectory named like the RTF file and writes the images into it.

Write even objects not used in document

[OPT-R440] Check this option if you would like to output all objects.

Otherwise, report skips for example unused data types or unused protocol services.

Write Qualifier

  • never: the specification will contain only the names of the CANdela objects, not the qualifiers;
  • if different from name: the specification will contain only qualifiers that differ from how the qualifier would be computed from the name. A qualifier may differ if it has been modified manually, or if it has been generated from the name in a different language.
  • always: the specification will contain all qualifiers
