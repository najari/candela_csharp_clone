File | Options | Job File

Ribbon Tab File | Options, Page "Edit"

This page lets you specify defaults for new Jobs created in CANdelaStudio.

Entry point

Specify the name of a function contained in the job file.

Version

Specify the version number of the job file.

File

Specify the name and path of the file that is to be used by default when a new job is created.
