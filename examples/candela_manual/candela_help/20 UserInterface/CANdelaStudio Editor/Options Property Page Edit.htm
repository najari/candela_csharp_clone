Ribbon Tab File | Options, Page "Edit"

Display negative responses when opening a diagnostic instance

If you select this option, CANdelaStudio shows the pages for the negative response codes when you enter a diagnostic instance:

Negative Responses Page In Diagnostic Instance

Check identifier for uniqueness

This option is no more available (CDS-68583 9.0). CANdelaStudio always checks identifiers for uniqueness but allows to define exceptions, see Check Identifier Uniqueness.

Variant Wizard allows to copy all diagnostic instances

Check this option if you want to enable copying for all instances in Variant Wizard.

If you do not check this option, in Variant Wizard, you can only create diagnostic instances as references, or skip them, see [VW-R040-CopyInsens].

Prompt for documenting changes on save

Select this option if you want a confirmation dialog on save which allows to open the revision dialog (otherwise available in menu File | Revision History).

Formatted Descriptions - Tab size

Specify the number of blanks that a TAB character represents. CANdelaStudio applies this setting when it exports a formatted description into a format that does not support rich text.

  • minimum: 2 characters
  • maximum: 256 characters

Byte order for new data types

When you create a new data type, CANdelaStudio sets the byte order of the new data type to the default selected here:

  • HighLow (Motorola)
  • LowHigh (Intel)

Dictionary (.tmx)

Enter the file path of a TMX file to be used as dictionary. Click the button ... to use the File dialog.
