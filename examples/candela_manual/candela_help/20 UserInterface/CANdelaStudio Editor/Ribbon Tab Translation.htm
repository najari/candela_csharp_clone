Ribbon Tab "Translation"

Ribbon Tab Translation

Translation Memory

CANdelaStudio contains an internal Translation Memory: a list of translated terms, like

English French German Japanese
Read Lecture Lesen 読込み
Write Ecriture Schreiben 書込み

You can store the Translation Memory to a *.tmx file and use it to automatically translate other CANdela documents.

Open TMX

[MENU-R1510] Loads a *.tmx file into the internal Translation Memory.

Save TMX

[MENU-R1520] Saves the internal Translation Memory to a *.tmx file.

Clear

[MENU-R1530] Clears the internal Translation Memory.

Edit

[MENU-R1540] Opens a dialog for editing the terms in the internal Translation Memory directly.

Learn Translations

[MENU-R1550] Stores translated terms of the CANdela document into the internal Translation Memory.

Translate Document

[MENU-R1560] Uses the translated terms of the internal Translation Memory to automatically translate not-yet-translated terms of the document.

If there are multiple choices for one term, CANdelaStudio shows a dialog.

Terms

Translation Dialog

[MENU-R1570] Translates one term.

Accept Reference as Translation

[MENU-R1580] copies the reference term to the target language and sets it up-to-date.

Use-case: in target language Japanese, you want to use the English term form the source language.

View

Show Translated Terms

[MENU-R1585] toggles display of translated terms. Non-translated terms are displayed always.

Find

Find

[MENU-R1590] Opens the Search Dialog for the translation list.

Note: in the ribbon, there is no Find Next, but if you open the dialog again, you can press "Find Next" within the dialog to continue search from the current selection.
