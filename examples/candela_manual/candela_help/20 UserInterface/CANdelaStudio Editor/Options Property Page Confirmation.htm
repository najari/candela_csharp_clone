File | Options | Confirmation

Ribbon Tab File | Options, Page "Edit"

Modify Referenced Diagnostic Instance

Here you can specify whether CANdelaStudio displays a confirmation before you change a reference diagnostic instance. This enables you to avoid inadvertent changes in multiple variants that reference the diagnostic instance.

Cf. the specific setting [RQ-R096] for update of diagnostic objects from requirements.

Insert Diagnostic Instance in Base Variant

There are different policies of using the Base Variant.

If you use it as a base for all other variants, you may want to insert new diagnostic instances from the Base Variant also in other variants.

This option lets you show a confirmation after you inserted a diagnostic instance into the Base Variant. In the dialog, you can select which other variants shall also contain the new diagnostic instance.

Delete Referenced Diagnostic Instance From Base Variant

Like the previous option, this option lets you show a confirmation after you deleted a diagnostic instance from the Base Variant.

Notify on Opening a CANdela document

If you select these options, CANdelaStudio shows a warning when you open a document version saved in an older or newer document format.

Typically each new CANdelaStudio version saves documents in a different format, in order to support new features.

Notify on Editing a CANdela document

If you select this option, CANdelaStudio shows a warning when you edit the identification patterns of a vehicle system group.

Background: adding an identification pattern to a vehicle system group lets it work as an Optional Subsystem.
