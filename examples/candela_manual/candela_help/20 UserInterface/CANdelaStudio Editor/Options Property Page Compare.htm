File | Options | Compare

Ribbon Tab File | Options, Page "Compare"

Colors

Specify the colors for missing objects, differences and selected objects in the Compare dialog.

Display - Differences of ObjectID

Select this option if you would like to compare ObjectIDs (OID), too.

As a default, the filter to show ObjectID differences in Compare view will be sensitive and on.

XHTML Export

Export icons

Select this option if the XHTML file should contain the same icons as the Compare view.

Start registered Windows application after export

If you have checked this option, after the export of the XHTML difference file, CANdelaStudio automatically starts the browser currently registered in the system (e.g. Internet Explorer).

Text Export

Truncate text at character position

The text export shows the compared objects side by side, like in a table. Enter the first character position to omit in each line, i.e. for both columns together.

  • minimum: 0
  • maximum: 999 characters
  • default: 80 characters

Example: for the (funny) value 10, the lines will be at most 9 characters long and look line

DID |DID 
 Qua| Qua
 Nam| Nam

Always use UTF-8 coding

Check this option if the characters in the exported text file shall be encoded in UTF-8. You can open these files with any text editor. But if the text editor does not support UTF-8 encoding, some characters may not be displayed correctly.

With the option unchecked, the exported text is encoded as ISO-8859-1 which will only represent characters typically used in English and Western European languages.

Start registered Windows application after export

If you have checked this option, after the export of the text difference file, CANdelaStudio automatically starts the text editor currently registered in the system (e.g. Notepad).

XML Export

Start registered Windows application after export

If you have checked this option, after the export of the XML difference file, CANdelaStudio automatically starts the XML editor currently registered in the system (e.g. Notepad).
