Ribbon Tab File | Options, Page "Specification" - "Chapters"

Chapter "Content"

Write Description of Data Objects

Specifies how to write data object descriptions [RP-R260].

Compact representation

Check this option if you want to output the specification in compact form.

Fault Memory Details

Check this option if the specification shall contain...

  • for each DTC
  • a table with the properties of the DTC
    • called DTC Columns
  • The option does not take effect on Snapshot Data and Extended Data.

Include significant data type properties in data object table

Check this option if you want to output additional properties of the data types besides name and description.

Chapter "State Dependency of Service Execution"

Diagrams

Check this option if you want to output the dependencies as a state graph in the specification (which requires the installation of GraphViz [STUI-R180]).

Tables

Check this option if you want to output the dependencies as a table in the specification.

Additional Chapters

Chapters "Authors" and "Revision History"

[OPT-R500] Check this option to include the information entered in the Revision History Dialog, which you may open via menu File | Revision History [MENU-R320].

Chapter "Libraries"

[OPT-R520.0 Report Libraries] Check this option if the specification shall include the libraries of the document, see [LIBUI-R500].

  • [OPT-R520-Compact] This option applies to Compact representation, too.

As a default, the option is off.

Chapter "Vehicle System Groups"

[OPT-R530] Check this option if the specification shall include an overview of all vehicle system groups.

Chapter "Attributes"

[OPT-R540.0 Report Attributes] Check this option if the specification shall include an overview of all attributes and their values.

Chapter "Index"

[OPT-R550] Check this option if the specification shall include an index chapter with links to all objects.
