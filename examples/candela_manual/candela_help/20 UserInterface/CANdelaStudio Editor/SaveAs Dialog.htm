SaveAs Dialog

CANdelaStudio SaveAs Dialog

Save read-only

This checkbox controls whether the result file is set write-protected after saving.

Execute action “Save current version done”

This checkbox controls whether after saving CANdelaStudio shall execute the action named “Save current version done”.

If you did not specifiy a command for this built-in action, the checkbox is shown read-only.
