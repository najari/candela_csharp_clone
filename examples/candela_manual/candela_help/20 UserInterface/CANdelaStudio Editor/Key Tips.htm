Key Tips

Introduction

For keyboard navigation, the CANdelaStudio Ribbon provides Key Tips:

Key tips for tabs

  • press and release the left Alt key
    • CANdelaStudio shows key tips for each ribbon tab,
    • e.g. "D" for ribbon tab Document
  • press one of the shown keys, e.g. "D"
    • CANdelaStudio shows the selected ribbon tab
    • ... and a key tip for each menu button in the ribbon tab,
    • e.g. "R" for Revision History
  • press one of the shown keys,
    • e.g. "R", to perform the respective operation.

Hiding Key Tips

Press the Alt key again to hide the key tips.

Submenus

For buttons that have a submenu, like ribbon tab Home - Replace, ...

  • press and release the left Alt key
    • CANdelaStudio shows key tips for each ribbon tab,

    • e.g. "H" for ribbon tab Home

      Key tips for tabs

  • press "H" for "Home"

    • CANdelaStudio shows key tips for ribbon tab "Home"

      Key tips for "Home" with submenu "Replace"

  • press the button for the submenu,
    • like "A" for "Replace"

    • CANdelaStudio expands the submenu and shows key tips for each menu item

      Key tips for submenu "Replace" menu items

  • finally press the key for the menu item,
    • like "C" for "Replace Reference with Copy".
