Vector Support Assistant (CDS-42291 v11)

[VSA-R010] CANdelaStudio integrates the Vector Support Assistant to assist you in resolving a problem with CANdelaStudio.

It is available via Windows Start menu and in CANdelaStudio via Ribbon Tab File [MENU-R1256].

Vector Support Assistant

Where to Get Info

  • For details about the Support Assistant dialog:
    • press the F1 key or the "Help" button in the dialog.
  • For the use in CANdelaStudio: go on reading this chapter.

Start

  • Manually: You can start the Support Assistant via Ribbon Tab File [MENU-R1256].
  • [VSA-R100] Automatically: the Support Assistant starts if CANdelaStudio crashes, or if an internal assertion has been violated.
    • In this case, the Support Assistant attaches the crash dump file.

Language

  • [VSA-R120] The Support Assistant starts in the same language as CANdelaStudio.

Attachments

[VSA-R130] The Support Assistant attaches...

  • the log files (.log and .bak)
  • the INI file
  • some internal files used by the Support Assistant

Button "Send Report"

The button does not send the report at once but opens an email, so that you can control the contents.

Shipping

CANdelaStudio ships the Vector Support Assistant as a Bundled Product [IBP-R060].

Installation Folder

See [IFLD-R060].
