Used Third Party Software

[MENU-R1240 Used Third Party Software] Opens info about Third Party Software used in the CANdelaStudio implementation.

The list is in the CANdelaStudio installation folder.

Release Notes

[MENU-R1280] Opens the online help with the Release Notes.

The file is in the CANdelaStudio installation folder.

Readme

[MENU-R1285] Opens the readme file shipped with CANdelaStudio in your internet browser.

It is also available in the Windows start menu [ISTM-R030-Readme].

The file is in the CANdelaStudio installation folder.

Vector Knowledge Base

[MENU-R1255] Opens the Vector Knowledge Base in your internet browser.

CANdelaStudio Videos

[MENU-R1265] Opens the internet browser to show a list of CANdelaStudio videos on YouTube.

Give Feedback

[MENU-R1250] Opens the User Feedback dialog.

Look for Service Packs

[MENU-R1230] Opens the Vector Download Center in your internet browser, with category "Service Pack" pre-selected.

In the Download Center, select "CANdelaStudio" under "Products and Topics" and hit "Show results". Then you can download and install a CANdelaStudio Service Pack.

Product Activation

[MENU-R655] Starts the Vector License Client to activate a new Vector License.

For activating an the old license, please start the Vector License Manager from the Windows start menu.

Background: CANdelaStudio supports two licensing mechanisms:

  • the old mechanism using the Vector License Manager;
  • the new Vector License using the Vector License Client, see [LIC-R600].

Special note for Pool Licenses:

  • If the pool license period is about to expire, CANdelaStudio automatically shows the Pool License Dialog at start-up.
  • Even before the expiration, you can start the Pool License Dialog directly:
  • [MENU-R650-Pool] If Pool Licensing is active, ribbon tab Help - Product Activation shows the Pool Licensing Dialog (CDS-34797 8.1 SP2).
  • [MENU-R650-VectorLicense] The menu item starts the Vector License Manager (old mechanism) even if CANdelaStudio uses a Vector license (CDS-40816 8.5 SP3).
