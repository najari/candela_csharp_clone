Diogenes Qualifier Overview (CDS-2920 5.0 SP1)

The Diogenes Qualifier Overview dialog (menu View, after “Qualifier overview”) is only available for documents and templates of the manufacturer Daimler. It offers an overview of all Diogenes Qualifiers in the document.

The dialog offers you the option of copying selected lines of the table to the Windows clipboard and paste them in other programs (e.g. Microsoft Excel).

Variant Selection

R002.0: New dialog “Variant Selection” for selecting the variants which are used for the view (dialog shall look and behave like the dialog used in the Diogenes export menu for variant selection. Note: the selection of the base variant is not mandatory)

Overview

R003.0: New dialog “Diogenes Qualifier Overview”. The table is the same as in Qualifier overview but with two additional columns:

  • one at the left hand side with the heading “Diogenes Qualifier”,
  • and another column “Variant” before the Object type column.

his dialog has just a “Close” button. No other control elements are available.

R011.0: The Diogenes qualifiers are shown as they are exported in the Diogenes file.

Example: for

<CLASSREF
LINKEND='...'>CDS-5291_NoClassrefForGlobalDiagServices_small.Diag_0003.SES_Normal_Default_Session</CLASSREF>

the following string is shown:

CDS-5291_NoClassrefForGlobalDiagServices_small.Diag_0003.SES_Normal_Default_Session

R012.0: If no CANdela qualifier is available for the Diogenes qualifier (e.g. for DIAG-SERVICEs exported for DTCs), just the Diogenes qualifier is listed with no CANdela qualifier or path.
