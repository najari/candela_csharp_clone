Recreate Qualifier

This dialog is used by the Qualifier Overview dialog.

Recreate Qualifier Dialog

Max. Length

Edit field (spinner control) whichholds the maximum length of the qualifier. Valid lengths are between 8 and the maximum qualifier length. Default length is always the maximum length defined by the template.

Note: it must be impossible to increase the length beyond the maximum length defined by the template!

On Recreation of Qualifiers...

[RCRQ-R200] Selects the algorithm for re-computing qualifiers, see [QUAL-R200].

  • [RCRQ-R200-VW5CharRule] If the document specifies Qualifier Generation Option "VW 5 Character Rule" [QUAL-R200-VW5CharRule], then all radio buttons are insensitive.
    • Motivation: ensure the setting is used consistently in the whole document.

Language

  • CANdelaStudio re-computes qualifiers from the names, which may occur in multiple languages.
  • In Expert View, the combobox “Language” allows selection from one of the document languages.
  • Re-computation will use the names in the selected language.

Incomplete Translation:

  • To be used for a qualifier, the respective name must be translated.
  • A language in which not all translatable strings have been translated is shown with a hint like in the File|Open dialog: “(translation incomplete)”.
  • On [OK], if the document is not completely translated in the chosen language, CANdelaStudio shows a warning message:

Prompt for Languages not Completely Translated

Choices:

  • “Skip not translated names”:
    • the Recreate Qualifier dialog will close immediately after clicking [OK] of the warning dialog.
    • Re-computation will skip all names which are not translated.
    • This results in not all qualifiers being re-computed, but saves the document from being potentially inconsistent.
  • “Choose another language”:
    • the Recreate Qualifier dialog will stay open after clicking [OK] of the warning dialog.
    • You may then choose another (translated) language.

Default: “Choose another language”.

Options

Options for...

  • re-computing a selection of qualifier,
  • all qualifier shown in the overview,
  • all qualifier of the document.

The default is

  • either “Re-compute only selected qualifier”, if there is at least one row selected, or
  • “Re-compute all qualifier shown in overview”, if nothing is selected (in this case, the first option must be insensitive).

OK

Re-computation of the qualifier starts as soon as you click button [OK] to close the options dialog.

After re-computation, the qualifier overview list updated.
