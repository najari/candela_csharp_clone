See names in CANdela.

Optionally provides access to a dictionary, see [DICT-R020-a1].

Qualifier

When you modify the name, CANdelaStudio creates and updates the qualifier automatically from the name. You can at any time modify the qualifier directly. If the qualifier does not have the value created from the name, CANdelaStudio no more updates it automatically when you modify the name.

Images and Attachments

CANdelaStudio...

  • ... provides the possibility to include images and attachments;
  • ... on double-click, starts the external application registered with Windows, so you can edit the attachment (similar to the handling of job files);
  • ... represents an attachment by a small icon, with the file name of the attachment at the bottom of the icon
  • ... displays an image file as an image within the description field, and allows to scale it.

To apply the formatting,

  • select the text to format,
  • then click the respective toolbar button.

For a number list or a bullet list , ...

  • click the button to start a list with the current paragraph
  • press ENTER to start a new paragraph. CANdelaStudio automatically inserts a number or bullet symbol in front of every new line.
  • To end the list, press ENTER twice.
