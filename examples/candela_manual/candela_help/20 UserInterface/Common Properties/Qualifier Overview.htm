Qualifier Overview

Qualifier Overview Dialog

The Qualifier Overview dialog (menu "View") gives you an overview of all qualifiers of the object on which the dialog was opened, including all contained objects.

You can modify individual qualifiers, or recompute the qualifiers from the respective object names - e.g. in order to shorten the qualifiers to fit the restrictions of a test system.

Modifying operations respect of the Authorization of the objects - in Standard View, you cannot modify the qualifier of an object if the object is "not modifiable". These are e.g. protocol services, diagnostic classes, diagnostic class templates and default attributes.

Context

When opened on "ECU Information" (the root of the document tree), the dialog shows all qualifiers of the document ("Whole document").

Otherwise, you can switch between

  • "Whole document" and
  • the "Current namespace", i.e. all qualifiers of the object on which you opened the dialog and its contained objects.

List

Shows all qualifiers of the specified namespace or the whole document (including all non-modifiable qualifiers), depending on the selection made in the "Context" combobox.

The list can be sorted by any of the three columns. Furthermore, it allows multiple selection of rows. This gives you the ability to exclude qualifier from being re-computed, e.g. if they have been modified otherwise.

Qualifier

The qualifier of the object. You can edit this column if the qualifier may be edited.

Name

The name of the object. You cannot edit this column.

Object Type

The type of the object, i.e. diagnostic instance, service etc. You cannot edit this column.

Fixed

This column is shown only if Fixed Qualifiers have been setup for the document.

  • yes: qualifier is fixed
  • no: qualifier is not fixed
  • "--": qualifier cannot be modified, anyway

Path

The path to the object with the given qualifier. You cannot edit this column. The path also indicates the namespace of the object.

Hide qualifier generated from names

Allows to hide all qualifier in the list that have been generated from the names of the corresponding objects. This check box is unchecked by default.

Show qualifiers of subordinate objects

If the dialog is opened on an object that has a qualifier, the checkbox is enabled. It allows to recursively show the qualifiers of the object and its contained objects.
