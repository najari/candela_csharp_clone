Object References Dialog

Reference Dialog using the Example of Diagnostic Instance

The dialog shows in which variants the selected object is referenced (= exists).

When you click the variant (shown as a hyperlink), CANdelaStudio navigates to the selected diagnostic instance in that variant and keeps the References dialog open.
