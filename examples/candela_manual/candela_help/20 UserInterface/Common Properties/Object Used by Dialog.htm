Object Used by Dialog

Reference Dialog using the Example of Data Type

The References ("Used by") dialog shows the object that reference (use) the current object.

Each referencing object shall be displayed with its path shown as a hyperlink.

A click on the hyperlink (with left mouse button) shall navigate to the object.

The dialog shall be available in main menu View | References and in the context menus of the referenced objects.
