Edit Command Line

Dialog "Edit Command Line"

In the Edit Command Line dialog you specify the commands (applications, file name extension .exe) to be run when an action is executed.

Edit Area

Enter the commands to be run.

To put a command on a separate line, hold the Ctrl key and press ENTER.

Variables

First select a variable from the list to the left, then press either "Insert (required)" or "Insert (optional)".

You can also directly type a variable into the command line, using the variable name and the delimiters.

Insert (required)

The button inserts the variable into the command line, marked as "required".

Insert (optional)

The button inserts the variable into the command line, marked as "optional". CANdelaStudio executes the action even if the variable has not been set.

Browse

The "Browse" button lets you select an application and will insert the path to the file selected.

If the path contains blanks, you must surround it by double-quotes to avoid errors.

Test

The "Test" button executes the action at once, so you can test whether application path and parameters are correct.
