"Edit Actions" Dialog

For details, see the Actions Feature.

Edit Actions

Actions

shows the list of actions. Each action is either

  • internal or
  • user-defined

Name

The name of the action, will be shown in the ribbon tab Tools [MENU-R975].

Qualifier

The qualifier of the action, used by CANdelaStudio internally.

Commands

specifies the commands (applications) to be executed when CANdelaStudio runs the action.

Each command must be place on a separate line. You can add a new line by pressing Ctrl-Enter.

For readability, you can enter empty lines.

Start in

optionally specifies the working directory in which CANdelaStudio executes the commands.

Document must be saved before execution

If checked, CANdelaStudio refuses to run the action in case the document has been modified but not saved.

Symbol

lets you select an Icon (.ico) to be displayed to the left of the action in the ribbon tab Tools [MENU-R975].

Edit

shows the Edit Command Line dialog which provides convenient insertion of CANdelaStudio variables.

Browse...

lets you select a command (application) using the File dialog.

Test

runs the action.
