Revision History Dialog - Property Page "Edit Author"

Revision History Property Page "Edit Author"

The Last Name is required.

Responsible for this ECU

The author property responsible for this ECU is visualized by a hat (due to the German phrase "den Hut aufhaben" = "be in charge", "have the say-so").

Default Values

CANdelaStudio...

  • remembers (in the Windows Registry) the values you enter in the dialog,
  • and uses them as a default on opening the dialog, if the author list...
    • is empty, or
    • does not contain an author with the remembered first and last name.
