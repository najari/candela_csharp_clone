Revision History Dialog

Introduction

The Revision History dialog lets you

  • edit the authors list
  • edit the revision list
  • update the modification date of the last revision to the current date

You can also edit the last revision for the document or variant from the Latest revision window below the working area.

Overview

[REVUI-R010] The dialogs shows two lists (see the following chapters):

  • Authors
  • History

Authors (Document)

Revision History Dialog - Authors Page

[REVUI-R100] The Authors page shows a list of all authors of the document.

The "Shortcut" column also visualizes whether the author is responsible for this ECU.

History

Revision History Dialog - History Page

See also the revision property dialog.

[REVUI-R150] The History page shows a list of all revision entries.

A modification description longer than 500 characters is shown in the list with "..." added (CDS-41249 8.5 SP2).

Status

The revision history dialog maps the following numeric status values to hard-coded strings:

Numeric Value English String German String
0 draft in Bearbeitung
1 completed fertig gestellt
2 tested geprüft
3 release freigegeben

If a revision entry has a numeric value not listed here, the dialog shows the numeric value directly (CDS-26520).

Properties

Opens the revision property dialog.

Delete All (Standard View)

[REVUI-R200-DeleteAll] In Standard View, button "Delete All"...

  • allows you to delete all revision entries together [REV-R200-DeleteAll], ...
  • but not to delete individual entries
    • Motivation: don't fake history.

Delete (Expert View)

[REVUI-R200-Delete] In Expert View, button "Delete"...

  • allows you even to delete individual entries [REV-R200-Delete]
    • Motivation: you're an expert.

New...

If...

  • there are no authors in the authors list,
  • or if all authors are marked as "obsolete",

... you must first...

  • create a new author,
  • or at least identify one author as not obsolete.

Otherwise, you cannot add a new revision to the Revision History.
