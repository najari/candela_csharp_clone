Revision History Dialog - Property Page "Edit Revision"

Revision History Property Page "Edit Revision"

Version Format

The revision dialog enforces the right revision version format:

  • if the version format is empty, the dialog allows any input
  • if the version format is not a correct regular expression, the dialog writes a message to the output window and treats it as empty (but does not replace the wrong format string)
  • When creating a document from a template, CANdelaStudio does not allow an instantiation of the document if the template contains an incorrect version format (empty version format is allowed).
  • if the version format is not empty, the dialog allows only input that matches the version format
  • the dialog visualizes the version format: a tooltip shows the human readable version format description
  • when the user creates a new revision, the dialog suggests a version by "auto-incrementing" the latest existing revision version (as in 4.0), but additionally checks this new Version against the version format - if it does not match, it leaves the edit-field initially empty.
  • when the version format has changed, there may be entries with incorrect revision versions which shall be corrected. When editing an existing entry, usually the old invalid entry is copied to the text input control. The control does not allow incorrect letters, therefore it must be set empty in this situation.
