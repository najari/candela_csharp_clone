Selector Data Object for Multiplexer

Dialog "Selector Data Object for Multiplexer"

If a data object refers to a Multiplexer (Mux) data type, it needs a selector data object.

The value of the selector data object selects the Mux alternatives ("cases"). It must be transported on the line before the data object that refers the Mux data type.

In the dialog "Selector Data Object for Multiplexer", you can select...

  • an existing data object (if its referenced data type matches the selector data type specified at the Mux), or...
  • a new data object which will be placed before the data object that refers the Mux.
