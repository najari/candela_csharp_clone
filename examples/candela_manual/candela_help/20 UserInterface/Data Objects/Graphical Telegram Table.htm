Graphical Telegram Table

[DOUIG-R010] CANdelaStudio visualizes the positions of data objects in a graphical telegram view.

Enabling

[DOUIG-R020] You can toggle the view on/off next to the textual telegram table (CDS-16944, CDS-40680 9.0)...

  • via a button in the top toolbar (DIDs), or
  • via a button at the bottom of the textual telegram table.

Display

  • [DOUIG-R110] Complex data types and referenced DIDs are flattened
  • [DOUIG-R050] The graphical view shows the real data objects.
    • [DOUIG-R050-Mux] For multiplexer: shows the longest alternative
    • [DOUIG-R050-FixedCountIter] For a Fixed Count Iteration: shows all repetitions (CDS-33703 v11).
    • [DOUIG-R050-Iter] For other iterations: shows one repetition.

String Termination

[DOUIG-R130] Graphical Telegram Table considers the String Termination [DTST-R100] of the data types referenced by the data objects in the telegram.

  • [DOUIG-R130-variable] For data types of "Field variable" length, the the graphical telegram table shows the maximum number of elements.
  • [DOUIG-R130-leading] For data types with string termination "leading size bytes", the graphical telegram table includes the leading size bytes.
  • [DOUIG-R130-zeroterm] For data types with string termination "zero terminated (no padding)" or "zero terminated (with padding)", the graphical telegram table includes the zero termination (1 byte for encoding ASCII, 2 bytes for encoding UNICODE)..
  • [DOUIG-R130-maxlen] For data types with string termination "zero terminated (no padding) maxlen EOS" or "zero terminated (with padding) maxlen EOS", the graphical telegram table does not include the zero termination.
    • Motivation: if maxlen or end of service reached, the zero termination may be omitted on the line.

Selection Coupling

[DOUIG-R120] Selection coupling:

  • Select a data object in the textual telegram table - CANdelaStudio selects the bytes/bits in the graphical view
  • Select a data object in the graphical telegram table - if that data object itself is contained in the textual table, CANdelaStudio selects the object in the textual table

Byte Oder

[DOUIG-R200] Graphical view shows the objects in the order of bytes on the line,

  • [DOUIG-R200-LsbFirst] therefore it does not reflect the document option Bit Ordering [DOC-R500-LsbFirst] (CDS-69433 9.1) which is about a display convention of bits.

Leading Size Bytes (CDS-70687 v11)

[DOUIG-R220] Graphical telegram view includes leading size bytes and zero termination [DTST-R100].

Shortening (CDS-70858 9.1 SP1 P3, CDS-70832 v11)

[DOUIG-R210] Graphical telegram view shortens...

  • data objects and reserved objects
  • longer than 24 bytes
  • on top-level (not in bitfield),
  • showing the first 23 bytes, then the last byte,
    • with "..." behind the number of the 23th byte,
    • and "..." before the number of the last byte.

Graphical Telegram View Shortened

Byte

Visualizes the byte position and represents compound objects (DIDs, complex data types) by lines.

Bit7 .. Bit 0

shows the bits covered by the data objects.
