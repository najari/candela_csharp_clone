Data Object Property Page Data

Data Object Property Page "Data"

Name

Shows the name of the data object.

Data Type

[DOUI-R910] Lets you select the data type to specify the size and other properties.

For a data object within a bit field, only simple data types are allowed [BF-R100-Simple].

Semantics

Selects the data object semantics from a list.

Default Value / Const Value

Specifies the optional default value or constant value of the data object.

If "No default / const value" is selected, the edit fields are read-only. If you have previously edited one of the values, that value is still shown in the disabled edit field, but not stored in the document.

CANdelaStudio enables the respective edit field if you click the "Default value" or "Const value" radio button.
