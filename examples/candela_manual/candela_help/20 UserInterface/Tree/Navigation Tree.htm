Maturity (CDS-4014 4.0 SP2)

Diagnostic Instance Shown with Maturity

[TREE-R200] If...

  • configured in the data model [MAT-D100],
  • and enabled for display in Ribbon Tab File | Options | Display,

CANdelaStudio displays the Maturity of diagnostic instances and job containers in the tree:

  • for a numeric attribute, CANdelaStudio shows a percentage, like [44%]
  • for an enumeration attribute [ATTR-R020-enum], CANdelaStudio shows the symbol, like [in progress]

You can edit the maturity value in the Attributes Property Page of an object.

Segment Number (CDS-6803 5.0 SP1)

[TREE-R210 Segment Number in Tree] If...

  • the template contains the "Segment_Number" attribute,
  • then CANdelaStudio shows the value of that attribute
    • for each diagnostic instance or job container in the tree,
    • behind the name of the object, like [SEGNUM=74],
    • in decimal notation.
    • Value 0 means “no Segment Number”.

For display in the tree, CANdelaStudio does not check the attribute category (CDS-69251 9.0 SP1; before, it checked for the category qualifier "DIOGENES").

See [SEGNUM-R100].
