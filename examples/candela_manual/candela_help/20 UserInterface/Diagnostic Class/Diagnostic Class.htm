Diagnostic Class

Diagnostic Instances

See the Diagnostic Instances List.

Properties

You can edit the description and attribute values of the diagnostic class in the properties dialog of the diagnostic class, available in the context menu in the tree (right mouse on the diagnostic class tree node).

Operations

New Diagnostic Instances from Repository

[DCLUI-R410 Select from Repository] The context menu item opens the Select from Repository dialog to import DIDs from a repository.

New Job Container

[DCLUI-R420] Creates a new Job Container, see Jobs.

New Security Level

[DCLUI-R430] In a diagnostic class with class type [DCLT-R200] "Security", starts the Security Wizard to create a new security diagnostic instance.

New Session

[DCLUI-R440] In a diagnostic class with class type [DCLT-R200] "Session", starts the Session Wizard to create a new session diagnostic instance.

Activate All

[DCLUI-R450] Sets all diagnostic instances and job containers contained in the diagnostic class to "activated" [DI-R150].

Deactivate All

[DCLUI-R455] Sets all diagnostic instances and job containers contained in the diagnostic class to "de-activated" [DI-R150].

Cut

[DCLUI-R460] Copies the diagnostic class to the clipboard internal to CANdelaStudio, marks it for deletion when inserted at another location.

The diagnostic class remains visible, but the icon gets grayed out.

Copy

[DCLUI-R465] Copies the diagnostic class to the clipboard internal to CANdelaStudio.

Paste

[DCLUI-R470] Pastes an object from the clipboard internal to CANdelaStudio.

Delete

[DCLUI-R475] Deletes the diagnostic class.

Paste as Reference

[DCLUI-R480] Pastes an object as a reference, from the clipboard internal to CANdelaStudio.

Sort (CDS-1500, CDS-3174 4.0 SP2)

[DCLUI-R490] Sorts the contained diagnostic instances and job containers persistently in the document.

Note: this is different from the temporary sorting in the list, by clicking a list header.

by Name

[DCLUI-R492] Sorts (see above) by the object name.

by Qualifier

[DCLUI-R494] Sorts (see above) by the object qualifier.

by Identifier

[DCLUI-R496] Sorts (see above)...

  • diagnostic instances first, sorted by the Identifier [DI-R100];
  • job containers second, sorted by name (CDS-17004 7.1).

by Maturity

[DCLUI-R498] This menu item is available if object Maturity [MAT-D100] has been configured for the document.

It sorts (see above) by the maturity value:

  • for a numeric attribute, numerically ascending
  • for an enumeration attribute [ATTR-R020-enum], by ascending symbol string

Export Open Diagnostic Data Exchange

[DCLUI-R500] Exports the selected object to ODX [ODXE-R120].

Qualifier Overview

[DCLUI-R510] Opens Qualifier Overview on the selected object.

Attribute Overview

[DCLUI-R520] Opens Attribute Overview on the selected object.

Target Group Overview

[DCLUI-R530] Opens Target Group Overview on the selected object.

Select as Left Side for Compare

[DCLUI-R540] Remembers the object as first object for a comparison in Compare View.

Compare to...

[DCLUI-R545]

  • If an object has been selected previously (see previous chapter),
  • uses the now selected object as second object for comparison and
  • opens Compare View

Properties of Data Type for Identifier

[DCLUI-R550] Opens the property dialog for the text table [DCLT-R400] configured in the diagnostic class template.

Properties

[DCLUI-R560] Opens the property dialog for the diagnostic class.
