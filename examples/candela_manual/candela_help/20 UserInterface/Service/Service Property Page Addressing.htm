Service Property Page "Addressing"

Service Property Page "Addressing" (details depend on template)

This page is identical to the variations of the Protocol Service Property Page Addressing, with the following changes:

  • the check-boxes in the top part are read-only (multiple responses, periodic responses, SPRMIB – if shown)
    • ... because the values [SVC-R710] etc. are taken from the Protocol Service;
  • the second static text is: "Settings for this service:"
  • in Standard view, the sensitivity of the controls is additionally restricted by the authorization settings [PS-R840] etc. at the ProtocolService.
  • for UDS, some data model properties that are fixed in UDS are not shown at all (CDS-39671 v11),
    • e.g. "ECU sends a response",
    • see the property descriptions in [PS-R760]ff.

Notes:

  • The text “All services based on…” is also shown in the service property dialog, it is also true here.
  • Combinations that do not make sense for the adressing values are allowed for the addressing authorization:
    • For the addressing values it would not make sense to have e.g.
      • un-checked “ECU supports physical request”,
      • but checked “The test system sets the SPRMIB to...”.
    • For the addressing authorization, i.e. whether the addressing value is modifiable, this combination is ok.
  • In the entry mask of the diagnostic instance, CANdelaStudio shows whether a service supports physical and/or functional addressing: on the icon for the service property dialog.
