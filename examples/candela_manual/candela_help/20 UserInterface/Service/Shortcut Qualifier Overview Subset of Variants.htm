Subset of Variants Dialog

Subset of Variants for Shortcut Qualifier Overview

The menu item "Shortcut Qualifier (ODX Service/Job) Overview" in ribbon tab "Document" leads to a first dialog that lets you select a subset of variants.

Select all

Checks all variants.

Deselect all

Un-checks all variants.

Button "OK" becomes insensitive if no variant is checked.
