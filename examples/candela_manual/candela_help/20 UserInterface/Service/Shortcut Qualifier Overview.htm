Shortcut Qualifier (ODX Service/Job) Overview

Shortcut Qualifier Overview Dialog

The Shortcut Qualifier Overview gives you an overview of all shortcut qualifiers in different variants in the document. The shortcut qualifiers are used as ODX SHORT-NAMEs when exporting to ODX.

The menu item in main menu "View" leads to a first dialog that lets you select a subset of variants.

Shortcut Qualifier (ODX SHORT-NAME)

This column shows the shortcut qualifier of the service or job.

You can edit the shortcut qualifier by pressing F2, or setting focus into the cell, then click again.

You can type a character to navigate to the next service whose shortcut qualifier begins with that character.

Shortcut Name

This column shows the shortcut name of the service or job.

Variants

The variants selected in the first dialog (see above) are shown as columns in the overview dialog.

Each cell contains...

  • "yes" if the shortcut qualifier exists in that variant,
  • "no" otherwise.

Path

If you click on a hyperlink in the "Path" column, CANdelaStudio keeps the dialog open and navigates to the respective object.

Hide services/jobs which are visible in all selected variants

If you check this, you can concentrate on services or jobs that are missing in some variants.

Copy selected table content

You can copy lines selected in the table to the Windows clipboard using the button "Copy selected table content" (or simply use Ctrl-C).
