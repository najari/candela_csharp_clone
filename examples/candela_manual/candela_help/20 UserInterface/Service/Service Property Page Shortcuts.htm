Service Property Page "Shortcuts"

Shortcut Name

Shows the shortcut name of the service. It is handled like a name in CANdela.

Optionally uses a dictionary [DICT-R020-a4].

Shortcut Qualifier

Shows the shortcut qualifier of the service. It is handled like a qualifier in CANdela.
