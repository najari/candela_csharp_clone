Service Property Page "Extended"

Service Property Page Extended

This Service Contains Objects of Defined Length only and may therefore be Combined

The read-only checkbox is based on the Protocol Service property "may be combined".

Semantics

The edit control may be empty.

You can enter any string, or select from a list that contains...

  • predefined values from the ODX Standard and
  • the values used in other services of the document (CDS-10940 6.0)

See the Service Feature [SVC-R200].
