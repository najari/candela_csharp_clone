Redirect Job File References (CDS-9280 6.0)

Dialog "Redirect Job File References"

Use-case: when adding job files to a CANdela document, you may have imported and referenced the wrong file. You cannot delete the job file if it is still referenced by a job or procedure data type.

To correct this, you can open menu Edit | "Job File Manager", select the job file and press button "Redirect". This opens the dialog "Redirect Job File References".

The following functions...

The list shows all functions (in a Job or in a Procedure Datatype) that reference the selected job file.

... are referencing job file:

Shows the file name of the job file selected in the Job File Manager dialog.

Redirect the functions...

The list shows all other job files available in the document.

Button "Redirect"

Replaces each reference to the job file selected in the Job File Manager dialog by a reference the job file selected in the list "Redirect the functions...".
