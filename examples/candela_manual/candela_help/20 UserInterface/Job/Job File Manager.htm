Job File Manager

Job File Manager Dialog

Job File List

The list shows the job files embedded in the CANdela document.

File, Last Change, Size

Properties of the embedded file from the file system: file name (with extension like ".jar"), modification date (in ISO format), size (in bytes).

Used

Shows "yes" if the embedded file is used by a CANdela object in the document.

Button "New"

Embed a file.

Button "Edit"

On the selected file, run the application registered in Windows.

Button "Replace"

Replace the selected file by another one from the file system.

Button "Redirect"

Redirect uses of the selected file by another one - using a dialog.

Button "Delete"

Deletes the file from the CANdela document.

Button "Save As"

Saves the file to the file system.

Button "References"

Shows which CANdela object reference the embedded file.

Properties of the Selected File

Shows the properties dialog for the file.

Runtime System

Specifies the runtime system capable to execute the file.

Version

Specifies the version of the file.

Encoding

Optionally specifies the encoding (encryption method) of the file.

Additional Files

The list shows additional files (e.g. source files) associated with the job file selected in the list above.

Original Path,Last Change, Size

Properties of the embedded file from the file system: file name (with extension like ".jar"), modification date (in ISO format), size (in bytes).

Button "Append"

Inserts a further additional file.

Button "Remove"

Removes the further additional file from the CANdela document.

Button "Replace"

Replaces the further additional file by another one from the file system.

Button "Save As"

Saves the selected additional file from the CANdela document to the file system.
