Copy/Paste of Protocol Service (CDS-9731 6.5)

This function is only available in the Admin edition.

[PSUI-R300] In the list of protocol services, you can copy/paste a protocol service using the ribbon tab "Home" [MENU-R413]/ [MENU-R415] or the context menu.

You can use this feature to copy protocol services from the Vector UDS Template to your specific template (see procedure How to create a New UDS Protocol Service).

Document Inconsistencies after Creation of Protocol Services

  • in the CANdela data model, there are some implicit dependencies between special protocol services (especially for fault memory) and other parts of the template.
  • Therefore after a paste operation, you may need to manually decide and resolve about such other parts of the template.
  • The following subchapters describe typical document inconsistencies after creation of protocol services and how they can be fixed.

Multiplexer Forbidden

Error: Invalid data type 'Memory Address and Size' found.
       Document settings forbid usage of multiplexer data types.

Meaning: A protocol service that uses multiplexer data types has been created but the document template forbids multiplexer data types.

Corrective Action:

  1. Allow the usage of multiplexer data types in the template settings (menu File | Properties | Data Type Authorization).

  2. Or: remove the created protocol service and the referenced multiplexer data types from the template.

Data Type Nesting Forbidden

Error: Illegal nesting detected.
       multiplexer data type 'SnapshotRecord DTC P000002 contains data object 'DID_DATA_0' which references a packet data type.
       The document settings do not allow any form of data type nesting

Meaning: A protocol service that uses nested data types has been created but the document template forbids that level of data type nesting.

Corrective Action:

  1. Allow the neccessary level of data type nesting in the template settings (menu File | Properties | Data Type Authorization).

  2. Or: remove the created protocol service and the referenced data types from the template.

Invalid Data Type for DTC Status

Variant: 'Basis Variante Diagnostic instance: 'Event And Fault Memory Management Content: 'DTCStatusMask': 
Proxy component 'DTCStatusMask shared in shared proxy component 'DTCStatusMask':
Fatal: dtc status bit group 'TestFailed': bad data type 'TestFailed (Availability Mask)' found. Expected data type: 'Test Failed'

Meaning: the DTC Status data type in the template is not compatible with the data type needed for the new Protocol Service (see DTC Status Bits).

Corrective Action:

  1. Drop existing Protocol Services and the incompatible data type.

  2. Or: remove the created protocol service and the referenced data types from the template.

OBD Error Code Table Missing

Fatal error: simple proxy comp with semantics 'obdDtc' detected, but record template of type 'obd fault memory' is missing.

Meaning: A protocol service has been added for ODB fault memory but a OBD fault memory error table is not activated for the template.

Corrective Action:

  1. Activate the OBD2 error table in the document tree node "Error Code Table".

  2. Or: remove the created protocol service.
