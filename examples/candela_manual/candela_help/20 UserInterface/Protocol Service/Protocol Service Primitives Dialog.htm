Protocol Service Primitives Dialog

[PSPUI-R100] You can open the dialog...

  • in the Protocol Services list
  • in a diagnostic instance using the hyperlink right to the service

[PSPUI-R110] The dialog shows the Primitives [PS-R100]

  • Request
  • Positive Response
  • Negative Response

[PSPUI-R120] The property button (right to the description control) provides access to the Protocol Service Property Dialog for futher individual properties of the Protocol Service.

AUTOSAR Fault Memory (CDS-71541 v13)

The dialog for creating a Proxy Component...

  • does not allow to create an sd Proxy Component (shows a message),
  • ... if the Primitive does not contain an sr Proxy Component.
  • This fulfills the consistency condition:
    • [PC-D050-sdsrUse] If a Primitive contains an sd proxy component, it must also contain an sr proxy component.
  • Effect: when leaving the Protocol Service property dialog, either both proxies exist, or none.
  • Dito for an ed Proxy Component without and edr Proxy Component, for [PC-D050-ededrUse].
