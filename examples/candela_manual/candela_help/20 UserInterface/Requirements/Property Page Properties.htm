Property Page "Properties" (Property Values)

The page provides convenient inspection and editing of the requiment selected in the list.

Requirements Property Page "Properties"

It is shown by the button in the "Requirements" tree node.

Rows

[RQUI-R150] The page shows only properties that exist for the selected requirement, depending on...

  • [RQUI-R150-Specific] the implemented definition [RQ-R030-Optional] of the specific property,
  • [RQUI-R150-UserDefined] the "for requirement type" setting [RQ-R040-ForType] of a user defined property.

Name

[RQUI-R140] The "Name" column shows localized property names.
