Property Page "Diagnostic Objects"

See also the Requirements Feature.

CANdelaStudio shows the page "Diagnostic Objects" at the bottom or to the right in the "Requirements" tree node:

Requirements Pool

The tree and list of the "Diagnostic Objects" page shall follow the general rules described for requirements.

Overview Tree

  • The left side is a tree representing the hierarchy of diagnostic objects of the selected variant.
  • The order of the diagnostic objects in the tree shall correspond with the order in the global CANdela tree.
  • Not supported diagnostic objects e.g. (reserved data objects, bit fields) shall be omitted.
  • The Diagnostic Instances shall be shown in a folder of the corresponding diagnostic class.

Requirements and DIDs

[RQUI-R230-DIDs] the user interface shall show a "DIDs" node as first child of the variant root node (CDS-41052 8.5 SP2).

  • For a "DID Definition" diagnostic instance [DI-D110], the user interface shall...
    • [RQUI-R230-DIDNot] ... not show the DID;
    • [RQUI-R230-DIChildren] ... show the data objects from the DID as children of the diagnostic instance (CDC-39298 8.5).
  • For a DID not used [DID-D001-d] by a "DID Definition" diagnostic instance [DI-D110], the user interface shall...
    • [RQUI-R230-DID] ... show the DID under the "DIDs" node;
    • [RQUI-R230-DIDChildren] ... show the data objects from the DID as children of the "DIDs" node.

Detail Tree

  • The right side of the diagnostic object linking is a tree.
  • It shows the contents of the diagnostic object selected in the Overview Tree (left).
  • Columns:
    • diagnostic object (typically the name),
    • the assigned requirement ID,
    • diagnostic object details.
  • If no requirement is assigned, a “-“ is shown for the requirement ID.

Filter

[RQUI-R300] Filter for Text (CDS-26762 9.1)

  • the control at the top right provides a filter for all displayed texts
  • when you reset the filter, CANdelaStudio keeps the selection.

[RQUI-R310] Filter for Link Status

  • The filter can be selected in the combo box above the list view.
  • In the list view, CANdelaStudio shows only objects matching the selected filter.
