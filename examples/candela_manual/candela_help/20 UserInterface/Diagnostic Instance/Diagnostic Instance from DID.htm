Diagnostic Instance Creation from DID (CDS-39296)

[DIUI-R030 Diagnostic Instance Creation from DID]

Context: [DIUI-R020] Diagnostic Instance Creation from DID.

Dialog "New Diagnostic Instance"

  • [DIUI-R030-Dialog] CANdelaStudio shows a selection dialog from the DID list of the variant
    • (like "Add DIDs" in Common Snapshot Data).
  • [DIUI-R030-showAll] "Show all DIDs"
    • The dialog provides a checkbox to select between...
    • [DIUI-R030-all] showing all DIDs of the current variant, and
    • [DIUI-R030-NotYetUsed] showing only DIDs of the current variant which are not yet used [DID-D001] by a diagnostic instance in the variant.
  • [DIUI-R030-Selection] The dialog supports multi-selection.
    • Note: CANdelaStudio creates one diagnostic instance for each selected DID, respectively.
  • [DIUI-R030-ButtonWithoutDID] Button "Create without DID"
    • If the diagnostic class template does not force the use of DIDs via the DID semantics [DID-R050],
    • and the diagnostic class is DID enabled [DCL-D001-a],
    • then the dialog provides a button "Create without DID" at the bottom left side of the dialog (CDS-40460 8.5 SP2).
    • Note: the dialog does not show the button because there is no choice if the diagnostic class
      • ... forces the use of DIDs (the dialog must create a DID),
      • ... is not DID enabled (the dialog shall not create a DID)
  • [DIUI-R030-Create] Checkbox "Create with New Identifier" (CDS-38622 v12)
    • If the checkbox is checked,
      • the DID list is insensitive, the edit control to the right is sensitive
      • this is the case automatically if the DID list is empty (CDS-38622 R080)
    • If the checkbox is un-checked,
      • the DID list is sensitive, the edit control to the right is insensitive
  • [DIUI-R030-NoDID] If the DID list is empty, the dialog initially...
    • checks "Create with New Identifier" and
    • focuses the identifier edit control.
  • [DIUI-R030-Invalid] When you enter an invalid identifier (e.g. an already existing one), the dialog shows a message and stays open.

Future: the dialog may have a button "Go to DID List".

Create without DID

[DIUI-R030-WithoutDID] When the user presses the button "Create without DID" ([DIUI-R030-ButtonWithoutDID] above), CANdelaStudio creates a diagnostic instance without DID Data Reference [DI-R010], and close the dialog.

OK

On OK, CANdelaStudio creates a diagnostic instance [DI-R020] and close the dialog.
