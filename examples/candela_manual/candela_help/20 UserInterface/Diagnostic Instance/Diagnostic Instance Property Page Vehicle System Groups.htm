Diagnostic Instance Property Page "Vehicle System Groups"

You can directly set or unset the association of a diagnostic instance or a job container to a vehicle system group in this dialog.

The list shows all vehicle system groups contained in the document.

Remove All

Unsets all checkboxes to the left of the Vehicle System Groups, so that these will no longer be associated with the diagnostic instance.

Add All

Sets all checkboxes to the left of the Vehicle System Groups, so that these will be associated with the diagnostic instance.
