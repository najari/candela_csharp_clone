Diagnostic Instances

Diagnostic Class with List of Diagnostic Instances

List

The list shows all diagnostic instances and job containers contained in the diagnostic class.

The list lets you select and edit multiple objects. Thus, for example, you can activate or deactivate all selected objects, move selected objects upwards or downwards or replace multiple references with copies.

In addition, you can edit the identifiers of the diagnostic instances, as well as the names: select the desired line and column and press F2, or again click into the colum.

The context menu provides the same commands as the the tree.

Sorting (CDS-7587 5.5, CDS-71276 v13)

[DIUI-R050] You can sort the list by clicking a header.

  • [DIUI-R050-View] This temporarily sorts the list view, not the data in the document.
  • [DIUI-R050-Move] The operations Move Up [MENU-R480] / Move Down [MENU-R485] do not make sense after the temporary sort,
    • therefore they're disabled then (CDS-22721 7.1 SP2).
  • This temporary sorting is different from the permanent sorting [DCLUI-R490].
  • Note: when you create or modify an object in this situation,
    • CANdelaStudio does not re-apply the sorting,
    • it is a feature to add new elements at the end (cf. CDS-38638, open).

[DIUI-D060] To keep Diagnostic Instances sorted, see Procedure How to Automatically Sort Diagnostic Instances.

Filter

The filter allows to restrict the list to objects matching the term entered (compared against the contents of the list), including

  • identifier (CDS-37587 8.5) and
  • services, e.g. ", Write" (CDS-39498 8.5).

You can reset the filter by clicking the button right to the edit control.

Icon

Shows the icon of the object, like in the tree.

Identifier

Shows the identifier of a diagnostic instance in hexadecimal format.

Name

Shows the name of the object.

Services

Shows the names of the services (comma separated) that exist in the diagnostic instance.

Attributes

[DIUI-R400] The list shows diagnostic instance attributes that have the "visible in separate table column" flag [ATTR-R090-DiagInst] set.

Go To...

To conveniently inspect an object shown in the list, use the context menu item, e.g. "Go To 'Braking'".

[DIUI-R110] For a diagnostic instance that transports a DID, there is an additional context menu item e.g. "Go To DID 'Braking'" that navigates to the data of the DID.

  • [DIUI-R110-filter] if CANdelaStudio does not currently show the DID due to a filter, it drops the filter (CDS-39992 9.1).

Replace Reference with Copy

[DIUI-R130] for a diagnostic instance referenced in multiple variants or libraries, the operation replaces the reference with a copy in the current variant/library only.

  • [DIUI-R130-ReqAsRef]
    • For a diagnostic instance that is required as reference [DIOP-R040-ReqAsRef],
    • CANdelaStudio shows the menu item "Replace Reference with Copy" insensitive (CDS-70993 v11).

Replace Copy with Reference in Base Variant

[DIUI-R140] for a diagnostic instance...

  • in an extended variant,
  • not referenced in the base variant,
  • a diagnostic instance with the same diagnostic class and qualifier exists in the base variant,
  • the diagnostic instance is not "Required as Reference",

... CANdelaStudio deletes the copy and instead inserts a reference to the diagnostic instance of the base variant.

  • [DIUI-R140-BaseVariant] in the base variant, the menu item is insensitive (CDS-39058 9.1).

Replace Copy with Reference in Base Library (CDS-39323 v11)

[DIUI-R160] for a diagnostic instance...

  • in a variant or library,
  • not referenced [DI-D010] in any other variant or library,
  • with a base library [LIB-D080] defined,
  • if a diagnostic instance with the same diagnostic class and qualifier exists in the base library,
  • the operation...
    • deletes the copy and instead...
    • inserts a reference to the diagnostic instance of the base library.
  • [DIUI-R160-InBaseLibrary] In the base library, the menu item is insensitive.
  • [DIUI-R160-Referenced] If the diagnostic instance is referenced [DI-D010], the menu item is insensitive.

Move Data to New DID (CDS-36881 8.2 SP2)

[DIUI-R070] See operation "Move Data to New DID" [DIOP-R070].

See [DOUI-R110] for the same operation within the telegram table.

New Instance

[DIUI-R100] Creates a new diagnostic instance [DI-R010] with default properties.

  • [DIUI-R100-Prompt] In the Base Variant, CANdelaStudio prompts to insert the new diagnostic instance also into other variants.
  • [DIUI-R100-Close] The prompt dialog has no "X" close button top right.
    • The close button typically represents "Cancel"
    • It could be misunderstand as cancelling the whole operation,
    • but (as the prompt says) the diagnostic instance has already been created at that point.

Diagnostic Instance Creation from DID (CDS-39296)

[DIUI-R020 Diagnostic Instance Creation from DID]

  • in a diagnostic class that is DID enabled [DCL-D001]
  • (whether DID semantics [DID-R050] is set in the diagnostic class template or not)...
  • when the user starts to create a diagnostic instance (context menu in tree, button in right side...),
  • CANdelaStudio shows a dialog "New Diagnostic Instance" providing selection from the DID list.
    • For dialog details, [DIUI-R030-Dialog].
  • On OK, CANdelaStudio creates diagnostic instances [DI-R020].

[DIUI-R020-report]

  • If for any selected DID the dialog cannot create a diagnostic instance,
  • the dialog finally reports the failed DIDs in one message box
  • with the ID + names of the DIDs (as shown in the list).
  • Note: details will be available only in the output window.

Check Identifier for Uniqueness

Context Menu: Check Identifier Uniqueness

[DIUI-R200] In the context menu of a diagnostic instance, CANdelaStudio...

  • provides a menu item with a checkbox, "Check Identifier for Uniqueness",
  • shows it sensitive iff. ...
    • the variant is not locked,
    • and the primary properties of the diagnostic instance are modifiable [DIA-R040]
    • and the attribute authorization allows property modification [ATTRA-R020],
  • shows it checked iff. the attribute requires the check [CIU-D040],
  • ... and modifies the attribute value according with [CIU-D050].

Delete Instance

Creates the selected diagnostic instances.

Repository

[DIUI-R150 Select from Repository] opens the Select from Repository dialog to import DIDs and create diagnostic instances from a repository.
