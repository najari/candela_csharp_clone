Diagnostic Instance Property Page "Target Groups"

The page lists the target groups (as defined in the template).

The checkbox for each target group specifies whether the object is to be considered for the target group.

If the checkbox is in an "indifferent" state (neither checked with a checkmark nor unchecked), ...

  • the target group is activated (checked) at the diagnostic instance,
  • but it is not activated (= it is un-checked) at one or more of the services in the diagnostic instance.

The icon represents "target groups" as shown in the navigation tree.
