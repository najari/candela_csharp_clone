Diagnostic Instance Property Page "Specification"

Class Type

Specifies the diagnostic use-case, e.g. Session, Fault Memory...

Occurs only once per Variant

Checked (read-only) if the diagnostic class template does not specify a variable value to distinguish multiple diagnostic instances, see [DCLT-R150].

Relevant for Requirements

If checked, the diagnostic class is shown in the requirements area [DCLT-R300].
