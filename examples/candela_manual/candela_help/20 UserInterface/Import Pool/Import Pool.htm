Import Pool

This chapter describes the User Interface of the Import Pool Feature.

Use the Import Assistant to fill the import pool, opened via menu File [MENU-R210] or a button at the bottom of the list.

Data Types

Import Pool - Data Types

CANdelaStudio allows to inspect the data type properties using the data type property page.

Data Objects

Import Pool - Data Objects

[IPUI-R200] The list provides a filter for the displayed texts (CDS-33052 9.1).

R020.0: CANdelaStudio allows to view attribute values of data objects via the attribute property page (for data types this property page already exists in the import pool).

Note, that the attributes of import pool objects are not visible via the attribute overview, as the import pool does not belong to the document.

R021.1: If synchronization is available (R010.0), CANdelaStudio shows a button “Synchronize” at the bottom of the import pool of data objects (at the left of the “Import data objects” button).

R022.0: If the attribute of R010.0 is available, CANdelaStudio shows an additional column for the value of the identifying attribute.

R023.0: If the attribute of R010.0 is available, CANdelaStudio shows an additional column “Synchronization State” representing the synchronization constellation of the data object in the Import Pool.

Allowed states are:

  • “In Use (up to date)”: The document contains at least one data object with the same identifying attribute value and the data object(s) in use match the one in the import pool (~responsible constellation “A”). Add a tooltip to the entries of the table column “The document contains data objects with the same identifying attribute value. All occurrences of the data object are up to date in regard to the one in the import pool.”

  • “In Use (not up to date)”: The document contains at least one data object with the same identifying attribute value and at least one of these data objects differs from the one in the import pool by its properties (~responsible constellation “A”). Add a tooltip to the entries of the table column “The document contains data objects with the same identifying attribute value but with different properties than the one in the import pool.”

  • “Not used”: The document does not contain a data object with the same identifying attribute value (~responsible constellation “B”) Add a tooltip to the entries of the table column “The document does not contain any data object which matches the identifying attribute value of the data object.”

  • (cell empty): The data object in the import pool does not have a value for the identifying attribute.

[IPUI-R024.0 Sync Dialog with Checkbox] When clicking the “Synchronize” button of R021, a pop up dialog shall inform the user about the consequence of the action, like

“This action will update data objects of the document according to the properties of the ones in the import pool. The data objects of the document and the import pool will be associated by the value of the identifying attribute “<ATTR-NAME>”. Identifying attribute values of data objects in use can be reset optionally if they are not contained in the import pool by activating the check box below. Do you want to continue?“

At the bottom, there are two buttons “OK” and “Cancel”. Above the two buttons add a check box “Reset identifying attribute value for data objects missing in the import pool”. The check box is unchecked by default.

A further dialog provides selection of the variants to synchronize.
