Attribute Export Wizard

[AEUI-R010] The Attribute Export Wizard lets you specify settings to export [ATTE-R100] attribute values to a CSV file.

Step 1: File and Separator

Attribute Export Wizard Step 1

The "Step 1" wizard page lets you specify

[AEUI-R100] ... a file path to which export will write the CSV file.

  • you can enter the path directly in the edit control,
  • or specify a path using the Windows file dialog.
  • Default: empty.

[AEUI-R110] ... the separator for the CSV file entries.

  • For details, see the Export format description [ATTE-R300].
  • Default: semicolon ";".

Supported separators (also in Import [AIUI-R110]):

Separator Description
; Semicolon
| Pipe
: Colon
# Number sign
\t Tabulator

Step 2: Which Data

Attribute Export Wizard Step 2

The "Step 2" wizard page lets you specify

[AEUI-R200] ... the categories [ATTR-R100] to export:

  • Either export all attributes without respect for the category,
  • or from the combobox, select one category to restrict export to attributes having this category.
  • Default: all categories.

[AEUI-R210] ... whether export shall include attributes from template data.

  • Template data includes Protocol Service, Primitive, Diagnostic Class Template etc.
  • See attribute occurrence [ATTR-R050-Template].
  • Default: yes.
