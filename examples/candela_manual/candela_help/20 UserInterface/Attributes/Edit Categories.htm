In Use

The "In use" column is always blocked and indicates whether default attributes have been assigned to the attribute category.

If the value "Yes" appears in this column, you cannot delete the attribute category. To delete the category anyway, first assign its associated default attributes to another attribute category.

May be read

Controls whether the category is shown in the attributes dialog.

Description

Details about the category.
