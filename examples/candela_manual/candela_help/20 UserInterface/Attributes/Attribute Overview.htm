Attribute Overview (CDS-2620 3.0.4)

Attribute Overview Dialog

[ATTOV-R100] The attribute overview dialog gives you an overview of all attributes in the subtree of an object or of the entire document.

It is available...

  • in Ribbon Tab "Document" [MENU-R750] and
  • in the context menu of some tree nodes.

You can use the attribute overview to override the attributes of multiple objects simultaneously with the same value.

Modifying operations respect of the Authorization of the objects - in Standard View, you cannot modify the attribute value of an object if the object is "not modifiable".

Context

When opened on "ECU Information" (the root of the document tree), the dialog shows all attributes of the document ("Whole document").

Otherwise, you can switch between

  • "Whole document" and
  • the "Current namespace", i.e. all attributes of the object on which you opened the dialog and its contained objects.

List

The list shows overridden attributes with a leading asterisk "*".

[ATTOV-R210] Referenced Diagnostic Instances

  • If a Diagnostic Instance is referenced in muliple variants [DI-D010],
  • the list shows it in the first variant only.
  • Cf. Attribute Export [ATTE-R210].

Attribute

The name of the attribute.

Value

  • In order to modify (override) the value of a single attribute, select the line of the attribute and press F2. You can enter the new value directly in the "Value" cell.

  • In order to modify the value of multiple attributes at the same time, select the attributes and click the button "Set Value". A dialog opens in which you can enter the new value and specify the scope of the modification.

Include template data

Buttons "Only Selected" / "All"

Lets you display only attribute values (rows) for the selected default attribute, or again show all attributes.

The filter is helpful if you want to modify the value of multiple attributes using "Set Value".

Button "Export"

[ATTOV-R185] Runs the Attribute Export [ATTE-R010].

Button "Import"

[ATTOV-R255] Runs the Attribute Import [ATTI-R010].

Button "Set Value"

Shows a dialog to set the value of one or multiple attributes.

The dialog lets you modify...

  • the selected attributes only,
  • all attributes in the current context
  • all attributes of the document

Button "Default"

Resets the value of an overridden attribute to the default value specified in the template at the attribute definition.
