Attribute Import Wizard

[AIUI-R010] The Attribute Import Wizard lets you specify settings to import [ATTI-R100] attribute values from a CSV file.

Step 1: File and Separator

Attribute Import Wizard Step 1

The "Step 1" wizard page lets you specify

[AIUI-R100] ... a file path from which import will read the CSV file.

  • you can enter the path directly in the edit control,
  • or specify a path using the Windows file dialog.
  • Default: empty.

[AIUI-R110] ... the separator for the CSV file entries.

  • For details, see the Import format description [ATTE-R300].
  • Default: semicolon ";".
  • Supported separators are as for the export [AEUI-R110].

Step 2: Which Data

Attribute Import Wizard Step 2

The "Step 2" wizard page lets you specify

[AIUI-R200] ... the categories [ATTR-R100] to import:

  • Either import all attribute values from the CSV file without respect for the category,
  • or from the combobox, select one attribute category of the document to restrict import to attributes having this category.
  • Default: all categories.
  • [AIUI-R200-Cat] The "Category" combobox lets you select from the categories available in the document.
    • The combobox is not restricted by categories present in the CSV file.
    • Background: the import does not create new attributes [ATTI-D100].
