Attribute Definition

See also the Attribute Values user interface and the Attributes Feature.

The Expert View of CANdelaStudio supports editing of default attributes (= attribute definitions) and attribute categories in a template and in a document.

Attributes List

Attribute List for Diagnostic Instances

Each attribute list has similar columns:

  • Name [ATTR-R010-Name]
  • Type [ATTR-R020]
  • Category [ATTR-R100]
  • Display (= display format)
  • Default value [ATTR-R040]
  • Description [ATTR-R010-Desc]

A combo box on top allows filtering by attribute category, or no filtering ("all"). If filtering is active, the "category" column must be insensitive.

For ease of use, attributes can be edited directly in the list.

Properties not displayed in the list can be edited in a property dialog.

Attribute Categories

Attribute categories are edited in a dialog of their own. It is opened using a button "Categories" in the list of attributes.

Creation

The type of an attribute [ATTR-R020] cannot be modified after creation of the attribute. Therefore, the attribute type must be selected in a special dialog before creation of the attribute:

Default Attribute Type Selection

After selecting the type of the attribute, the attribute property dialog appears. The attribute is created only if you click “Apply” or “OK” in the property dialog.

Creation of enumeration attributes requires special handling: the set of enumeration symbols must not be empty. When you create a new enumeration attribute, the property dialog will stay open, until either “Cancel” is clicked or at least one symbol has been created. If none of the symbols is defined as default, then CANdelaStudio will automatically set the first symbol as default.

Page General

Default Attribute Property Page General

The page contains the attribute’s name, qualifier and description.

Page "Unsigned", "Signed"...

Default Attribute Property Page Unsigned

Page for the type of attribute values (named after the type [ATTR-R020]) containing additional data of the attribute:

  • type (read-only),
  • category
  • default value
  • display option (if applicable).

For changing the default value, see [ATTR-R040-mod].

Enum

For attribute type “Enum” [ATTR-R020-enum] only:

  • the button "Edit symbols..." opens the dialog for editing the enum symbols;
  • the combo-box "Display order" specifies the sort order of the symbols.

For deleting an enum symbol used in overridden values, see [ATTR-R020-enumDel].

Page "String Format"

Default Attribute Property Page "String Format"

The page “String Format” allows to specify an optional restriction on the values of string attributes, using a regular expression.

Format

The regular expression used to restrict the values.

If empty, values are not restricted.

Description

A readable description of the regular expression.

Predefined Format

A list of regular expressions to start with.

Button "Use Format"

Inserts the regular expression selected in the "Predefined Format" list into the edit controls "Format" and "Description". You can still adapt the inserted values.

Page "Restrictions"

Default Attribute Property Page "Restrictions"

The page “Restriction” only appears for attribute definition lists that support restrictions (e.g. diagnostic instance). It must allow multi-selection e.g. from the set of diagnostic classes, or "no restriction".

Page "Authorization"

Default Attribute Property Page "Authorization"

Covers the flags “view” and “modify”.

Format Restrictions

This page is shown only for default attributes that support occurrence restrictions.

R030.1: Dialog accessibility and behavior:

  1. Edit the string format in the default attribute property dialog in a separate property page.

  2. When changing the string format, and some strings do violate the new format restrictions, warn the user that strings do not conform to the new format but do not enforce to change the strings.
