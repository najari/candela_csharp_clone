Vehicle System Groups

You can create and edit vehicle system groups in the subchapter "Vehicle system groups" of the CANdela document:

Vehicle System Group

Assigned Diagnostic Instances and Job Containers

Checkbox "Variant" defines the variant context.

The table list all assigned diagnostic instances and job containers in the selected variant.

Click "Please click here..." to add more (from a selection list).

Note: this assignment is also shown in the property dialog of a diagnostic instance or job container in page Vehicle System Groups.

Assigned DTCs

Checkbox "Variant" defines the variant context.

The table list all assigned DTCs in the selected variant.

Click "Please click here..." to add more (from a selection list).

Note: this assignment is also shown in the property dialog of a DTC in page Vehicle System Groups.

Availability for Variants

See Vehicle System Group - Available in Variant.

The list shows the variants of the document, with a checkbox to specify that the Vehicle System Group is available for that variant.

Identifying Patterns

If Identifying Features are defined for Vehicle System Groups, the "Identifying Patterns" page lets you specify the data values that identify the given Vehicle System Group.

New Group

Creates a new Vehicle System Group, inserts it into the tree and shows it in the right side.

Delete Group

Deletes the Vehicle System Group, removes it from the tree.
