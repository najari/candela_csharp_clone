Menu File | Properties, page "Document Info"

Template

[DOCUI-R110] Shows on which template the document is based, see at the Document Feature, empty for a template.

Protocol Standard

[DOCUI-R120] Shows the Protocol Standard on which the document is based, see [DOC-R140].

Can be modified in Expert view only.

Diagnostics Based on

[DOCUI-R140] This is the key information about any process specific handling of the template or document. See the "Diagnostics Based on" Feature.

Save Number

[DOCUI-R150] The save number is a document property [DOC-R200] incremented with each save of the document.

Status

[DOCUI-R160] Shows the status of the last revision entry.

Manufacturer

[DOCUI-R170] See the Manufacturer Feature.

Supported Languages

[DOCUI-R200] The list of languages supported in the document (e.g. for names and descriptions).

Document May Contain Duplicate ObjectIDs

[DOCUI-R310] Some operations may lead to duplicate ObjectIDs. Therefore the default is to allow duplicate ObjectIDs.

Document Supports TextIDs

[DOCUI-R320] Enables TextIDs in the document.

Supports AUTOSAR (CDS-71296 v13)

[DOCUI-R520] All the following is available in Standard View.

Checkbox "Supports AUTOSAR"

[DOCUI-R500] This checkbox controls the "AUTOSAR Type", see [DOC-R530].

  • checkbox unchecked:
    • attribute does not exist, or
    • value 0.
  • otherwise: see the following.

[DOCUI-R500-Checked] When you check the checkbox and leave the dialog with OK, ...

  • CANdelaStudio ensures the required CANdela attributes that store AUTOSAR properties [ASR-D001] exist:
  • for any attribute not yet existing at the respective object type (based on the qualifier):
    • creates the attribute;
    • writes an info message Creating "<object type>" attribute "<name>".
    • Note: before 9.1 (CDC-43826), CANdelaStudio set the default value of "ASR Encoding" to "BOOLEAN" instead of the specified empty string.
  • for any attribute existing at the respective object type (based on the qualifier)
    • leaves it unchanged;
    • writes a status message Skipping existing "<object type>" attribute "<name>".
  • Note: there is no convenient way to delete the AUTOSAR attributes.
  • Note: before v13, ...
    • the checkbox was called "Attributes for AUTOSAR Diagnostic Extract export" (CDS-41055 9.0);
    • only indicated the existence of the attributes, and allowed comfortable creation;
    • was not stored explicitly in and attribute.
    • Therefore the migration added attributes required in a new CANdelaStudio version
      • if all known AUTOSAR attributes of the older CANdelaStudio version existed.

[DOCUI-R510] When you un-check the checkbox and leave the dialog with OK, ...

  • CANdelaStudio does not delete any AUTOSAR related attributes.

AUTOSAR Type Radio Buttons

[DOCUI-R530] The following radio buttons control the "AUTOSAR Type" [DOC-R530]:

  • [DOCUI-R530-Classic] Radio button "Classic"
  • [DOCUI-R530-Adaptive] Radio button "Adaptive"
  • [DOCUI-R530-Reset] Clicking any of these buttons resets the AUTOSAR Version.
    • Motivation: be defensive - for the first AUTOSAR versions, the version strings differ in Classic and Adaptive, so you have to reconsider the version entered.

AUTOSAR Version

  • [DOCUI-R540] The "Version" edit control represents the "AUTOSAR Version" [DOC-R540]:
  • You can enter any value.
  • [DOCUI-R540-Combobox] Additionally, a comboxbox provides...
    • the version strings known at the time of implementation,
    • filled according with the selected AUTOSAR Type.

Supports Events (CDS-71376 v12)

[DOCUI-R600] The checkbox "Support Events" represents the document property "Supports Events" [EV-R010], see details there.

  • You can modify the property in Expert view only [EVOP-R010].
  • When the checkbox is checked, and you un-check it (each time you do this in the dialog), CANdelaStudio lets you confirm:
    • "If you disable Event support for the current document, CANdelaStudio deletes all Events.\n Continue anyway?"
