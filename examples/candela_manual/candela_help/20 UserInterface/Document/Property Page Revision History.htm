Property Page Revision History

Menu File | Properties | Revision History

The dialog edits the format for revision items.

When changing the version format, and the revision items violate the new format restrictions, the dialog warns that revision items do not conform to the version format. The dialog does not enforce to change the versions.

Version Format

Editable text field for the regular expression

Format Description

Editable text field for the human readable description of the format

Predefined Patterns

Combobox with a set of common predefined patterns

Use Format

Assigns the currently selected pattern in the "Predefined Patterns" combobox to the Version Format.

Every Variant Has an Individual Revision History

If checked, revision history is available for each individual variant.

OK

Checks the regular expression for correctness and accepts (and closes the dialog) or disregards it (so you cannot close the dialog).

Cancel

Closes the dialog without changing the existing version format
