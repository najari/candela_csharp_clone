ODX ECU-SHARED-DATA Dialog

The dialog shows all ODX ECU-SHARED-DATA imported into the document via the import scope "Selected Parts only".

Note: the dialog does not show ECU-SHARED-DATA imported into a Library [LIB-R026].

[ESD-R050] The dialog heading states that the ECU-SHARED-DATA originate from "Selected Parts only" import.

The dialog shows:

  • [ESD-R060] SHORT-NAME
  • [ESD-R070] properties from the file system: path and file name, last modification, byte size
  • [ESD-R080] ODX version (CDS-27179, 8.0)

The dialog provides

  • [ESD-R200] deletion of selected ECU-SHARED-DATA from the document;
  • [ESD-R210] editing of the short name (first column, in-place) (CDS-12615, 7.0 SP1)
    • [ESD-R210-Attr] CANdelaStudio updates the data type attribute "DOCREF" with the new short name at every data type overwriting the attribute.
  • [ESD-R220] editing the path and file name (CDS-12615, 7.0 SP1)
