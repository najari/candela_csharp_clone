Menu File | Properties, Page "Qualifier Generation Options"

The page Qualifier Generation Options lets you set global options [QUAL-R200] for automatic generation of qualifiers from names.

Use-Case

A tool in the diagnostic tool-chain cannot handle qualifiers up to the maximum length allowed by CANdela, so qualifiers must be shorter.

Solution

Each CANdela document contains a setting to further limit the length of qualifiers generated in the future. The maximum value is as given by the Qualifier Feature.

Length

The limit is not automatically applied to existing qualifiers; you can apply it using the Qualifier Overview Dialog.

Qualifiers that are longer than the limit are reported during a consistency check...

  • ... in a template (CDDT): as a warning (CDC-28381 8.2 SP3)
  • ... in a document (CDD): as a status message (CDC-38846 8.2 SP3)

On Regeneration of Qualifiers

[DOCUI-R700] The radio buttons specify the document-wide Qualifier Generation Options [QUAL-R200]:

  • Use upper-/lowercase characters of names
  • Use uppercase characters only
  • Use lowercase characters only
  • VW 5 Character Rule (80124)

Note:

  • the setting may be locally overridden in the "Recreate Qualifier" dialog [RCRQ-R200] of the Qualifier Overview
