File | Properties | Display of DTCs

Ribbon Tab File | Properties, page "Document Info"

DTC Format

[DOCUI-R610] This setting represents the CANdela document property "DTC Format", for details see [DOC-R400].

ISO 14229-1 / HEX

[DOCUI-R610-14229] With this option, the 3 byte DTC number is used as a single value, see [DOC-R400-14229].

The editor setting Ribbon Tab File | Options | Display lets you select between DTC display as hexadecimal / with prefix "PCBU".

ISO 15031-6 / SAE J2012

[DOCUI-R610-J2012] With this option, the 3 byte DTC number is structured in 16 + 8 bits, see [DOC-R400-J2012].

[DOCUI-R610-CBJ2012] The combobox specifies the text table data type that specifies the FTB values.

  • if the document does not contain a suitable data type, the combobox is grayed out.

SAE J1939-73 (Version 4)

[DOCUI-R610-J1939] With this option, the 3 byte DTC number is structured in 19 + 5 bits, see [DOC-R400-J1939].

[DOCUI-R610-CBJ1939] The combobox specifies the text table data type that specifies the FMI values.

  • if the document does not contain a suitable data type, the combobox is grayed out.

Byte Order (CDS-37113 9.1)

[DOCUI-R620] At the bottom, the dialog informs about the byte order of DTC transmission [DTC-R050]. This is a property of the template used.

Please contact Vector in the rare situation that you need to modify this byte order.
