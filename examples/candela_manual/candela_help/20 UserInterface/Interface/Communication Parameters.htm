Communication Parameters

When you select an interface in the CANdelaStudio navigation tree, CANdelaStudio shows the list of the communication parameters defined for the interface:

Communication Parameters Standard View

In Standard View, you can modify the values of communication parameters, but you cannot add or remove a whole interface or a communication parameter.

Expert View

Communication Parameters Expert View

[CPUI-R050] In Expert view, the list contains additional columns:

  • Display [CP-R040]
  • Default Value [CP-R050]
  • Is Standard (D-PDU) [CP-R060] (CDS-32611 8.2)

Editing

[CPUI-R060] In Expert View, you can edit the name and description of the communication parameter either in the table or in the properties dialog.

To open the properties dialog, click on the [Properties…] button in the dialog or in ribbon tab "Home".

[CPUI-R070] Restrictions for communication parameters with usage "system" [CP-R070]:

  • you cannot delete them (CDS-41372 8.5 SP2)
  • context menu "Edit Parameter" is available only in a template, not in a document.
    • The "Edit Parameter" dialog provides e.g. editing the list of enum symbols [CP-R030].
    • Note: context menu "Properties" is available, it provides editing the value.
