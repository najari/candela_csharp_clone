Interface

An ECU supports one or multiple interfaces, like "Diagnostic CAN" or "Powertrain CAN".

Supported Interfaces

In a CANdela document, these are described in the navigation tree under "ECU Information" in the node "Supported interfaces".

The set of interfaces can be edited in the document template only.

Interface Property Page Enum

Creating an entry in this table automatically adds a new interface chapter in the tree.

Each interface contains a set of communication parameters. These are also predefined in the document template.
