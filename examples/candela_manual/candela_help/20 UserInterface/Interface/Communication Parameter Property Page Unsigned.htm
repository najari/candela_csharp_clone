Communication Parameter Property Page "Unsigned"

This chapter explains the page "Unsigned" as an example for the other possible types [ATTR-R020]...

  • Signed,
  • Float,
  • Text,
  • String and
  • Enum.

In Standard View,

  • you can edit only the Overridden Value,
  • all other properties are fixed (predefined in the template).

Properties...

  • are the same as for Attributes,
  • since CANdelaStudio describes Communication Parameters using Attributes.

Communication Parameter Property Dialog - Unsigned Page

Category

Shows the category [ATTR-R100] of the communication parameter.

Default Value

The default value [ATTR-R040] takes effect unless you override it in a CANdela document.

For editing, see the "General" page.

Display Format

Specifies the format in which the value is shown: decimal, hexadecimal or binary.

Can Be Overwritten at Services

[CPUI-R210] Controls whether the Communication Parameter can be overwritten at Services.

See Communication Parameters at Services and Jobs.

Can Be Overwritten at Jobs

[CPUI-R220] Controls whether the Communication Parameter can be overwritten at Jobs.

See Communication Parameters at Services and Jobs.
