Services Supported for Interfaces (CDS-22520 7.5)

See also the description of the "Services Supported for Interfaces" feature.

[SSIUI-R100] In Expert View for a CANdela document or template, CANdelaStudio shows the page "Services Supported for Interfaces" below the "Supported Interfaces":

Services Supported for Interfaces

Service

The "Service" column shows Services per Diagnostic Class, in the form Sessions/Start:

  • first the diagnostic class name
  • second the service name

In the data model, the relevant object is the Used Protocol Service, i.e. a Protocol Service assigned to a Diagnostic Class Template.

Protocol Service

This column shows the Protocol Service used in the Diagnostic Class Template.

Prefix

This column shows the Service Abstract of the service.

Columns for Interfaces

The list shows one column for each interface defined in the document (whether "supported" under "Supported Interfaces" or not),

The value in a cell defines whether...

  • the interface (column)
  • is supported (yes/no)
  • for a given service (row).

To modify the value of one or multiple cells, select the rows, press F2, select the desired value.
