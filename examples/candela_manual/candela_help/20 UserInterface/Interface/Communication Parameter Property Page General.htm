Communication Parameter Property Page "General"

Note that CANdelaStudio describes Communication Parameters using attributes, therefore Communication Parameters have the same properties as attributes.

Communication Parameter Property Dialog - General Page

Name, Qualifier, Description

See the Property Page "General" for any CANdela objects.

In expert view on template and document, CANdelaStudio allows editing ComParam name, qualifier, description and default value (CDS-37906).

Exception: communication parameters with usage system.

Note: to preserve the qualifier prefix taken from the interface qualifier (e.g. “CAN_D”), CANdelaStudio shows the communication parameter qualifier in a separate read-only edit control to the left of the qualifier edit control.
