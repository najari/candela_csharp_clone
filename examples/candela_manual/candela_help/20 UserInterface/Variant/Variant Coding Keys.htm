Variant Coding Keys (VCK)

Variant coding keys are supported for specific manufacturers only, see the Variant Coding Keys Feature.

List of VCKs

If the support for VCKs is enabled in a document, CANdelaStudio shows a special tree node for the Variant Coding Keys. It provides an overview of all variant coding keys of a variant, and allows to recalculate the codes.

The table has the following columns:

  • The "Diagnostic instance" column indicates the diagnostic instance that codes the variant.
  • The data objects that accept the variant code are output in the "Data object" column.
  • The "Byte" and "Bit" columns indicate the position of the data objects in the telegrams of the diagnostic instances.
  • The start and end values of the table entries are output in the "Start" and "End" columns in the text table.
  • The "Assigned text" column contains the text in the text table.
  • The last column (manufacturer-dependent) outputs the assigned code.

For documents with VCK mode != "none", CANdelaStudio does not force to enter VCKs (CDS-19410 7.0 SP1):

  • in entry mask "Variant Coding Keys", CANdelaStudio allows to enter empty text;

  • if you enter non-empty text, CANdelaStudio triggers a consistency check (to assure a valid key is entered).

Recompute Variant Coding Keys

If you edit the telegram of a diagnostic instance in the "variant coding" class, there may be gaps in the variant coding keys. To correct them, click the button "Recompute Variant Coding Keys". CANdelaStudio recalculates all VCKs and updates the table.

Note: when a variant coding key is being calculated, only the contents of activated diagnostic instances is considered.

Export

You can export the variant coding keys into a "Variant Coding Keys" file.
