Dialog "Identifying Feature"

"Diagnostic Instances/Job Container" shows a tree with diagnostic classes that have a reading service, and job containers.

When the dialog opens, it will select a diagnostic instance from diagnostic class “Identification” (i.e. the diagnostic class with class type "identification").

Deactivated diagnostic instances are shown with a small red cross as in tree view.

The list to the right shows all data objects of the selected diagnostic instance, or output parameters of the selected job.

On [OK], the selected data object is added into the table of chapter Identifying Features.
