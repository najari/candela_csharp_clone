Identifying Features

See also the dialog for Identifying Patterns in extended variants and the Variant Identification Feature.

Dialog "Identifying Features"

List of Identifying Features

The chapter “Identifying Features” of the Base Variant contains a list of identifying features, i.e. data objects and services, to be used in automatic detection of a variant at runtime.

None of the columns can be sorted. Instead, the lines can be reordered by menu items Edit | Move up and Edit | Move down – exactly like data objects.

Diagnostic Instance/Job Container

Contains the name of the diagnostic instance or job container to which the data object (see next item) belongs to. For bold font, see mandatory below.

Data Object

Contains the data object used for identifying a variant. For bold font, see mandatory below.

Mandatory

Describes whether the identifying feature is mandatory (see below).

Only column "Mandatory" can be edited directly.

Status

Describes the status of the data object. Since the data object is referenced by a path to a data object, the path can be invalid. This will be indicated by this column:

  • “Usable”
  • “Invalid path”
  • “Invalid diagnostic instance”

Path

Contains the path to the data object. Paths for identifying features are always qualifier paths. If a path is invalid, it will be shown in red.

New Feature

A click on [New Feature…] or the magic line opens the dialog Identifying Feature which allows create a new identifying feature using a data object.

Change Path

A click on [Change Path…] opens the same dialog Identifying Feature which allows select a different data object. This is necessary e.g. if the previously selected data object has been deleted.

Delete

Identifying features can be deleted by clicking on the appropriate icon in the tool bar or by selecting command Edit | Delete from the main menu or context menu.

See mandatory below for restrictions.

Go To Data Object

Navigates to the referenced data object (if the path is valid).

Copy Path

Copies the path to the referenced data object to the clipboard.

Properties of Data Type

If the path to the referenced data object is valid, opens its referenced data type.

Mandatory Identifying Features and Patterns (CDS-7937 5.0)

Each identifying feature has a flag whether it is mandatory.

  • R010.1: allow toggling the flag in expert mode (= on CDDT and on CDD).

  • R011.0: in each variant, in the list of identifying patterns, display the columns "Diagnostic Instance/Job Container" and "Data Object" in bold font iff. the identifying feature is mandatory.

  • R012.0: deleting an identifying feature marked mandatory is only allowed in expert view.
