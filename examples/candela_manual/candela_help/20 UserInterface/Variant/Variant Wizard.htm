Variant Wizard

Introduction

Variant wizard, a special dialog in CANdelaStudio, allows creation of new ECU variants. It uses a variant already existing and allows copying or referencing objects from an existing variant into a new variant.

Variant Wizard

Name

See Names in CANdela.

Create (CDS-68705 v12)

[VW-R040] The radio buttons control how the wizard handles objects of the variant specified in the combobox "on basis of":

  • [VW-R040-Ref] "Variant with References"...
    • creates all diagnostic instances and job containers as references [DI-D010]
  • [VW-R040-Copy] "Variant with Copies"...
    • creates all diagnostic instances and job containers as copies,
    • except those that are "required as reference" [DIA-R020-reqAsRef].
    • [VW-R040-CopyInsens] The radio button is insensitive, depending on the option in Ribbon Tab File | Options | Edit | "Variant Wizard allows to copy all diagnostic instances".
  • [VW-R040-Empty] "Empty Variant"...
    • creates only diagnostic instances and job containers that are "required as reference" [DIA-R020-reqAsRef].
  • [VW-R040-Default] The default selection is "Variant with References".

on Basis of

[VW-R050] The combobox "on basis of" determines the variant used for the radio buttons under "Create" [VW-R040]:

  • [VW-R050-Lib] The combobox contains the libraries of the document, above the variants.
  • [VW-R050-Var] The combobox contains the variants of the document.
  • [VW-R050-Default] The base variant is selected as default.
  • [VW-R050-Sens] The combobox is sensitive only for "Create"... "Variant with References" and "Variant with Copies".

Action for All Instances

Actions

An action describes the state of the respective object in the variant to be created:

  • "unused": object not created
  • "copy": copy created
  • "reference": reference created

For objects that contain other objects (variant, diagnostic class), the action may also be

  • "(mixed)": the contained objects have different actions.

Folders

The "Create" radio buttons [VW-R040] (above) determine the default action for the entire new variant.

Additionally, you can modify the actions...

  • for diagnostic classes (shown as folders) and
  • for individual diagnostic instances.

Hence the action combobox for variant and diagnostic classes serves two purposes:

  • Modify the actions of all contained objects.
  • Summary of the actions of all contained objects

Change Propagation

  • If you change the action of a folder,
    • the wizard updates the actions of the contained objects.
  • If you change the action of a contained object,
    • the wizard updates the resulting action of the folder, maybe to "(mixed)".
  • Initially, all contained objects have action "reference"
  • You cannot set the action of a folder to "(mixed)" directly.
    • This value is displayed as a summary for the actions of the contained objects, it is not shown in the combobox.
  • If all contained objects have the same action, the containing object automatically gets this action, too.
  • For "required" objects, the wizard does not allow action "unused".

Tree (left)

[VW-R100] The wizard shows the tree like the CANdelaStudio tree (including the icons).

[VW-R110] The tree contains the variant from "on basis of" with its diagnostic classes, job containers and diagnostic instances.

List (right)

[VW-R200] The list to the right displays the contents of the currently selected tree element.

  • For leaf elements of the tree (job containers and diagnostic instances), the list contains just this element.
  • The list contains...
    • the name of the object,
    • the action to be performed for it (see below),
    • and an indication whether the element is "required".

Actions

Action Visualization

Folders (diagnostic classes) have two icons only:

  • one for the selected,
  • one for the de-selected state.

The icon of a diagnostic instance reflects its action: unused, copy, reference.

Note: the icons...

  • do not reflect the copying/sharing state of the variant selected in "is based on",
  • they rather reflect the state of the new variant!

Action "Reference" for Diagnostic Classes

The wizard provides the action "reference" for a diagnostic class.

Its effect is just that all its diagnostic instances will be referenced.

Background: the CANdela data model supports...

  • copying and referencing [DI-D010] of diagnostic instances,
  • but only copying of diagnostic classes (no references!).

OK

[VW-R500] On OK, CANdelaStudio creates a new variant [VAR-R100] with the specified name.

[VW-R510] Copy Variant Attributes (CDS-41769 8.5 SP3)

  • If "Action for All Instances" is "Reference" or "Copy" (not "Unused" or "Mixed"),
  • then CANdelaStudio copies all variant attributes [VAR-R100-Attributes] to the new variant.
