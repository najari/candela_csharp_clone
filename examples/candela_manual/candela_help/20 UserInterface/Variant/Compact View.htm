Compact View (CDS-4391 4.0 SP2)

Compact View of Variants

The Compact View is opened on a first variant (using menu View or the context menu).

The dialog...

  • lets you select a second variant from a combobox
  • and provides an overview of diagnostic instances in the first variant that are not referenced from the second variant, i.e.
    • are copies
    • or do not occur in the second variant.

Such diagnostic instances...

  • have either been modified in either variant, so that their contents is different;
  • or have unnecessarily been created by the operation "Replace Reference with Copy", without further modification. You may consider to re-establish the reference, which saves space and clearly indicates the intention to have identical data.

Note: to inspect the property differences in detail, use the Compare View.

[VARCV-R050 Compact View and Library] CANdelaStudio shall not show Libraries in Compact View.

Variant

Lets you select the second variant.

The list contains all variants except the first one.

Result (Left Tree)

The tree to the left displays the second variant with its diagnostic classes, diagnostic instances and job containers.

Result (Right Tree)

The tree to the right displays those diagnostic instances and job containers of the first variant which are not referenced from the second variant.

Trees Details

Properties like identifier, target groups, service addressing and maturity are shown like in the document tree, depending on the settings in the options dialog.

Copy Path

(context menu) Copies the object path of the selected object to the clipboard.

Go To Object

(context menu) Navigates to the object in the CANdelaStudio application (under the Compact View dialog).

(this operation had an issue in 8.0 .. 8.2 due to CDS-28807, fixed in CDS-39744 8.5)

OK, Cancel

Close the dialog.
