Identifying Patterns

The chapter "Identifying Patterns" in an extended variant contains two tables. It is based on the data of the dialog Identifying Features defined in the base variant.

See also the Variant Identification Feature.

Dialog "Identifying Patterns"

Upper Table

The upper table has only one column named “Identifying Pattern”, which cannot be edited directly.

The table shows Identifying Patterns. To identify the variant, it suffices that any of the patterns matches (disjunction, logical "OR").

The column shows a summary of the details defined in the bottom table:

  • for a new pattern, the column show e.g. text “*, *, *“ (the number of asterisks is the number of identifying features defined).

  • for a pattern with identifying details, the column shows the values of all details, separated by a comma “,”.

New

Clicking button "New" or the magic line creates a new identifying pattern, whose details are to be described in the bottom table.

New Range

Allows convenient creation of multiple identifying patterns.

Delete

Removes the selected identifying patterns.

Bottom Table

The table shows values to expect in an ECU response for the selected Identifying Pattern in the upper table. To identify the variant, all checked values must match (conjunction, logical "AND").

You cannot create new identifying details directly in this bottom table, i.e. the table has no magic line. When you create a new identifying pattern in the upper table, all identifying features will be shown in the table as "details" with deactivated checkboxes.

Diagnostic instance/Job container, Data object, Status, Path

These columns correspond with the columns of the Identifying Features list. None of these columns can be edited.

Value

Contains the expected value of the data object which identifies the variant of the identifying pattern. This column can be edited (select the cell, then single click or press F2).

Data Type

Shows the data type used by the data object.

Checkbox

A checkbox to the left of each row determines whether the corresponding feature shall be used to identify the variant. The value of a detail can only be edited if the checkbox is activated. Clicking into column “Value” automatically activates the checkbox.
