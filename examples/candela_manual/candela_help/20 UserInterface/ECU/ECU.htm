ECU

Since a CANdela document describes one ECU, the CANdelaStudio navigation tree shows the "ECU Information" tree node on top.

See also the ECU (Feature).

Right Side

Right Side of ECU Information

Name

Shows and lets you edit the name of the ECU.

Note: CANdelaStudio uses the name to generate the qualifier, but flash containers or other applications may already refer to the existing qualifier. Therefore CANdelaStudio prompts for confirmation if you modify the name (as soon as you leave the tree node).

Properties

The Properties button to the right of the "Name" edit field lets you open the ECU Property Dialog.

It is also available in the context menu of the "ECU Information" tree node.

Description

The ECU description is shown first when you open an CANdela document, therefore it is a good place for an introduction or overview of the ECU functionality. You can also insert an image of the ECU using the File Manager.
