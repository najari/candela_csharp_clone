ECU Property Page "Maximum Number of Identifiers"

Page Maximum Number of Identifiers

The property dialog for an ECU contains this page if any Protocol Service of the document has the "may be combined" flag set (CDS-7882 5.5).

Maximum Number of Identifiers

The edit control lets you edit the Maximum Number of Identifiers.

Maximum Number of Identifiers in ECU Scheduler

If the checkbox to the left of the text is checked, the edit control lets you edit the Maximum Number of Identifiers in ECU Scheduler.

If the checkbox is unchecked, the value is not stored.
