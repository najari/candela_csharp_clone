New Document Upgrade Rework List

[RWL-R010] After a New Document Upgrade [DOCUP-R600], you can review changes in the Rework List.

Rework List

Visibility of the list is controlled by ribbon tab Document | Views | Rework List [MENU-R625].

For details about the contents of the Rework List, see [DOCUP-R650].

The list works like the Output Window - you can move it, click a hyperlink to navigate to objects in the document, etc.

Columns

  • Is Done: for your personal use, to track your review progress
  • Link: optional hyperlink to an object in the document
  • Message: important information from the Document Upgrade

Operations

  • [RWL-R110] Copy selected tasks to clipboard
  • [RWL-R120] Delete contents of the Rework List
  • [RWL-R130] Open Rework List
  • [RWL-R140] Save Rework List
  • [RWL-R150] Specify filter text
  • [RWL-R160] Reset all filter settings
  • [RWL-R170] Shows or hides the toolbar.
    • Note: if the toolbar is hidden, you can show it again via the context menu.
  • [RWL-R180] Shows or hides the line with the column headers.
