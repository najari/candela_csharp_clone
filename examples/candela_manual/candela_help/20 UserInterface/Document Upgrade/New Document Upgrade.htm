New Document Upgrade Dialog (CDS-70041 v11)

[DUUI-R100] The dialog controls the New Document Upgrade operation [DOCUP-R600].

You start it via ribbon tab Document | Template | New Document Upgrade [MENU-R568].

The dialog provides 3 steps (described below):

  1. Configure
  2. Resolve Conflicts
  3. Finish

New Document Upgrade Dialog

1. Configure

Show Paths

[DUUI-R105] The checkbox "Show Paths"...

  • takes effect on...
    • the edit control Old Template
    • the edit control New Template
    • the fixed text Document.
  • When un-checked,
    • the controls show the file name only,
    • the edit controls are read-only (when editing, the folder info would be missing);
  • when checked,
    • the controls show the complete path to the files (folder and file name).

Current Template

[DUUI-R110] In this edit control, please specify the CANdela template on which the current document is based.

Use the button "..." to the right for a file selection dialog.

New Template

[DUUI-R120] In this edit control, please specify the newer CANdela template from which you want to transfer data into the current document.

Use the button "..." to the right for a file selection dialog.

Document

[DUUI-R130] For information, the path to the currently opened document.

The operation modifies the document.

Variants to be Upgraded

[DUUI-R140] The list shows all variants of the document.

The document upgrade will transfer data from the new template to the variants you select here.

Note:

  • modifications to template data (like adding a default attribute) automatically take effect for all variants [DOCUP-R640-Global].
  • The operation will enumerate them in the Rework List [DOCUP-R640-ReworkList].

[DUUI-R145] The checkbox "All Variants" allows to select / de-select all variants in the list.

"Document Upgrade transports only selected template objects T"

[DUUI-R150] The static text documents the coverage of the implementation [DOCUP-R610-Coverage] for template objects.

2. Resolve Conflicts

[DUUI-R200] In the second step, the dialog shows all objects where a conflict [DOCUP-R620] must be resolved.

[DUUI-R200-Default] As a default, the dialog puts the value from the new template into column "Result Document"

[DUUI-R200-Order] The order of objects corresponds with the one in the CANdelaStudio tree [TREE-R010] (CDS-71518 v12).

[DUUI-R200-NonSelVariants] Non-selected variants are shown in red (CDS-71372 v12).

New Document Upgrade Step 2

Search

[DUUI-R230] The edit control at top right provides a filter: the list...

  • filters all shown texts by your input
  • always shows the elements in the tree hierarchy above the element that contains a match.

Description of Columns

[DUUI-R240]

[DUUI-R240-Type] Object Type:

  • shows the tree structure of the document and template.

[DUUI-R240-Document] Document Based Changes:

  • shows the values from the document.

[DUUI-R240-Right] Right arrow:

  • lets you take over the value(s) from the document to the Result Document.
  • A double arrow indicates the entire subtree of values will be transferred.
  • The button is insensitive if column "Result Document" already contains the value from the document.

[DUUI-R240-Result] Result Document:

  • shows the values to be used if you leave the dialog with "Continue with Result Document" [DUUI-R220].
  • You resolve the conflicts by putting either values into this column.
  • [DUUI-R240-Desc] For a conflict in a description, the cell contains a button to open the Description Merge Editor (see next chapter).

[DUUI-R240-Left] Left arrow (like Right arrow above):

  • lets you take over the value(s) from the new template to the Result Document.

[DUUI-R240-Template] Template Based Changes:

  • shows the values from the new template.

Description Merge Editor (CDS-70745 v11)

[DUUI-R250] The Description Merge Editor is available in the column "Result Document" for conflicting descriptions (see [DUUI-R240-Desc] above).

Description Merge Editor

  • [DUUI-R250-Default] On entry, the dialog shows the description from the "Result Document" cell.
  • You can freely modify the text.
  • [DUUI-R250-Reset] Button "Reset Merge" puts both conflicting texts into the edit field:
    • the description from the document, followed by
    • the description from the new template.
  • Button "OK" closes the dialog and puts the current description into cell "Result Document".
  • Button "Cancel" closes the dialog and leaves the description in cell "Result Document" unchanged.

Note: to accept one of the texts and discard the other one, you can simply use the respective arrow button in the table directly.

Export

[DUUI-R260] Ribbon Tab Export provides an export of the conflicts shown:

  • [DUUI-R260-XML] ... to an XML format
  • [DUUI-R260-TXT] ... to plain text
  • [DUUI-R260-HTML] ... to HTML
  • [DUUI-R260-Filter] The export contains information about the filter [DUUI-R230] (CDS-71383 v12).

Button "Continue"

[DUUI-R220] This button...

  • performs the Document Upgrade,
    • using data from the document or from the template,
    • as shown in column "Result Document",
    • i.e. the button preserves your choices in resolving the conflicts;
  • proceeds to "3. Finish".

3. Finish

[DUUI-R300] As a last step, the dialog shows the results.

  • The operation has finished, the document has been modified.

New Document Upgrade Step 3

[DUUI-R310] Button "Create Revision" lets you can optionally create a revision entry...

  • using the "Edit Revision" Dialog,
  • pre-filled with information generated by the New Document Upgrade.
  • After closing the revision dialog, the button will be insensitive.
    • [DUUI-R310-Cancel] (v11) ... even when you left the dialog with Cancel (CDS-71266). Note:
  • [DUUI-R310-NoAuthor] If the document does not contain an author,
    • CANdelaStudio shows the Revision History Dialog [REVUI-R010] so that you can create an author first.
    • (v11) When you create a new revision item within this dialog, the information generated by the New Document Upgrade is not available (CDS-71266).

[DUUI-R320] Button "Help" shows this page.

Rework List

After finishing the operation, you can inspect the Rework List for objects to check.

For details about the Rework List contents, see [DOCUP-R650].
