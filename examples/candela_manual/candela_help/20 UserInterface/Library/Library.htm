Library

[LIBUI-R340.0 Contents of Library Tree Node]

  • [TREE-R010-LIB1] Libraries are shown as child of the „Libraries“ tree node.
  • [LIBUI-R340-a] CANdelaStudio shall show the right side as for an ECU Variant
  • [LIBUI-R340-c] no Identification Feature tree node
  • [LIBUI-R340-d] no Identification Pattern tree node
  • [LIBUI-R340-e] For a locked Library, do not allow interactive modification of the contents in Standard Mode.
  • [LIBUI-R340-f] For a locked Library, allow interactive modification in Expert Mode
  • [LIBUI-R340-g] for a diagnostic instance in a Library, show the tree icon as if the diagnostic instance were in the Base Variant:
    • [LIBUI-R340-g1] In library only: dark
    • [LIBUI-R340-g2] Otherwise (referenced in other library or any variant): dark on bright.

Operations

[LIBUI-R350 New Button] in the right side, CANdelaStudio shall show the button [LIBUI-R332-New].

[LIBUI-R352 Delete Button] in the right side, CANdelaStudio shall show a button "Delete". If pressed, CANdelaStudio shows an information if deletion is not possible, or prompts and on confirmation deletes the library selected in the tree [LIB-R105].

Context Menu

[LIBUI-R360] CANdelaStudio shall provide a context menu for the Libraries tree node.

  • [LIBUI-R360-New] "Create New Library" creates another library [LIB-R100] with a default name and qualifier, like [LIBUI-R332-New].
  • [LIBUI-R360-Delete] "Delete" deletes the library like [LIBUI-R352].
  • separator
  • [LIBUI-R360-Lock] "Lock" is sensitive iff. the library is not locked [LIB-R020]. When pressed, after confirmation, CANdelaStudio locks the library [LIB-R120].
  • [LIBUI-R360-Unlock] "Unlock" is sensitive iff. the library is locked [LIB-R020]. When pressed, after confirmation, CANdelaStudio unlocks the library [LIB-R120].
  • separator
  • [LIBUI-R360-ExportODX] "Export Open Diagnostic Data Exchange (ODX)...". When pressed, prompts for a file path and exports the library to that path [LIBDX-R630].
  • separator
  • [LIBUI-R360-QualifierOverview] "Qualifier Overview..." like [LIBUI-R332-QualifierOverview], with "Current Namespace" = the library.
  • [LIBUI-R360-AttributeOverview] "Attribute Overview..." like [LIBUI-R332-AttributeOverview], with "Current subtree" = the library.
  • [LIBUI-R360-TargetGroupOverview] "Target Group Overview..." like [LIBUI-R332-TargetGroupOverview], with "Current subtree" = the library.
  • separator
  • [LIBUI-R360-SelectAsLeft] "Select as Left Side for Compare" remembers the library for later compare.
  • [LIBUI-R360-CompareTo] "Compare to..."
    • shall be sensitive if [LIBUI-R360-SelectAsLeft] has been performed on a library;
    • shows the name of the library in double-quotes, like Compare to "Base Library"...;
    • opens Compare View comparing the two libraries selected.
  • separator
  • [LIBUI-R360-MoveUp] "Move up"
    • sensitive if the library is not the first one
    • moves the library to the front of the libraries list [LIB-R108]
  • [LIBUI-R360-MoveDown] "Move down"
    • sensitive if the library is not the last one
    • moves the library one element to the back of the libraries list [LIB-R108]
  • separator
  • [LIBUI-R360-RevisionHistory] "Revision History..."
    • shall be visible if Variant and Library specific Revision History has been enabled [REV-R050-LIB];
    • shall open the Revision History Dialog on the revision history of the selected library.
  • [LIBUI-R360-Properties] "Properties..."
