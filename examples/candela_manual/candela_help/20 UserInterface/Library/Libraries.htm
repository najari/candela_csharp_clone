Libraries (List)

Libraries Tree Node and List

[LIBUI-R322.0]: For the „Libraries“ tree node, in the right side, CANdelaStudio shall show a list of Libraries…

  • [LIBUI-R322-a] like for ECU Variants, but omit all the text except the heading „Libraries“
  • [LIBUI-R322-b.1] Columns „Name“ (first), „Description“ (last)
  • [LIBUI-R322-FS] Columns "Path and Filename", "Last Change", "File Size" (same as [ESD-R070])
  • [LIBUI-R322-ODXVer] Column "ODX Version" (same as [ESD-R080])

Operations

[LIBUI-R330 New Button] in the right side, CANdelaStudio shall show a button "New Library" that creates a library [LIB-R100] with a default name and qualifier.

Context Menu

  • [LIBUI-R332] CANdelaStudio shall provide a context menu for the Libraries tree node.
    • [LIBUI-R332-New] "Create New Library" creates a library [LIB-R100] with a default name and qualifier (like [LIBUI-R330] above).
    • [LIBUI-R332-QualifierOverview] "Qualifier Overview..." opens the Qualifier Overview with "Current Namespace" = Libraries.
    • [LIBUI-R332-AttributeOverview] "Attribute Overview..." opens the Attribute Overview with "Current subtree" = Libraries...
    • [LIBUI-R332-TargetGroupOverview] "Target Group Overview..." opens the Qualifier Overview with "Current subtree" = Libraries...
