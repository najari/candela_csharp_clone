Diagnostic Class Template Property Page "Specification"

Class Type

The combo-box lets you select from a list of predefined class types.

Occurs only once per Variant (Singleton)

The checkbox is read-only. It visualizes whether a variant will contain...

  • at most one (singleton)
  • or even multiple (non-singleton)

... diagnostic instances based on the diagnostic class template [DCLT-R150].

Relevant for Requirements

The checkbox controls whether the diagnostic class template supports requirements.
