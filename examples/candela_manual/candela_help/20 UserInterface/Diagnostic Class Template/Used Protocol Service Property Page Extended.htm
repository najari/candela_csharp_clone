Used Protocol Service Property Page "Extended"

You can open this dialog in the Diagnostic Class Template page, in the "Used Protocol Services" list.

Used Protocol Service Property Page "Extended"

Semantics

The edit control lets you specify the ODX Semantics [DCLT-R320] for services based on the Used Protocol Service.

You can...

  • enter any string (even leave it empty), or
  • select from a list of predefined ODX service semantics (click the down arrow at the right end of the edit control).

Subfunction - Text Table (CDS-18874 8.0)

If the ProtocolService has a variable value, CANdelaStudio lets you specify a Text Table for the Identifier value in diagnostic instances based on the diagnostic class template.

The dialog allows only text tables that have the same length as the variable value.
