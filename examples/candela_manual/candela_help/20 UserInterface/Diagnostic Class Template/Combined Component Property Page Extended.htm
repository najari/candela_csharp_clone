Combined Component Property Page "Extended"

Data Types

Specifies the creation/usage of data types in telegram tables based on the combined component, see Data Type Authorization [DTAUTH-R210].

This is a refinement of the options for data types on Document Level [DTAUTH-R110].

Allowed Variable Length of Data Objects

[CPCUI-R060] Optionally restricts data objects of variable length to occur only at the end of a telegram based on the combined component, see feature [CPC-R060].

  • To restrict this in the entire document, see [DLA-R060], dialog [DOCUI-R440].
