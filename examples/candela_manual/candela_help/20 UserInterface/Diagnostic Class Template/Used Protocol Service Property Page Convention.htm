Used Protocol Service Property Page "Convention"

You can open this dialog in the Diagnostic Class Template page, in the "Used Protocol Services" list.

Used Protocol Service Property Page "Convention"

Edits the convention of the Used Protocol Service, which controls whether services based on the Used Protocol Service are mandatory.
