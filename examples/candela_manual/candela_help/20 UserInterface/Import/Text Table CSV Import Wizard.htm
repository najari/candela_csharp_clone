Text Table CSV Import Wizard

The Wizard provides import of text table entries from a .csv file.

Step 1

Text Table CSV Import Wizard Step 1

CSV File

The wizard lets you select a .csv file using...

  • the input control
  • or the file dialog available via button "...".

Note: the CANdelaStudio installation ships with a sample import file "SampleTextTable.csv".

Separator

The wizard lets you select the column separator used in the .csv file.

Separator Name
, Comma
; Semicolon
| Pipe
: Colon
# Number sign
(TAB) Tabulator

Step 2

Text Table CSV Import Wizard Step 2

In the second step, you define the mapping of...

  • columns in the .csv file
  • to properties in the CANdela text table
    • start value
    • (optionally) end value of a range
    • text
    • additional information

The table lists the information from the .csv file and separator specified in step 1.

Use First Data Record as Column Titles

If checked, the wizard takes the first data record (line) of the .csv file for column titles, and does not create a text table entry from it.

Value Ranges

  • Generate Start: the wizard generates consecutive start values;
  • Import Start: the wizard takes the start values from the .csv file column you select in the combo-box;
  • ... and End: if you specified "Import Start", you may optionally also specify the .csv file column for the end value of a text table entry.

Conventions:

  • For a signed data type,
    • the .csv file may contain negative values (CDS-70011 v10),
    • but only decimal (not hexadecimal) values.

Text Values

  • Assigned text: the wizard takes the text of the text table entry from the .csv file column you select in the combo-box;
  • Additional information: dito for the additional information of the text table entry.

Step 3

Text Table CSV Import Wizard Step 3

In step 3, the wizard shows a preview of the generated or imported text table entries.

List

  • Import: a checkbox lets you decide whether to import each individual text table entry or not;
  • Exists in target: shows whether the value of the text table entry is already contained in the target text table;
  • Value: the numeric value (or start of a range)
  • End of range: for a text table with discrete values, this equals the value (start of range).
  • Assigned text: as taken from the import file
  • Additional information: dito.

Select all / Select none

Lets you check / un-check all rows.

Step 4

Text Table CSV Import Wizard Step 4

Shows a final preview of the data to import.
