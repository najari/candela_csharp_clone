Select from Repository

CANdelaStudio provides a dialog for the Repository Integration.

Note: as a default after installation, CANdelaStudio uses a sample repository [RPS-R400] reading from a .csv file.

The dialog provides...

  • search for objects in the repository,
  • inspection of object properties, and
  • import of selected objects into the CANdela document.

DID Selection Dialog

DID Selection Dialog

The dialog is available via...

  • button “Select from repository…” in the DID pool [DIDUI-R725]
  • button “Repository…” in right hand side of all diagnostic classes with DID semantic (set in template) [DIUI-R150]
  • As a context menu item “New Diagnostic Instances from Repository” at all diagnostic class nodes in the standard tree with DID semantic [DCLUI-R410]

Activation of DID Selection Dialog

The dialog shows...

  • information about the repository
  • a filter for the DID list
  • the DID list
  • the number of DIDs available

The DID list contains several columns:

  • Checkbox to select a DID
  • Identifier
  • Name
  • Summary (names of data objects contained in the DID)

DTC Selection Dialog (CDS-32365 8.2 SP2)

Dialog to Select DTCs from Repository

The dialog works like the DID Selection Dialog.

It is available via...

  • button “Select from repository…” in the DTC pool [DTCPUI-R150]
  • button “From repository…” in the DTC list of the FaultMemory instance [DTCUI-R410]
