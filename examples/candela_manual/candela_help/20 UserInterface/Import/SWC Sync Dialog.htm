SWC Sync Dialog (CDS-41056 = SWCSYNC-4 v10)

SWC Sync Dialog

The SWC Sync Dialog is available via...

  • button [MENU-R280] in the ribbon tab "Data Exchange", or
  • button [RQUI-R220] in the Requirements page.

Filter

[SWCUI-U0500]: The dialog provides a text filter (matching all displayed lists columns). If you provide a filter text, the dialog...

  • hides all entries which do not match the filter text
  • highlights the filter text matches in the list of remaining entries.

Note: to literally find a text containing blanks, enclose it in double-quotes like "Present Values".

Statistics: Visible Objects

[SWCUI-R0120]: The dialog shows information about the effect of the filter, like

21 of 93 visible in view
  • "21" is the number of objects actually shown (with the filter applied) in the list (current tab)
  • "93" is the total number of objects in the list (current tab)
    • i.e. the number counts only objects of the category shown in the current tab

Tabs (Views)

[SWCUI-U0200]: The dialog provides five views on the extracted data:

  • All Elements
  • DIDs (Present Value and Stored Data Objects)
  • Routines
  • IO Controls
  • DTCs
  • Unclassified (objects potentially relevant for diagnostics, CDS-70044 v12)

The tabs show objects of different types, therefore the lists contain different columns.

The following chapters show screenshots of the tabs.

For details about specific columns, see the chapters further below.

For an overview of which SYS-EX data will be shown in which pages of the dialog, see [SWC-R1200] in the Features section.

The dialog shows objects that are potentially relevant for diagnostics:

  • they have no requirements ID
  • they have no service dependency with a diagnostic value or service need.

Column "Synchronize"

[SWCUI-U0400]: For each object displayed, the dialog allows to decide whether the object shall be processed further.

[SWCUI-R0160]: Lines of objects deselected from further processing are displayed in grey.

Column "Target"

[SWCUI-U0300]: For each object displayed, the dialog shows whether the object...

  • Target "Variant/Library": can be synchronized (there is a matching requirements ID), or
  • Target "not synched": can be synchronized (there is a matching requirements ID), or
  • Target "Import Pool only": can only be imported into the import pool
    • (since the object is "new" in the system extract)
    • [SWCUI-R0140]: this info is highlighted in red.

[SWCUI-R0150]: The info whether the object can be synchronized is placed next to the user editable checkbox by default (that is: as the second most left column).

Column "ShortName"

[SWCUI-U0310] Shows the shortname of the object from the system extract.

In CANdela, this corresponds with the qualifier.

For DTCs, the shortname contains the hexadecimal code.

Column "Requirements Object Name"

[SWCUI-U0320] Shows the object name (CANdela: name) of the object from the system extract.

Column "Requirements ID"

[SWCUI-U0330] Shows the requirements ID of the object from the system extract.

For an object shown with target "Import Pool only", the requirements ID is not present in the CANdela document.

Column "UUID"

[SWCUI-U0335] Shows the UUID of the object from the system extract.

SWC Sync will put the UUID into the attribute [ASR-D001_ASR_UUID].

Column "Category"

[SWCUI-U0340] Describes the type of object:

  • Stored Data (shown in tab "DIDs")
  • Present Value (shown in tab "DIDs")
  • Routine
  • IO Control
  • DTC

Column "Display Format"

For tabs "DIDs" and "IO Controls", shows the display format (dec/hex...) of the element.

Column "Data Type Name"

For tabs "DIDs" and "IO Controls", shows the name of the data type

Column "Data Type Category"

For tabs "DIDs" and "IO Controls", shows the kind of data type, like

  • RECORD
  • ARRAY
  • LINEAR
  • TEXTTABLE
  • SCALE_LINEAR_AND_TEXTTABLE

Column "Operation Summary"

For tabs "Routine", shows a summary of the

  • routine type (Start, Stop, RequestResults)
  • parameters (name, in/out, data type name, data type category)

Target Variant/Library

[SWCUI-R345] Selects the target for the synchronization.

Note: this setting is also controlled in the Requirements Property Page Settings [RQUI-R100-Variant].

Checkbox "Synchronize Element References"

[SWCUI-R350]

  • Default: checked
  • Un-check this setting only if the objects in the SYS-EX are mere placeholders; in this case, the objects synchronized in the CANdela document won't get Element References assigned.
  • For details, see [SWC-R1600].

Checkbox "Combine Parameters of Synchronized DIDs in DEXT Export"

[SWCUI-R360]

  • Default: un-checked
  • Check this only if SWC Sync shall set the attribute ASR3_Legacy_Combine_DID, which will trigger DEXT Export of the DID as uint8 array.
  • For details, see [SWC-R1600].

Statistics: Selection

[SWCUI-R0125]: The dialog shows information about the objects selected for synchronization, like

71 of 72 elements in this view are selected for synchronization
  • this line describes the selected / total number of elements in the current view (tab)
    • it does not matter whether the elements are visible or filtered
    • this line is not shown for tab "All Elements"
92 of 93 total elements are selected for synchronization
  • this line describes the selected / total number of elements in tab "All Elements"
    • it does not matter whether the elements are visible or filtered

Dialog State

[SWCUI-R0130]: The state of the dialog (column widths, sorting etc.) gets restored when opened the next time.

Synchronization Progress

[SWCUI-R0190]: After closing the dialog, for large system extract files, CANdelaStudio shows the progress of the synchronization.
