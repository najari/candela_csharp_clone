State Groups and States

This page shows all state groups and their states.

In order to create a new session or a new security level, ...

  • click the respective entry in the upper list,
  • then click "Please click here to create a new element" in the lower list.

State Groups

Each state group represents one mechanism to block execution of services, see the introduction to the State Dependency Feature:

  • Session
  • Security Access
  • Authorization (certificate based)
  • ... your own ...

Name

See the name feature.

Semantic

Allows to assign a predefined semantics [STG-R050]:

  • session
  • security
  • authorization

For other state groups, use none.

Negative Response Code

A NRC to be used as default in services that are relevant for the state group, to indicate that the request has been denied due to the state group. See [NRC-R050].

States

State Position in the List

The first state in the list is used as the initial state.

You can move one or multiple states up or down using the buttons in ribbon tab Home | Move.

Name

See the name feature.

Create New State

For the first state of a State Group (CDS-12262 6.0), CANdelaStudio sets...

  • all existing services as executable
  • no service performs a state transition

For a subsequent state of a State Group, CANdelaStudio prompts (CDS-11638 6.0):

Are the existing services executable in the new state <state> of state group <state group>?

Please specify the initial setting now.

You can edit the state transitions for individual services in the 'Dependencies' dialog later.

The dialog provides a checkbox like

Add NRC "0x22" to all services

with the NRC defined at the state group.
