State Dependencies (User Interface)

See also the State Dependency Feature.

The dialog offers three Views.

[STUI-R150] You can select the view using the following buttons:

  • [STUI-R150-Diagram] Shows a graph of the currently selected state group and variant.
    • [STUI-R150-DiagramTwice] Pressing the button if the graph is already shown has no effect (CDS-69683 9.1).
  • [STUI-R150-Overview] Shows a tabular overview of all state transitions.
  • [STUI-R150-Editing] Shows a table in which you can edit the state transitions.

State Diagram (Graphical View)

Graphical View of State Transitions at Services

CANdelaStudio offers a graphical overview of all states and state transitions of the services in a CANdela document. This function needs installation of GraphViz (see next chapter).

Only services which are relevant for the state group are shown. Services contained in deactivated instances are not listed.

The starting state is surrounded in bold.

Required Tool: GraphViz

[STUI-R180] CANdelaStudio uses the tool "GraphViz" from AT&T for the graphical view (in the user interface and in report).

  • The CANdelaStudio installation does not include GraphViz [IBP-D090]
  • The "GraphViz" package is available from https://www.graphviz.org.
  • CANdelaStudio locates GraphViz...
    • using the Windows PATH variable [IWS-D200], or
    • the setting from Ribbon Tab File | Options [OPT-R250].
    • [STUI-R180-64] Heuristics: under 64-Bit Windows, search also in C:/Program Files (x86)C:/Program Files (x86) (CDS-20544 7.0 SP2)

Zoom

Under Zoom you can select the magnification of the graph. Possible values lie between 10% (very small) and 250% (very large). However, you can also input your own values. The default setting is 100%.

Font

Under Font you can select a different font for displaying the graph. This would be advisable, for example, if you want to make the labeling in the specification in the same font as the text.

Variant

[STUI-R200] Under Variant you can select the variant whose state transitions should be displayed.

[STUI-R200-LIB No selection of library in state dependencies] Libraries are not shown (individual state transitions can be viewed in the service property dialog within the library).

State Group

Under State Group you can select the state group whose states and state transitions you wish to display.

Show Service Names

(context menu) toggles to show...

  • the names of the diagnostic class, diagnostic instance and the service, e.g. "Session: Default Session: Start"
  • the signature (service prefixes), e.g. "10 01"

Colored Transitions

(context menu) fills in the edges of the graph with color.

This makes the graph easier to read, especially when there are many state transitions.

The transition of each state change which is performed using the same service is colored with the same color (differing from all other transition colors). E.g. all transitions of the service $10 01 are colored blue. No other transition is colored blue.

Tooltip

The view provides a tooltip for nodes: which services may be executed within this state (compressed view like in RTF export).

Example:

12 34 DiagClass/Instance/Read
15 xx DiagClass/*/Write

Overview (Tabular)

State Dependencies Overview (Tabular)

The overview shows all services in rows, grouped by diagnostic classes. The diagnostic class is shown in a path like notation, e.g. "Sessions/*/Start":

  • "Session": the diagnostic class
  • "*": any diagnostic instance
  • "Start": the service

The diagnostic instance names are shown below the line of the diagnostic class:

  • "Default Session"
  • "Programming Session"
  • "Extended Diagnostic Session"

The right-most columns show the states of the state groups.

After having opened the view, the maximally compressed view is shown. This means: if all services of one Used ProtocolService are of the same behavior, then only that one is shown as a representative. It can be opened and closed.

If the behavior of a service differs, and the node is closed, then the representative behaviour is marked as "(mixed)".

The table can be sorted by clicking on the column-headers

Cell Values

Each cell defines...

  • if the ECU is in the given state (column),
  • for the given service (row)

  • whether the service...

    • is blocked ("no"), or
    • may be executed without a transition ("yes"), or
    • may be executed, and if successfully executed, the ECU shall transit to another state.

Show Service Addressing

Toggles display of addressing information as a suffix in the first column "Service/Job". This info is also shown in the diagnostic instance view at the service icons.

Extend All Nodes

Shows all services in all diagnostic instances.

Collapse All Nodes

Shows only the lines for diagnostic classes.

Collapse State Columns to the Left

If the document contains a large number of states, the table in the tabular view may become very wide. For the states at the right end of the table, their context from the most left columns may not be visible any more.

Using the context menu (right mouse) entry "Collapse State Columns to the Left", you can collapse all states columns to the left of the selected column.

Extend all Columns

Expands all state columns (if collapsed as described in the previous chapter).

Editing (Tabular)

State Dependencies Editing (Tabular)

The table overview shows all services in rows, in a path like notation, e.g. "Sessions/Default Session/Start":

  • "Session": the diagnostic class
  • "Default Session": the diagnostic instance
  • "Start": the service

The right-most columns show the states of the state groups.

For details on columns and context menu actions, see the Overview chapter above.

Using two-stage-sorting, you can get complex information, e.g. questions like “Which services of a specific Diagnostic Class are not executable within a certain state?”.

Edit

To modify a state transition, select the respective cell, then click again or press F2.

You can select multiple lines in a column to modify the transition for a given state (column) for multiple services (rows).

Write-Protection

For write-protection of columns, see Editing of State Transitions.
