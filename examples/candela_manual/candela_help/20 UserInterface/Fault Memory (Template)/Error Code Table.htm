Error Code Table (in Template)

See also the Error Code Table feature.

The chapter "Error code table" of a CANdela template lets you edit the columns of the DTC table of a fault memory (in Expert View only).

Error Code Table

Supported Fault Memory

Selects the fault memory supported by the template with its bit length.

For...

  • Normal Fault Memory, bit lengths 16 and 24 are available,
  • OBD Fault Memory, only the 16-bit length is available.

Consistency condition: this length information must be consistent with the length of proxy components with semantics "dtc" in the Protocol Services.

Columns of the DTC Table of Fault Memory

The combobox lets you select between two lists: DTC Colums for the Normal and for the OBD2 Fault Memory.

Each list displays and provides editing of the DTC columns.

Convention

Shows and edits the Convention [DTCC-R060] of the DTC Column.

Name

Shows and edits the Name [DTCC-R020-Name] of the DTC Column.

[ECT-R110] when you modify the DTC Column name within the list, CANdelaStudio shows a hint that the change may result in a change of the qualifier, with possible data loss when you transport DTCs between documents.

Type

Shows the Type [DTCC-R010] of the DTC Column.

You cannot modify the type of an existing DTC Column.

Display

Shows and edits the Display Format [DTCC-R070] of the DTC Column.

Note: editing is disabled if the Type allows only a single Display Format.

Default Value

Shows and edits the Default Value [DTCC-R080] of the DTC Column.

Value May Be Duplicate

Shows and edits the "may be Duplicate" [DTCC-R050] property of the DTC Column.

Note: if true, the cell value...

  • specifies that a given value may occur at multiple DTCs,
  • not that a single DTC can have multiple values.

Description

Shows and edits the Description [DTCC-R020] of the DTC Column.

Button "New"

Clicking the button

  1. shows a dialog to specify the type of the DTC column.
  2. Then CANdelaStudio shows the "Properties of column..." dialog.

Button "Properties"

Clicking the button shows the "Properties of column..." dialog.

The dialog lets you edit the properties of the DTC column.

[ECT-R210] when you modify the DTC Column qualifier within the dialog, CANdelaStudio shows a hint about possible data loss when you transport DTCs between documents (cf. [ECT-R110] for editing within the list).

  • CANdelaStudio shows the hint only when you modify the qualifier (CDS-41199 9.1).
