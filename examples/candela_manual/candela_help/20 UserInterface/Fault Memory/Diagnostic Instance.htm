Fault Memory (Diagnostic Instance)

In CANdelaStudio, you edit the Fault Memory of the ECU in a special diagnostic instance.

CANdelaStudio shows the Fault Memory diagnostic instance in the subchapter "Supported diagnostic classes" of the base variant or of an extended variant or library.

Fault Memory Diagnostic Instance

Because the Fault Memory services are special, the entry mask of the fault memory diagnostic instance contains the following special Tab pages. The name of the pages may vary, they are defined in the template.

  • DTC table: contains a table in which you can enter DTC codes, error texts, test conditions, conditions for setting and resetting events etc. (as defined in the tempate).
    • The DTC table represents a data object (typically 3 bytes on the line). You can access the properties of this data object via the context menu (right mouse) in the DTC table.
  • Group of DTC
  • Status of DTC
  • Snapshot Data (or Environment Data)
  • AUTOSAR Fault Memory: the "camera" button shows the "Snapshot Records" page [SRUI-R010]
  • AUTOSAR Fault Memory: the "statistics" button shows the "Extended Data Records" page [EDUI-R010]

Failure Type Bytes (FTB) or Failure Mode Identifiers (FMI) are only used if the template allows, see at the DTC Feature.
