Snapshot Data

The following describes the user interface for snapshot data defined within the service structure in a diagnostic instance (based on a Multiplexer in the Protocol Service).

For the user interface of the specific AUTOSAR data model available since CANdelaStudio 13, see the AUTOSAR Fault Memory GUI.

Overview

A Service with Snapshot Data ("ww")

Occurrences of a Multiplexer component in the Protocol Service are displayed and modified in the diagnostic instance ("ww" in the screenshot above):

Snapshot Data in a Diagnostic Instance

The name of the page in the diagnostic instance (e.g. "Snapshot data") is defined in the template and may vary.

The "(ww)" identifies the Protocol Service Components that represent the snapshot data. The "w" character has no meaning in itself and may change; CANdelaStudio just uses it to distinguish it from other Protocol Service components.

DTC

Shows all DTCs from the DTC list, and a special first entry shown as "(Default)".

Snapshot data specified for "(Default)" automatically applies to all DTCs for which you do not specify "individual" snapshot data.

DTCs that have individual snapshot data are shown with a "*" in front.

Edit Ranges

The entries in the list at bottom left are single DTCs by default for which you specify snapshot data in the list at bottom right.

Beginning with the DTC selected in the list - not "(Default)" - you can specify a range of DTCs that shall have the same snapshot data. A popup dialog lets you select the end of the range. Possible values are all DTCs following the selected one up to the first following DTC that has individual snapshot data.

To get rid of a range definition and enable snapshot data for each individual DTC from the range, just specify the start to be the end range, too.

Use Default

Specifies that snapshot data for the selected DTC is taken from the "(Default)" entry.

If the "(Default)" entry is selected in the left list, "Use Default" is the only possible setting.

When "Snapshot Data Specific for DTC..." is set, and you click "Use Default", CANdelaStudio confirms because all data objects defined in the telegram table will be deleted, and the DTC will fall back to the data defined for "(Default)".

Snapshot Data Specific for DTC...

Specifies that snapshot data for the selected DTC is described in the telegram table at the bottom.

Copy into Selected Environment Data

(context menu of telegram table)

Lets you copy data objects from one DTC (or range of DTCs) to other DTCs. Lets you select the DTCs to copy data into.

Create All Missing Specific Snapshot Data

(context menu of telegram table)

Sets all DTCs from "Use Default" to "Snapshot Data Specific for DTC...".

Delete All Specific Snapshot Data (Use Default)

(context menu of telegram table)

Sets all DTCs from "Snapshot Data Specific for DTC..." to "Use Default", deletes all data objects in the individual telegram tables.

This is the reverse of the previous operation.
