19 06 Wizard (CDS-11966 6.5)

The following describes the user interface for Extended Data defined within the service structure in a diagnostic instance (based on a Multiplexer in the Protocol Service).

For the user interface of the specific AUTOSAR data model available since CANdelaStudio 13, see the Extended Data Records (v13, AUTOSAR) page.

See also

  • the 19 06 Wizard Data Model
  • the introduction to Fault Memory.

Overview

The dialog lets you edit the dependency of Extended Data Record Numbers (shown as columns) on DTCs (shown as rows).

Dialog "Edit Dependencies"

To make the dialog visible, the protocol services $19 $04 and $19 $06 must be defined in a specific way, see the data model.

You will find a detailed description of the required layout also in Application Note AN-IDG-1-010 "How to create UDS protocol services 19 04 and 19 06", which you can download at the Vector Download Center.

The dialog is not available if the protocol services are setup for the new fault memory data model of CANdelaStudio 13.

The dialog is available in Fault Memory in the page for the last component of the 19 06 request, via a button "Edit":

Button "Edit" to Open the "Edit Dependencies" Dialog

Note: do not create/delete Record Numbers after you have modified cells in the table. The dialog does not support this - it will show a warning.

Filter (DTC)

Filters the DTCs shown in the list.

Record Number

The edit field specifies the argument for button "New" and "Delete".

Button "New"

Creates a new Record (i.e. column) with the Number specified in the "Record Number" edit field.

Button "Delete"

Deletes the Record (i.e. column) with the Number specified in the "Record Number" edit field.

Table

The table allows multi-selection and multi-editing (via F2).

To modify a cell value, click into a cell, then click again or press F2. You can also select multiple lines and modify their values in the selected column altogether.

DTC (Rows)

Each row represents a DTCs. The first (leftmost) column of the table shall contain the DTC numbers read-only. The format of the DTC numbers must be the same as the format of the DTC numbers in the DTC overview.

The heading of the first column shall be the same as the corresponding column heading of the DTC overview.

Extended Data Record Numbers (Columns)

The headings of the further columns contain the record numbers taken from the “ExtendedDataRecordNumbers” Master data type.

Extended Data Record Number Is Supported (Cells)

The columns to the right of the first column shall contain dependency information for each extended data record number using strings

  • “yes” (= DTC supports record number) and
  • “no” (= DTC does not support record number).

When clicking on a cell or pressing F2 in the table, a combo box shall appear containing the “yes” and “no” strings.

Diagnostic Instance

In the property page of the available snapshot / extended data record numbers of the fault memory diagnostic instance, if the document contains objects as defined by the data model definitions D001 through D004:

  • CANdelaStudio sets the radio buttons (“Use default”, …) and the telegram table insensitive;

  • CANdelaStudio shows a button [Edit…] to the right of the button “Range”, opening the above dialog.

OK

After you click "OK", ...

  • CANdelaStudio generates new text tables as described in the data model chapter.
  • It reports the names with a link in the output window.
  • The link lets you navigate directly to the text table in the "Data types" section, where you can adapt the text table name.
