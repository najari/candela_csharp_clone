Diagnostic Instance Property Page "AUTOSAR Fault Memory" (CDS-71541 v13)

[DIUI-R350] For Protocol Services setup according with AUTOSAR (shown as "sr", "sd"...):

  • if a Fault Memory Diagnostic Instance has a Snapshot Records List (see [SR-R030]),
  • the diagnostic instance property sheet...
  • shows an additional TAB "AUTOSAR Fault Memory"

[DIUI-R360] The TAB contains a radio group for the Snapshot Numeration Type [DI-R310]:

  • Values:
    • "Configured"
    • "Calculated"
  • The property is modifiable in Standard View.
  • If the Snapshot Numeration Type is "Configured",
    • and the Snapshot Record List [SR-R030] contains an UDS Snapshot Record [SR-R130-UDS],
    • then the radio group is insensitive,
    • the dialog contains a static text like
      "(not modifiable while configured UDS Snapshot Records exist)"
  • A change triggers the operation [DIOP-R310] or [DIOP-R350].

[DIUI-R355] The TAB contains an edit control for the Default Number of Calculated Snapshot Records (Numeration Type "Calculated") [DI-R320].
