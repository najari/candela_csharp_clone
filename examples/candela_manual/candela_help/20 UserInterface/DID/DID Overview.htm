DID Overview (8.5)

The DID overview shows...

  • for all DIDs of the document
  • in which libraries/variants they occur (= yes/no), and
  • in which libraries/variants they have the same properties and data (= shown on the same line).

Using the context menu on a cell, you can directly navigate to the DID in the respective library/variant.

The filter at top right provides convenient search for a DID and data objects of a DID.

DID Overview

[DIDOV-R610]: in the tree, CANdelaStudio shows a top-level node “DID Overview”, see [TREE-R010].

[DIDOV-R630] The right side contains a list of DIDs in libraries/variants, like in DTC Overview.

[DIDOV-R640] The list shows one line per DID that has identical properties and data (with OID and TextID differences ignored)

  • Future: may distinguish DIDs that are referenced (as of [DID-R040]) vs. ones with just identical properties.

[DIDOV-R650] List columns:

  • [DIDOV-R650-ID] “Identifier”
  • [DIDOV-R650-Name] “Name”
  • [DIDOV-R650-Var] One column per library/variant,
    • [DIDOV-R650-yes] with “yes” if the DID is in that object, otherwise “no”.
    • For the display of libraries, see the checkbox [DIDOV-R670] below.
    • Order of columns: according with [LIB-R060] and [DID-D300].
    • [DIDOV-R650-Unique] (CDS-70864 v12) If objects have the same name, the column header of each one except the first...
      • gets the suffix " (Library)" or " (Variant)";
      • if the resulting name is still duplicate, the dialog adds a number like " (1)", with the number increased until the name is unique.
      • Note: in a valid document, a name can be duplicate only at one library and one variant [LIB-R012-bVar].
  • [DIDOV-R650-Data] a column “DID Data”
    • format see [DID-R155-DefaultDisplay]
    • CANdelaStudio shows the column iff. the checkbox [DIDOV-R660] described next is checked.

[DIDOV-R660] The dialog provides a checkbox “Show DID Data”

  • it controls whether CANdelaStudio shows the above column "DID Data" [DIDOV-R650-Data].

[DIDOV-R670] The dialog provides a checkbox “Show Libraries”.

  • The list shows columns for libraries [DIDOV-R650-Var] iff. the checkbox is checked.

[DIDOV-R620] Action to go to the selected DID:

  • For each library/variant, the context menu contains an item
    • “Go To <Identifier> <Name> in <Library/Variant Name>”
    • in the order of the columns [DIDOV-R650-Var].
    • If a DID is referenced in multiple libraries/variants, a menu item is shown for each one.
    • If you select the menu item, CANdelaStudio navigates to the DID in the DID list in the respective library/variant.
  • If you open the context menu in the column of a library/variant, it contains the item for this object only (like in DTC overview).
