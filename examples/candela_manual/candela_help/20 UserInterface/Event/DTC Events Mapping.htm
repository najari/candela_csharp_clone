DTC Events Mapping (CDS-42224 v12)

See also the Events List, the Events Introduction, the detailed Events Data Model and the Event Operations.

The DTC Events Mapping page is located in the right side of a Fault Memory diagnostic instance, opened via button at the bottom.

DTC Events Mapping

[EVUI-R230] The DTC Events Mapping page shows from left to right:

  • Left: Unmapped DTCs (below)
  • Middle: DTCs with their mapped Events (below)
  • Right: Unmapped Events (below)

Conditions for Modifying Operations

See [EVUI-R010] for Authorization.

[EVUI-R232] If the Boolean flag Supports Events [EV-R010] is false, the respective operation in the DTC Events Mapping page is insensitive (as noted in details below).

Two-List Focus

[EVUI-R235] In order to support the mapping operation, two of the three lists have focus at any time:

  • [EVUI-R235-DTC] Either the left "Unmapped DTCs" or the middle "Mapped DTCs + Events" list
  • [EVUI-R235-Event] The right "Unmapped Events" list

Motivation:

Example: Two lists with Selection and Focus

  • Focus: usually the one list where e.g. keyboard operations apply
    • (example screenshot above: blue)
  • Selection: within any list, the selected objects
    • (example screenshot above: gray in upper list, blue in lower list)
  • Usually, within a dialog, at most one list has focus
  • ... but the mapping operation needs two objects
  • The dialog shall make clear which objects are affected by the mapping operation.
    • Therefore two lists must have focus.

Left Side: Unmapped DTCs

List

[EVUI-R240] The list "Unmapped DTCs" shows all DTCs defined in the diagnostic instance for which no Event exists that references [EV-R230] the DTC.

  • [EVUI-R240-MultiSel] The list provides multi-selection.
  • [EVUI-R235] Either the "Unmapped DTCs" or the middle "Mapped DTCs + Events" list has focus.

Map

[EVUI-R242] Button "Map"

  • If one DTC is selected in the left "Unmapped DTCs" list, ...
    • lets the Events selected in the right "Unmapped Events" list reference [EV-R230] the selected DTC.
  • See also Authorization [EVUI-R010]
  • The button is insensitive if any of the two involved lists is empty:
    • the "Unmapped DTCs" list,
    • the "Unmapped Events" list
  • The button is insensitive if more than one DTC is selected in the "Unmapped DTCs" list.
  • As a result,
    • the DTC and Events will be shown selected in the "Mapped DTCs + Events" list
    • for the resulting selection in the "Unmapped Events" list, see [UI-R340-SelDel]
    • the middle list has focus (cf. two-list focus [EVUI-R235-DTC])
  • Tooltip: "Maps selected Events to the first selected DTC in the focussed other list."

Map with new Events

[EVUI-R244] Button "Map with new Events"

  • for each DTC selected in the "Unmapped DTCs" list,
  • if an Event exists whose name matches the DTC error text,
    • if it is unmapped: maps the existing Event to the DTC;
    • if it is mapped: skips it;
  • if no such Event exists: creates a new Event with the name set to the DTC error text, and maps it.
  • For details, see Event operation [EVOP-R244].
  • See also Authorization [EVUI-R010]
  • The button is insensitive if...
    • the "Unmapped DTCs" list is empty, or
    • [EVUI-R232] operations are insensitive since the flag "Supports Events" [EV-R010] is false
  • As a result of the operation,
    • the DTCs and Events will be shown selected in the middle "Mapped DTCs + Events" list
    • the middle list has focus (cf. two-list focus [EVUI-R235-DTC])
  • Tooltip: "Maps existing Events whose name matches the DTC error text; creates and maps new Events for the remaining DTCs."

Filter

[EVUI-R246] If the filter edit control contains text, the "Unmapped DTCs" list shows only DTCs that match [LIST-R500] this text.

  • [EVUI-R246-Sens] The edit control is sensitive even if the list is empty.

Clipboard Operations

[EVUI-R247] No clipboard operations available.

Middle: Mapped DTCs + Events

List

[EVUI-R260] The list "Mapped DTCs + Events" is based on the reference from an Event to a DTC [EV-R230] in the data model.

  • [EVUI-R260-Combined] For a DTC referenced by one Event, the list shows DTC and Event combined in one line.
  • [EVUI-R260-Multiple] For a DTC referenced by multiple Events, the list shows...
    • [EVUI-R260-DTC] first the DTC on a line, without Event information;
    • [EVUI-R260-Event] then each Event on one line, without DTC information.
  • [EVUI-R260-MultiSel] The list provides multi-selection.
  • [EVUI-R260-SelCombined] When you select a DTC referenced by multiple Events, the list automatically selects all the referencing Events, and vice versa.
    • Motivation: it might be confusing to select the referenced DTC but none or only part of the Events that reference the DTC.
  • [EVUI-R235] Either the "Unmapped DTCs" or the middle "Mapped DTCs + Events" list has focus.

Map

[EVUI-R261] Button "Map"

  • If one DTC is selected in the middle "Mapped DTCs + Events" list, ...
    • lets the Events selected in the right "Unmapped Events" list reference [EV-R230] the selected DTC.
  • See also Authorization [EVUI-R010]
  • The button is insensitive if any of the two involved lists is empty:
    • the "Mapped DTCs + Events" list,
    • the "Unmapped Events" list
  • The button is insensitive if more than one DTC is selected in the "Mapped DTCs + Events" list.
  • As a result,
    • the mapped Event will be shown selected in the "Mapped DTCs + Events" list
    • for the resulting selection in the lists, see [UI-R340-SelDel]
    • the middle list has focus (cf. two-list focus [EVUI-R235-DTC])
  • Tooltip: "Maps selected Events to the selected DTC."

Unmap

[EVUI-R262] Button "Unmap"...

  • for the Events selected [EVUI-R260-MultiSel] in the "Mapped DTCs + Events" list,
  • resets the reference [EV-R230]
  • using operation [EVOP-R240], see also Authorization [EVUI-R010].
  • The button is insensitive if the "Mapped DTCs + Events" list is empty.
  • As a result, ...
    • the Events will be shown selected in the "Unmapped Events" list;
    • DTCs for which all Events have been unmapped will be shown selected in the "Unmapped DTCs" list.
    • Remaining mapped Events will be shown selected,
      • combined in one line [EVUI-R260-Combined] or
      • on separate lines [EVUI-R260-Event], as described above
  • Tooltip: "Removes the DTC reference from the selected Events."

Filter

[EVUI-R266] If the filter edit control contains text, the "Mapped DTCs + Events" list shows...

  • lines where the text of the object itself (DTC or Event) matches [LIST-R500]
  • [EVUI-R266-DTC] additionally: those DTC lines [EVUI-R260-DTC] where
    • the text of the DTC itself does not match
    • but any of the texts of the referencing Events matches.
  • [EVUI-R266-Sens] The edit control is sensitive even if the list is empty.

Clipboard Operations

No clipboard operations available.

Right Side: Unmapped Events

List

[EVUI-R280] The list "Unmapped Events" shows all Events defined in the diagnostic instance [EV-R020] which do not reference [EV-R230] a DTC.

  • [EVUI-R280-MultiSel] The list provides multi-selection.
  • [EVUI-R235] The "Unmapped Events" list always has focus.

Map

[EVUI-R282] Button "Map"...

  • lets the Events selected in the right "Unmapped Events" list...
  • reference [EV-R230] the first selected DTC in...
    • the left "Unmapped DTCs" list, or
    • the middle "Mapped DTCs + Events" list,
    • whichever has focus, see [EVUI-R235-DTC] above.
  • See also Authorization [EVUI-R010]
  • The button is insensitive if any of the two involved lists is empty:
    • the focussed one of the "Unmapped DTCs" or "Mapped DTCs + Events" list,
    • the "Unmapped Events" list.
  • As a result,
    • the DTC and Events will be shown selected in the "Mapped DTCs + Events" list
    • for the resulting selection in the other lists, see [UI-R340-SelDel]
  • Tooltip: "Maps selected Events to the first selected DTC in the focussed other list."

Map with new DTCs

[EVUI-R284] Button "Map with new DTCs"

  • for each Event selected in the "Unmapped Events" list,
  • if a DTC exists whose error text matches the Event name, maps the Event to the existing DTC;
  • otherwise creates a new DTC with error text set to the Event name, and maps it.
  • For details, see Event operation [EVOP-R284].
  • See also Authorization [EVUI-R010] and the conditions in [DTCOP-R010]
  • The button is insensitive if the "Unmapped Events" list is empty.
  • As a result,
    • the DTCs and Events will be shown selected in the middle "Mapped DTCs + Events" list
    • the middle list has focus
    • for the resulting selection in the other lists, see [UI-R340-SelDel].
  • Tooltip: "Maps existing DTCs whose error text matches the Event name; creates and maps new DTCs for the remaining Events."

Filter

[EVUI-R286] If the filter edit control contains text, the "Unmapped Events" list shows only Events that match [LIST-R500] this text.

  • [EVUI-R286-Sens] The edit control is sensitive even if the list is empty.

Clipboard Operations

No clipboard operations available.

DTC Representation

[EVUI-R400] Depending on the DTC Format [DOC-R400] specified in File | Properties | Display of DTCs [DOCUI-R610], CANdelaStudio shows DTCs in the dialog as follows:

  • for ISO 14229-1
    • Error Code - depending on File | Options | Display | Format of Error Codes:
      • Hexadecimal: 3 byte hex
      • SAE: 3 byte SAE
    • Error Text
  • for ISO 15031-6 / SAE J2012
    • Error Code - depending on File | Options | Display | Format of Error Codes:
      • Hexadecimal: 3 byte
      • Hexadecimal: 2 byte hex, 1 byte hex
      • SAE: 2 byte SAE, 1 byte hex
      • like: "0x0007, 0x01"
    • Error Text
  • for SAE J1939-73
    • Error Code:
      • 19 bit decimal, 5 bit decimal
      • like: "0x000892 (264192, 18)"
    • Error Text
