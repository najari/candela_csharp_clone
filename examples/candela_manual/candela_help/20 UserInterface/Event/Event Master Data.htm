Event Master Data (CDS-42224 v12)

See also the Events List, the Events Introduction and the detailed Events Data Model.

The Events Master Data page is located in the right side of a Fault Memory diagnostic instance, opened via button at the bottom.

It shows the Event Master Data [EV-D040], i.e. master lists used for Event properties.

Event Master Data

Conditions for Modifying Operations

See [EVUI-R010].

Operation Cycle

[EVMUI-R500] Defines the list of Operation Cycles [EV-R500] in the diagnostic instance.

See operations [EVOP-R510]ff.

Indicator

[EVMUI-R600] Defines the list of Indicators [EV-R600] in the diagnostic instance.

[EVMUI-R630 Delete] When an Indicator is referenced by an Indicator Connection [EV-R140], CANdelaStudio shows a prompt indicating that the Indicator is referenced.

See operations [EVOP-R610]ff.

Counter-Based Debounce Algorithm

[EVMUI-R1200] Defines the list of Counter-Based Debounce Algorithms [EV-R1200] in the diagnostic instance.

[EVMUI-R1230 Delete] When a Counter-Based Debounce Algorithm is referenced by an Event [EV-R220], CANdelaStudio shows a prompt indicating that the Debounce Algorithm is referenced.

See operations [EVOP-R1210] and [EVOP-R1120]ff.

Time-Based Debounce Algorithm

[EVMUI-R1300] Defines the list of Time-Based Debounce Algorithms [EV-R1300] in the diagnostic instance.

[EVMUI-R1330-Delete] When a Time-Based Debounce Algorithm is referenced by an Event [EV-R220], CANdelaStudio shows a prompt indicating that the Debounce Algorithm is referenced.

See operations [EVOP-R1310] and [EVOP-R1120]ff.

Condition

[EVMUI-R700] Defines the list of Conditions [EV-R700] in the diagnostic instance.

[EVMUI-R730 Delete] When a Condition is referenced by an Event as Enable Condition [EV-R200] or Storage Condition [EV-R210], or by a Condition Group [EV-R830], CANdelaStudio shows a prompt indicating that the Condition is referenced.

See operations [EVOP-R710]ff.

Condition Group

[EVMUI-R800] Defines the list of Condition Groups [EV-R800] in the diagnostic instance.

A Condition Group references the Conditions defined in the Condition list [EVMUI-R700] described above.

[EVMUI-R830 Delete] When a Condition Group is referenced by an Event as Enable Condition [EV-R200] or Storage Condition [EV-R210], CANdelaStudio shows a prompt indicating that the Condition Group is referenced.

See operations [EVOP-R810]ff.
