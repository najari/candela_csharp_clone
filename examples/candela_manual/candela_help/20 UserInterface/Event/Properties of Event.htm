Events Page

Introduction

[EVUI-R2000] The property sheet to the right provides editing of the properties also shown in the Event list, plus Qualifier and Description.

[EVUI-R2010] The property sheet supports mass editing:

If you select multiple Events in the list:

  • if all selected Events have the same value,
    • the control in the sheet shows that value;
    • when you enter a different value, CANdelaStudio assigns that value to all selected Events.
  • if the selected Events have different values,
    • the control in the sheet shows an "indifferent" state;
    • when you enter a value, CANdelaStudio assigns that value to all selected Events;
    • the control does not provide a way back to the "indifferent" state.

For details, see [UI-D410] in the Basic User Interface Rules.

Name, Qualifier, Description

[EVUI-R2100] The controls show the Event name, qualifier and description [EV-R100].

See [EVUI-R100] for the Name column of the Event list.

The description can be multi-line, but plain text only (no rich-text).

[EVUI-R2100-Desc] The control for editing the description accepts line-breaks via key ENTER and Ctrl-ENTER (CDS-71939 v13).

Event Attributes

Event attributes are not available in the property page.

You may use the Attribute Overview on the Diagnostic Instance (e.g. via the context menu of the tree node).

Indicator Connections

See also the representation [EVUI-R140] in the Event list.

[EVUI-R2140] The list shows and edits the Indicator Connections [EV-R140] of the Event, which associates the following mandatory properties:

  • [EVUI-R2140-Indicator] the Indicator [EV-R300], from the list defined in the Event Master Data [EVMUI-R600]
  • [EVUI-R2140-Behavior] a Behavior [EV-R310], predefined by AUTOSAR
  • [EVUI-R2140-HealingCycle] a Healing Cycle [EV-R320], from the list of Operation Cycles defined in the Event Master Data [EVMUI-R500]
  • [EVUI-R2140-Threshold] a counter threshold [EV-R330] for the Healing Cycle
  • [EVUI-R2140-Sort] sorted by Indicator name

Conditions:

  • [EV-R140-Card] The list may be empty.
  • [EV-R140-unique] A given Indicator can be used only once for the same Event.
  • [EV-R140-noSort] As a default, the list is sorted by the Indicator name.

Add

[EVUI-R2142] Button "+" (Add) adds a further Indicator Connection to the list.

  • [EVUI-R2142-Insens] If all defined Indicators [EV-R600] have already been used in the list, the button is insensitive.
  • [EVUI-R2142-No] if no Indicator or no Operation Cycle has been defined, Add is insensitive.

Modify

[EVUI-R2144] You can modify all properties directly in the list.

  • [EVUI-R2144-Unique] >the combo-box for "Indicator" shows only Indicators not yet used in the list,
    • since a given Indicator can be used only once for the same Event [EVUI-R2144-Unique].

Remove

[EVUI-R2146] Button "x" (Remove) removes the selected Indicator Connections from the list, with confirmation [EVUI-R015].
