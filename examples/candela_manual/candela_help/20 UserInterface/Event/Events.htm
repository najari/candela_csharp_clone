Events Page

[EVUI-R005] The Events page is located in the right side of a Fault Memory diagnostic instance, opened via button at the bottom.

  • [EVUI-R005-OBDII] The Events page is not available in a diagnostic instance with OBDII DTCs.
    • Reason: Events are not allowed in an OBDII Fault Memory Diagnostic Instance [EV-R020-OBDII], so an Event cannot reference an OBDII DTC [EV-R230-OBDII].

The Events page shows...

  • a list of Events (left; details follow below)
  • a property sheet with Event properties (right; described in Properties of Event)

Authorization

The operations in the Event dialogs are subject to authorization, see [DIOP-D010].

[EVUI-R010] In a diagnostic instance where the authorization forbids operations, ...

  • the dialogs offer the operation anyway (e.g. with buttons sensitive), but shows a hint.
  • This includes showing the "magic line" ("Create here to create a new element").
  • [EVUI-R010-MultiSel] For multiple selected objects, if an operation is forbidden on some objects, CANdelaStudio performs the operation on the rest and finally informs about the remaining unmodified objects (see the Basic User Interface Rules [UI-R340-SelDel]).

Confirmation

[EVUI-R015] Before any deletion, CANdelaStudio shows a confirmation dialog which allows to cancel the operation.

Event List

[EVUI-R020] The Event List shows and edits the Events [EV-R020] defined in the diagnostic instance.

  • [EVUI-R020-Sort] By default, the list is sorted by name.
  • [EVUI-R020-New] Clicking the magic line "Please click here..." creates a new Event [EVOP-R020].
  • [EVUI-R020-Del] Pressing the Del key deletes the selected Events [EVOP-R040], with confirmation [EVUI-R015].

[EVUI-R025] Pressing the F1 key leads to the page here.

Hint for Supports Events

[EVUI-R030] If...

  • the document property Supports Events [EV-R010] is false
    • (modifiable in Expert View in File | Properties | Document Info [DOCUI-R600]),
  • then CANdelaStudio shows a hint above the Event list:
    • "This document does not support Events."
    • with an info button that shows an explanation in a tooltip.

Name

[EVUI-R100] The Name column shows the Event name [EV-R100], which must be unique [EV-R100-Qualified] in the list.

Kind

[EVUI-R110] The Kind column shows the Event kind [EV-R110]:

  • "SWC" (Software Component)
  • "BSW" (Basis Software)

Operation Cycle

[EVUI-R120] The Operation Cycle column shows the optional Operation Cycle [EV-R120] of the Event.

Failure Cycle Counter Threshold

[EVUI-R130] The column shows the optional Failure Cycle Counter Threshold [EV-R130] of the Event.

Indicator Connections

[EVUI-R140] The column shows the list of Indicator Connections [EV-R140]:

  • possibly empty
  • comma separated
  • read-only
  • sorted by Indicator name
  • in the data model, these are the names of the Indicators referenced in Indicator Connections [EV-R300] of the Event.

You can edit the list in the property sheet, see [EVUI-R2140].

Prestore Freeze Frame ("prestorageFreezeFrame")

[EVUI-R150] The column shows the mandatory Freeze Frame Prestored flag [EV-R150], i.e. whether the Event uses a prestored freeze frame.

... in Memory ("Freeze Frame Prestored nonvolatile", "prestoredFreezeframeStoredInNvm")

[EVUI-R155] If the Freeze Frame is prestored (as of the previous column), the column shows one of the available values "undefined", "volatile" and "non-volatile".

If the Freeze Frame is not prestored, the column value should be "undefined" (CANdelaStudio does not enforce this, [EV-D155]).

Clear Fault Memory Allowed ("eventClearAllowed")

[EVUI-R165] The column shows one of the available values "always" and "requires callback execution" for the Clear Allowed [EV-R165] property.

If Clear Denied ("Clear Behavior", "clearEventBehavior")

[EVUI-R170] The column shows one of the available values "undefined", "no status byte change" and "reset operation cycle and readiness" for the Clear Fault Memory Allowed (Clear Behavior) [EV-R170] property.

Recoverable in Same Operation Cycle

[EVUI-R190] The column provides a combo-box for selecting from the available values "undefined", "no" and "yes" for the Recoverable in Same Operation Cycle [EV-R190] property.

Enable Conditions

[EVUI-R200] The column shows the Condition or Condition Group of the Event [EV-R200].

Condition Groups are marked by a special symbol .

It provides a combo-box for selecting from the Conditions [EV-R700] and Condition Groups [EV-R800] defined in the Event Master Data page [EVMUI-R700] and [EVMUI-R800].

You may select no Condition or Condition Group.

Note: in the CANdela data model, you can directly reference a Condition, as opposed to AUTOSAR DEXT where the reference is always to a Condition Group, see [EV-R720-Condition].

Storage Conditions

[EVUI-R210] The column behaves exactly as the previous column "Enable Conditions".

Note: in the CANdela data model, the same Condition can be used for Enable Condition and for Storage Condition, it does not have this type in itself which is the case in AUTOSAR DEXT, see [EV-R215] and [EV-R720-Use].

Debounce Algorithm

[EVUI-R220] The column shows the optional Debounce Algorithm of the Event [EV-R220].

It provides a combo-box for selecting from the Debounce Algorithms defined in the Event Master Data page: Counter-Based Debounce Algorithms [EVMUI-R1200] and Time-Based Debounce Algorithms [EVMUI-R1300]

You may select no Debounce Algorithm.

Clipboard Operations

[EVUI-R500] Clipboard operations available:

  • [EVUI-R520] Copy [MENU-R413] - same as "Copy" [EVUI-R620] below
  • [EVUI-R530] Paste [MENU-R415] - same as "Paste" [EVUI-R630] below
  • [EVUI-R540] Delete [MENU-R420] - same as "Delete" [EVUI-R640] below

Context Menu

[EVUI-R600] Context Menu

[EVUI-R620] Copy: copies the selected Event(s) to the clipboard.

[EVUI-R630] Paste: pastes Event(s) from the clipboard into the list.

  • The menu item is insensitive if no Events were copied previously.
  • Uses operation [EVOP-R050] (within diagnostic instance) or [EVOP-R060] (across diagnostic instances).
  • The operation preserves a DTC reference, based on the error code, see [EVOP-R060-Ref].
  • If referenced Event Master Data in source and target diagnostic instance is different, ...
    • CANdelaStudio preserves references to Event Master Data, based on the qualifier, see [EVOP-R060-Master].

[EVUI-R640] Delete: removes the selected Event(s), with confirmation [EVUI-R015].

Drag'n Drop

[EVUI-D700] Drag'n drop is not available.
