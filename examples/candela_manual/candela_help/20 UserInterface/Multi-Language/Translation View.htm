Translation View

Languages and Translatable Items

Translation View processes two languages:

  • A reference language (the language in which the document has been opened, the document must be up-to-date with respect to this language)

  • A target language (the document may be up-to-date with respect to this language or not)

Translation View offers a selection of the target language. The selection contains pretty representations of the internally used language codes.

Translation view shows every applicable language string, with the properties:

  • language string of reference language (read-only)
  • isUpToDate of target language (can be toggled manually)
  • language string of target language,
  • is the string rich-text ("structured") or plan-text ("simple")
  • the status of the string with respect to the internal Translation Memory
  • the object type (e.g. "data object")
  • the path to the translatable (read-only).

If a language string has been changed in editing, CANdelaStudio automatically sets it up-to-date.

Consistency conditions (e.g. that a name must be unique within a given list) must be respected in each up-to-date language.

There is no unification of language strings that are identical in the reference language. For convenience, there is an "apply to all identical strings in reference language" action (depending on an option in menu Tools|Options|Translation).

Reference Language

An up-to-date language.

Target Language

Any language of the document, this one will be translated.

Update

Updates the list and and re-applies filters.

When CANdelaStudio sets a term translated, and "Show translated terms too" is off, it does not remove the term from the visible list (avoid flickering) but still shows the term with "Translated?" = yes. Only after you press "Update" will CANdelaStudio re-apply the filter and hide translated terms.

Restrict to Variant/Library

[TRV-R200] The list provides an optional filter for a variant/library (CDS-36280 9.1): it shows in a combo-box...

  • the default entry "(Whole document)"
  • each variant
  • each library

[TRV-R210] Effect:

  • With the filter applied, the list contains translatable terms of:
    • objects defined in the variant, e.g. data objects in a telegram table,
    • [TRV-R210-DataTypes] data types referenced from objects within the variant, or transitively referenced from such data types (CDS-71772 v11 P4, v13)
  • The default entry shows terms from all variants, but also from outside variants.
  • Other filters like "Show translated terms too" take effect independently.

Translation Memory: Edit

Opens a dialog to inspect and edit the translated terms.

Translations

Shows the number of terms in the translation memory.

Learn Translation

Extracts the translated terms from the CANdela document and puts them into the separate translation memory.

Translate Document

Processes terms in the CANdela document not yet translated - if a matching term with is found in translation memory, CANdelaStudio takes its translations from the translation memory.

Find

Via menu [MENU-R1590], you open the search dialog for translation view.

Menus

  • [MENU-R940-TrView] Menu item "Plugins (Document)" is not available in Translation View.
