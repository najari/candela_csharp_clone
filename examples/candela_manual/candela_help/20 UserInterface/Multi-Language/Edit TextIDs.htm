Edit TextIDs

See the TextIDs Feature:

  • a CANdela object (e.g. a data object)
  • has a translatable property (e.g. a name, or a description)
  • which is assigned a TextID.

Filter (TextID, Term)

Specifies a filter on the two first columns TextID and Term.

TextID

The TextID of the translatable property.

Term

The translatable property, e.g. a name or a description.

Object Type

The type of CANdela object that owns the translatable property, e.g. a data object.

Path

The path to the CANdela object.

The suffix of the path distinguishes some translatable properties, e.g "#NAME" and "#DESC":

npath://[NRC]General reject#NAME
npath://[NRC]General reject#DESC

Edit TextIDs

[TID-R050] In menu Edit | TextIDs, in documents with both TextID mode "completion only" or "edit", CANdelaStudio does not allow modification (no direct editing, no "Delete all" etc.) of TextIDs at

  1. datatypes imported from ODX ECU-SHARED-DATA (cf. CDS-5624);
  2. an attribute storing units from ECU-SHARED-DATA (cf. CDS-3861 "Selection list for units").
