Properties of Snapshot Record

See also the overview of the v13 Snapshot Records GUI.

Snapshot Records Page

Introduction

[SRUI-R2000] The property sheet to the right provides editing of the properties also shown in the Snapshot Record list, plus Qualifier and Description.

[SRUI-R2010] The property sheet supports mass editing:

If you select multiple Snapshot Records in the list:

  • if all selected Snapshot Records have the same value,
    • the control in the sheet shows that value;
    • when you enter a different value, CANdelaStudio assigns that value to all selected Snapshot Records.
  • if the selected Snapshot Records have different values,
    • the control in the sheet shows an "indifferent" state;
    • when you enter a value, CANdelaStudio assigns that value to all selected Snapshot Records;
    • the control does not provide a way back to the "indifferent" state.

For details, see [UI-D410] in the Basic User Interface Rules.

Number

[SRUI-R2120] The control shows the Snapshot Record Number [SR-R120].

See [SRUI-R220] for the Number column of the Snapshot Record list.

  • [SRUI-R2120-Mod]
    • When you modify the Snapshot Record Number,
    • CANdelaStudio v13 allows only values valid for UDS:
    • not 0x00 (OBD II Freeze Frame)
    • not 0xFF (wildcard in 0x19 0x04 request)

Name, Qualifier, Description

[SRUI-R2130] The controls show the Snapshot Record name, qualifier and description [SR-R110].

See [SRUI-R230] for the Name column of the Snapshot Record list.

The description can be multi-line, but plain text only (no rich-text).

Protocol

[SRUI-R2140] The control shows the Protocol [SR-R130] of the Snapshot Record.

  • See [SRUI-R240] for the Snapshot Records list.
  • See the note [FM-D050] about OBD on UDS.

Storage Trigger

[SRUI-R2150] Shows the Storage Trigger [SR-R150] as a group of radio buttons.

  • See [SRUI-R250] for the Snapshot Records list.

Custom Trigger

[SRUI-R2155] Shows the customTrigger string [SR-R155] as an edit control.

  • The edit control is sensitive iff. Trigger has the value "custom".
  • See [SRUI-R250] for display in the Snapshot Records list.

Updated

[SRUI-R2160] shows the Boolean property Updated [SR-R160] as a checkbox.

  • See [SRUI-R260] for the Snapshot Records list.

Snapshot Record Attributes

Snapshot Record attributes are not available in the property page.

You may use the Attribute Overview on the Diagnostic Instance (e.g. via the context menu of the tree node).
