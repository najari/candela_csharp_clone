Right Side: TAB "Snapshot Records to Store" (Configured)

CANdelaStudio shows this TAB if the Snapshot Record Numeration Type [DI-R310] is "configured".

[SRUI-R810] The TAB shows...

  • a list of Snapshot Records
  • for each Snapshot Record, whether it is stored for the DTC(s) selected in the list of DTCs [SRUI-R600]

UDS Snapshot Data per DTC - right side: Snapshot Records to Store (Numeration Type "Configured")

List Columns

[SRUI-R812] Number

  • shows the Snapshot Record Number [SR-R120]
  • see [SR-R120-DefaultDisplay]

[SRUI-R814] Name

  • shows the Snapshot Record Name

[SRUI-R816] to Store

  • a checkbox
  • checked iff. "Snapshot Record Stored for DTC" [SR-R300] is true
  • If multiple DTCs are selected:
    • see the Basic User Interface Rules [UI-R400].
  • [SRUI-R816-Check] Checking "Stored":
    • Performs operation [SROP-R260]
  • [SRUI-R816-Uncheck] Un-checking "Stored":
    • Performs operation [SROP-R265]

Buttons "Store all" / "Store none"

  • [SRUI-R840] If a filter has been applied,
    • the buttons apply to the reduced list only,
    • therefore the button text changes to "Store all filtered" / "Store none filtered".

Actions

  • [SRUI-R820] Check "to Store"
    • Performs operation [SROP-R260]
    • Applies to all selected DTCs.
  • [SRUI-R825] Un-check "to Store"
    • Performs operation [SROP-R265]
    • Applies to all selected DTCs.
