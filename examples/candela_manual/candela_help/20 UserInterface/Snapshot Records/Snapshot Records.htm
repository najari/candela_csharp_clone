Snapshot Records

This chapter describes the list of Snapshot Records in the TAB Snapshot Records [SRUI-R100].

See also the overview of the GUI Snapshot Records.

Snapshot Records List

List of Snapshot Records

[SRUI-R200] The list of Snapshot Records shows all Snapshot Records defined in the diagnostic instance [SR-R030].

  • [SRUI-R210-Fixed] For Numeration Type Calculated, the list has fixed height: 2 rows (for 0x00, 0xF0).
  • [SRUI-R210] By default, the list is sorted by ascending Snapshot Record Number.
    • cf. [SR-R035] The Snapshot Records have no persistent sort order.
  • [SRUI-R212] The list can be sorted by clicking a header.
    • CANdelaStudio remembers the sort order within the session.
  • [SRUI-R214] The list contains a line "Click here to create a new Snapshot Record".
  • [SRUI-R216] The list supports multi-selection.
  • [SRUI-R218] The list can be filtered by a text control at top right, which applies to all texts shown (including the "custom" prefix [SRUI-R250-custom]).

Toolbar

[SRUI-R205] The toolbar allows to...

  • [SRUI-R205-UDS] create a UDS Snapshot Record, see action [SRUI-R270] below.
  • [SRUI-R205-OBD] create an OBD on UDS Snapshot Record, see action [SRUI-R272] below.
  • [SRUI-R205-Del] delete the selected Snapshot Record(s), see action [SRUI-R275] below.

List columns

  • [SRUI-R220] Number
    • shows the Snapshot Record Number [SR-R120]
    • hexadecimal
    • with leading zero, filled to 2 hex digits
    • e.g. "0x01"
  • [SRUI-R230] Name
    • shows the name [SR-R110] of the Snapshot Record
  • [SRUI-R240] Protocol [SR-R130]
    • "UDS"
    • "OBD on UDS"
  • [SRUI-R250] Storage Trigger [SR-R150]
    • shows the enum value literally
    • [SRUI-R250-custom] except for enum value custom:
      • the prefix "(custom) ",
      • followed by the customTrigger string [SR-R155]
    • See [EDUI-R250] for Extended Data Records
    • See [SRUI-R2150] for display in the Property Sheet.
  • [SRUI-R260] Updated [SR-R160]: "yes"/"no"
    • same as [EDUI-R260] for Extended Data Records
    • See [SRUI-R2160] for display in the Property Sheet.

Actions

  • [SRUI-R270] When creating a UDS Snapshot Record
    • using toolbar [SRUI-R205-UDS] or the the magic line [SRUI-R214],
    • if all valid Snapshot Record Numbers [SR-R120-Range] exist, CANdelaStudio shows a hint and skips creating a new one.
    • [SRUI-R270-Ref] Otherwise, CANdelaStudio decides the Snapshot Record Number based on a Reference Snapshot Record R
      • as described in the Basic User Interface Rules [UI-R335]
      • object: Snapshot Record
      • number: Snapshot Record Number
      • valid range: [SR-R120-Range], minus the OBD on UDS numbers [SR-D120-OBDonUDS].
    • Note: Snapshot Record Numbers are unique [SR-R120-Unique].
    • CANdelaStudio sets the Protocol to "UDS".
    • See operation [SROP-R100].
  • [SRUI-R272] When creating a OBD on UDS Snapshot Record
    • using toolbar [SRUI-R205-OBD],
    • if all valid Snapshot Record Numbers [SR-R120-Range] exist, CANdelaStudio shows a hint and skips creating a new one.
    • If no Snapshot Record with Snapshot Record Number 0x00 exists, uses 0x00,
    • Otherwise, dito for 0xF0.
    • Otherwise, CANdelaStudio decides the Snapshot Record Number as for UDS [SRUI-R270-Ref].
    • CANdelaStudio sets the Protocol to "OBD on UDS".
    • See operation [SROP-R100].
  • [SRUI-R275] When deleting Snapshot Records:
    • If the action deletes the last Snapshot Record for UDS OBD on UDS, CANdelaStudio prompts like
    • "Deleting Snapshot Record(s) will drop all Snapshot Data for OBD on UDS.
      Do you really want to delete the Snapshot Record(s)?"
      • If yes, it adapts the GUI according with [SRUI-R300-OBDonUDS].
    • See operation [SROP-R110].
