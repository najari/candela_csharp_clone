Context Menu

  • [SRUI-R781] Add DIDs...
    • Shows a dialog to select DIDs
    • With the selected DIDs, performs operation [SROP-R225]
  • [SRUI-R785] Remove selected DIDs
    • Performs operation [SROP-R235]
    • Insensitive if the DID list is empty.
      • Sensitive even in multi-selection constellation [SRUI-R775-Diff],
      • deletes all DIDs for each selected DTC.
  • [SRUI-R782] Copy
    • Copies the selected DIDs to the CANdelaStudio clipboard
    • Insensitive if the DID list is empty, or in multi-selection constellation [SRUI-R775-Diff].
  • [SRUI-R783] Paste
    • For the DIDs in the CANdelaStudio clipboard, performs operation [SROP-R225]
    • Insensitive if the clipboard does not contain a DID.
      • Sensitive even in multi-selection constellation [SRUI-R775-Diff],
      • adds to each case individually.
  • [SRUI-R788] Move selected DID up
    • Performs operation [SROP-R200]
    • Insensitive if...
      • the DID list is empty, or
      • in multi-selection constellation [SRUI-R775-Diff], or
      • the selection contains the last DID, or
      • the selection is not continuous (i.e. has not selected DIDs in between)
  • [SRUI-R789] Move selected down
    • Performs operation [SROP-R210]
    • Insensitive: same as "Move up", except:
      • if the selection contains the first DID.
  • [SRUI-R7815] Reset to Default
    • Performs operation [SROP-R250]
    • Insensitive if all selected DTC(s) have Default Snapshot Data [SR-R230-Default]
