List "UDS Snapshot Data per DTC"

See also the overview of the GUI Snapshot Records and the TAB "UDS Snapshot Data per DTC".

[SRUI-R600] List of DTCs with Snapshot Data and Snapshot Records to Store

  • [SRUI-R600-Default] with a special first entry "(Default)"
  • [SRUI-R610-DTCs] The list shows all DTCs defined in the diagnostic instance.
  • [SRUI-R610-Sort] The DTCs are sorted by ascending Code.
    • No sorting by the user.
  • [SRUI-R610-MultiSel] The list supports multi-selection.
  • [SRUI-R612] The list can be filtered by a text control at top right, which applies to all texts shown.

DTC List for Snapshot Data per DTC (Numeration Type "Configured)"

DTC List Columns

  • [SRUI-R620] DTCs
    • shows the special entry [SRUI-R600-Default], or the DTC Code and name.
  • [SRUI-R630] Snapshot Data
    • for the Special "(Default)" list row:
      • the Default Snapshot Data [SR-R230-Default]
    • for a regular DTC list row with Overridden Snapshot Data [SR-R230-Overridden]
    • otherwise "(Default)"
    • Default Snapshot Data and Overridden Snapshot Data are shown as follows:
      • DIDs separated by comma + blank
      • for each DID, the identifier [DID-R025-DefaultDisplay]
      • optionally followed by blank + the DID name
  • for Numeration Type "Configured":
    • [SRUI-R640] Snapshot Records to Store
    • "n/a" for the special entry [SRUI-R600-Default]
    • "(all)" if all checked
    • otherwise Snapshot Records
      • separated by comma + blank
      • for each Snapshot Record, the Snapshot Record Number [SR-R120-DefaultDisplay]
      • optionally followed by blank + the Snapshot Record name
  • for Numeration Type "Calculated":
    • [SRUI-R645] Number of Snapshot Records to Store
    • "n/a" for the special entry [SRUI-R600-Default]
    • the Number of Calculated Snapshot Records Stored per DTC [DTC-R310]

DTC List for Snapshot Data per DTC (Numeration Type "Calculated)"

DTC List Context Menu

The list has no context menu.

DTC List Actions

  • multi-selection
  • no sorting
