GUI Snapshot Records (v13 AUTOSAR Fault Memory, CDS-71541)

The following describes the user interface of the specific AUTOSAR data model available since CANdelaStudio 13, see the AUTOSAR Fault Memory GUI.

See also the Snapshot Record Data Model and Snapshot Record Operations.

Overview of Snapshot Data dialogs (AUTOSAR Fault Memory):

  • Snapshot Records Page [SRUI-R010] below
  • TAB: Snapshot Records [SRUI-R100]
    • List of Snapshot Records [SRUI-R200]
    • Snapshot Data Common for All DTCs [SRUI-R300]
  • TAB: UDS Snapshot Data per DTC [SRUI-R500]
    • List UDS Snapshot Data per DTC [SRUI-R600]
    • Right Side: TAB "Snapshot Data" [SRUI-R700]
    • Right Side: TAB "Snapshot Records to Store" (Configured [SRUI-R810]
    • Right Side: TAB "Snapshot Records to Store" (Calculated) [SRUI-R900]
  • TAB: OBD on UDS Snapshot Data per DTC [SRUI-R550]

Snapshot Records Page

[SRUI-R010] The Snapshot Records page contains 2 or 3 top-level TABs, each with a main area and a details area to the right.

  • TAB "Snapshot Records" [SRUI-R100]
  • TAB "UDS Snapshot Data per DTC" [SRUI-R500]
  • (optional) TAB "OBD on UDS Snapshot Data per DTC" [SRUI-R550]

Snapshot Records Page

Dialog Visibility (CDS-72050)

[SRUI-R020] CANdelaStudio shows the Snapshot Data dialogs iff. any Protocol Service contains a SimpleProxyComp with semantics

  • [PC-R050-sr] Snapshot Records or
  • [PC-R050-sd] Snapshot Data
