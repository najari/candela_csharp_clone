Common Snapshot Data

[SRUI-R300] The "Common Snapshot Data" area shows...

  • [SRUI-R300-UDS] UDS Snapshot Data [SR-R200-UDS]
  • [SRUI-R300-OBDonUDS] OBD on UDS Snapshot Data [SR-R200-OBDonUDS]
    • iff. an OBD on UDS Snapshot Record [SR-D130-OBDonUDS] exists.
    • See the note [FM-D050] about OBD on UDS.
  • a unique heading for either one
  • a filter control
  • a list of Common Snapshot Data [SR-R230-Common], i.e. DIDs stored for all DTCs.
    • [SRUI-R310] The list is sorted by the order of the data [SR-R240-Ordered].
    • [SRUI-R314] You can move the selected list items up/down (affecting the order of the data).
    • [SRUI-R312] There is no way to change the displayed sort order without affecting the order of the data.
    • [SRUI-R318] The list contains a line "Add DID...". TODO effect: dialog, DIDs not in Specific...
    • [SRUI-R320] The list supports multi-selection.
    • [SRUI-R322] The list can be filtered by a text control at top right, which applies to all texts shown.

List Columns

  • [SRUI-R330] Identifier
    • shows the DID Identifier [DID-R025]
    • formatted as in the DID List [DIDUI-R702-Identifier]
  • [SRUI-R335] Name
    • shows the name of the DID
  • [SRUI-R340] DID Data [DID-R155]
    • shows as comma separated list of data, like in the DID list [DIDUI-R702] and DID Overview [DIDOV-R660].

Context Menu

[SRUI-R350] Common Snapshot Data Context Menu

For details, see next chapter "Actions".

  • [SRUI-R352] Add DID(s)...
  • [SRUI-R354] Remove Selected DID(s)
  • [SRUI-R356] Move selected DID Up
  • [SRUI-R358] Move selected DID Down

Actions

  • [SRUI-R360] Add DID(s)
    • Triggered by line "Add DID..." [SRUI-R318] or context menu [SRUI-R352].
    • If all DIDs of the variant are already used in the Common Snapshot Data, CANdelaStudio shows a message "No further DID is available".
    • Note: if you add a DID already used in Default Snapshot Data or Specific Snapshot Data, CANdelaStudio removes it there without notice [SROP-R220-OnlyCommon].
      • This preserves condition [SR-R230-OnlyCommon].
      • Motivation: your intention to use the DID for all DTCs wins.
    • See operation [SROP-R220].
  • [SRUI-R365] Remove DID(s)
    • Triggered by context menu "Delete DID..." or context menu [SRUI-R354]
    • If no further DID is available, CANdelaStudio shows a message "No further DID is available".
    • See operation [SROP-R220].
  • [SRUI-R370] Move Up
    • Triggered by Ribbon button "Up" [MENU-R480], context menu [SRUI-R356] or Ctrl-U.
    • Not available if the first DID is selected,
    • ... or the selected DIDs are not in a continuous range.
    • Moves the selected DIDs up one row.
    • See operation [SROP-R200].
  • [SRUI-R375] Move Down
    • Triggered by Ribbon button "Down" [MENU-R480], context menu [SRUI-R358] or Ctrl-D.
    • Not available if the last DID is selected,
    • ... or the selected DIDs are not in a continuous range.
    • Moves the selected DIDs down one row.
    • See operation [SROP-R210].
