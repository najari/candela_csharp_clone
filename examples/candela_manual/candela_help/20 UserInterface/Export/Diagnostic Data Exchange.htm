Diagnostic Data Exchange Export

The Diagnostic Data Exchange Export is available in ribbon tab Data Exchange | Manufacturer Specific [MENU-R140].

SaveAs Dialog for Diagnostic Data Exchange Export

File Type

[DDXUI-R203] The file name extension shall be “.xml”

Variant

[DDXUI-R201 One Variant]

  • [DDXUI-R201-OneVariant] The “Save As” dialog shall only allow one variant to be selected at all times.
  • [DDXUI-R201-AllVariants] The checkbox “All variants” must not be present.

[DDXUI-U100-CommonDiagnostics] Remove "Common Diagnostics" from the list of exportable variants (CDS-38028 8.2 SP3)

[DDXUI-U200-DefaultFilename] Use the name of the selected variant as the default file name.

Audience

[DDXUI-R202] The selection of audiences shall not be present in the “Save As” dialog.
