SaveAs CANdela Target Group Oriented Export

See the Export CANdela (Target Group Oriented) feature.

SaveAs Dialog

Version

Specifies the version of the exported CANdela document.

Save read-only

The checkbox is checked and not modifiable, because the exported file is always set read-only.

Execute action "Save current version done".

The checkbox is checked and not modifiable, because the action is executed unconditionally.

All Variants

The checkbox...

  • indicates whether all variants are checked in the list below;
  • allows to conveniently check all variants in the list below.

Variant

Allows selection of a subset of the variants in the document.

The base variant is mandatory (CDS-3510).

Audience

Allows the selection of target groups for the export.
