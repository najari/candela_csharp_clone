Job Container with Jobs List

A diagnostic class template with class type "Jobs" or "Flash jobs" must not contain any Used Protocol Service. A corresponding diagnostic class cannot contain a diagnostic instance but only job containers.

For a regular diagnostic class template with Used Protocol Services, the corresponding diagnostic class can contain diagnostic instances as well as job containers. In such a job container, a job can "replace" a service. Therefore, the job container may contain only one job for each service of the diagnostic class. Each job must have the same name and qualifier as the service it replaces. CANdelaStudio ensures this automatically.

Jobs for the Test System

Shows the list of jobs in the job container.

You can edit the job name and description directly in the list.

The associated job file is specified in the property dialog for the job in page "Function".

Attributes

[JCUI-R200] The list shows job attributes that have the "visible in separate table column" flag [ATTR-R090-Job] set.

New Job

If you have specified a default file for jobs, CANdelaStudio automatically assigns that file to each new job.

Job Parameters for...

Shows the list of input parameters and output parameters of the selected job.

The parameters are edited in a telegram table. In this context, bit-sized data objects are allowed on top-level.
