Available DTCs

The "Fault Memory/Diagnostic Trouble Codes/Available DTCs..." page contains a "pool" of DTCs to be referenced or copied in variants.

Depending on the setup in the template, there may be one or two such pages, for DTCs of size 16 and 24 bit, respectively.

Each line represents a DTC, identified by the code.

  • each line represents a different set of DTC properties
  • in a disjoint set of variants (indicated by "yes" in the variant column)

You can edit directly in the list (press F2), or in the property dialog.

Show Column Info

Displays the names and descriptions of the DTC columns (DTC properties), as setup in the template.

Filter (all columns)

Filters the list (filter applied to the displayed contents).

To show the entire list again, press the button right to the filter edit control.

DTC

The code, displayed as specified...

  • in File | Properties | "Display of DTCs"
  • and (for option "ISO 14229-1 / HEX" there) in Ribbon Tab File | Options | Display.

Error Text

The short description of the DTC.

Used

[DTCPUI-R050] shows whether the DTC exists as reference in a Fault Memory diagnostic instance.

Erroneously, in 8.2 SP3, column "Used" is always "No" (CDS-39750).

Erroneously, in 9.0 before SP1, column "Used" is always "Yes" (CDS-69130).

(further columns)

Show/edit the DTC properties.

New DTC Code

(context menu) Inserts a new DTC.

Properties

Opens the DTC Properties Dialog.

Select from Repository

[DTCPUI-R150 Select from Repository] opens the Select from Repository dialog to import DTCs from a repository.
