DTC Property Page "General"

This is a page in the DTC Property Dialog.

List of DTC Properties

The page shows a list of DTC properties.

Error Text

Optionally uses a dictionary [DICT-R020-a2].

Values for Translatable DTC Columns

[DTCUI-R095] For a translatable DTC column with a selection list [DTCC-R095],

  • in order to specify a text not contained in the selection list,
  • in the DTC properties dialog page "General", check "Show details",
  • then enter the text.

Note: you can conveniently start the editing from within the DTC list via menu item [DTCUI-R090].

Show Details

If the checkbox "Show Details" is un-checked, the list contains two columns: the name of the DTC property, and the value of the DTC property.

If the checkbox "Show Details" is checked, the list contains one column: the name of the DTC property. The area to the right shows the detailed value of the selected DTC property.

Up / Down

You can use the buttons [Up] and [Down] at the bottom of the dialog to navigate through the list of DTC properties

Tip: press the Alt key and one of the underlined characters on the buttons to navigate via keyboard.

Hide Empty Lines

Checking this checkbox hides all properties that have an empty value.
