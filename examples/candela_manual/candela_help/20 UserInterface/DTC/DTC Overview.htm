DTC Overview

The "Fault Memory/Diagnostic Trouble Codes/Overview Fault memory..." page contains an overview of DTCs in all variants and libraries ("objects") of the document.

Depending on the setup in the template, there may be one or two such pages, for DTCs of size 16 and 24 bit, respectively.

The overview shows "yes" in the cells of all objects in which the DTC has the same properties. This may be the case...

  • if the "Fault Memory" diagnostic instance is referenced in some of these objects,
  • the DTC has been referenced from the DTC Pool in some of these objects,
  • or the DTC is a local "copy" but just has the same properties

Therefore, the list may contain multiple lines for the same code:

  • each line represents a different set of DTC properties
  • in a disjoint set of objects (indicated by "yes" in the object column)

The DTC overview does not provide a way to edit the DTC properties - to do this, navigate to the "Fault memory" diagnostic instance of the respective object (using the context menu).

Show Details of Error Codes

If checked, the list contains additional columns right to the variants and libraries, with the properties of the DTC.

Show Libraries (CDS-37946 8.5 SP2)

[DTCOV-R400.0 DTC Overview Show Libraries]

  • [DTCOV-R400-a] CANdelaStudio shall show a checkbox „Show Libraries“ right to „Show details of error codes“, default true, remembered across sessions.
  • [DTCOV-R400-b] If on, CANdelaStudio shall show Libraries as columns between „Available DTCs“ and the base variant (see [LIB-R060]).
  • [DTCOV-R400-c] If off, CANdelaStudio shall not show Libraries.

(new in 8.5 SP2)

If checked, the list contains additional columns right to the variants, with the properties of the DTC.

Go To <Variant or Library>...

[DTCOV-R410 DTC Overview Go To] Navigates to the DTC in the object (variant or library).

[DTCOV-R410-1] In the column of an object, the context menu shows a "Go To..." item only for this object.

[DTCOV-R410-all] In the other columns, the context menu shows one "Go To..." item for each library (first) and each variant.

Copy to Variants

Opens a dialog to copy (not reference) the DTC into selected objects (variant or library).

  • [DTCOV-R450] CANdelaStudio shall provide Libraries in the context menu.

Reference in Variants

Opens a dialog to reference the DTC in selected objects (variant or library).

  • [DTCOV-R460] CANdelaStudio shall provide Libraries in the context menu.

Delete

Allows to delete the DTC from selected objects (variant or library).

  • [DTCOV-R470] CANdelaStudio shall provide Libraries in context menu „Delete“.
