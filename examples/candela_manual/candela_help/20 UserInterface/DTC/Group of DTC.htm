Group of DTC

A Service with Group of DTC "vv"

Occurrences of a Group of DTC component in the Protocol Service are edited in the diagnostic instance ("vv" in the screenshot above).

Group of DTC in a Diagnostic Instance

The name of the page in the diagnostic instance (e.g. "Group of DTC") is defined in the template and may vary.

In the screenshot, "(vv)" identifies all Protocol Service Components that represent the Group of DTC.

Text Control

The text control shows the name of the Group of DTC Data Object. It is read-only in the text control.

Properties Button

The properties button right to the text control opens the property dialog for the Group of DTC Data Object.

Groups

Shows all DTC groups supported by the ECU. These are taken from a data type defined in the template (shown in the property dialog).

Check the groups that the respective service(s) shall support.

Supports Single Errors

Specifies whether the service support single errors (individual DTCs), besides the DTC groups.

Button ">>"

If "Supports Single Errors" is checked, button ">>" navigates to the DTC table.

Default Value

The default value for the Group of DTC Data Object can be edited in the property dialog.
