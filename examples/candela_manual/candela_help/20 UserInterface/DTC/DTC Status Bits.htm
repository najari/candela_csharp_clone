DTC Status Bits

Some Services with DTC Status Bits "zz"

All occurrences of DTC Status Bits in the Protocol Service are combined to be edited in one list in the diagnostic instance ("zz" in the screenshot above).

DTC Status Bits in a Diagnostic Instance

The name of the page in the diagnostic instance (e.g. "DTC Status") is defined in the template and may vary.

In the screenshot, "(zz)" identifies all Protocol Service Components that represent the DTC Status bits.

Mandatory bits are shown in bold.

Available

Defines whether the bit is available (supported) by the ECU.

You cannot uncheck bits that have been declared as mandatory in the template.

Request Default

Defines whether a generic test system shall set the bit in a request as a default.
