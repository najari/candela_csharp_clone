DTC Property Page "Vehicle System Groups"

This is a page in the DTC Property Dialog.

See the DTC and Vehicle System Groups Feature.

DTC Property Page Vehicle System Groups

The page contains a list of all Vehicle System Groups.

Checkbox

If the checkbox to the left of the Vehicle System Group name is checked, the DTC is associated with that Vehicle System Group, otherwise not.

Name

This column shows the name of the Vehicle System Group.

Available in Variant

This column shows a property of the Vehicle System Group: whether it is available in the variant of the given DTC.

Identifying Pattern

This column shows the Identifying Pattern assigned for the Vehicle System Group.

A Vehicle System Group can have an Identifying Pattern only if the document contains an Identifying Feature for Vehicle System Groups.
