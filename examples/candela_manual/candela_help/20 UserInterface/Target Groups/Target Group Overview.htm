Target Group Overview

Target Group Overview Dialog

[TGOV-R010] The Target Group Overview dialog (menu "View") shows an overview of all target groups of the object on which the dialog was opened, including all contained objects.

You can modify individual qualifiers, or recompute the qualifiers from the respective object names.

Modifying operations respect of the Authorization of the objects - in Standard View, you cannot modify the qualifier of an object if the object is "not modifiable".

Context

When opened on "ECU Information" (the root of the document tree), the dialog shows all qualifiers of the document ("Whole document").

Otherwise, you can switch between

  • "Whole document" and
  • the "Current subtree", i.e. all qualifiers of the object on which you opened the dialog and its contained objects.

List

Diagnostic Instance / Job Container

Shows the name of the object.

Service / Job

Shows the name of the object.

(Names of Target Groups...)

The list has one column for each target group defined in the document.

The value "yes" in a cell indicates that the target group is set for the object given by the row.

You can modify the value by selecting the cell, then clicking again (slowly) or pressing F2 (first switch to editing mode: under "View", see below).

To edit multiple values at the same time, select multiple lines, then press F2 and modify the value, then press ENTER.

Path

Shows the path to the object.

Read-Only (CDS-40739 8.5 SP2)

[TGOV-R050 Read-only] A row in target group overview shall be read-only if...

  • [TGOV-R050-Container] it represents a diagnostic instance or job container, and that object has authorization "Secondary properties modifiable" = false [DIA-R050-TargetGroups].

  • [TGOV-R050-ServiceJob] it represents a service or job, and the parent diagnostic instance or job container has authorization "Secondary properties modifiable" = false [DIA-R050-TargetGroups].

Context menu "Copy Path"

Lets you copy the path shown in column "Path" to the clipboard.

View

Lets you select the view mode:

  • Overview (no editing)
  • Edit Diagnostic Instances and Job Containers (column "Service / Job" now shown)
  • Edit Services and Jobs

Button "Set"

Shows a dialog where you can set or reset each target group by checking a checkbox.
