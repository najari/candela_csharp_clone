Target Group Property Page "Usage in Document"

The page lets you optionally set or reset the target group at all existing objects in the document.

Button "Apply Target Group Settings to Document"

  • Leave Unchanged: no modifications to be done, the button is insensitive
  • Selected: the button is sensitive; when you press it, CANdelaStudio asks for confirmation and sets the target group at all diagnostic instances, job containers and services of the document.
  • Not Selected: dito, but CANdelaStudio resets the target group.
