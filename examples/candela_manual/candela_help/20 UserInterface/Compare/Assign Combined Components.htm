Assign Combined Components

Context

CANdelaStudio shows the "Assign Combined Components" dialog when you perform a Document Upgrade of a CANdela document to a CANdela template.

Overview

The CANdela document contains...

  • the original CANdela template, and
  • data that describe the ECU (diagnostic instances, services, data objects in telegram tables...).

A telegram table in a diagnostic instance must refer to a combined component in the template (diagram from the Protocol Services chapter):

Protocol Services and Services (3 Layers)

Document Upgrade

Therefore, during document upgrade, CANdelaStudio must associate...

  • the telegram tables of the document
  • with the combined components of the new template.

As a default, CANdelaStudio uses the combined component that has the same qualifier than the combined component of the document.

Assign Combined Components

"Assign Combined Components" Dialog

If there is no combined component with the same qualifier, CANdelaStudio shows the "Assign Combined Components" dialog so that you can manually select a combined component from the new template.

This typically happens when...

  • the template author changed a combined component qualifier, or
  • you try to upgrade to a totally different template.

If you don't select a combined component, CANdelaStudio drops the telegram table.

Diagnostic Class Template

The upper list shows all diagnostic class templates of the document that contain unassigned Combined Components:

  • Diagnostic Class Template: the name of the Diagnostic Class Template.
  • Number of Unassigned Components: the sum of Combined Components that have "(unassigned)" in the lower table.

Combined Components

The lower list shows the Combined Components of the diagnostic class template selected in the upper list.

  • in Source (Left Side) lists the name of the Combined Component in the document.
  • matches in Target (Right Side) lists the currently associated Combined Component of the new template:
    • either "(unassigned)" if none has been associated so far,
    • or the name of the associated Combined Component.

In order to associate a Combined Component:

  • click into the cell in the "matches in Target (Right Side)" column;
  • click again, or press key F2 to enter edit mode;
  • from the list, select a Combined Component.

If the list does not show a Combined Component, the diagnostic class templates are not compatible. In this case, you cannot take over the telegram table to the new template.
