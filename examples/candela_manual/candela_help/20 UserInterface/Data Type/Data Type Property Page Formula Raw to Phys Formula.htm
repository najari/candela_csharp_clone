Data Type Property Page "Raw to Phys Function"

For more information about data type properties, see the Data Types Feature.

The page "Phys to Raw Formula" has the same structure.

Function, Button "Insert"

The combo-box provides a list of functions supported by the CANdela tool-chain, to be inserted into the formula text using button "Insert".

Formula

The text of the formula, like x+50 + x.

CANdelaStudio checks the syntax of the text when you press one of the buttons "Compute", "OK" or "Apply".

Test Value, Button "Compute", Result

To check whether the formula works as intended, CANdelaStudio provide an instant computation for an x value. The Result control shows the resulting y value, including the unit specified for the data type.

The unit is shown blank separated, in square brackets like [°C].
