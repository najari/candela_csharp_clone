Data Type Property Page "Text Table"

Data Type Property Page "Text Table"

For more information about data type properties, see the Data Types Feature.

General Data Type Properties

See the Data Type Properties Dialog.

Bit Length / Field Size

Variable length is not allowed.

Discrete Values

[TTUI-R110] If this option is checked, the text table contains only discrete values, no ranges [TT-R100-Range].

Note: the checkbox setting is not part of the data model - if you un-check it, but use only identical values for Start and End, the checkbox will be checked again when you re-enter the dialog.

Use Inverse Values

If this option is checked, you can specify an inverse value for each line (start/end value) in the table. The inverse value is used for conversion from a physical to a raw value.

Start

The raw value for the conversion.

If "Discrete Values" is checked, this is the start of a range of values (inclusively).

Optionally uses a dictionary [DICT-R020-a3].

End

If "Discrete Values" is un-checked, this is the end of a range of values (inclusively).

Assigned Text ("Mapped Text")

The physical value for the Start value or Start..End range.

Additional Information

Optional additional information.

Inverse Value

Enabled by the option "Use Inverse Values".

Import

Opens the Text Table CSV Import Wizard.
