General Data Type Properties

See the Data Type Properties Dialog.

Bit Length / Field Size

Fields (arrays) of fixed or variable length are not allowed.

x, Mapped Value

The (x, y) pairs.

For the mapped (y) value, input of decimal places (positions after the decimal point) is restricted by the number of significant digits specified in the "Precision" input control.

Interpolated

If this is checked, raw values are interpolated.
