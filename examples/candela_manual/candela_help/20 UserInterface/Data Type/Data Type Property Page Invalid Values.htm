Data Type Property Page "Invalid Values"

Invalid Values Page

See the Invalid Values Feature.

Activate

To enter invalid values, the checkbox "Activate" must be checked.

Un-check it to delete all invalid values.

List of Invalid Values

The list lets you define individual values (Start= End) or ranges of invalid values.

Click the line "Please click here" or the "New" button to create a new invalid value.
