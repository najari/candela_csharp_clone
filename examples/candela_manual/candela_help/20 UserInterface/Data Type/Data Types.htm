Unit from ECU-SHARED-DATA (CDS-34835 8.2 SP2)

[DTLIST-R200] The data types list shall provide a column with the information whether a unit used by a data type originates from an integrated ODX ECU-SHARED-DATA.

  • [DTUI-R200-Attr] CANdelaStudio shall show the additional column only if the Units attribute ECU exists at the ECU.
  • caption of the column: "Unit in Library", "Einheit in Bibliothek".
  • "yes" if the unit of the data type is contained in the list of the ECU attribute "Units" (that means a part of the ECU-SHARED-DATA)
  • "no" it the unit of the data type is not in the list of the ECU attribute "Units"
  • "" (empty string) if the data type does not support units, or no unit is set
  • CANdelaStudio shall allow sorting by the column.

Special Function

Shows whether the data type is used as

  • Bit Field Default Entry
  • Failure Type Byte
  • Failure Mode Identifier
