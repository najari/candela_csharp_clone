Replace Similar Data Types Dialog (CDS-68992 v11)

This chapter describes the "Replace Similar Data Types" dialog.

For details of the operation, see the "Replace Similar Data Types" Feature.

You can open the dialog via [MENU-R500].

The dialog proceeds in 3 steps:

Step 1

"Replace Similar Data Types" Dialog (1)

Select Data Types

[RDTUI-R110] Shows the types of conversions that the replace operation supports [RDT-R010].

You have to select at least one conversion to search for similar data types.

Select Ignored Properties for 'XXX'

[RDTUI-R120] For the configuration selected in the list described above, un-check the crucial properties [RDT-R020] (that shall not be ignored).

Example for two data types differing in encoding only:

  • if "Encoding" is checked, such data types are similar (may be deleted)
  • if "Encoding" is un-checked, these data types are not similar (will be kept)

If the check boxes are greyed out, the setting has been frozen in the CANdelaStudio options [INI-R500].

[RDTUI-R120-TextID] The checkbox for "TextID" is shown only if the current document supports TextIDs [DOCUI-R320].

Note the known issues for v11 [RDT-R020-v11].

Compute Groups

[RDTUI-R130] The button "Compute Groups"...

  • analyzes all data types of the data type list,
  • puts each set of similar data types into a group, based on the configuration described above,
  • and navigates to the next step.

Step 2

"Replace Similar Data Types" Dialog (2)

[RDTUI-R210] The table shows all detected groups of similar data types.

For each group:

  • [RDTUI-R210-Original] you can define one data type as "Is Original".
    • All references to other deleted data types of this group will be replaced by a reference to the original.
    • These data types will be deleted.
  • [RDTUI-R210-Keep] If you additionally want to keep a data type besides the "original":
    • check "Keep Data Type" for it
    • the operation will not delete that data type
    • the operation will not change references to this data type
  • [RDTUI-R210-KeepAll] If you want to keep all data types of a group:
    • check "Keep Data Type" for all data types in the group.
    • In this case, you do not need to choose a data type as "Is Original".

[RDTUI-R220] You can still cancel the operation here.

Replace Data Types

[RDTUI-R230] The button "Replace Data Types" performs the replace operation as specified in the table described above.

The operation does not modify data types...

  • which have "Is Original" or "Keep Data Type" checked, or
  • which are used in some special context in the document
    • e.g. in a DTC status mask.

Step 3

"Replace Similar Data Types" Dialog (3)

[RDTUI-R310] The last page shows a summary of the result:

  • [RDTUI-R320] the list of data types actually replaced and deleted, and
  • [RDTUI-R330] the affected variants.
