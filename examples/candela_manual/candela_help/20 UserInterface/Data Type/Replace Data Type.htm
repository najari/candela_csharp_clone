Replace Data Type Dialog

"Replace Data Type" Dialog

You can read the dialog from top to bottom:

Replace Data Type...

Shows the data type on which you opened the dialog. You cannot change this.

... with Data Type...

The combobox lets you select the data type to assign instead.

... at all (Data) Objects Selected below:

The list shows all references to the data type on which you opened the dialog.

By checking/un-checking rows, you can include/exclude objects from the replacement.

In case of conflicts (e.g. a length contraint would be violated), the "Conflicts" column lists the details, and you cannot check the row.

Select All

Checks all rows that do not have a conflict.

Select None

Un-checks all rows.
