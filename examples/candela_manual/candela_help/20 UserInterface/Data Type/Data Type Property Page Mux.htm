General Data Type Properties

See the Data Type Properties Dialog.

Selector Data Type

Provides selection from the list of data types.

Selector Value

Shows the list of cases.

The selector values in this list are taken from the data type you selected under Selector data type. You might have to create new values first, depending on the data type used. To do this, click [New].

The case constants are either

  • from the fixed set defined in a Selector Data Type with fixed set of elements (like a Text Table data type), or
  • "free", i.e. any value (like for a Raw Value data type).

Data

If "Use default" is selected, the data shown in the list at the bottom is taken from the Default case.

If "Multiplexer specific for Selector value..." is selected, the data shown in the list at the bottom is specific for the case constant selected under "Selector Value".

The list at the bottom shows a telegram table to specify the data objects contained in the respective Mux case.
