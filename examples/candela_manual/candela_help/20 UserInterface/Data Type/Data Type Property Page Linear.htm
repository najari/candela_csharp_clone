General Data Type Properties

See the Data Type Properties Dialog.

Bit Length / Field Size

Fields (arrays) of fixed or variable length are not allowed, see [DTDEP-R100].

Lower Limit (raw), Upper Limit (raw)

Optional limits for the raw values, see [LIN-R120].

Lower Limit (phys), Upper Limit (phys)

[DTUIL-R530] Optional limits for the physical values.

These limits are computed using the conversion formula.

They are for user interface convenience only - the CANdela data model stores the raw limits only.

Factor, Divisor, Offset

[DTUIL-R550] These input controls specify the linear formula, see [LIN-R110].

Inverse Value

[DTUIL-R560] A checkbox enables editing the Inverse Value. This mechanism is enabled if the factor is 0.

[DTUIL-R565] The input control specifies the Inverse Value if factor is 0, see [LIN-R1300].
