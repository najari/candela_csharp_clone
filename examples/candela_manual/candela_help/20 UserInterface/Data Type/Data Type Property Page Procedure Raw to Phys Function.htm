Support Several Runtime Systems

If this is checked, the properties "Job file", "Version" and "last change" or shown not once but in a list so that you can define multiple job files for different runtime systems (e.g. for Java and a manufacturer specific system).

Job File

A file to be included in the CANdela document.

Version

An optional version string describing the job file.

Last modified

The time stamp of the job file (from the file system).

Entry Point

Optional entry point (method name) to be used in the job file, e.g. a function name like main() for job files with runtime system "fm".

Button "Job Files"

Opens the Job File Manager which controls files included in the CANdela document.

Button "Save As"

Lets you extract the job file from the CANdela document and save it in the file system.
