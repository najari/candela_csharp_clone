Data Type Property Page "Piecewise Linear"

Data Type Property Page "Linear"

For more information about data type properties, see the Data Types Feature.

General Data Type Properties

See the Data Type Properties Dialog.

Bit Length / Field Size

Fields (arrays) of fixed or variable length are not allowed.

Start, End

Limits for the raw values.

Factor, Offset

These input controls specify the linear formula.

Start (phys), End (phys)

Limits for the physical values, computed from the raw values using the linear formula.

Inverse Value

This edit control is enabled if the factor is 0.
