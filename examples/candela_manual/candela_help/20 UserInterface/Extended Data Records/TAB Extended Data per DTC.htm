TAB Extended Data per DTC

[EDUI-R500] The "Extended Data per DTC" TAB shows...

  • a list of DTCs and Extended Data Records to Store [EDUI-R600]
  • a TAB "stored for Extended Data Records" [EDUI-R800]

Extended Data per DTC

List "Extended Data per DTC"

[EDUI-R600] List of DTCs with Extended Data Records to Store

  • [EDUI-R610-DTCs] The list shows all DTCs defined in the diagnostic instance.
  • [EDUI-R610-Sort] The DTCs are sorted by ascending Code.
    • No sorting by the user.
  • [EDUI-R610-MultiSel] The list supports multi-selection.
  • [EDUI-R612] The list can be filtered by a text control at top right, which applies to all texts shown.

List Columns

[EDUI-R620]

  • [EDUI-R630] DTCs
    • shows the DTC Code and name.
  • [EDUI-R640] Extended Data Records to Store
    • "(all)" if all Extended Data Records checked [EDR-R300]
    • otherwise comma separated Extended Data Records (number + name)

Right Side: TAB "Extended Data Records to Store"

[EDUI-R800] The TAB shows...

  • a list of Extended Data Records
  • for each Extended Data Record, whether it is stored for the DTC(s) selected in the list of DTCs [EDUI-R600]

Extended Data per DTC

List Columns

[EDUI-R812] Number

  • shows the Extended Data Record Number [EDR-R120]
  • see [EDR-R120-DefaultDisplay]

[EDUI-R814] Name

  • shows the Extended Data Record Name

[EDUI-R816] to Store

  • a checkbox
  • checked iff. "Extended Data Record Stored for DTC" [EDR-R300] is true
  • If multiple DTCs are selected:
    • see the Basic User Interface Rules [UI-R400].
  • [EDUI-R816-Check] Checking "Stored":
    • Performs operation [EDOP-R260]
  • [EDUI-R816-Uncheck] Un-checking "Stored":
    • Performs operation [EDOP-R265]

Buttons "Store all" / "Store none"

  • [EDRUI-R840] If a filter has been applied in the DTC list,
    • the buttons apply to the reduced list only,
    • therefore the button text changes to "Store all filtered" / "Store none filtered".

Actions

  • [EDUI-R820] Check "to Store"
    • Performs operation [EDOP-R260]
    • Applies to all selected DTCs.
  • [EDUI-R825] Un-check "to Store"
    • Performs operation [EDOP-R265]
    • Applies to all selected DTCs.
