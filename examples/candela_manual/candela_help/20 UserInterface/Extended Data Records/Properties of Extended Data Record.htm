Properties of Extended Data Record

Introduction

[EDUI-R2000] The property sheet to the right provides editing of the properties also shown in the Extended Data Record list, plus Qualifier and Description.

[EDUI-R2010] The property sheet supports mass editing:

If you select multiple Extended Data Records in the list:

  • if all selected Extended Data Records have the same value,
    • the control in the sheet shows that value;
    • when you enter a different value, CANdelaStudio assigns that value to all selected Extended Data Records.
  • if the selected Extended Data Records have different values,
    • the control in the sheet shows an "indifferent" state;
    • when you enter a value, CANdelaStudio assigns that value to all selected Extended Data Records;
    • the control does not provide a way back to the "indifferent" state.

For details, see [UI-D410] in the Basic User Interface Rules.

Number

[EDUI-R2120] The control shows the Extended Data Record Number [EDR-R120].

See [EDUI-R220] for the Number column of the Extended Data Record list.

Name, Qualifier, Description

[EDUI-R2130] The controls show the Extended Data Record name, qualifier and description [EDR-R110].

See [EDUI-R230] for the Name column of the Extended Data Record list.

The description can be multi-line, but plain text only (no rich-text).

Storage Trigger, Custom Trigger, Updated

[EDUI-R2150] Shows the Storage Trigger [EDR-R150] and Updated [EDR-R160] of the Extended Data Record(s).

  • Same as [SR-R150] and [SR-R160] for Snapshot Data Records.
  • See [EDUI-R250] and [EDUI-R260] for display in the Extended Data Records list.

Extended Data Record Attributes

Extended Data Record attributes are not available in the property page.

You may use the Attribute Overview on the Diagnostic Instance (e.g. via the context menu of the tree node).
