GUI Extended Data (v13 AUTOSAR Fault Memory, CDS-71541)

The following describes the user interface of the specific AUTOSAR data model available since CANdelaStudio 13, see the AUTOSAR Fault Memory GUI.

See also the Extended Data Record Data Model and Extended Data Record Operations.

Overview of Extended Data dialogs (AUTOSAR Fault Memory):

  • Extended Data Records Page [EDUI-R010] below
  • TAB: Extended Data Records [EDUI-R100]
    • List of Extended Data Records [EDUI-R200]
    • Extended Data [EDUI-R300]
  • TAB: Extended Data per DTC [EDUI-R500]
    • List Extended Data per DTC [EDUI-R600]
    • Right Side: TAB "stored for Extended Data Records" [EDUI-R800]

Extended Data Records Page

[EDUI-R010] The Extended Data Records page contains 2 top-level TABs, each with a main area and a details area to the right.

  • TAB Extended Data Records [EDUI-R100]
  • TAB Extended Data per DTC [EDUI-R500]

Extended Data Records

Dialog Visibility (CDS-72050)

[SRUI-R030] CANdelaStudio shows the Extended Data dialogs iff. any Protocol Service contains a SimpleProxyComp with semantics

  • [PC-R050-edr] Extended Data Records or
  • [PC-R050-ed] Extended Data
