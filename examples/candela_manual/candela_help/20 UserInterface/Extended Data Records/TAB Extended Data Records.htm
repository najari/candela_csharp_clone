TAB Extended Data Records

See also the overview of the GUI Extended Data (v13 AUTOSAR Fault Memory).

[EDUI-R100] The Extended Data Records TAB shows...

  • the list of Extended Data Records [EDUI-R200]
  • for the selected Extended Data Record, the Extended Data [EDUI-R300]
    • i.e. a list of data objects
    • In an AUTOSAR implementation, these are typically objects managed by the Diagnostic Event Manager (DEM) internally, like the "DTC Occurrence Counter".
  • the properties of the selected Extended Data Record [EDUI-R2000]

Extended Data Records

List of Extended Data Records

[EDUI-R200] The list of Extended Data Records shows all Extended Data Records defined in the diagnostic instance [EDR-R030].

  • [EDUI-R210] By default, the list is sorted by ascending Extended Data Record Number.
    • cf. [EDR-R035] The Extended Data Records have no persistent sort order.
  • [EDUI-R212] The list can be sorted by clicking a header.
    • CANdelaStudio remembers the sort order within the session.
  • [EDUI-R214] The list contains a line "Click here to create a new Extended Data Record".
  • [EDUI-R216] The list supports multi-selection.
  • [EDUI-R218] The list can be filtered by a text control at top right, which applies to all texts shown.

List columns

[EDUI-R220]

  • [EDUI-R230] Number
    • shows the Extended Data Record Number [EDR-R120]
    • hexadecimal
    • with leading zero, filled to 2 hex digits
    • e.g. "0x01"
  • [EDUI-R240] Name
    • shows the name [EDR-R110] of the Extended Data Record
  • [EDUI-R250] Storage Trigger [EDR-R150]
    • same as [SRUI-R250] for Snapshot Records
    • See [EDUI-R2150] for display in the Property Sheet.
  • [EDUI-R260] Updated [EDR-R160]: "yes"/"no"
    • same as [SRUI-R260] for Snapshot Records
    • See [EDUI-R2150] for display in the Property Sheet.

Actions

  • [EDUI-R270] When creating a new Extended Data Record (using the magic line [EDUI-R214]):
    • If all valid Extended Data Record Numbers [EDR-R120-Range] exist, CANdelaStudio shows a hint and skips creating a new one.
    • Otherwise, CANdelaStudio as a default sets the Extended Data Record Number to...
      • 0x01, if the list is empty
      • the value of the last list entry + 1, if the list is sorted by Extended Data Record Number
      • the maximum used Extended Data Record Number + 1, otherwise. If this gives a number not in the valid range, CANdelaStudio searches for an unused number starting from 0x00.
    • Note: Extended Data Record Numbers are unique [EDR-R120-Unique].
    • See operation [EDOP-R100].
  • [EDUI-R275] When deleting Extended Data Records:
    • See operation [EDOP-R110].
