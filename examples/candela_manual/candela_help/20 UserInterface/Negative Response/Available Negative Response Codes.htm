Available Negative Response Codes (NRC Pool)

Page "Available Negative Response Codes"

The page "Available negative response codes" contains the "pool" for negative response codes of the document.

If you insert new negative response codes here, these are available in all diagnostic instances and state groups.

Negative Response Codes List

To edit a value, select a cell, then press F2 or click again.

Response Code

The column shows the response code in hexadecimal format.

Name / Error Text

The name of the response code. In this context of a negative response, the name is also called "error text".

Description

The description of the response code may be empty.

The description specified for the NRC here in the NRC pool can be overridden in a diagnostic instance for each individual service.
