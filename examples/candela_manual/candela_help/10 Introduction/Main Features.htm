Main Features

  • AUTOSAR workflow support (requirements, SWC Sync, DEXT export)

  • Support for protocol standards UDS, KWP and OBD II

  • Support for open standards and data formats:
    • ODX (2.0.1, 2.1.0, 2.2.0)
    • AUTOSAR (System extract, DEXT)
    • FIBEX
    • A2L
    • CDI (CANdela Data Import, a structured XML format)
    • RTF
    • CSV
    • XML
    • XHTML
  • Support for manufacturer-specific data formats:
    • Diogenes (Daimler)
    • MDX (Ford)
    • DDx (FCA)
    • ...

  • Describe UDS Services with DIDs, Routines, IO Controls, DTCs, Snapshot Data, Extended Data

  • Describe AUTOSAR Events

  • Sychronisation of requirements

  • CANdelaStudio works file-oriented.
    • It stores data in a CANdela document (CDD file - CANdela Diagnostic Data), a structured XML format.
    • A single user opens a CANdela document, eventually modifies and saves it.
    • there is no inherent multi-user or client-server functionality (it may be added using import/export, plug-ins, actions).

  • Support of document templates for creating new CANdela documents

  • Object-oriented description of...
    • data (data objects) and
    • operations (services)
    • ... bundled in a diagnostic instance

  • Compare View for comparing diagnostic objects and whole CANdela documents

  • Multiple variants of a control unit, in both...
    • chronological (for example improved versions) and
    • functional variants (for example with additional/different functions)

  • Variant wizard for creating variants of a control unit

  • Ribbons provide convenient access to operations

  • Data entry in lists and Property dialogs

  • Fault Memory in a special chapter

  • Non-redundant storage of data through reuse of diagnostic instances

  • Data Types provide re-usable conversion between
    • coded information (on the line) and
    • physical information (for a human)

  • Consistency checks, both when a document is edited and before it is saved or exported

  • Specification export to RTF and HTML

  • Full support for Unicode, as well as Eastern European and Asian languages

  • Support for multi-language documents, and translation using an integrated translation view and TMX files (Pro and Admin Editions)

  • Integration of external applications via actions, for example code generators, compilers, editors for special data formats
