Getting started

  • One CANdela document describes one ECU.

  • Create a new document: use menu File|New and specify the CANdela template to be used (typically provided by the vehicle manufacturer).

  • the CANdelaStudio installation contains templates and sample documents to start with, see Example Files.

  • CANdelaStudio displays a CANdela document in a tree view, like the chapter of contents of a book.

  • DTCs: navigate to "Diagnostic Trouble Codes", element "Overview...". In the DTC list in the right side, right click on a DTC and click "Go To..." to inspect or edit the DTC in a specific variant.

  • DIDs: in the tree, navigate to the "Base Variant" (or "Common Diagnostics"), in there navigate to "DIDs".

  • Communication parameters: navigate to the first node "ECU information" / "Supported interfaces"

  • To enable CANdelaStudio to open documents created with an even newer version than your installation: install the "Converters" add-on from the Vector homepage: http://vector.com/persistors .

  • To save a document for some other tool of Vector which supports opening only documents of older CANdelaStudio versions: menu File | SaveAs, then select the older version in the "Version" list at the bottom of the dialog.

Tips for editing

  • Edit properties of a diagnostic object in a Property dialog: use the "Properties" menu item in the context menu (right mouse). Most often, a double-click will work, too (a double click means "Open" which sometimes just navigates in the tree).

  • Edit an object directly in a list: press key "F2" (or left click twice, slowly).

  • Edit multiple objects at once: select the objects in a list in the desired column, press key "F2", specify the new value, press ENTER. Note: not all lists in CANdelaStudio support this feature.

  • Copy data from a list e.g. to a spreadsheet: select the list rows, then press Ctrl-C. This copies "what you see" to the clipboard.

  • Remember an object and quickly navigate to it again later: use the "Back" and "Forth" buttons of ribbon or copy its "object path" ("npath://...") from the navigation area to the Windows clipboard and paste it back later.
